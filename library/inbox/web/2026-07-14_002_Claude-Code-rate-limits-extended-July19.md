# Claude Code週次利用制限50%増を7月19日まで延長

- ソース: web
- 言語: en
- テーマ: claude-code

## 要約
Anthropicが2026年7月13日発表。Claude Codeの週次利用制限50%増プロモーションを7月19日23:59 PT まで延長。対象プラン：Pro/Max/Team/旧来のEnterprise席。非対象：無料プランおよび従量課金型Enterpriseシート。Claude Code（CLI・IDE拡張・デスクトップ・Web）のみが対象で、他Claudeプロダクトや5時間上限には影響なし。手続き不要で自動適用。期限後は標準レベルに自動復帰、課金変更なし。
