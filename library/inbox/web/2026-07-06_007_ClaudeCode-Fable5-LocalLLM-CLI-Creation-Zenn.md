## 要約
Claude Code + Fable 5 を使ってローカルLLM環境を補助するシェル支援 CLI ツールを開発した実践記録。Fable 5 の長文生成能力を活用し、コード以上に「仕事の進め方・段取り」の提案が優れていたという実体験を共有。ローカルLLM（Ollama 等）と Claude Code を組み合わせるアーキテクチャ設計も記載。具体的なプロンプト設計・ツール構造・SKILL.md 定義が含まれており再現性が高い。Fable 5 の実用的ユースケースとして価値のある一次実験記録。Claude Code で新モデルを使いこなすヒントが豊富。
