## 要約
Anthropic が 2026年7月1日より Claude Sonnet 5 を Free・Pro ユーザーのデフォルトモデルに設定した経緯と影響をまとめた記事。Sonnet 5 は 1M トークンのネイティブコンテキストウィンドウを持ち、長文タスク・エージェント型作業に最適化。プロモーション価格は $2/$10 per Mtok（入力/出力）で8月31日まで。Claude Code では v2.1.197 以降でデフォルト使用可能。旧 Sonnet 4.6 は引き続き API 経由で利用可能。Max/Team/Enterprise ユーザーもデフォルト変更されており、既存のワークフローへの影響と移行時の注意点を解説。
