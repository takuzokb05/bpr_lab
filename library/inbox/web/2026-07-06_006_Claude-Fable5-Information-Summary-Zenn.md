## 要約
Anthropic が一時停止していた Claude Fable 5 を再提供（7月7日 PT）した経緯と機能を整理した Zenn 記事。Fable 5 は創造的タスク・長文生成・コード補助に特化したモデルで、当初は輸出規制問題（国家安全保障リスク）により一部機能が制限されていた。再提供時の変更点、Pro/Max プランでの週次上限と無料使用割り当て（7/8以降50%まで）を解説。Claude Code での Fable 5 利用方法と、Sonnet 5 との使い分け指針も記載。日本語ユーザーが実際に試した感想と性能評価を含む一次情報。
