# Anthropic's Claude Fable 5 Available Again After U.S. Lifts Export Controls

## 要約
Claude Fable 5（Mythos-classモデル）が2026年7月1日に全世界で再利用可能に。経緯：6月9日公開→6月12日、Amazonの研究者がセーフガードバイパス手法を発見→トランプ政権が輸出規制を適用しAnthropicは外国ユーザーのアクセスを一時停止→Anthropicが新分類器を導入（問題手法を99%以上ブロック）→6月30日に輸出規制解除→7月1日に全プラットフォームで再開。Fable 5のスペック：コンテキスト1Mトークン・最大128k出力トークン・料金$10/$50（入力/出力、百万トークン）。競合他社モデルも同様の脆弱性を持つことが確認済み。7月7日まではPro/Max/Team/一部Enterpriseユーザーが週間使用制限の50%まで無料利用可能（その後はクレジット必要）。Claude Platform・claude.ai・Claude Code・Claude Coworkで利用可能。
