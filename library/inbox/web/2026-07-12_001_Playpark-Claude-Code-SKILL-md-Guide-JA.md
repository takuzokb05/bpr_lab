# Claude Code skill.md とは？書き方の最短ルートと運用で気をつけること

- URL: https://www.playpark.co.jp/blog/skill-md-guide
- ソース: web
- 言語: ja
- テーマ: claude-code
- 取得日: 2026-07-12

## 要約
合同会社playparkによるClaude Code skill.md実践ガイド。SKILL.mdの基本構造（frontmatter + 本文）、description フィールドの重要性（Claude Codeがセッション起動時にdescriptionのみを読み込んで一覧化し、ユーザー発話との意味的マッチングに使う）、配置場所（.claude/skills/スキル名/SKILL.md）を解説。運用上の注意点として「descriptionは呼び出し条件を自然文で書く」「本文は使用時のみ読み込まれるため長くても可」を指摘。実際のSKILL.mdサンプルも提示しており、初めてスキルを作る実践者向けの最短ルート解説記事。
