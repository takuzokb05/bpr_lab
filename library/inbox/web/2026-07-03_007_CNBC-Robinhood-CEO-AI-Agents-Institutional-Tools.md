# CNBC：RobinhoodCEO「AIエージェントは近く人間トレーダーに匹敵する」

- ソース: web
- 言語: en
- テーマ: ai-trading
- 取得日: 2026-07-03

## 要約

CNBC報道（2026年7月2日）。Robinhood CEOがCNBCに出演し、AIエージェントによるトレーディングの将来展望を語った。主な発言：①AIエージェントは「近いうちに」人間のトレーダーに匹敵するレベルに到達する；②個人投資家が機関投資家・高頻度取引ファームと同等のツールを利用できる時代が来る；③Agentic Trading（5月27日発表）は「アジェンティックファイナンスの幕開け」と位置付け。MCP経由でAIエージェントが直接ブローカーアカウントにアクセスして取引執行する仕組みを解説。現在はベータ段階で一部ユーザーに限定提供。リスク：AI駆動戦略は特定の市場環境で大幅に失敗する可能性があり、リアルタイム監視・停止が困難な場合がある点を注記。
