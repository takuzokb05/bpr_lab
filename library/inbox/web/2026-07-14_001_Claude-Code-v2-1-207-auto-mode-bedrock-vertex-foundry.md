# Claude Code v2.1.207: Auto Mode Default on Bedrock/Vertex AI/Foundry

- URL: https://dev.classmethod.jp/en/articles/20260711-cc-updates-v2-1-207/
- ソース: web
- 言語: en
- テーマ: claude-code
- 取得日: 2026-07-14

## 要約
Claude Code v2.1.207（2026年7月11日）でBedrock/Vertex AI/Foundryにおけるauto modeがデフォルト有効に。これまで必要だったCLAUDE_CODE_ENABLE_AUTO_MODE環境変数が不要に。対応モデルはSonnet 5・Opus 4.7・4.8のみ（エイリアスは非対象）。デスクトップアプリに内蔵ブラウザ追加。非対話実行でセキュリティダイアログをバイパスできた重大バグを修正。プラグインフックでシェルインジェクションにつながる${user_config.*}記法を拒否。ターミナルフリーズ・AWS SSO認証繰り返し問題も解決。
