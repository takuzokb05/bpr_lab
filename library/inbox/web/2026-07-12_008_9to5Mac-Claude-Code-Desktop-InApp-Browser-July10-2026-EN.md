## 要約
9to5Macによる2026年7月10日発表のClaude Codeデスクトップ内蔵ブラウザ機能の解説記事。Claude Codeのデスクトップアプリにサンドボックス化されたブラウザが追加され、コードエディタを離れることなくドキュメント・デザイン・任意のWebサイトを閲覧・操作可能に。主要仕様：Ctrl+Shift+B（Win）/Cmd+Shift+B（Mac）でアクセス、セッション永続性はユーザーが設定可能、ブラウジング履歴なしのクリーンな分離プロファイル、外部サイトへの書き込み操作（クリック・テキスト入力）には安全分類器によるレビューとユーザー明示承認が必要。JavaScriptレンダリング対応でDOM直接取得も可能。開発者のコンテキストスイッチングを大幅に削減する機能。
