## 要約
Totalumブログが提供するClaude Code Skillsの包括的ガイド。Skills・MCP・Subagents・Hooksの4コンポーネントを「Skills=ワークフロー、MCP=データ、Subagents=計画、Hooks=イベント」と明確に整理。Skillsはフォルダベースの指示パックでSKILL.mdファイルへのMarkdown記述だけで作成可能。公式17種スキル（code-review・verify・deep-research等）の用途別解説とユースケース別の選択フローチャートを提供。カスタムスキルは「この作業をスキルにして」と話しかけるだけでClaude Codeが自動生成。4コンポーネントの組み合わせパターン（例：MCP→Skills→Hooks連鎖）も具体例付きで解説。2026年版で動的ワークフローや階層型エージェントとの組み合わせも対応。
