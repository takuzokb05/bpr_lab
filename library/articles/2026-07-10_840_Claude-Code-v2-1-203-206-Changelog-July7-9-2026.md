# Claude Code v2.1.203〜v2.1.206 Changelog（2026年7月7〜9日）

- URL: https://code.claude.com/docs/en/changelog
- ソース: web
- 言語: en
- テーマ: claude-code
- 取得日: 2026-07-10

## 投稿内容

### v2.1.206（2026-07-09）
- /cdコマンドにディレクトリパス補完を追加（/add-dirと同動作）
- /doctorにCLAUDE.mdのトリム提案チェックを追加（コードベースから導出可能なコンテンツの削減提案）
- Gateway：/loginがAnthropicが運用するパブリックゲートウェイエンドポイントに対応
- EnterWorktreeがプロジェクトの.claude/worktrees/外にあるgitワークツリーへの入室前に確認を求めるように変更
- /commit-push-prがリポジトリ設定のpushリモート（remote.pushDefault、またはリモートが1つの場合はそのリモート）へのgit pushをoriginに加えて自動許可
- バックグラウンドエージェントがClaude Code更新直後にバックグラウンドで新バージョンにアップグレード
- /code-reviewの品質がclaude-opus-4-8の全努力レベルで向上
- agentsビューのステータス列が64文字切り捨てではなく端末幅いっぱいを使用
- バグ修正：ログイン失効時に「There's an issue with the selected model」というミスリーディングなエラー表示を修正
- バグ修正：claude --resumeと--continueが起動時にキーボード入力に応答しない問題を修正
- バグ修正：--mcp-configまたは.mcp.jsonで設定されたMCPサーバーのper-server request_timeout_msが無視される問題を修正
- バグ修正：CLAUDE_CODE_EXTRA_BODYがバックグラウンドワーカーでサイレントに無視される問題を修正
- バグ修正：OAuth MCPサーバーがトークンリフレッシュ失敗後に手動再認証を要求する問題を修正
- バグ修正：/modelピッカーが誤った価格とモデルの不一致を表示する問題を修正

### v2.1.205（2026-07-08）
- autoモードに、セッショントランスクリプトファイルの改ざんをブロックするルールを追加
- autoモードが解決できない変数に対してrm -rfを実行する前に確認を求めるように改善
- バグ修正：--json-schemaがスキーマ無効時にサイレントで非構造化出力を生成する問題を修正
- バグ修正：NTFSジャンクション/シンボリックリンクが存在する場合にWindowsのワークツリー削除がワークツリー外のファイルを削除する問題を修正
- バグ修正：resumeされたバックグラウンドエージェントが「failed」/「completed」として表示され続ける問題を修正

### v2.1.204（2026-07-08）
- ヘッドレスセッションのSessionStartフック中にフックイベントがストリーミングされない問題を修正

### v2.1.203（2026-07-07）
- ログイン期限切れ直前の警告を追加
- 手動パーミッションモード時にフッターにグレーの⏸バッジを追加
- セッションの追加作業ディレクトリをMCPのroots/listに追加
- バグ修正：デーモンのセッショントークン失効時にバックグラウンドセッションが永久に無応答になる問題を修正
- バグ修正：バックグラウンドエージェントがWindowsデーモンから古いPATHを継承する問題を修正
- バグ修正：多数のgitワークツリーを持つリポジトリでBashが"argument list too long"で失敗する問題を修正
- バグ修正：ワークツリー分離されたサブエージェントが自身のチェックアウトではなく親チェックアウトでコマンドを実行する問題を修正

## 要約
2026年7月7〜9日にリリースされたClaude Code v2.1.203〜v2.1.206の公式チェンジログまとめ。4リリース合計で主要な新機能と20件以上のバグ修正を含む。新機能ハイライト：/cdのパス補完・/doctorのCLAUDE.md肥大化警告・`claude mcp login/logout`（別途追加）・ゲートウェイエンドポイント対応・ログイン期限切れ警告・autoモードのトランスクリプト改ざん防止ルール。修正の重点はバックグラウンドセッション/エージェントの安定性向上とMCP認証の信頼性強化。/code-reviewのOpus 4.8での品質向上も重要な改善点。Windows向け修正も複数含む。
