## 要約
Claude Code 2026年版アジェンティックワークフローパターン完全ガイド。5つのパターン：(1) Sequential Flow—固定順序パイプライン、シンプルタスク向け。(2) Operator Pattern—中央オーケストレーターが専門サブエージェントに委任。(3) Split-and-Merge—並列エージェントが独立したgit worktreeで並行作業（ファイル競合ゼロ）。(4) Dynamic Workflows（2026年5月28日リリース）—Claudeが自身のオーケストレーションプログラムをその場で作成、エージェント艦隊を起動、1プロンプトで単一の検証済み結果を返す。(5) Agent Teams—階層型エージェント連鎖（最大3レベル深さ）で大規模コードベース移行等に対応。本番要件：計画ファイル・エージェントスコープ・ロックファイル・テストゲート・ロールバックパスを持ち、セッション間を生存できる設計。Planモードを活用した「実装前に全決定を解決する」アプローチが最も生産性高い。FX自動取引マルチエージェントシステムの設計参考として有用。
