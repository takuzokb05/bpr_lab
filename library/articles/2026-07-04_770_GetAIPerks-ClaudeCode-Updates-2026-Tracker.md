## 投稿内容

GetAIPerks による Claude Code 2026年アップデートの総括トラッカー記事。主要マイルストーンを時系列でまとめている。

**最新状態（2026年7月時点）：**
- Claude Sonnet 5 がデフォルトモデルに（8月31日まで $2/$10/Mtok の割引価格）
- 1M トークンネイティブコンテキストウィンドウ
- 最大3階層までの子エージェントスポーン（階層型タスク分解）

**Week 26（6月22〜26日）追加機能：**
- `claude mcp login/logout` コマンドによるシェルからのMCPサーバー認証
- `/rewind` コマンドで `/clear` 前の会話を復元可能に
- バックグラウンドサブエージェントが権限プロンプトをメインセッションに浮上させる
- シェルモードがコマンド出力に2回目のプロンプトなしで応答するように改善

**v2.1.200-201（7月3日）：**
- AskUserQuestion のデフォルト自動継続廃止
- デフォルトパーミッションモードが「Manual」に変更

**その他2026年追加機能：**
- fallbackModel 設定によるモデルチェーン（レジリエントなモデル切り替え）
- コミュニティツールマーケットプレイス追加
- 対話型チャート・図・ビジュアライゼーション・モバイルアプリ生成

## 要約

Claude Code の2026年アップデートを網羅した英語圏向けトラッカー記事。Claude Sonnet 5 デフォルト化（$2/$10/Mtok 割引）・MCP認証コマンド・/rewind・バックグラウンドエージェントの権限浮上・3階層子エージェントスポーンなど、6〜7月の主要機能追加を1記事で確認可能。特に fallbackModel による複数モデルチェーン設定は自動化・本番運用での障害耐性向上に重要。Manual パーミッションモードへのリネームと AskUserQuestion 挙動変更は無人運用に影響するため要確認事項として有用。
