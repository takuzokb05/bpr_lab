# Claude Sonnet 5 公式リリース：最もアジェンティックなSonnetモデル（2026-06-30）

- URL: https://www.anthropic.com/news/claude-sonnet-5
- ソース: web
- 言語: en
- テーマ: claude-ecosystem
- 取得日: 2026-07-03

## 要約

2026年6月30日、AnthropicがClaude Sonnet 5を正式リリース。Opus 4.8に近い性能をSonnet価格帯で提供する最もアジェンティックなモデル。

主要スペック：①1Mコンテキストウィンドウ・最大128K出力；②アダプティブシンキングをデフォルト有効；③新トークナイザー（同テキストで約30%多くトークンを生成）；④推論・ツール使用・コーディング・知識作業でSonnet 4.6を大幅上回る。

価格：入門価格$2/$10（入力/出力 per million tokens）を2026年8月31日まで提供、その後$3/$15に移行。Free/Proプランのデフォルトモデルに指定、Max/Team/Enterpriseでも利用可能。

提供プラットフォーム：Claude API・AWS Bedrock・Google Cloud・Microsoft Foundry（preview）。Claude Codeの新デフォルトモデルとしても設定済み。計画・ブラウジング・ターミナル操作などの自律タスク実行能力が特に向上。
