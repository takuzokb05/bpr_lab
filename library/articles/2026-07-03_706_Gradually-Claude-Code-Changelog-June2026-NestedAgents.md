## 要約

Gradually.aiによるClaude Code 2026年6月のアップデート集約。前月からの主要変更点をエンジニア視点で整理。

主要アップデート10選：
①**ネストされたサブエージェント**——最大3階層の親子エージェント構造でタスク分解が可能に；
②**フォールバックモデルチェーン**——プライマリモデル障害時の自動切替で可用性向上；
③**コミュニティツールマーケットプレイス**——スキル・MCP・プラグインの探索・共有基盤が開設；
④**エージェントごとのコスト帰属**——どのサブエージェントがいくら消費したかを追跡可能；
⑤**スコープ付きパーミッション**——サブエージェントへの権限をオーケストレーター側で制御；
⑥組織デフォルトモデル設定；
⑦読みやすいセッション名の自動生成；
⑧クリック可能なファイル添付；
⑨バックグラウンドセッション信頼性改善；
⑩MCP・プラグイン・音声入力・ターミナルパフォーマンスの広範な修正。

Claude Code v2.1以降でマルチエージェントワークフローを構築するプロダクション活用者必読のまとめ。
