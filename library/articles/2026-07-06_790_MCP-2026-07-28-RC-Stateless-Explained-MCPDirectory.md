## 投稿内容
MCP ディレクトリ公式ブログによる 2026-07-28 RC の包括的解説。6つのSEP（SEP-2575: ステートレスコア、SEP-2549: キャッシュ制御、SEP-1865: MCP Apps、SEP-1492: Tasks、SEP-2322: Multi Round-Trip Requests）の詳細な仕様変更内容。MCP Apps によってサーバーがインタラクティブHTML UIをホスト側に提供できる点は新エコシステムの可能性を開く。既存の5,800+サーバーへの影響と互換性維持策。SDK ティア別対応スケジュール（Tier 1: 10週、Tier 2: 6ヶ月）も記載。

## 要約
MCP ディレクトリ公式ブログによる 2026-07-28 RC の全体解説。6つのSEPが統合される背景と設計思想を詳解。特に MCP Apps（SEP-1865）によりサーバーがインタラクティブ HTML UI をホスト側に提供できる点は新しいエコシステムの可能性を開く。Tasks（SEP-1492）による長時間非同期処理の標準化、ttlMs/cacheScope によるキャッシュ制御。5,800+ 既存サーバーへの影響と SDK ティア別対応スケジュール（Tier 1: 10週、Tier 2: 6ヶ月）を整理。
