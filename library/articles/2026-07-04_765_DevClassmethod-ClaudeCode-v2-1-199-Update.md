# Claude Code v2.1.199 の主要アップデート（スキル連続呼び出しとエージェント安定化）

## 投稿内容

2026年7月2日リリース。24件の変更を含み、バックグラウンドエージェントとサブエージェントの安定性向上・ネットワーク周辺の信頼性改善に焦点を当てたリリース。

**新機能：スラッシュスキルの連続呼び出し**
`/skill-a /skill-b do XYZ` のような複数スキル呼び出しで、先頭に並んだスキルを「最大5個まですべて読み込む」ようになった（従来は1つのみ）。

**重大バグ修正2件：**
- Linux 上のデーモンが破損したワーカーレコードにより約50秒ごとに全エージェントを強制終了していた問題を解決
- サブエージェントが「API エラーを成功として親に報告」していた問題を修正（サイレント失敗の排除）

**セキュリティ改善：**
プランモードにおけるブラウザツール呼び出し時の確認要件を改善し、読み取り専用操作のみ自動許可に。

## 要約

Claude Code v2.1.199 の実質的なハイライトは2点。(1) スラッシュスキル連続呼び出し（最大5個）により複合ワークフローの1コマンド化が可能になった。(2) Linux デーモンの全エージェント強制終了バグ解消により長時間のマルチエージェント実行が安定化した。加えてサブエージェントのサイレント失敗（APIエラーを成功として親に報告）が修正されたことで、エラーが見えない問題が解消。複数エージェント並行運用・長時間自動化タスクのユーザーに最も恩恵のある更新。DevelopersIO による詳細な日本語解説付き。
