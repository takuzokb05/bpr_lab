## 要約
Claude Code Skillsの選定基準と段階的導入手順を実践目線で解説した2026年版ガイド。

**スキル選定の3軸**:
- 頻度（高頻度タスクから着手）
- 重要性（品質・一貫性への影響度）
- 自動化適性（再現可能なワークフローか）

**推奨スキル6選**:
1. **skill-creator**: 対話でスキルを作るための基盤スキル（最初に導入）
2. **コードレビューシステム**: チームのレビュー観点を標準化
3. **ドキュメント生成**: docx/pdf/xlsx/pptxを自動作成
4. **frontend-design**: UI生成品質の向上
5. **webapp-testing**: Playwrightベースのブラウザ自動化テスト
6. **セキュリティチェック**: コード・依存関係の脆弱性スキャン

**段階的導入戦略**: 「最頻度タスクに合うスキル1つから始め、認識と自動トリガーを確認してから拡張」—一度に全部入れない。

**核心知見**: スキルはモデルが説明フィールドだけを見て使用判断する→曖昧な説明では未使用のまま終わる。自動トリガー条件を具体的フレーズで明示することが成功のカギ。

**配置場所**: 個人スキル（`~/.claude/skills/`）vs チーム共有（`.claude/skills/`、リポジトリに含めgitで共有）。
