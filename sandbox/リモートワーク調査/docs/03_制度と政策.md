# リモートワークに関する制度と政策

## エグゼクティブサマリー

日本におけるリモートワーク（テレワーク）の制度・政策は、既存の労働法体系の枠内で運用されており、テレワーク専用の包括的な法律は存在しない。主な制度的基盤は以下の通りである。

- **法的枠組み**: 労働基準法・労働安全衛生法・労災保険法等がそのままテレワーク労働者にも適用される。2024年4月の労働条件明示ルール改正により、テレワークを含む就業場所の「変更の範囲」の明示が義務化された。
- **ガイドライン**: 厚生労働省「テレワークの適切な導入及び実施の推進のためのガイドライン」（2021年3月改定）が、労働時間管理・費用負担・安全衛生等について包括的な指針を示している。
- **助成金**: 人材確保等支援助成金（テレワークコース）が中小企業のテレワーク導入を支援。令和7年度に手続き簡素化の改正が実施された。IT導入補助金も間接的にテレワーク環境整備を支援する。
- **税制**: 国税庁FAQ（2021年1月公開）により、在宅勤務手当の課税・非課税の判断基準が明確化された。実費精算は非課税、一律支給は課税対象。
- **地方創生**: デジタル田園都市国家構想交付金（地方創生テレワーク型）により、サテライトオフィス整備等を支援。2025年度からは「新しい地方経済・生活環境創生交付金（第2世代交付金）」に再編。
- **海外比較**: EUではフランスを皮切りに「つながらない権利」の法制化が進む。日本では2024年の労働基準関係法制研究会で議論が開始され、ガイドライン策定が提言されている段階。

## 1. 法的枠組み

### 1.1 基本原則：既存労働法の全面適用

テレワークを行う労働者には、以下の労働基準関係法令がそのまま適用される。テレワークであることを理由に適用が除外される法律はない。

| 法律 | テレワークへの適用 |
|------|-------------------|
| 労働基準法 | 全面適用（労働時間・休日・深夜業・年次有給休暇等） |
| 最低賃金法 | 全面適用 |
| 労働安全衛生法 | 全面適用（健康診断・ストレスチェック・安全配慮義務等） |
| 労働者災害補償保険法 | 全面適用（業務遂行性・業務起因性の要件を満たす場合） |
| 労働契約法 | 全面適用 |

ソース: [厚生労働省「テレワークにおける適切な労務管理のためのガイドライン」（PDF）](https://www.mhlw.go.jp/content/11911500/000683359.pdf)

### 1.2 労働時間制度の適用

労働基準法に規定されている労働時間制度のうち、テレワーク（在宅勤務）について適用を認めていないものはない。以下の制度がいずれも適用可能である。

#### (1) 通常の労働時間制度
- 原則として1日8時間・1週40時間以内（労働基準法第32条）
- 時間外労働には36協定の締結・届出が必要（同法第36条）
- テレワークでも残業代の支払い義務は変わらない

#### (2) フレックスタイム制
- 清算期間内で定められた総労働時間を働く制度
- テレワークとの親和性が高く、中抜け時間にも柔軟に対応可能
- 事業場外であることや労働時間算定困難の要件は不要

#### (3) 事業場外みなし労働時間制（労働基準法第38条の2）
- テレワークに適用するには以下の**2要件を同時に満たす**必要がある:
  1. 情報通信機器が使用者の指示により常時通信可能な状態におくこととされていないこと
  2. 随時使用者の具体的な指示に基づいて業務を行っていないこと
- 常時Web会議接続やチャット即時応答を義務付けている場合は適用不可

#### (4) 裁量労働制（専門業務型・企画業務型）
- 対象業務に該当すれば、テレワークでも適用可能
- みなし労働時間が適用される

ソース: [厚生労働省ガイドライン概要（PDF）](https://www.mhlw.go.jp/content/000807036.pdf)、[事業場外みなし労働時間制とテレワーク（AKASHI）](https://ak4.jp/column/deemedworkinghours-system/)

### 1.3 労働条件明示ルールの改正（2024年4月施行）

2024年4月1日から、労働条件明示のルールが改正され、テレワークに直接関連する変更が加わった。

- **就業場所の「変更の範囲」の明示が義務化**: 雇入れ時の就業場所だけでなく、将来テレワークを行う可能性がある場合は、自宅やサテライトオフィス等を「変更の範囲」として労働条件通知書に明示する必要がある
- 全ての労働者（正社員・有期雇用・パート等）が対象
- 就業規則にもテレワーク勤務に関する規定の整備が求められる

ソース: [2024年4月1日改正 労働条件明示のルール（PCA）](https://pca.jp/p-tips/articles/rou24030101.html)、[労働条件明示ルール変更（PROACTIVE/SCSK）](https://proactive.jp/resources/columns/obligation-to-state-working-conditions/)

### 1.4 労災保険の適用

テレワーク中の負傷等も、**業務遂行性**と**業務起因性**の2要件を満たせば労災として認定される。

#### 労災認定されるケース（例）
- 業務中にトイレに行こうとして転倒し負傷した場合
- 業務中に自宅の作業環境に起因して負傷した場合
- 長時間のPC作業による腰痛・眼精疲労等が業務に起因する場合

#### 労災認定されにくいケース（例）
- 休憩時間中に私用で外出した際の事故
- 業務と無関係な家事中の負傷
- 業務時間外の活動中の事故

#### 認定のポイント
- 業務時間や作業内容が明確に定められているほど、業務遂行性が認定されやすい
- テレワーク中の労災申請では、業務中であったことの証明（ログ、メール等）が重要
- 使用者には、テレワーク中の事故に備え、労働時間の適切な記録・管理が求められる

ソース: [テレワークでも労災は認められる？（マネーフォワード）](https://biz.moneyforward.com/payroll/basic/82868/)、[テレワーク時の労災適用（KDDI）](https://www.kddimatomete.com/magazine/201001161855/)

### 1.5 今後の法改正動向

厚生労働省は2024年1月に「労働基準関係法制研究会」を設置し、2025年1月に報告書を公表した。報告書では以下の論点が含まれる。

- **つながらない権利**: 勤務時間外の連絡に関する社内ルールの労使協議を推奨。ガイドライン策定が提言された
- **13日を超える連続勤務の禁止**: 現行法の4週4休制度下で最大48日連続勤務が可能な問題を解消するため、法定休日の特定義務化が議論されている
- 2026年の労働基準法改正に向けた審議が労働政策審議会・労働条件分科会で継続中

ソース: [第13回労働基準関係法制研究会 議事録（厚生労働省）](https://www.mhlw.go.jp/stf/newpage_45069.html)、[第204回労働政策審議会労働条件分科会 議事録（厚生労働省）](https://www.mhlw.go.jp/stf/newpage_66496.html)

## 2. 厚生労働省ガイドライン

### 2.1 ガイドラインの概要

| 項目 | 内容 |
|------|------|
| 正式名称 | 「テレワークの適切な導入及び実施の推進のためのガイドライン」 |
| 策定日 | 2021年3月25日（改定版公表） |
| 前身 | 「情報通信技術を利用した事業場外勤務の適切な導入及び実施のためのガイドライン」（2018年） |
| 改定の背景 | COVID-19による「新たな日常」への対応、テレワークの急速な普及 |
| 構成 | 従来4項目 → 全11項目へ抜本的改定 |

ソース: [厚生労働省 テレワークガイドライン公式ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/shigoto/guideline.html)

### 2.2 ガイドラインの主要なポイント

#### (1) テレワークの対象者
- テレワーク実施が難しいと考えられる業種であっても、個々の業務単位で実施を検討すべき
- **非正規雇用を理由にテレワーク対象者から除外してはならない**
- オフィスに出社する労働者に業務が偏らないよう配慮が必要

#### (2) 労働時間管理
- テレワークでも労働時間の適切な管理は使用者の義務
- 労働時間の把握方法として、PCのログオン・ログオフ記録、勤怠管理ツール、自己申告制などが利用可能
- **中抜け時間の取扱い**: 労働基準法上、使用者は把握しても把握しなくてもよい。把握する場合は休憩時間または時間単位年休として扱うことが可能
- 始業・終業時刻の変更を可能とする場合は、就業規則への記載が必要

#### (3) 費用負担
- 在宅勤務に係る通信費・光熱費・事務用品費等の費用負担について、**あらかじめ労使で十分に話し合い、就業規則等に定めておくこと**が推奨される
- 労働基準法第89条第5号により、労働者に負担させる場合は就業規則に定める必要がある

#### (4) 安全衛生
- テレワーク労働者にも、健康診断、ストレスチェック（常時50人以上の事業場）、長時間労働者への面接指導等が義務付けられる
- 自宅等で作業する場合、事務所衛生基準規則等は直接適用されないが、**同等の作業環境となるよう使用者が適切な助言等を行うことが望ましい**
- 「テレワークを行う労働者の安全衛生を確保するためのチェックリスト」及び「自宅等におけるテレワーク作業環境確認チェックリスト」が提供されている

#### (5) ハラスメント防止
- テレワークの有無にかかわらず、パワーハラスメント・セクシュアルハラスメント等に関する法令上の措置義務が適用される
- テレワーク実施者へのオンラインでのハラスメント（いわゆるリモートハラスメント）にも注意が必要

#### (6) その他の重要ポイント
- 不必要な押印・署名の廃止、書類のペーパーレス化を推進
- 人事評価について、テレワーク実施者のみを不利に扱うことがないよう留意
- 通勤手当・在宅勤務手当の取扱いについて労使で合意を形成すること

ソース: [厚生労働省「テレワークガイドライン」公式ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/shigoto/guideline.html)、[改定ガイドラインのポイント（Sanpo Navi）](https://sangyoui-navi.jp/blog/280)、[テレワークガイドラインまとめ（HR NOTE）](https://hrnote.jp/contents/soshiki-telework-guideline-20240419/)

|-------------|------|

## 3. 助成金・補助金制度

### 3.1 人材確保等支援助成金（テレワークコース）

厚生労働省が所管する、中小企業のテレワーク導入・拡大を支援する助成金制度。

| 項目 | 内容 |
|------|------|
| 所管 | 厚生労働省 |
| 対象 | 中小企業事業主（テレワーク新規導入・拡大） |
| 制度導入助成 | 1企業あたり**20万円** |
| 目標達成助成 | 1企業あたり**10万円**（賃金要件を満たす場合は**15万円**） |

#### 主な受給要件

**制度導入助成:**
- 前3か月間に職場風土作りの取組（必須）を実施
- 就業規則拡充・コンサルティング・研修のいずれかを実施
- テレワーク実施対象労働者が「全員1回以上実施」または「週間平均1回以上」を達成
- 過去にこの助成金の支給を受けていないこと

**目標達成助成:**
- 制度導入後の離職率が導入前以下
- 評価時の離職率が30%以下
- テレワーク実績が基準回数以上

#### 令和7年4月1日の改正内容
- **事前にテレワーク実施計画を提出し認定を受けることが不要**になった（手続きの簡素化）
- 令和6年度改正では、既にテレワークを導入済みで実施を拡大する事業主も対象に追加

#### 賃金要件（加算対象）
- 目標達成助成で15万円を受給するには、テレワーク実施対象労働者の毎月決まって支払われる賃金を「評価期間開始から1年以内に5%以上増加」させる必要がある

ソース: [厚生労働省 人材確保等支援助成金（テレワークコース）](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/telework_zyosei_R3.html)

### 3.2 IT導入補助金

経済産業省（中小企業庁）が所管する、中小企業・小規模事業者のデジタル化を支援する補助金制度。テレワーク関連ツールの導入にも活用可能。

| 項目 | 内容 |
|------|------|
| 所管 | 経済産業省（中小企業庁） |
| 対象 | 中小企業・小規模事業者 |
| 2025年度の申請枠 | 通常枠、インボイス枠、セキュリティ対策推進枠、複数社連携IT導入枠 |
| 補助率 | 1/2〜2/3以内（枠により異なる） |
| 申請開始 | 2025年3月31日〜 |

#### テレワーク関連での活用例
- Web会議ツール、クラウド勤怠管理システム、VPN等のセキュリティツール
- 電子契約、ペーパーレス化ツール
- グループウェア、プロジェクト管理ツール

#### 2025年度の変更点
- 補助対象となる業務プロセスが拡大
- 最低賃金近傍の事業者への補助率が「2/3以内」に拡大

**注意**: IT導入補助金はテレワーク専用ではなく、ITツール導入全般を対象とする制度。テレワーク関連ツールは対象になり得るが、登録されたITツールである必要がある。

ソース: [中小企業庁「IT導入補助金2025」](https://mirasapo-plus.go.jp/hint/28998/)、[IT導入補助金解説（freee）](https://www.freee.co.jp/kb/kb-accounting/it-shien/)

## 4. 税制上の取り扱い

### 4.1 国税庁FAQ（2021年1月公開）

国税庁は2021年1月15日に「在宅勤務に係る費用負担等に関するFAQ（源泉所得税関係）」を公開し、在宅勤務に関する費用の課税・非課税の判断基準を示した。

#### 基本原則

| 支給形態 | 課税区分 | 理由 |
|---------|---------|------|
| **実費精算** | **非課税** | 在宅勤務に通常必要な費用の実費相当額であるため |
| **一律定額支給**（返還不要） | **課税（給与所得）** | 実費精算に当たらず、給与として扱われるため |

#### 通信費の業務利用分の算出

通信費はプライベートでの利用や家族の利用と切り分けて計算する必要がある。国税庁FAQが示す**概算計算方法**は以下の通り。

**通信費（インターネット回線等）:**
```
業務利用分 = 月額通信費 × (在宅勤務日数 / 当該月の日数) × 1/2
```
- 1/2は、プライベート利用分の控除

**電気料金:**
```
業務利用分 = 月額電気料金 × (業務使用部屋の床面積 / 自宅の床面積) × (在宅勤務日数 / 当該月の日数) × 1/2
```
- 在宅勤務日数に加え、業務に使用した部屋の床面積も考慮する

#### 注意点
- 上記はあくまで概算計算方法であり、より精緻な方法で算出した金額を企業が支給しても給与課税はされない
- テレワーク用の備品（机・椅子等）を企業が購入し貸与する場合は、給与課税されない（所有権が企業にある場合）
- 従業員が購入し企業が事後精算する場合も、業務使用が明確であれば非課税

ソース: [国税庁「在宅勤務に係る費用負担等に関するFAQ」（PDF）](https://www.nta.go.jp/publication/pamph/pdf/0020012-080.pdf)、[在宅勤務手当の課税・非課税（OBC360）](https://www.obc.co.jp/360/list/post165)、[国税庁の課税判断指針（BCN+R）](https://www.bcnretail.com/market/detail/20210118_209083.html)

### 4.2 通勤手当の取り扱い

- テレワークにより通勤日数が減少した場合、通勤手当の支給方法を見直す企業が増加
- 定期券代から実費精算（出社日数に応じた交通費）への切り替えが一般的
- 通勤手当は非課税限度額（月額15万円）以内であれば非課税の取り扱いは変わらない

### 5.4 ワーケーション関連

- 観光庁と各自治体がワーケーション推進に取り組んでいる
- ワーケーションとは、Work（仕事）とVacation（休暇）を組み合わせた造語で、リゾート地や観光地でテレワークしながら休暇を楽しむ働き方
- 多くの自治体が独自のワーケーション誘致施策（滞在費補助、コワーキングスペース整備等）を展開

#### 自治体のワーケーション施策例
- 温泉地でのワーケーション費用補助
- コワーキングスペース利用料の助成
- 「お試しテレワーク移住」プログラム

**課題**: ワーケーション中の労働時間管理、労災の適用範囲、費用負担の取り扱い等について、明確な法的整理が十分ではない。ガイドラインで「労使で事前にルールを定めること」が推奨されている。

ソース: [ワーケーション自治体事例（NTT東日本）](https://business.ntt-east.co.jp/bizdrive/column/bizdrive_workation_case.html)、[ワーケーション補助金自治体情報](https://workationjapan.jp/gotoworkation/999/)

## 6. 海外の制度との比較

### 6.1 「つながらない権利」（Right to Disconnect）

「つながらない権利」とは、労働時間外に業務上のメールや電話への応答を拒否できる権利のこと。テレワークの普及に伴い、仕事と私生活の境界が曖昧になる問題への対応として注目されている。

#### 各国の法制化状況

| 国 | 法制化年 | 概要 |
|----|---------|------|
| **フランス** | 2016年（施行2017年） | 従業員50名超の企業に対し、つながらない権利について労使で協議し労働協約を締結することを義務化。世界初の法制化 |
| **イタリア** | 2017年 | スマートワーカー（時間的・場所的拘束を受けない労働者）保護のため、つながらない権利を雇用契約に明記する義務を設定 |
| **スペイン** | 2018年 | データ保護法の一部として「デジタル・ディスコネクション」の権利を規定 |
| **ベルギー** | 2022年 | 連邦公務員に先行適用後、従業員20人以上の民間企業にも拡大（2023年施行） |
| **ポルトガル** | 2021年 | 企業が就業時間外の従業員に連絡することを原則として禁止 |
| **ギリシャ** | 2021年以降 | コロナ禍を受けて法制化 |
| **EU全体** | 検討中 | 欧州委員会が2024年にソーシャルパートナーとの第一段階協議を開始。2025年7月に第二段階協議に移行。EU全体の法制化は未確定 |

ソース: [EUにおけるテレワーク規制（EURES）](https://eures.europa.eu/remote-workers-and-their-right-disconnect-regulating-telework-eu-2024-05-17_en)、[フランスの「つながらない権利」（青山学院大学）](https://research.a01.aoyama.ac.jp/blog/insights/)、[つながらない権利の各国状況（eleminist）](https://eleminist.com/article/3603)

### 6.2 日本の現状

- **日本には「つながらない権利」に関する法規制は存在しない**（2025年時点）
- 厚生労働省のテレワークガイドラインでは、「時間外等に業務の指示や報告のメール等を送付することの自粛」を推奨するにとどまる
- 2024年に設置された労働基準関係法制研究会の2025年1月報告書では、「勤務時間外にどのような連絡までが許容でき、どのようなものを拒否できるかといった社内ルールを労使で検討していくことが必要」と提言し、**ガイドラインの策定**が推奨された
- 2026年の労基法改正で明文化されるかどうかは現時点では未確定だが、審議は進行中

ソース: [労働基準関係法制研究会議事録（厚生労働省）](https://www.mhlw.go.jp/stf/newpage_45069.html)、[つながらない権利の法制化可能性](https://note.com/saeki2020/n/n40f8f7a724aa)、[JILPT労働政策フォーラム「つながらない権利」](https://www.jil.go.jp/event/ro_forum/20240905/houkoku/01-opening-address-yamamoto.html)

### 6.3 日本と欧州の制度比較まとめ

| 比較項目 | 日本 | EU（主要国） |
|---------|------|-------------|
| テレワーク専用法 | なし（既存労働法で対応） | フランス・スペイン等で部分的に法制化 |
| つながらない権利 | ガイドラインで自粛推奨のみ | 複数国で法制化済み。EU全体での法制化を検討中 |
| 労働時間管理 | 使用者の管理義務あり（ガイドライン準拠） | 各国の労働法に準拠。EUでは労働時間指令あり |
| 在宅勤務の「権利」 | 法的権利ではない（使用者の裁量） | オランダ等では在宅勤務の請求権を法制化 |
| 費用負担 | 労使合意（ガイドライン推奨） | ポルトガル等では企業負担を法的に義務化 |
| 安全配慮義務 | 適用（労働安全衛生法＋判例法理） | 各国の労働安全衛生法に準拠 |
