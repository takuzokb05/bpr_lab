# 日本のリモートワーク導入率と現状

## エグゼクティブサマリー

日本のテレワーク導入率は、コロナ禍の2020〜2021年にピークを迎えた後、緩やかな減少傾向にある。総務省「令和6年通信利用動向調査」によると、テレワークを導入している企業は**47.3%**（前年49.9%から2.6ポイント低下）。一方、労働者ベースの実施率は**15〜22%台**で推移しており、「定着はしたが拡大はしていない」フェーズにある。業種別では情報通信業（56.2%）と対人サービス業（6.2%）の間に**約50ポイントの格差**が存在し、企業規模別でも従業員1万人以上（38.2%）と100人未満（13.2%）で大きな差がある。地域別では東京都（約45%）と地方圏（10%台前半）の差も顕著で、テレワークの恩恵は一部の産業・地域・企業に偏在している。

---

## 1. 全体の導入率推移

### 1.1 企業の導入率（総務省 通信利用動向調査）

| 年度 | 導入率 | 備考 |
|------|--------|------|
| 2019年（令和元年） | 20.2% | コロナ前 |
| 2020年（令和2年） | 47.5% | 1回目の緊急事態宣言後、急増 |
| 2021年（令和3年） | 51.9% | ピーク |
| 2022年（令和4年） | 51.7% | ほぼ横ばい |
| 2023年（令和5年） | 49.9% | 微減開始 |
| 2024年（令和6年） | 47.3% | 減少傾向が継続 |

ソース: [総務省 令和7年版 情報通信白書「テレワーク・オンライン会議」](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r07/html/nd21b220.html)、[総務省 令和6年版 情報通信白書](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r06/html/nd21b220.html)

コロナ禍で20%台から一気に50%近くまで上昇したが、2022年をピークに緩やかな減少に転じている。ただし、コロナ前の20%と比較すれば依然として**2倍以上の水準**を維持している。

### 1.2 労働者ベースの実施率

労働者個人のテレワーク実施率は、調査機関により数値が異なる。

| 調査機関 | 時期 | 実施率 | 対象 |
|---------|------|--------|------|
| パーソル総合研究所（第9回） | 2024年7月 | **22.6%** | 正規雇用社員 |
| 日本生産性本部（第15回） | 2024年7月 | **16.3%** | 20歳以上の雇用者 |
| カオナビHRテクノロジー総研 | 2024年3月 | **17.0%** | 全雇用者 |
| 国土交通省（テレワーク人口実態調査） | 2024年度 | **24.6%** | 雇用型テレワーカー |

ソース: [パーソル総合研究所 第9回テレワーク調査](https://rc.persol-group.co.jp/news/202408221000/)、[カオナビHRテクノロジー総研 2024年3月調査](https://ri.kaonavi.jp/20240827/)、[JILPT「テレワークの現状」2024年12月号](https://www.jil.go.jp/kokunai/blt/backnumber/2024/12/top_02.html)

> **注意**: 企業の「導入率」（47.3%）と労働者の「実施率」（15〜25%）は異なる指標である。導入していても全社員が実施しているわけではなく、一部の部署・職種に限定されているケースが多い。

### 1.3 導入形態

テレワーク導入企業における導入形態（令和6年通信利用動向調査）:

| 形態 | 割合 |
|------|------|
| 在宅勤務 | **90.9%** |
| モバイルワーク | 32.4% |
| サテライトオフィス勤務 | 15.7% |

在宅勤務が圧倒的に主流であり、サテライトオフィス勤務は限定的にとどまっている。

ソース: [総務省 令和7年版 情報通信白書](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r07/html/nd21b220.html)

### 1.4 導入目的の変化

テレワーク導入の目的は、コロナ対応から本質的な経営課題へと移行している。

- **「新型コロナウイルス感染症への対応」**: 前年より減少
- **「勤務者のワークライフバランスの向上」**: 増加傾向
- **「業務の効率性（生産性）の向上」**: 増加傾向
- 導入企業の**85.6%**が「効果があった」と回答（「非常に効果があった」21.0% + 「ある程度効果があった」64.6%）

ソース: [総務省 令和7年版 情報通信白書](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r07/html/nd21b220.html)

## 2. 業種別の導入率

業種間のテレワーク導入率には大きな格差が存在する。

### 2.1 業種別実施率（パーソル総合研究所 第9回調査、2024年7月）

| 業種 | 実施率 | 備考 |
|------|--------|------|
| 情報通信業 | **56.2%** | 最も高い |
| 学術研究・専門技術サービス業 | **36.9%** | 前年比+8.3pt |
| IT・インターネット（カオナビ調査） | **55.8%** | ほぼ同水準 |
| マスコミ・広告（カオナビ調査） | **28.2%** | |
| 通信・インフラ（カオナビ調査） | **28.1%** | |
| サービス業（対人） | **6.2%** | 最も低い |
| 保安・農林漁業 | **6.3%** | 現場作業が主体 |
| 販売業 | **6.6%** | 店舗接客が必須 |

ソース: [パーソル総合研究所 第9回テレワーク調査](https://rc.persol-group.co.jp/thinktank/data/telework-survey9/)、[カオナビHRテクノロジー総研 2024年3月調査](https://ri.kaonavi.jp/20240827/)

### 2.2 格差の要因

業種別導入率には**約50ポイント**の格差がある（情報通信業56.2% vs 対人サービス業6.2%）。

- **デジタル化の進展度**: 情報通信業は業務の大半がPC上で完結
- **対面の必要性**: 医療・福祉・販売・保安業は、利用者・顧客との直接対応が本質
- **セキュリティ要件**: 金融業は導入率が高いが、実施頻度は制限的
- **物理的な作業の有無**: 製造業・建設業は現場作業があるが、事務・開発部門は対応可能

## 3. 企業規模別の導入率

### 3.1 企業規模別テレワーク実施率

**パーソル総合研究所 第9回調査（2024年7月、正規雇用社員）:**

| 企業規模 | 実施率 | 前年同期比 |
|---------|--------|-----------|
| 1万人以上 | **38.2%** | +2.8pt |
| 1,000〜1万人未満 | **30.2%** | -- |
| 100〜1,000人未満 | **20.1%** | -- |
| 10〜100人未満 | **13.2%** | -- |

ソース: [パーソル総合研究所 第9回テレワーク調査](https://rc.persol-group.co.jp/news/202408221000/)、[オフィスのミカタ](https://officenomikata.jp/news/16569/)

**日本生産性本部（第16回、2025年1月調査）:**

| 企業規模 | 実施率 |
|---------|--------|
| 1,001名以上 | **31.8%** |
| 101〜1,000名 | **17.7%** |
| 100名以下 | **9.3%** |

ソース: [日本生産性本部「働く人の意識調査」](https://www.jpc-net.jp/research/detail/007482.html)

> **注意**: 日本生産性本部の調査は半年ごとに実施されており、調査回次により数値が異なる。上記は第16回（2025年1月）のデータ。

### 3.2 格差の要因

- **IT投資余力**: 大企業はVPN、クラウド、セキュリティ基盤等への投資が可能
- **専門部署の存在**: 大企業にはIT部門がテレワーク環境を整備
- **業務の分業化**: 大企業ほど事務・企画等のテレワーク可能な業務が独立して存在
- **中小企業の課題**: 多能工的な業務形態、対面顧客対応の比率が高い、IT人材不足

## 4. リモートワーク実施頻度とハイブリッド勤務

### 4.1 実施頻度の推移

テレワーク実施者の中で、完全リモートは減少し、**ハイブリッド勤務が主流**化している。

**パーソル総合研究所 第9回調査（2024年7月）:**

- 週2〜3日以上のテレワーク実施者が増加（特に企画・マーケティング、IT系技術職、営業事務）
- 大手企業では**2年ぶりに実施率が上昇**し、頻度も増加傾向
- 商品開発・研究、IT系技術職、営業職でテレワーク実施率が増加

ソース: [パーソル総合研究所 第9回テレワーク調査](https://rc.persol-group.co.jp/thinktank/data/telework-survey9/)

**日本生産性本部の推移:**

| 時期 | テレワーク実施率 |
|------|----------------|
| 2020年5月（1回目緊急事態宣言下） | 31.5% |
| 2021年4月 | 19.2% |
| 2023年7月 | 15.5% |
| 2024年1月 | 14.8% |
| 2024年7月 | 16.3% |

ソース: [JILPT「テレワークの現状」2024年12月号](https://www.jil.go.jp/kokunai/blt/backnumber/2024/12/top_02.html)

### 4.2 ハイブリッド勤務の定着

- 「完全リモート」は急速に減少し、多くの企業が**週2〜3日出社 + 週2〜3日在宅**のハイブリッド型に移行
- テレワーク実施者の週あたりの出社日数は**平均3〜4日**が中心帯
- 企業側は「週○日出社」のルールを設定する傾向が強まっている

## 5. 地域差

### 5.1 東京都 vs 地方

テレワーク実施率には顕著な地域差が存在する。

| 地域 | テレワーク実施率 | ソース |
|------|----------------|--------|
| **東京都（企業）** | **45.9%**（従業員30人以上、2024年10月） | 東京都テレワーク実施率調査 |
| **東京都（企業導入率）** | **54.4%** | 総務省 通信利用動向調査（都道府県別） |
| **東京都（個人）** | 約30〜35% | パーソル/NTTドコモ調査 |
| **関東圏全体** | **31.7%** | パーソル総合研究所 |
| **全国平均** | 約15〜22% | 各種調査 |
| **地方圏** | 約10〜15% | NTTドコモモバイル社会研究所 |

ソース: [東京都テレワーク実施率調査（2024年10月）](https://www.metro.tokyo.lg.jp/tosei/hodohappyo/press/2024/12/06/10.html)、[NTTドコモモバイル社会研究所](https://www.moba-ken.jp/project/lifestyle/20230925.html)

### 5.2 地域差の要因

- **産業構造**: 東京は情報通信業・金融業・専門サービス業が集積しており、テレワーク親和性が高い
- **通勤時間**: 首都圏の長い通勤時間がテレワーク需要を押し上げる
- **IT基盤**: 大都市圏ほど通信インフラが整備されている
- **企業規模**: 大企業が集中する東京でテレワーク導入率が高い

## 6. 国際比較

### 6.1 日本の国際的位置づけ

日本のテレワーク実施率は、先進国の中では**低い水準**に位置する。

| 国・地域 | テレワーク実施率（概算） | 備考 |
|---------|----------------------|------|
| オランダ | 約50〜55% | 柔軟勤務法（Wet flexibel werken）により勤務場所の変更を請求する権利を規定（ただし雇用主は合理的理由で拒否可能） |
| フィンランド | 約30〜40% | 北欧諸国は総じて高い（Eurofound調査。定義・集計方法により幅あり） |
| アメリカ | 約25〜30% | ハイブリッド勤務が主流（Stanford WFH Research。フルリモート+ハイブリッド合算） |
| イギリス | 約35〜40% | コロナ後も高水準を維持 |
| ドイツ | 約25〜30% | 微減傾向 |
| **日本** | **約15〜25%** | 先進国中で低位 |
| 韓国 | 約15〜20% | 日本と同程度 |

ソース: [総務省 令和6年版 情報通信白書 国際比較](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r06/html/nd21b220.html)、[JILPT 国際比較を通して見た日本（OECD）](https://www.jil.go.jp/foreign/jihou/2020/10/oecd_01.html)

> **注意**: 各国の統計は調査方法・定義が異なるため、数値の直接比較には限界がある。大まかな順位付けとして理解すべきである。

### 6.2 日本が低位にある要因

- **対面主義の文化**: 出社＝勤勉という価値観が根強い
- **紙文化・ハンコ文化**: 書類の電子化が欧米に比べて遅れている
- **法制度の差異**: オランダの柔軟勤務法（勤務場所変更の請求権）やフランスの「つながらない権利」のような法制度が日本にはない
- **住宅事情**: 日本の都市部の住宅は狭く、専用の作業スペースを確保しにくい
- **産業構造**: 製造業・サービス業の比率が高く、テレワーク可能な業務の割合が相対的に低い
