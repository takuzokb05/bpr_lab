# リモートワーク調査

## プロジェクト概要

- **目的**: 日本におけるリモートワークの普及状況を多角的に調査し、現状・課題・制度面の全体像を明らかにする
- **対象**: 日本国内の企業・労働者のリモートワーク実態
- **主要な価値**: コロナ後のリモートワーク定着度合いと、今後の働き方の方向性を把握する

## 調査ルール

### ソースと信頼性

- **全ての主張にソース（URL・出典）を必ず付ける**
- 一次ソース（公式ドキュメント・学術論文・政府資料）を優先する
- 同じ情報を異なるソースでクロスチェックする
- 情報の鮮度（年度）に注意し、古いデータには明示する
- 厚生労働省・総務省・内閣府の公式統計を最優先ソースとする
- 民間調査（パーソル、リクルート等）は補助ソースとして利用

### 分析姿勢

- 主張を無批判に受け入れない（批判的検証を徹底する）
- 具体的な数字・データを優先する（定性的な印象より定量的な根拠）
- 反例や不利なデータも公平に扱う
- 「リモートワーク推進ありき」のバイアスに注意する

### 品質チェック

- 各ドキュメントは fact-checker で事実検証を実施
- 統合ドキュメントは devils-advocate で論理攻撃を実施
- fact-checker → 修正反映 → devils-advocate の順序を守る（並列不可）

## レビューワークフロー

```
Phase 1: researcher (並列OK) → 各doc作成
Phase 2: fact-checker (並列OK) → 事実修正を各docに反映
Phase 3: devils-advocate → 論理攻撃 → 設計修正を反映
Phase 4: devils-advocate 2回目 → 修正の検証
```

  - scope: doc名（01, 02等）

## 利用可能なスキル

## 利用可能なエージェント

- agents/researcher.md - Web調査（バックグラウンド並列実行可能、最大3並列）
- agents/fact-checker.md - 事実検証（doc間は並列OK、researcherの後に実行）
- agents/devils-advocate.md - 反論・論理攻撃（逐次実行、fact-checkerの後に実行）

## プロジェクト固有のルール

- 統計データは2020年以降のものを優先する（コロナ前後の比較が重要なため）
- 「リモートワーク」「テレワーク」「在宅勤務」は同義として扱う（出典の表記に合わせる）
- 海外との比較データがあれば積極的に含める（ただし主眼は日本国内）
