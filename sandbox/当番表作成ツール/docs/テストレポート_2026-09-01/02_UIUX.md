## Critical

### C-1. キーボードだけでは主要操作がほぼ全て実行不可能（WCAG 2.1.1）
- **現象**: クリック可能要素の大半が `<span>`/`<td>`/`<div>` + clickリスナーで、Tabで到達不能。実測のフォーカス巡回はタブボタン・select・`.btn` のみ。素通りするもの: ミニカレンダーの日付（祝日切替）、当番表セル42個（手動割り当ての入口）、タグチップ、曜日チェック、設定折りたたみヘッダー。
- **根拠**: 【実測】`a11y_data.json` の `clickableNonFocusable`、`keyboard_data.json`。`tabindex`/`keydown` はファイル全体で0件（Grep実測）。該当: v2.html:657, :1986, :877, :1607, :1666, :2968
- **改善案**: クリック対象を原則 `<button>` 化（`all:unset`+既存クラスで見た目維持）。tdは `tabindex="0"` + Enter/Space の keydown を付与。

### C-2. 「割り当てをクリア」が確認なし・Undo不能で1クリック全消去
- **現象**: 1ヶ月分の割り当て（手修正込み）が確認なしで即消える。このボタンだけ `pushUndo()` を呼ばないため「元に戻す」でも復元不能（自動割り当てとセル編集は pushUndo 済み）。「自動割り当て」の真横に配置。
- **根拠**: 【コード】:1841-1846（pushUndo なし）。`confirm(` は0件（Grep実測）。配置は 02_calendar.png
- **改善案**: pushUndo 追加（1行）+ 「◯件の割り当てを消します。よろしいですか？」の確認 + 復元手段の案内トースト。

### C-3. 主要CTA「自動割り当て」のコントラスト不足（WCAG 1.4.3）
- **現象**: 白文字×緑 `#16A34A` = **3.30:1**（基準4.5:1）。タグバッジも白×緑3.30、白×橙`#D97706` **3.19:1** で不合格。
- **根拠**: 【実測】`audit2_result.json` contrast。該当: :104, :125-128, :26
- **改善案**: 成功色を `#15803D`（4.54:1）へ。タグバッジは背景輝度で文字色を黒/白自動切替。

## High

### H-1. 初回起動時の導線がない（空状態ガイダンス欠如）
初回はカレンダータブ＋空グリッド30行のみで「何から始めるか」の記載ゼロ【実測 01_initial_empty.png】。改善: 職員0人時にグリッド領域へ「①職員登録（Excel貼り付け可）→②当番枠設定→③自動割り当て」の3ステップ案内。「説明なしで使える」方針への最大ギャップ。

### H-2. 破損データが無言で初期化され、次の保存で完全消失
破損JSONだと console.error のみで画面は初回起動と同一【実測 01b_broken_data.png / console_log.txt】。1操作で saveData が上書きし復旧不能に。該当: :379-399。改善: 破損rawを別キーへ退避 + 「読み込めなかったため初期状態で起動。バックアップから復元してください」バナー常設。

### H-3. セル編集モーダル: 人数表示が更新されず、定員超過も警告されない
「現在: 6人」がチェック操作後も固定。実測で6人枠に13人チェックできたが警告なし【実測 11_overassign_no_warning.png / audit2_result.json cellModalLiveCount: updated=false】。「同日重複」バッジも開いた時点で凍結。該当: :2045, :2076-2087。改善: change時に再計算し、超過は赤字表示。SPEC「エラーは即座に赤ハイライト」の未実装箇所。

### H-4. モーダルがEscで閉じない・フォーカス管理なし（WCAG 2.4.3/2.1.2）
【実測】escClosesModal: false。open時のfocus移動・close時の復帰・focusトラップいずれも実装なし（keydown 0件）。改善: Escape対応 + 初期focus + 復帰focus（約20行）。

### H-5. 職員編集モーダル: 背景クリックで編集内容が無言で破棄
時短・不可日等を入力中に外側を1クリックすると確認なしで全消失【コード :2982-2987】。改善: 差分ありなら「保存せずに閉じますか？」確認、または overlay クリックでは閉じない。

### H-6. 「曜日セルをダブルクリックで時間帯切替」は発見不可能
日別の午前/午後切替（SPEC記載機能）が dblclick + title ツールチップのみで、カレンダータブの説明文にも記載なし【コード :1927-1943】。改善: カレンダータブに明示的な全日/午前/午後切替UIを置く。dblclick依存は廃止。

### H-7. 職員・タグの「削除」も確認なし
1クリック即削除、Undo対象外（undo履歴は assignments のみ）。「編集」の真横で誤クリック距離が近い【コード :1170-1179, :1063-1071 / 05_staff.png】。改善: 「◯◯さんを削除しますか？当番表からも消えます」確認。

### H-8. A4印刷: 枠が多いと右端の列が黙って切り落とされる
4枠は印刷幅754pxちょうどに収まる【実測】が、8枠だと table 880px > 754px で `overflow-x:auto` ラッパーが印刷時にクリップ【実測 audit2_result.json printWide: overflows=true / 09b_print_8slots.pdf】。紙では欠落列に気付けない。該当: :169, :247-255。改善: print時 `overflow:visible` + `table-layout:fixed` か横向き切替、または印刷前警告。
良い点: 4枠30日はA4縦3ページに収まり、thead が各ページで繰り返される（table-header-group 実測確認）。

### H-9. セル編集モーダルに検索がなく200人規模で破綻
全職員を登録順に列挙するだけ（30人でもスクロール必須）【実測 07c_cell_edit_modal.png】。想定は200人規模。職員タブには検索がある（:1093）のにこちらにはない（:2064-2124）。改善: 検索ボックス流用 + 割り当て可能→警告ありの順ソート + チェック済みを上部固定。

## 最重要指摘トップ5（要約）

1. **C-2 「割り当てをクリア」が確認なし・Undo不能**: 1ヶ月分の手修正込みデータが1クリックで復元不能に消える唯一の操作。pushUndo追加1行+確認ダイアログで解消できるため費用対効果最大。
2. **C-1 キーボード操作がほぼ全滅（WCAG 2.1.1違反）**: カレンダー日付・当番セル・タグ・曜日チェックが全てspan/td+clickで、tabindex/keydown/ARIAがファイル全体で0件（実測）。button化ヘルパーで横断対応を。
3. **H-1 初回起動の導線ゼロ**: 空グリッドだけが表示され「職員登録→枠設定→自動割り当て」の順路がどこにもない。「説明なしで使える」という最優先方針との最大の乖離。
4. **H-3 セル編集で定員超過し放題**: 6人枠に13人チェックできても「現在: 6人」のまま警告なし（実測）。SPECの「制約違反は赤ハイライト」が手修正の中心画面で未実装。
5. **C-3 + H-8 見た目の実害2点**: 主要CTA緑ボタンとタグバッジがコントラスト3.3:1以下でAA不合格（実測値あり）。印刷は枠が5枠以上になると右端の列が紙から黙って欠落する（8枠で実測880px>754px）。
