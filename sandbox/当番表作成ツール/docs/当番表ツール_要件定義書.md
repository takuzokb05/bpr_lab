# 当番表ツール 要件定義書

## 概要

| 項目 | 内容 |
|---|---|
| 形式 | 単一HTMLファイル |
| 配布方法 | ファイル配布（インストール不要） |
| 対象 | 庁内汎用（特定部署に依存しない設計） |
| データ保存 | localStorage（ブラウザに保存） |
| 出力 | クリップボードコピー → Excel貼り付け |

---

## 機能定義

### 1. カレンダー設定

- 年月を選択すると1ヶ月分のカレンダーを生成する
- 土日・祝日はデフォルトで「休日（当番なし）」
- 祝日は手動で日付を指定して設定する
- 日ごとに以下の時間帯を設定可能
  - 全日
  - 午前のみ
  - 午後のみ
  - ※ 実際の時間管理は枠ごとの開始・終了時刻で行う（後述）
- 任意の日を「休日 ↔ 勤務日」に手動で上書き可能

---

### 2. 当番枠設定

- 枠は自由に追加・削除できる（初期値1枠）
- 枠ごとに設定する項目：

| 設定項目 | 内容 |
|---|---|
| 枠名 | 自由編集（例：「当番A」→「窓口担当」） |
| 開始時刻 / 終了時刻 | 自由設定（例：09:00〜13:00、12:00〜13:00） |
| 必要人数 | 1人〜N人（枠ごとに設定） |

時間帯の設定例：

| ケース | 開始 | 終了 |
|---|---|---|
| 終日 | 09:00 | 17:00 |
| 午前 | 09:00 | 12:00 |
| 昼のみ | 12:00 | 13:00 |
| 午前〜昼 | 09:00 | 13:00 |
| 午後 | 13:00 | 17:00 |

---

### 3. 職員管理

職員を登録し、1人ずつステータスを設定する。ステータスは複数組み合わせ可能。

#### 当番頻度

職員ごとに当番の割り当て頻度を5段階で設定できる。自動割り当て時の優先度に反映される。

| 設定 | 内部倍率 | 動作 |
|---|---|---|
| できるだけ入れる | 2.0 | 平均の2倍まで優先的に割り当てる |
| 多め | 1.5 | 平均より多めに割り当てる |
| 通常（既定） | 1.0 | 平均的に分散する |
| 少なめ | 0.5 | 平均より少なめに割り当てる |
| 出さない | 0 | 自動割り当ての対象外にする（在籍はしているが当番に入れない） |

※「出さない」は「対象外（免除）」とは異なり、期間指定ではなく恒常的に当番から外す用途（例：メンタル面の配慮、事務スキルの制約など）

#### ステータス

| ステータス | 動作 |
|---|---|
| 通常 | 制約なし |
| 時短（勤務時間帯指定） | 勤務可能な開始〜終了時刻を設定。時間帯が重なる枠にのみ割り当てる（例：〜13:00までの職員は14:00〜の枠には入らない） |
| 曜日固定 | 指定した枠×指定した曜日に確定アサイン（複数曜日設定可） |
| 公休日あり | 指定した曜日を毎週当番対象外にする（会計年度任用職員向け） |
| 不可日指定 | 個別の日付を当番対象外にする |
| 研修中（ペア） | 指定した職員とセットで同じ枠に入る。枠の数え方を選択可能：「2人で2枠」（既定。2人で必要人数を2消費）または「2人で1枠」（研修生+指導者で1人分として扱い、必要人数を1消費） |
| 対象外（免除） | 当月の指定日以降を当番対象外にする（産休・育休・異動等） |

- 職員名を変更すると当番表に即時反映される（異動時の差し替えに対応）

---

### 4. 自動割り当て

#### 優先ルール（上から順に厳守）

1. **ハード制約**（絶対に違反しない）
   - 曜日固定のアサインを確定させる
   - 時短職員を勤務時間帯が重なる枠にのみ割り当てる（時刻の重複チェックで判定）
   - 公休日・不可日の職員を割り当てない
   - 対象外職員を割り当てない
   - ペア設定された職員は必ずセットで同じ枠に入れる

2. **同日重複禁止**
   - 同一職員が同じ日に複数の枠に入らない

3. **連続当番の回避**
   - 前日・翌日に同じ職員を連続して割り当てない

4. **回数の自然な分散**
   - 職員ごとの「当番頻度」設定（倍率）に基づき、重み付きで分散させる
   - ソートキー: 重み付き全体回数（回数÷倍率）→ 枠別回数 → 同曜日回数
   - 「出さない」（倍率0）の職員は候補から除外する

#### 手動修正

- 自動生成後、各セルを手動で上書き修正できる
- 修正後も制約違反がある場合は警告表示する（任意対応）

---

### 5. 出力

#### Excelコピー

- 「コピー」ボタンをクリックするとクリップボードにコピー
- Excelに貼り付けると以下の列構成で展開される

```
日付 | 曜日 | 枠名1（担当者名） | 枠名2（担当者名） | …
```

#### 印刷

- 印刷用CSSを実装（A4縦想定）
- ブラウザの印刷機能からそのまま印刷可能

## 実装上の注意（セキュリティ・品質）

### 必ず守ること

| 場面 | NGパターン | 代替手段 |
|---|---|---|
| 職員名・ユーザー入力の表示 | `element.innerHTML = val` | `element.textContent = val` |
| イベント登録 | `<button onclick="fn()">` | `addEventListener('click', fn)` |
| 任意コード実行 | `eval()` / `new Function(str)` | 使わない |
| タイマーコールバック | `setTimeout("fn()", t)` | `setTimeout(() => fn(), t)` |
| DOM全体の書き換え | `document.write()` | 使わない |

### localStorageの読み書き

```javascript
// 書き込み
localStorage.setItem('key', JSON.stringify(data));

// 読み込み（必ずtry-catchで囲む）
try {
  const data = JSON.parse(localStorage.getItem('key') ?? 'null');
} catch (e) {
  // 破損データのフォールバック処理
}
```

### 変数宣言・要素生成

- `var` は使わない → `const` / `let` を使う
- DOM要素はcreateElementで組み立てる（innerHTML禁止）

```javascript
// NG
container.innerHTML = `<td>${name}</td>`;

// OK
const td = document.createElement('td');
td.textContent = name;
container.appendChild(td);
```

### 背景（なぜ避けるか）

- `innerHTML` はユーザー入力を経由したXSS（スクリプト注入）のリスクがある
- `onclick` 等のインラインJSは庁内CSP（コンテンツセキュリティポリシー）が `unsafe-inline` を禁止している場合に動作しない
- `eval()` は任意コードを実行できるため問題外

## 職員タグ管理

### 概要

班・雇用形態・役職などの分類を「ロジックで強制」するのではなく、**色とタグで可視化して人間が判断できる**設計にする。

### タグ設定

- タグは自由に作成・編集・削除（例：「A班」「B班」「会計年度」「管理職」）
- タグごとに色を設定（例：A班→緑、B班→青）
- 1人の職員に複数タグを付与可能

### 表示

- 職員は「カード形式」で表示し、タグ色をバッジとして視覚的に識別できる
- 当番表グリッドのセルにも職員名とともにタグ色を表示
- 「この日A班が誰もいない」などが目視で即座にわかる

### 班制約について

- 班ごとの電話・設備などに起因する制約は自動割り当てでは強制しない
- タグの色表示を見て手動修正で対応する運用を想定（8割自動・2割手修正）

---

## UI/UX方針

**「分かりやすさ」を最優先とする。**

- 操作に迷わない：初めて使う職員でも説明なしで使えることを目指す
- 設定項目は段階的に開示：最初に全部出さず、必要な時に詳細設定が出てくる構成
- エラーは即座にわかりやすく：制約違反は赤ハイライト等で一目でわかる
- モバイル対応は不要（庁内PC使用前提）、A4印刷を考慮したレイアウト
- 専門用語を避ける：「ハード制約」「アサイン」等ではなく日本語で平易に表現

## デスクネッツNEO連携（CSVエクスポート）

### 概要

当番表の内容をデスクネッツNEOのスケジュールにCSVインポートできる形式でエクスポートする。

### インポート仕様の前提（2026-09-01確認・重要）

NEOのスケジュールCSVインポートは、**登録先のユーザー/組織をNEO側のインポート画面で選択する**仕様
（機能管理者は[ユーザー／組織選択]で指定、一般ユーザーは自分の予定に読み込み）。
CSV内の「ユーザー/グループシステムID」列で登録先を振り分けることは**できない**（1ファイル=1登録先）。
このため職員ごとのシステムIDマッピングは不要であり、同日にマッピングUIを廃止した。

### 出力モード

| モード | 用途 | 内容 |
|---|---|---|
| まとめて1枚のCSV | 課内当番など共有アカウント/組織の予定として入れる | 全員分を1CSVに出力。予定欄を「枠名（職員名）」にして誰の当番か分かるようにする |
| 職員ごとのCSVをZIPで | 各職員が自分の予定として入れる | 職員1人につき1CSV（当番のない職員は出力しない）。ファイル名に職員名を含め、ZIPでまとめてダウンロード。ZIPは無圧縮STORE方式・ファイル名UTF-8フラグ付きの自前実装（外部ライブラリ不使用） |

### CSVフォーマット（19列固定・ヘッダーなし）

庁内で実運用確認済みのインポート形式（搬送便CSV運用スキルと同一形式。2026-09-02反映）：

| # | 列名 | 当番表での値 |
|---|---|---|
| 1 | ID | 0固定（新規追加） |
| 2 | 開始日 | 当番日（YYYY/MM/DD） |
| 3 | 開始時刻 | 枠の開始時刻（HH:MM） |
| 4 | 終了日 | 当番日（YYYY/MM/DD） |
| 5 | 終了時刻 | 枠の終了時刻（HH:MM） |
| 6 | 予定 | まとめ版=「枠名（職員名）」／個人別=枠名 |
| 7 | 予定詳細 | 空欄 |
| 8 | 場所 | 空欄 |
| 9 | 場所詳細 | 空欄 |
| 10 | 内容 | 空欄 |
| 11 | 情報公開レベル | 空欄 |
| 12 | 外出区分 | 空欄 |
| 13 | 重要度 | 空欄 |
| 14 | 予約種別 | 空欄 |
| 15 | フラグ | 空欄 |
| 16 | アイコン番号 | 空欄 |
| 17 | 承認依頼 | 空欄 |
| 18 | 通知の方法：メール | 空欄 |
| 19 | 通知の方法：伝言 | 空欄 |

### 制約と注意事項

- **ヘッダー行は出力しない**（インポート時「先頭行は無視する」にはチェックを入れない）
- **文字コード**：BOMなしUTF-8。改行コードはCRLF
- **区切り文字**：カンマ区切り（CSV）。全フィールドをダブルクォートする
- 旧形式（V8.0エクスポート互換23列＋ヘッダー＋BOM付き）は2026-09-02に廃止。実際のインポートで通る形式は上記19列だった

### エクスポートの流れ（ユーザー操作）

- **共有アカウント運用**: 「NEO連携」タブ →「まとめて1枚のCSV」→ アクセス権のある担当者がNEOのインポート画面で共有アカウント/組織を選んで読み込む
- **個人運用**: 「NEO連携」タブ →「職員ごとのCSVをZIPで」→ ZIPを展開し、各職員に自分の名前のCSVを渡して、各自がNEOのインポート画面で自分の予定に読み込む
