3. 今週の重要トピック

CLAUDE CODE

Claude Mythos -- HAWK-256耐量子暗号の構造的欠陥を60時間で発見

未公開モデル「Claude Mythos Preview」がNIST耐量子署名候補HAWK-256の格子構造に未利用の非自明な自己同型写像を発見。実効鍵強度を2^64から2^38に低下させる鍵回復攻撃を導出した。HAWKチームは同日NIST選考から自主撤退。指数時間アルゴリズムのため即座の実用的脅威ではないが、専門家2年分のレビューをAIが2.5日で凌駕した前例は暗号設計レビューのパラダイムシフトを意味する。7ラウンドAES-128への攻撃でも200~800倍の高速化を達成。

Claude Codeベストプラクティスの標準化

OpenHands、genai-ai.co.jp、複数の日本語メディアから、Claude Codeの運用知見が一斉に整理された週だった。核心は3つ: (1) CLAUDE.mdは200行以内に収める（超過すると精度が95%→60%に低下）、(2)「探索→計画→実装」のexplore-plan-codeワークフローが標準形（無誘導の成功率は約33%）、(3) Hooks=強制ルール、Skills=文脈的知識、Subagents=委任境界、という整理フレームワーク。大規模プロジェクトでは@importや.claude/rules/のpaths分割を推奨。月1回のCLAUDE.mdメンテナンスサイクルも提案された。

Claude Code v2.1.219 -- 深度3サブエージェントとCowork Dispatch

7/21~24のサブエージェント制御の変動（v2.1.217でネスト完全禁止→v2.1.219で深度3復活）が安定着地。CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTHとCLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS（デフォルト20）で制御可能。サブエージェントのツール呼び出しが親の承認キューから除外されるUX改善も実施。Cowork Dispatch（7/7開始）ではラップトップを閉じてもサーバー側でセッション実行が可能に。

REGULATION

EU AI法第50条 -- 8月2日施行

AIコンテンツのウォーターマーキング、AIインタラクション開示、ディープフェイクラベリングが義務化。違反罰金は世界年間売上の3%または1,500万ユーロ。AI Omnibus規制（6/29最終承認）で一部期限延長・中小企業特例あり。高リスクシステムの完全義務はAnnex III単独型が2027年12月、Annex I製品組込型が2028年8月まで猶予。同日、EUはAI Gigafactory入札も正式開始し、「規制+インフラ」の二本柱でAI主権戦略を推進。

米国AI AGENT法案 -- FXエージェントへの受託者義務

Warner上院議員のAI AGENT法案（6/29ディスカッションドラフト）が3つの柱を提示: (1) 5,000万MAU超プラットフォームへのAIエージェント相互接続義務、(2) FTC認定AIエージェントレジストリ、(3)「Custodial User Agent」登録+受託者義務。CUAは「財務管理・契約・購買を行うAI」と定義され、FX自動取引エージェントはこの定義に該当する可能性が高い。CyberScoopはFTCレジストリを「実質的なAIエージェント免許制度」と評価。

Claude for Government Desktop -- FedRAMP High認定

Claude CodeとClaude Coworkが政府機関向けにFedRAMP High認定環境で公開ベータ開始。全管理者アクションをハッシュチェーン式改ざん検出監査ログに記録、機密操作には二者承認制を採用。ATO（Authorization to Operate）サポート文書を完備。日本の自治体への直接的影響は現時点では限定的だが、政府グレードAI利用の国際標準としてウォッチすべき動き。

5. アクション提案

  1. 緊急 MCPサーバーのステートレス移行を開始する
    自前のMCPサーバーがあれば、initializeハンドシェイク除去・セッション管理コード除去・_metaフィールド追加・エラーコード変更（-32002→-32602）の4点を実施。SDKベータ版が出揃っているので移行の技術的障壁は低い。12ヶ月の猶予はあるが、早期移行でステートレス設計の恩恵（LBシンプル化・テスト容易化）を先取りできる。
  2. 緊急 CLAUDE.mdを200行以内に圧縮し、月次メンテナンスを設定する
    OpenHands検証でCLAUDE.md超過時の精度低下が確認された。現在のCLAUDE.mdを監査し、@importや.claude/rules/のpaths分割を活用して200行以内に収める。Hooks/Skills/Subagentsの使い分けフレームワークに沿って責務を整理する。
  3. 今週中 Opus 5 effortトグルでコスト最適化を検証する
    同価格帯（$5/$25/Mトークン）でlow/medium/highの3段階を切り替え可能。日常の簡単なタスクをlowに、複雑なエージェント作業をhighに振り分けることで、品質を落とさずコストを削減できる可能性がある。特にスケジュールタスクやバッチ処理での効果を測定すべき。
  4. 今週中 TradingAgentsフレームワークのFX適用可能性を調査する
    7エージェント対立構造（Bull vs Bear）のバックテスト結果（AAPL +26.62%、シャープ8.21）は印象的だが、FXへの直接適用には通貨ペア特性・レバレッジ・24時間市場への適応が必要。Claude+MCP+MT5連携が最低レイテンシという結果は、既存のFX自動売買基盤との親和性が高い。まず調査フェーズとして、フレームワークのFXバックテスト環境構築を検討する。
  5. 継続監視 AI AGENT法案のCUA定義をウォッチし続ける
    現時点ではディスカッションドラフト（正式法案前）だが、「財務管理・契約・購買を行うAI」に受託者義務を課すCUA定義はFX自動取引エージェントに直接該当する可能性がある。法案の進捗と、日本の金融庁がどう反応するかの両面で監視が必要。中国の3段階AIエージェント規制（強制報告制度）も参考事例として追跡する。
