Claude Code v2.1.86: セッションID公開とHooksの条件分岐

Auto Mode設計の内部解説: Anthropicエンジニアリングブログ

Anthropicがエンジニアリングブログで、Auto Modeの設計思想を公開した。confirmed 2段階分類器の構成で、第1段階は高速なyes/no判定、フラグが立った場合のみ第2段階でChain-of-Thought推論に入る。重要な設計方針として、分類器にはClaudeの中間推論を見せない。エージェントが「この操作は安全です」と説得的な理由を生成しても、分類器はそれを無視する。内部テストでは誤検出率0.4%、合成データでのすり抜け率5.7%。「全部許可」と「毎回確認」の間の現実的な中間地点を、データ付きで示した点に価値がある。
