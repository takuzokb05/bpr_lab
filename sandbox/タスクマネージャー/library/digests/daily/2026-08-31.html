Claude Code・エコシステム

CLAUDE.mdが「プロジェクト向け永続システムプロンプト」として再定義される

今週、CLAUDE.mdのベストプラクティスが複数メディアで特集された。共通するメッセージは明快だ：200行以内、コマンド先頭、フォーマッタと重複しない。Amit Rayのガイド[^1]が示す「CLAUDE.mdが良ければClaude Codeはコードベースを即座に理解、悪ければ30分の往復問答が必要」という逆算は、ヘビーユーザーには体感として共鳴するはずだ。Blink社の10セクションテンプレート[^2]とMaketocreate版[^3]はほぼ同一の3原則に収束しており、業界コンセンサスとして定着しつつある。実用上のニッチな知識として「HTMLブロックコメントはClaudeのコンテキストに渡されない」—つまりトークンゼロで人間向けメモを書ける点は今すぐ使える。

Claude Code v2.1.237—5週間30リリースの全貌

Uravationが日本語でv2.1.69〜v2.1.237を総まとめした記事[^4]は、高頻度更新に追いきれていないユーザーへの救済資料。Focus View（Ctrl+Alt+Fトグル）、PermissionDenied Hook（拒否イベントの自動処理）、PID名前空間分離（セキュリティ強化）、フリッカーフリーレンダリングエンジン（60%速度向上）が特に実用的な追加機能。MarkTechPostの25機能ガイド[^5]（一次ソース確認済み）によれば、Opus 4.6は1Mトークンコンテキスト（ベータ）と128K出力上限に対応—「64K〜128K」という記述は誤りで128Kが正確な値。AgentTeamsによる最大3段階の階層的サブエージェント実行も実績ある機能として紹介されている。

Claude Agent SDK—プロダクションへの実践ルート

SerpAPIのチュートリアル[^6]は、Claude Codeと同じエージェントループをライブラリとして使う実装ガイド。Python版v0.2.139とTypeScript版v0.3.233は毎週リリース中で、ファイルアクセス・シェルコマンド・マルチエージェント協調がOut-of-the-boxで利用可能。モデル選択（Opus 4.8/Sonnet 4.6/Haiku 4.5）からインプロセスMCPサーバー統合まで段階的に解説されており、「生APIループを書かずに済む」入門として完成度が高い。

AIニュース・業界動向

MCP新ロードマップ—「誕生以来最大の改定」が5重点分野を明確化（一次ソース確認済み）

GIGAZINEが2026年8月24日に報道[^7]したMCP新ロードマップは、blog.modelcontextprotocol.ioで内容確認済み。5重点分野：①Tasksエクステンション（長時間処理・信頼性）、②OAuth 2.1対応によるエージェント認証強化（DPoP・Workload Identity Federation）、③MCP Appsによるインタラクティブないダッシュボード/UI配信、④ステートレスコアによるラウンドロビンLB対応（エンタープライズスケーラビリティ）、⑤MCPメッシュ・A2A統合への伏線。Anthropic・OpenAI・BlockがLinux Foundation傘下のAgentic AI Foundationで共同標準化を推進している構図も改めて確認できた。

複数のMCP解説記事[^8][^9][^10]が並行公開されたことで、2026-07-28仕様RC（「MCP誕生以来最大の改定」）の採用が実務者レベルで加速する。Quollio Technologies[^11]はPRTimeで国内先行事例としてデータカタログへのMCP統合を発表—Claude CodeがQDICのデータ系譜・品質メタデータを直接参照できるようになる。エンタープライズデータ活用とAIコーディングの接合点として、今後の類似事例の先駆けになりそうだ。

EU AI Act透明性義務が実際に動き出した（一次ソース確認済み）

Axiosが8月28日に報道[^12]（一次ソース確認済み）：EU AI Act Article 50の透明性義務が8月2日から正式施行。チャットボット開示・AI生成コンテンツのラベリング義務が発効、違反時は最大€1500万または全世界年間売上高の3%。一方、採用ツール・信用スコアリング・法執行など高リスクAI分野への完全義務化は2027年12月2日に延期済み。EU市場向け製品を持つ日本企業は透明性開示対応が喫緊の課題で、公務員として自治体のAI調達・契約にも影響するルールとして把握しておきたい。

生成AI：「使う」から「任せる」へのステージ移行

日本語の業界トレンドまとめ[^13][^14]から見えるのは同一の方向性：Gartner予測「2026年末までに企業向けアプリの40%がタスク特化AIエージェント搭載（2025年5%未満→急拡大）」、日本AI事業者ガイドライン1.2版でのエージェントへの人間監視要件明記、モデル競争の安定化（Qwen3.8-Max 2.4Tパラメータ・コスト50%低下）。「安いモデル×賢い使い方」が勝ち筋とする市場観は、Claude CodeヘビーユーザーとしてHaiku 4.5を組み合わせる現在の運用とも一致する。

AIトレーディング

バックテストと本番の乖離問題が学術的に整理されてきた。ArXivの論文[^15]は「30日で約7%リターン（S&P500比4.5%超過）だが22%ドローダウン・再現性なし」というTradingAgentsの実例を挙げ、取引コスト・スリッページ・市場レジーム変化が本番乖離の主因と分析。推奨ワークフロー「AI for context → トレーダー判断 → ルールベースBot執行 → バックテスト検証 → デモ練習 → ハードリスク上限」はFX自動取引設計の理論的裏付けとして有用だ。
