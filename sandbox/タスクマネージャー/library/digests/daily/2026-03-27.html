Claude Code

Computer Useの正式プレビューと、成長痛としてのレート制限問題

Computer Use: AIがデスクトップを操作する時代へ

3月23日、AnthropicはClaude CodeとClaude CoworkにComputer Use機能をリサーチプレビューとして公開した。confirmed ClaudeがmacOS上でファイルを開き、ブラウザを操作し、開発ツールを起動する。まずPro/Maxサブスクライバー向けに限定提供で、CNBCが報じたデモではPDFエクスポートからカレンダー添付まで自律的にタスクを完了する様子が紹介された。Gizmodo Japanも「スマホから指示してPCを操作させる」という切り口で報道している。Windows対応は予定されているが具体的な日程は未発表。

Auto Mode: 自律実行とセーフティの綱引き

Computer Useと並行して、TechCrunchはAuto Mode（Research Preview）のローンチをバランスよく報じた。confirmed 内部AIセーフティ分類器が各アクションを実行前に安全性確認し、安全なものを自動承認、危険なものをブロックする。Anthropicは「サンドボックス環境での使用を強く推奨」としており、長時間自律実行に伴うリスクへの慎重な姿勢が見える。

v2.1.74〜v2.1.84: 3月のアップデートラッシュ

3月だけでバージョンが2.1.63から2.1.84へと急速にイテレーションされた。Qiitaのまとめ記事によると、主な新機能はRemote Control、MCP Elicitation、/copy Nコマンド、そして前述のComputer Use正式対応。英語圏の包括的まとめでは、Voice Mode（スペースキーで音声入力・20言語対応）、/loopスケジュールタスク、/effortコマンド（3段階の努力レベル設定）、Auto Memoryも紹介されている。

レート制限問題: 需要がインフラを超えた

3月23日頃から、MacRumorsが報じたようにClaude Codeユーザーから「5時間枠が1〜2時間で枯渇する」という報告が殺到した。confirmed GitHub Issue #38335にはMax 5xユーザーが90分で上限到達、Max 20xユーザーが1プロンプトで21%から100%に跳んだという報告もある。The Registerによると、AnthropicはFreeからMax 20xまで全プランで一時的にサービス提供量を削減した。Anthropicのシヒパー氏は「増大する需要に対応するためピーク時の制限を調整している」と声明を出している。裏を返せば、Claude Codeの成長速度がインフラ拡張を上回っている証左だ。

実務活用: 月400PR、サブエージェント自動テスト、楽天のHooks活用

日本の開発者コミュニティからも充実した実践事例が出てきた。KnowledgeWork社は月400件超のPRを一人チームで生産するワークフローを公開。スマートショッピングはサブエージェントによるテスト自動修正を、楽天テックはスピナーテキストのカスタマイズでGitHubリリース情報を作業中に流し読みする仕組みを公開した。Agent Teamsを使った並列作業や、Claude Code ActionによるGitHub CI/CD統合も解説されている。

Claude Code作者Boris Chernyのワークフローも深掘りされた。「10〜15の並列セッションを同時実行」「Plan Modeから必ず開始」「CLAUDE.mdを100行以内に維持」が彼の原則だという。

開発ツール競争の現在地

LogRocketのAI開発ツールパワーランキング（3月版）ではWindsurfが総合1位、Claude 4.6 OpusがSWE-bench 75.6%でモデル1位。GoogleがGemini Code Assistを個人開発者向けに完全無料化した動きも注目される。MITテクノロジーレビューは「生成的コーディング」を2026年の10大ブレークスルー技術に選定しており、MicrosoftのコードのうちAI生成が30%、Googleも25%超に到達したと報告している。

AI Trading

学術・規制・実装が三位一体で進むAIトレーディング

学術: TradingAgentsとStockBench

TradingAgents（ArXiv）は、実際のトレーディング会社の組織構造をLLMマルチエージェントで再現するフレームワークだ。ファンダメンタル・センチメント・テクニカルの各アナリスト、ブル/ベアのリサーチャー、リスクマネージャーが議論を通じて意思決定する。累積リターン・シャープレシオ・最大ドローダウンでベースラインを有意に上回る結果を実証した。

StockBenchは実市場でのLLMエージェントの取引能力を評価したベンチマーク研究で、テスト対象の大部分がバイ・アンド・ホールドを上回る成績を示した一方、推論チューニングモデルが命令チューニングモデルに対して一貫した優位性を持つわけではないという興味深い結果が出ている。

規制の同時進行: 米財務省・ESMA・日銀

規制側も急速に動いている。米財務省はFS AI RMF（金融サービスAIリスク管理フレームワーク）を公表した。confirmed NIST AI RMFを金融向けにアレンジした230のコントロール目標を含む実務的なガイダンスで、現時点では法的拘束力はないが、監査基準への影響が見込まれる。

欧州ではESMAがMiFID II下のアルゴリズム取引監督ブリーフィングを2月26日付で公表し、ストレステスト要件・事前取引コントロール・AI利用規制を明確化した。日本では日本銀行金融研究所がAI取引の法的責任に関する論文を公開し、投資判断でAIを利用して損失が生じた場合の責任の所在を分析している。米・欧・日の三極で規制議論が同時進行している状況だ。

FMSB（金融市場標準委員会）も2月の実務報告書で、AI取引モデルへの明確な人間責任者の設置を求めている。

実装最前線: LLMを実弾で動かす人たち

Zack JacksonはLLMオプション取引で$20kを$400kに増やした実験を公開した（Medium、2026年1月）。LLMが約2週間のポジション保有サイクルを特定し、モメンタムベースのプレミアム獲得戦略を自動実行した記録だ。個人の一次情報だが、再現性の検証は読者に委ねられている。

日本国内ではGoogle GeminiをAI判断エンジンにしたETH/JPY自動売買ボットの実装記事（Qiita）が出ており、毎分マーケットデータを収集してGeminiがENTER_LONG/SHORT/HOLD/EXITをJSON返却する仕組み。GMOコインはGPT-Tradeとの連携で生成AI自動売買サービスを商用提供しており、国内のLLMトレーディング商用化が進んでいる。

企業間連携では、三井物産とPreferred Networksが商品先物市場向けAIモデルを共同開発。Kaggle等で集めた計算モデルを自動選択・配分するシステムを構築している。

Ecosystem

エージェント基盤の商用化とマルチエージェントの標準化

ソフトバンク「AGENTIC STAR」: 国内エージェント商用化の象徴

ソフトバンクが3月27日に法人向け自律型AIエージェントプラットフォーム「AGENTIC STAR」を発表した。confirmed 特定ベンダーに依存せず複数のAIモデルをオーケストレーションできる設計で、タスクに応じてテキスト・画像・動画の最適モデルを動的選択する。SaaS形式でブラウザからアクセス可能。日本の大手通信キャリアが「コパイロット」ではなく「自律実行エージェント」を前面に出したことは、市場の成熟を示唆している。

NVIDIA・ガートナー: エージェントが産業構造の前提に

NVIDIAはLangChainと統合したオープンなエージェント開発プラットフォームを発表。LangChainはGitHub Stars 126k超・10億回超のダウンロードを持つ業界標準ツールであり、NVIDIAがここと組んだことでエンタープライズエージェント開発の基盤が固まりつつある。

ガートナージャパンの2026年戦略的テクノロジートレンドでは「マルチエージェント・システム」が主要トレンドとして挙がり、A2A（Agent-to-Agent）とMCPプロトコルの重要性が強調された。2030年までに80%の組織がAIネイティブ開発プラットフォームを採用するとの予測も出ている。

日本のAIエージェント実態: 理想と現実のギャップ

大和総研のレポートは冷静だ。2025年を「AIエージェント元年」と振り返りつつ、62%の企業が試験導入したものの本格スケールできたのはわずか23%。Google Cloudが国内120社の生成AI導入事例を公開した一方で、現実には「がっかりしない導入手法」を模索するフェーズにある。

デジタル庁「源内」: 国産LLM 7件を選定

デジタル庁がガバメントAI「源内」用の国産LLMを選定した。confirmed NTTデータ「tsuzumi 2」、KDDI/ELYZAの「Llama-3.1-ELYZA-JP-70B」、Preferred Networks「PLaMo 2.0 Prime」、ソフトバンク「Sarashina2 mini」、日本電気「cotomi v3」、富士通「Takane 32B」、カスタマークラウド「CC Gov-LLM」の7件。5月頃に約18万人の政府職員向け大規模実証を開始し、2027年4月から正式な政府調達に移行する予定。

Industry News

Mythos リーク、IPOレース、TurboQuantショック

Anthropic「Mythos」: データリークが明かした次世代モデル

3月26日、Fortuneがスクープした。confirmed Anthropicのコンテンツ管理システムの設定ミスにより、コードネーム「Mythos」（新モデル階層名は「Capybara」）の存在がリークされた。Anthropicは「これまで開発した中で最も強力」「能力の段階的飛躍」と評し、ソフトウェアコーディング・学術推論・サイバーセキュリティの各テストでClaude Opus 4.6を「劇的に上回るスコア」を記録したとされる。同時にリークされた内部文書はサイバーセキュリティリスクの急増を警告しており、能力と安全性の緊張がより先鋭化している。

IPOレース: AnthropicとOpenAIの上場競争

Bloombergは3月27日付で、Anthropicが2026年10月にもIPOを実施する方向でGoldman Sachs、JPMorgan、Morgan Stanleyと協議中と報じた。confirmed 調達額は$60B超との報道もあり、2月に確保した$30B（評価額$380B）に続く動きだ。一方OpenAIも2026年Q4以降のIPOを準備しており、$850B+の評価額を正当化するためチャットボット路線から「生産性ツール」への転換を図っている。AI業界の二大巨頭が上場レースに入ったことで、業界構造の転換期に入った感がある。

GoogleのTurboQuant: メモリ圧縮の衝撃波

Googleが3月25日に発表した「TurboQuant」は、LLMのKey-Valueキャッシュメモリを最大6倍削減し、NVIDIA H100上で最大8倍の高速化を達成する圧縮アルゴリズムだ。confirmed ICLR 2026で発表予定。精度を損なわず3ビットまで圧縮でき、モデルの再トレーニングも不要。SK Hynix株が6%下落、Samsung株も5%近く下落するほどのインパクトがあり、Cloudflare CEOが「GoogleのDeepSeek」と評した。AI推論コストの構造を変える可能性がある。

AI資金調達: 史上最大の月を記録

SiliconANGLEの報道によると、2026年2月はスタートアップ資金調達で史上最大の月次記録（$189B）を達成した。OpenAI($110B)、Anthropic($30B)、Waymo($16B)の3社が牽引。TechCrunchのトラッカーは2026年最初の7週間で$100M以上調達した米国AIスタートアップを17社リストアップしており、xAI($20B)、ElevenLabs($500M)、SkildAI($1.4B)なども名を連ねる。2026年Q1時点で2025年全体の50%超の資金が既に調達済みという異常なペースだ。
