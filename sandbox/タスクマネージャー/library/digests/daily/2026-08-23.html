主なBreaking Changeを整理する：

| 変更点 | 影響 |

|--------|------|

| httpx → httpx2 移行 | カスタムHTTPクライアントを使っている場合は要修正 |

| Python 3.9以下のサポート終了 | 3.10+必須 |

| Text Completions API削除 | 使用中なら Messages API へ移行 |

| async `.with_raw_response` 変更 | `await response.parse()` が必要になった |

| AnthropicBedrock AWSリージョン未設定時エラー化 | 公式記事には未記載のBreaking Change（リリースノートで確認） |

`temperature`・`top_p`・`top_k` パラメータも Messagesメソッドから削除されているので、

引数で直接渡していたスクリプトは確認が必要だ。

移行の手順：Claude Code v2.1.239以降では `/claude-api upgrade` コマンドが

0.x→1.x移行を半自動化してくれる。まずClaude Codeをアップデートして

このコマンドを実行するのが最短ルートとなる。
