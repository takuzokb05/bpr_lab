非エンジニア職場への浸透——定量事例が語る現実

Claude Code道場がまとめた日本企業20社の活用事例は、エンジニア以外への浸透を裏付ける定量データが揃っている。工場の作業手順書・安全衛生マニュアル約200件の見直しが従来比3倍速、新人習熟期間が2週間から10日に短縮。カスタマーサクセス部門ではサポートチケット返信作成が週10時間→3時間に減り、チャーン率が月2.3%→1.4%に改善した事例も報告されている。週数十本・1本15,000字以上のブログ記事生成や月次レポート自動化など、業種を問わず「書く作業」の変革が進んでいる。

IDE連携でも進化は止まらない。VS Code 1.128での強化（Visual Studio Magazine報告）は「yet another boost」と表現されるほど更新頻度が高く、VS CodeがClaude Code利用の主要経路として事実上定着していることを示している。

MCPエコシステムの構造転換——ステートレス化と企業認証

MCP 2026-07-28仕様変更の最大のポイントはステートレス化だ。従来のMcp-Session-Idヘッダとプロトコルレベルのセッション管理が廃止されることで、任意のMCPリクエストをどのサーバーインスタンスにもルーティングできるようになる。スティッキールーティングや共有セッションストアが不要になり、AWS ALB・CloudflareなどのPaaSで普通のHTTPインフラそのままMCPサーバーをスケールできる（HackerNoon詳報）。

企業認証（EMA: Enterprise-Managed Authorisation）はStableに昇格済みで、Okta・Microsoft・Asana・Figmaなどが採用。IDプロバイダー経由でMCPサーバーへのアクセスを一元管理できる。日付注意: InfoQ記事では「2026-07-28仕様でStable昇格」と書かれているが、ファクトチェックによりEMA Stable昇格は実際には2026年6月18日の模様（EMA機能内容は正確）。

規制の二正面作戦——中国の施行と米国の立法ラッシュ

一次ソース確認済み（注記あり）: 中国の「知能エージェントに関する実施意見」が7月15日から施行開始。ただし規制対象は「人型AI対話（AIコンパニオン）」に特化しており、「全AIエージェント専用規制」という表現は正確ではない。Doubao/Qwen停止・14,000件以上の非準拠エージェント削除は確認済み。

米国では2026年Q2だけで35本以上のAI関連法が成立（Inside Global Tech報告）。イリノイ州が年間売上5億ドル超のフロンティアモデル開発者に独立安全計画の年次監査を義務付ける米国初の州法を制定。医療保険のAI活用に人間レビューを義務付ける法律もアラバマ・ジョージア両州で成立。FTCはAIモデルの「truthful outputs」を変更させる州法についてのポリシーステートメントを公表し、パブコメを2026年7月31日まで募集中（Federal Register掲載）。FX自動売買など実運用AIシステム開発者が把握すべき規制リスクが急速に具体化している。
