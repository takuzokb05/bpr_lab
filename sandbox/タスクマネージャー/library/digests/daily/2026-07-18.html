Claude Code・エコシステム

MCPがインフラ層へ：ステートレス化とエンタープライズ化

MCPエコシステムは2026年後半に入り、成熟の段階へ移行しつつある。7月28日最終版リリース予定の仕様RC（SEP-2575/SEP-2567）における最大変更はステートレス化だ。従来のinitialize/initializedハンドシェイクとMcp-Session-Idヘッダが廃止され、スティッキーセッション不要でラウンドロビンLBが動作可能になる。14,000以上のサーバー・SDK累計9,700万DLを抱えるエコシステムには10週間の移行ウィンドウが設定されており、Claude CodeのMCPサーバー開発者は早期対応を推奨される。（MCP 2026-07-28 RC）

この仕様改定と並走する形で、エンタープライズ採用も加速している。X（旧Twitter）が6月30日に公式MCPサーバーを開始したことはMCPが事実上の業界標準となったことを示すマイルストーンであり、OpenAI・Google・Microsoft・Anthropicを横断してMCPが採用される構図が固まった。国産SaaS（楽楽精算・freee・kintone）の対応も進んでいる。（TechCrunch）

Claude Agent SDK（旧Claude Code SDK）は6月15日から独立した月次クレジット課金に移行し、プロダクトとして本格格上げ。コード実行ツールが全言語対応（Python/TS/Go/Java/Ruby/PHP/C#）となり、Enterprise向け管理者APIも追加された。月次検索ボリュームが1年で50→14,800件（約300倍）と急増しており、開発者コミュニティの裾野が急速に広がっている。（releasebot.io）

Claude Code Week 29：エージェント実用化が加速

Week 29の目玉はArtifacts βと3段階ネストの2つだ。Artifactsはセッション成果物をclaude.aiのライブ共有ページとして公開・インプレース更新できる機能で、チーム内での成果物共有フローが変わる。3段階ネストの階層型エージェントスポーンにより、複数モジュール横断タスクを親→子→孫の構造で分解できるようになった。Opus 4.8がMax/Enterprise向けデフォルトとなり、複雑なエージェントタスクの標準品質が底上げされた。（releasebot.io）

実務活用という観点では、日本語ガイドとチートシートが今週まとめて公開された。Uravationによる2本（6月新機能活用ガイド・業務自動化10事例）は、Cron+Claudeによる議事録自動化パイプラインの実例と実装プロンプトを公開しており、即日導入できる内容だ。TechBytesのチートシートはHook 4種の使い分け（HTTP/MCPツール/プロンプト/エージェント）を整理しており、タスクマネージャーのスキル設計判断の参考になる。CLAUDE.md 200行以下推奨・HTML commentはトークン消費なしという設計指針も明記されている。（Uravation / TechBytes）
