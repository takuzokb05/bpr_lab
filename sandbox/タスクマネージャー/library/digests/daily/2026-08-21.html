Claude Code・エコシステム

プラグインエコシステムが成熟期へ

Claude Codeのプラグイン市場が量・質ともに充実してきた。MediumとScrimbaが同日に異なる視点の記事を公開したことで、現状の全体像が見えやすくなっている。

公式マーケットプレイスには250本以上、コミュニティカタログには2,000本超が存在する。Mediumの記事（<https://medium.com/@hii_mohit/9-claude-code-plugins-every-developer-should-install-in-2026-9a35b8fe5a83>）では実務ユースケース付きで9本を推奨し、Figma・Playwright・Vercel・PostgreSQL・GitHubのMCPが上位に挙げられている。`/plugin`コマンドで一括導入できる点も今年の大きな改善だ。

一方Scrimbaのレポート（<https://scrimba.com/articles/best-claude-code-plugins-2026/>）は11本を実テストして4本のみを推奨する厳しめの評価を出しており、「過剰プラグイン導入によるコンテキスト肥大化リスク」を明示的に警告している。Skills・Hooks・Subagentsの3層でプラグインを評価する枠組みも提示しており、導入判断の基準として使える。「まず触ってみる」派には良いカウンターバランスになる視点だ。

コマンドとVSCode統合：2026年8月の現状

Qiitaのコマンド完全ガイド（<https://qiita.com/superdora-cloud/items/979295520a85f28e0cab>）はコマンド体系の変遷を整理しており、2026年内で行われた整理が把握できる。`/review`→`/code-review`統合、`/fork`の再定義、`/agents`廃止など、スラッシュコマンドの大規模な棚卸しが行われた。また、v2.1.221でサンドボックス資格情報ファイルに`mode: "mask"`が追加され、Linux/WSL環境で外部APIに実値を渡さずに呼び出せるようになった点はセキュリティ改善として重要。一次ソース確認済み：Opus 5が2026年7月24日リリース、1Mコンテキスト、Opus 4.8と同価格（$5/$25/Mトークン）。

VSCode連携の最新状況をまとめたUravation記事（<https://uravation.com/media/claude-code-vscode-integration-complete-guide-2026/>）も同じ内容を日本語で補足しており、Focus view（ツールログ折りたたみ）とマスクモードの実設定手順が丁寧に解説されている。Opus 5デフォルト化による1Mコンテキスト拡大でコーディング体験が向上している点も確認済みだ。

マルチエージェントアーキテクチャとSDKの進化

Temboのマルチエージェントガイド（<https://www.tembo.io/blog/claude-code-multi-agent-orchestration>）は、Claude Code 2026の構成を3層で整理している。①同一セッション内のサブエージェント（軽量並列処理）②Agent Teams（独立コンテキストの並列チームメート、タスクリスト経由で相互メッセージ可能）③外部オーケストレーター（複数リポジトリ横断）。Claude Agent SDKへの統合により、これらが個別実装不要で使えるようになったのが2026年の変化の核心だ。

TecniForge記事（<https://tecniforge.com/claude-agent-sdk-2026-features/>）は「Code with Claude」開発者イベントで発表されたAgent SDK 2026の新機能を詳報している。「Dreaming」（長期計画・バックグラウンド処理）、「Outcomes」（成果物追跡・ゴール到達度可視化）、「Claude Finance」（財務分析・レポート生成等の10エージェント）が主要トピック。Managed Agentsの強化点として、アクティブセッション中にツール・MCP設定のライブ更新が可能になり（再起動不要）、100K+トークンのツール出力サポートも追加された。ツール実行を自前インフラで行いつつオーケストレーションをAnthropicに委託する「外部実行」モードは、セキュリティ要件の厳しい組織向けに有用なオプションだ。

MCPが事実上の業界標準へ

LabMemoの日本語MCP完全ガイド（<https://labmemo.com/mcp-server-openai-google-microsoft-ai-2026/>）は、2026-07-28仕様の最大の変化「プロトコルのステートレス化」を解説している。セッション依存が廃止され、一般的なWebサービスと同様の水平スケーリングが可能になった。Anthropic・OpenAI・Microsoft・Google全4社が採用表明し、Linux Foundationへの寄贈も決定。国内では117選MCPディレクトリ（34カテゴリ）が整備され、SansanなどのSaaSも公式MCP提供を開始している。
