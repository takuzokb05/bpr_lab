Claude Code・エコシステム

9月1日の価格改定と直近のAPI変更 ✅一次ソース確認済み

Anthropicが8月に入り複数の重要変更を実施中。Claude Sonnet 5のプロモーション価格（$2入力/$10出力/MTok）は8月31日で終了し、9月1日から$3/$15の標準料金に移行する。ただし新トークナイザーが同一テキストで約30%多くカウントするため、実効コスト増は50%超になる可能性がある（eesel AI / finout.io試算）。Claude Codeサブスクライバー向けの50%週次使用量ブーストは8月19日まで延長されているので、今週中の集中活用が得策。

モデル廃止も進む。Opus 4.1は8月5日（本日）退役、Opus 4.7はFast modeが廃止されspeed: "fast"を指定するとエラーを返すようになった。移行先はOpus 5またはOpus 4.8。レガシーWorkbench APIと実験的プロンプトツールAPIは8月17日廃止予定。

API面ではMid-conversation tool changes（ベータ）が登場。Fable 5/Mythos 5/Opus 4.8/Opus 5で、会話の途中でツールの追加・削除が可能になった（ヘッダー`mid-conversation-tool-changes-2026-07-01`で有効化）。プロンプトキャッシュを維持しながらツールセットを動的に変更できるのは、複雑なエージェントアーキテクチャにとって重要な機能追加。Fallbacksパラメータに"default"モードも追加され、Anthropic推奨のフォールバックモデルを自動適用できるようになった。

Claude Codeの実践活用—スキルのセキュリティと活用パターン

Claude Code Skillsに関して重要なセキュリティ警告が出た。Snyk社の調査によれば公開スキル全体の36.8%にセキュリティ問題が存在する。Prompt Injection・権限昇格・機密漏洩リスクが含まれており、安全な活用基準（公式リポジトリ・著名開発者のスキルを優先、SKILL.md内容のコードレビュー必須）を守ることが推奨されている。自作スキルを使うこのリポジトリの運用方針は正解といえる。

実践ガイドとしては、データエンジニア向けにSkills（パイプライン最適化）・MCPs（BigQuery/Snowflake/dbt Cloud接続）・Hooks（デプロイ前データ検証）の3軸活用が解説された。FX自動取引のデータパイプライン設計にも転用できるパターンが多い。またClaude Code + Cursorのハイブリッドワークフローでは、Claude Codeをバックグラウンドエージェント（テスト実行・ドキュメント生成・セキュリティレビュー）として使いながらCursorでリアルタイム編集する分業が効率的とされている。CLAUDE.mdを両ツールで共有できるルールセットとして設計することがポイント。

AIニュース・業界動向

EU AI Act施行開始—正確な制裁金ティアを把握する

2026年8月2日、EU AI Actが「適用」フェーズから「執行」フェーズへ移行した。ただし注意点がある：8月2日から始まったのは第50条の透明性義務のみ。具体的には(1)チャットボット等の対話型AIはユーザーにAIと対話していることを明示する義務、(2)AI生成・改変コンテンツ（ディープフェイク含む）へのラベル表示義務の2点だ。高リスクAI義務はDigital Omnibusパッケージにより2027年12月2日（製品組込型は2028年8月2日）まで猶予。

制裁金についても誤情報が流通しているので整理する。透明性義務（第50条）違反の制裁金は最大€1,500万または年間売上高の3%（高い方）。7%は第5条の禁止行為違反に適用されるが、こちらの施行は2026年12月2日から。「7%が日本企業にも適用」という記事が出回っているが、これはティアの混同であり誤り（一次ソース確認済み）。日本企業でEUユーザーへのAIサービスを提供している場合、今すぐ対応が必要なのは「AIと対話していることの明示」と「AI生成コンテンツへの機械可読な透明性表示」の2点のみ。同日、カリフォルニア州AI透明化法も施行（月間100万超ユーザーのAI提供者に無料判定API提供義務）。

> 参考: EU公式発表 / 日本語解説（日本AI開発センター）

Sakana AI「Namazu」—国産LLMの実態 ✅一次ソース確認済み（注釈あり）

Sakana AIが8月3日、日本語特化LLM API「Sakana Namazu」の提供を開始した。日本語ベンチマーク（FairPoliticsQA 34.1%→56.3%等）での向上は確認されているが、モデルの実体はMoonshot AI「Kimi K2.6」の日本語・ビジネス向けファインチューニング版であり、独自開発モデルではない。価格は$0.95/M入力・$4.00/M出力。EU/EEA/UK/スイスでは現時点でGDPR対応中のためAPI提供なし。「国産LLM」として期待値を置くなら、この実態は把握しておきたい。
