Claude Code・エコシステム

8月29日アップデート：3つの即効性ある変更（一次ソース確認済み）

8月29日リリースのClaude Code最新版は、ヘビーユーザーほど恩恵が大きい。

まず Linuxバイナリが約75MB（従来比約1/4.5）に圧縮された（zstd採用）。CI/CD環境でのインストール時間短縮に直結する。

次に `/cost`・`/usage`・`/tasks` コマンドにトークン詳細表示 が追加された。セッション・タスク単位でトークン消費がわかるようになったため、コスト最適化の打ち手が立てやすくなった。

`/permissions` 画面には Auto modeタブ が加わり、デフォルトルールセットの確認とallow/denyルールのUI追記が可能になった。

もっとも注目すべきは `--restricted mode` の追加だ。Bash実行・WebFetchを無効化し、ファイルツールをworking dir内に限定するセキュリティ強化モード。信頼できないコードベースのレビュー・監査用途に使える。「小さく試して実績を積む」スタイルで、まずレビュー専用セッションにこのモードを組み合わせてみると判断しやすい。

v2.1.245はLinux最新glibc環境での起動クラッシュバグも修正済み。[^1]

Hooks + MCPで広がる自動化の射程

今日はHooksとMCPに関する実践記事が計3本出た。ストーリーとして読むと「Claude Codeの自動化できる範囲がさらに広がった」という一言に集約できる。

Hooksの活用パターン（2026年チュートリアル、全21イベント対応）は3軸に整理される——①enforcement（lint・安全ゲート・監査ログ）②observability（コマンドロギング・Slack通知）③automatic side effects（フォーマット自動適用）。

スラッシュコマンドでデプロイをトリガーし、PostToolUse hookでBashコマンドを自動ログする複合パターンは、運用中のFX自動取引ログ管理にそのまま転用できる発想だ。[^2]

MCP実践では4系統が有用と評価されている——GitHub公式MCP（PR作成・Issue検索を自然言語で）、PostgreSQL MCP（マイグレーションSQL自動生成）、Playwright（E2Eテスト自動化）、Context7（ライブドキュメント取り込みでハルシネーション激減）。

MCPの2026-07-28仕様では ステートレスプロトコルコア に転換しており、設定シンプル化・ロードバランサ対応が実現した。月間97億回超のSDKダウンロードを誇り、Linux Foundation傘下Agentic AI Foundationが統治する本格エコシステムになった。[^3][^4]

Claude Agent SDK：90分でエージェント構築

Anthropicが無償公開するClaude Agent SDKのハンズオンガイド（Tech Insider）が出た。

`@tool` デコレータで任意のPython関数をClaudeが呼べるツールに変換、`query()` でエージェントループを起動するだけで、ファイルR/W・Bash実行・WebSearch・サブエージェント並列起動がゼロ設定で使える。

実装例として「リポジトリトリアージエージェント」（TODO/FIXME/HACKコメントをスキャン→サブエージェントで重大度評価→Markdownレポート集約）が示されており、CI組み込みの構成参考になる。[^5]

AIニュース・業界動向

モデル選択の実務判断材料：Opus 5 vs Fable 5（一次ソース確認済み）

DataCampがClaude Opus 5（2026-07-24リリース）とFable 5（2026-06-09）の詳細比較を公開した。

価格差はちょうど2倍——Opus 5が$5/$25/Mトークン、Fable 5が$10/$50/Mトークン。

両モデルとも1Mコンテキスト・最大128k出力に対応し、コーディング・知識作業ではほぼ同等以上の性能。

実務的な使い分けは明快：Fable 5が必要なのは政府輸出規制ゲートやMythos-class安全審査が必須の場合のみ、それ以外はOpus 5一択でコストを半減できる。

注：「Opus 5がFable 5を上回る」という記事の一部主張は一次ソースで確認できず、誇大表現の可能性がある。Frontier-Bench v0.1スコア43.3%（Opus 5）は確認済み。[^6]

フレームワーク勢力図の地殻変動（一次ソース確認済み）

エージェントフレームワーク選定の判断基準が更新された。

AutoGenがメンテナンスモードに移行済み（移行開始は2025年10月）。長期プロジェクトでは1〜2年内の移行計画が必要になる。

代替として注目すべきは Microsoft Agent Framework 1.0（2026-04-03リリース確認済み）——Semantic Kernel + AutoGenを統合した統一エンタープライズ基盤で、厳格セキュリティ要件にも対応。

LangGraph は月間PyPIダウンロード3000万超、金融機関・製造業での本番採用が増加しており複雑ワークフローの本命。

CrewAI v1.13.0（2026年4月）はGPT-5・マルチモーダル対応を追加しチームシミュレーション用途で健在。

富士通研究所フレームワークを含め、主要プレーヤーはすべてGoogle A2A + Anthropic MCPに対応済みで、エコシステム横断通信が実現した。[^7]
