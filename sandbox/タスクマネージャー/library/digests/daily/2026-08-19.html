MCPのステートレス化でエージェントインフラが変わる（一次ソース確認済み）

MCP v2026-07-28が業界最大の改訂として複数方向から詳解された。initialize/initializedハンドシェイクとMcp-Session-Idヘッダの廃止が最大の変更で、全リクエストが自己記述的になったことでロードバランサーが任意インスタンスにルーティング可能となる。要するに、MCPサーバーが普通のステートレスWebサービスとして扱えるようになった。

GoogleはこれをDevelopers Blogで詳解しており、Anthropic・Microsoft・Googleが共同でエコシステムを構築している構図が改めて明確化された。Enterprise Managed AuthorizationがStableに昇格し、組織がMCPサーバー認可を一元管理できるようになったことも見逃せない。移行コストは低く、12ヶ月の猶予期間が設けられている（MCP公式ブログ・Developers Digest・Google Developers Blog）。

Claude Agent SDK（Claude Codeと同じエージェントループを開発者向けに公開）の本番投入ガイドも公開されており、agent-memory-2026-07-22 betaヘッダによるメモリAPI安定化がプロダクション利用の実用的な道筋を示している（Totalum）。

AIトレーディング

LLMトレーディングの現実：バックテストと本番の乖離

LLMを使った自動取引について、2026年の現状評価が出揃った。バックテストでは好成績を記録するが、本番では取引コスト・スリッページ・マーケットレジーム変化で大幅乖離するのが典型パターンとして繰り返し報告されている。注目すべきはRobinhoodが2026年5月にAIエージェントの証券口座直接接続を発表した点で、「アジェンティックファイナンスの始まり」として業界の注目を集めている。

オープンソースのTradingAgentsは記事では「80,000+スター」と表記されているが、実際は約60,000スター（複数ソース確認で不一致判明）。LangGraph上の7エージェント構成（アナリスト→リサーチャー→リスクマネージャー→トレーダー）というアーキテクチャ自体は原著論文由来で信頼性が高い（CoinEdition・AlgoInsights/Medium）。

FX自動取引への応用としては、マルチモーダルLLMによるチャート画像読み込みと外部センチメント分析の多層フィルター組み合わせが実例として紹介された。まず汎用LLM（Claude/Perplexity等）をリサーチ・分析ツールとして使うところから段階的に特化ツールへ移行する構成が推奨されている（genai-ai.co.jp）。
