Claude Code・エコシステム

MCP 2026-07-28：ステートレス化でエンタープライズの壁を突破

MCP（Model Context Protocol）の最新仕様 2026-07-28 が正式リリースされ、アーキテクチャが根本から変わった。最大の変化は「ステートレスコア」—サーバー側のセッションストアが不要になり、ラウンドロビンLBでそのままスケールアウトできる。ヘッダーベースルーティングが旧来の sticky session 問題を解消し、TypeScript/Python SDK（ともに累計10億ダウンロード超）はv3.0+で自動対応済み。OAuth/OIDCの強化でエンタープライズ認証も容易になった。さらに「MCP Apps拡張」でサーバー側からReactダッシュボード等のUIコンポーネントをホストにプッシュできる新機能も加わった。

Cloudflare公式ブログはWorkers上でのネイティブMCPホスティングを解説し、WAF・R2・Durable Objectsとのシームレスな連携パターンを公開した（Cloudflare Blog）。AAIF（Agentic AI Foundation）は移行ガイドを出し、既存ステートフルサーバーからの移行推奨パスは「セッションIDをHTTPヘッダーに移動し、Tier 1 SDKの依存を更新するだけ」と整理している（AAIF）。公式仕様はMCP Blogで確認可能。

「小さく試して実績で引っ張る」スタイルには好都合な変化—まずSDK依存を更新するだけで新仕様の恩恵が得られる。本番での段階的移行（カナリアリリース）が推奨されており、リスクを絞りながら移行できる。

Claude Code 8月：実務直結の新機能群とベストプラクティス

KAWAI氏の日本語解説（note）によると、8月前半のClaude Code主要機能は実務優先でこの順に使いたい：Focus view（Ctrl+Alt+F）でチャットUIをシンプル化→Concise output styleモードで結果先行の出力（「簡潔に」プロンプト不要）→xhigh effortモード（Opus 4.7向け、複雑推論の精度向上）→Staggeredファンアウト（同一プレフィクス兄弟エージェントがキャッシュ再利用でコスト削減）。

業務自動化の実践面では、Uravation社が10事例と実装プロンプトを公開した（Uravation）。請求書・議事録・帳票・データ照合など定型業務で月30〜80時間削減、誤差率0.1%未満の精度を達成した事例もある。公務員業務でも帳票・月次集計・データ照合あたりは直接参考になる領域だ。

SmartScope社のアドバンスドベストプラクティス11選（SmartScope）は概念整理として有用。核心は「CLAUDE.mdはお願い、Hooksは保証」—ゼロ例外の要件はHooksで実装するという原則と、アーキテクチャ選択の4軸（ルール強制→Hooks、文脈知識→Skills、委任境界→Subagents、常時ガイダンス→CLAUDE.md）。

Claude Agent SDKとAdmin API：エンタープライズ展開の整備

Claude Agent SDK（旧Claude Code SDK、2025年9月に改名）の包括ガイドが公開された（Hidekazu Konishi）。1000以上の公開MCPサーバーに接続でき、MCP統合の命名規則はmcp__servername__toolname。Managed Agentsはallowed_domainsなどでドメインレベルのセキュリティ制御が可能になった。

同時期に業務ハックLabがまとめた8月アップデート総括（YouGears Lab）では、Admin APIのユーザー管理エンドポイントGAが特筆される—Enterprise組織でメンバー・招待・カスタムロール管理がAPIで完結するようになった。組織制度は「入念にリサーチしてから動く」ポリシーの実践として、Admin API周りの設計は一度しっかり調べておきたい。

EU AI Act施行と規制対応の進捗

AIトレーディング

GPTrader（GPTrader）がFX向けAIエージェント2026年版レビューをまとめた。FX Prime Bot（MT5連携、ML+LLMセンチメント分析）とTradingAgents（マルチエージェントLLMフレームワーク、ファンダメンタル+テクニカル+センチメント統合）が主要評価対象。

結論は手厳しい：「バックテストでは印象的な成果を示すが、ライブ取引ではトランザクションコスト・スリッページ・マーケットレジーム変化が実績を大きく削る」。LLMは固定ルールシステムより柔軟だが予測不可で説明責任が困難という整理も重要な視点だ。現在FX自動取引を運用しているなら、AIエージェントを「判断の補助」として組み込む前にライブ vs バックテスト乖離の計測を先行させることが分かる。
