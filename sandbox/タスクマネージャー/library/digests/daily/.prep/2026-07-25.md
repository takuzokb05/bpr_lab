## Claude Code・エコシステム

### 7月アップデートの全体像

7月のClaude Codeは機能追加とアーキテクチャ整備が同時進行した。7/16に追加された `/fork` コマンドは現在の会話をバックグラウンドセッションにコピーしながら作業を継続できる機能で、並列作業フローを一段引き上げる。あわせて `/subtask` がインセッションサブエージェントの正式コマンドとして `/fork` と役割分担し、セッション全体でのWebSearch呼び出し数制限とサブエージェントスポーン上限も追加された（暴走ループ防止）。7/20リリースの `sandbox.filesystem.disabled` 設定はファイルシステム分離をスキップしつつネットワーク出口制御を維持でき、サンドボックス戦略の細かい調整が可能になった。

研究機関VILA-Labのリポジトリ「Dive into Claude Code」では、これらの設計原則（Tools/Skills/Hooks/MCP/Subagents/Sessions）を体系的に整理し、Claude Codeを「AIエージェントシステム設計のリファレンスモデル」として位置づけている。実装者よりも研究者視点の資料だが、アーキテクチャ判断の根拠を言語化するには有用。
([Dive into Claude Code](https://github.com/VILA-Lab/Dive-into-Claude-Code) / [MeanCEO July 2026 Roundup](https://blog.mean.ceo/claude-code-news-july-2026/))

### 拡張プリミティブの整理と実践

Skills・Hooks・Subagents・MCPという4拡張手段の役割が2026年時点で再整理されている。要点は「**Hooks = 決定論的ガードレール、Skills = on-demand知識パック、Subagents = 委任境界、MCP = 外部ツール/データ統合**」という明確な分業。Skillsはメタデータのみ常時ロードされるためコンテキスト消費を抑えつつ多数共存できる。Pluginsはこの4つをひとつのインストール可能なパッケージに束ねた上位概念として登場した。
([Totalum Skills Guide](https://www.totalum.app/blog/claude-code-skills-totalum) / [SmartScope Best Practices](https://smartscope.blog/en/generative-ai/claude/claude-code-best-practices-advanced-2026/))

CLAUDE.mdのベストプラクティスとして「**200行以下に保つ**」原則の根拠が示された。Chroma 2025ベンチマークでは全フロンティアモデルが入力増加とともに精度が95%→60%以下に低下（コンテキスト劣化）。「なぜ（Why）を書く」ことでモデルがエッジケースを汎化できるという設計指針も実証されている。
([DEV.to CLAUDE.md Guide](https://dev.to/nishilbhave/claudemd-best-practices-the-complete-2026-guide-435j))

日本語環境の実務者向けには、KEITOによるNote記事がSkill構成・SKILL.mdの書き方・業務スキルテンプレートを日本語で体系化している。非エンジニアにも適用しやすい業務自動化スキルの紹介が中心。
([Note: 必須スキル11選](https://note.com/keito_12kk2/n/n02fa151f551b))

### APIとSDKのレイヤー変化

Anthropic APIのリリースノートまとめ（一次ソース確認済み・ただし**価格情報に誤りあり**）によると、**Opus 5は$5/$25/Mトークン**（記事の$10/$50という記載は誤りで、これはFable 5の価格）。Opus 5のリリース日（7/24）・Fast mode廃止（7/24）は正確。`speed: "fast"` リクエストが現在エラーを返すため、Fast modeを利用していた場合は早急に設定変更が必要。7月にはSonnet・HaikuのAPIレート制限がOpusと同等に引き上げられた。
([Fazm API Release Notes](https://fazm.ai/t/anthropic-latest-api-release-notes-2026))

Claude Agent SDKはManaged Agentsの下位層に位置し、スケジューラ・成果評価機能が追加されている。CLAUDE.md/Skills/Subagents/Hooks/MCPをプログラマティックに操作でき、繰り返し実行・バッチ処理・外部イベントトリガーの用途でCLIより適切。
([Totalum Agent SDK Guide](https://www.totalum.app/blog/claude-agent-sdk-totalum-2026))

MCPは公式レジストリ9,400以上のサーバーを抱え、Claude Code・Cursor・VS Codeなど主要IDEで利用可能な標準インフラになった。月間9,700万SDKダウンロードは全主要AIベンダーが対応済みという事実の裏づけ。
([Fungies MCP Guide](https://fungies.io/mcp-servers-developers-guide-2026/))

### EU AI Act 8月2日施行（一次ソース確認済み・罰金体系に補足あり）

**2026年8月2日**がAI規制の最重要日付となる。EU域内で稼働する大多数のAIシステムにEU AI Actのコア義務が適用される。即日施行の透明性義務はAIチャットボットを使用している旨のユーザー通知を義務付ける。罰金については記事の「最大1,500万ユーロまたは3%」は高リスク違反の数値で、禁止行為違反は最大€35M or 7%、情報虚偽提供は€7.5M or 1%という段階的体系が正確。EUへのAIサービス提供を検討している場合は8月2日前に確認が必要。

## AIトレーディング

LLMトレーディングは「実験的アイデア」から金融界の主要話題に成長した。転換点はRobinhoodが2026年5月に発表した「AIエージェントとブローカーアカウントの直接接続」で、CEOは「エージェント型ファイナンスの始まり」と表現している。機関投資家の主流は「クオンツ-AIハイブリッドシステム」—古典的統計モデルとAI層を組み合わせ、ポジションサイジングとエッジケース処理をAIが担う構成。完全自律型エージェントはフラッシュクラッシュ等の異常イベントでの誤動作リスクが依然として課題。
([CoinEdition LLM Trading 2026](https://coinedition.com/llm-trading-in-2026-can-ai-agents-actually-outperform-humans/))

個人実装の有力出発点はTradingAgents（TauricResearch）。GitHub 80,000+スター・フォーク15,500+、7月v0.3.1でClaude Sonnet 5対応済み。4つのアナリストエージェント（並列処理）→ Bull/Bear Researcher → Risk Manager → Traderという7エージェント構成で、GPT・Claude・Gemini・Grokをバックエンド選択できる。FX用のMT5や証券APIとの統合は中間APIレイヤーを挟む構成が推奨されている。
([GPTrader Open Source Rankings](https://gptrader.app/ai-trading/best-open-source-ai-trading-agents-github-2026) / [PickMyTrade Tutorial](https://blog.pickmytrade.io/build-a-multi-agent-ai-trading-system-with-trading-agents-2026/))
