## Claude Code・エコシステム

### v2.1.238〜241：週5本リリース体制と実用機能の充実

8月17〜22日の1週間で、Claude CodeはHavopticの集計によれば7バージョンをリリースした。最も変更が多かったのは
v2.1.238〜239の合算で、DevelopersIOが技術詳解を公開している（一次ソース確認済み）。

**現場で使えるキーバインド強化**：v2.1.238で追加された `keybindingFlavor: "readline"` は、
`settings.json` に1行追加するだけでClaude Codeターミナル内でBashスタイルのキーボードショートカットが使える
ようになる。`Ctrl+W` で直前の単語削除、`Alt+F` / `Ctrl+→` で単語単位の移動など、
Bash使いなら即戦力になる設定だ。

**Bedrock二重課金バグの修正**：Content-TypeヘッダーをトリムするプロキシをBedrock経由で使っていた場合に
サイレントに二重請求されていたバグが修正された。Bedrock経由で運用しているユーザーは更新を推奨する。

**コスト透明性の向上**：v2.1.239でデータレジデンシーワークスペース向けに1.1×US推論プレミアムを含む
正確なコスト見積もりが追加された。クラウド利用コストの把握がしやすくなっている。

その他 v2.1.235〜241の主要変化は以下のとおり：
- v2.1.237：カスタムゲートウェイのプロンプトキャッシュ修正 ＋ Concise出力スタイル追加
- v2.1.236：新セッション開始時のモデル制御拡張
- v2.1.235：スペルチェック機能（オプション）追加

### Anthropic Python SDK v1.0.0 正式GA：移行は早めに（一次ソース確認済み）

2026年8月20日、待望だったAnthropicのPython SDK v1.0.0がリリースされた。
主なBreaking Changeを整理する：

| 変更点 | 影響 |
|--------|------|
| httpx → httpx2 移行 | カスタムHTTPクライアントを使っている場合は要修正 |
| Python 3.9以下のサポート終了 | 3.10+必須 |
| Text Completions API削除 | 使用中なら Messages API へ移行 |
| async `.with_raw_response` 変更 | `await response.parse()` が必要になった |
| AnthropicBedrock AWSリージョン未設定時エラー化 | 公式記事には未記載のBreaking Change（リリースノートで確認） |

`temperature`・`top_p`・`top_k` パラメータも Messagesメソッドから削除されているので、
引数で直接渡していたスクリプトは確認が必要だ。

**移行の手順**：Claude Code v2.1.239以降では `/claude-api upgrade` コマンドが
0.x→1.x移行を半自動化してくれる。まずClaude Codeをアップデートして
このコマンドを実行するのが最短ルートとなる。

> 参考: [GitHub リリースページ](https://github.com/anthropics/anthropic-sdk-python/releases)
