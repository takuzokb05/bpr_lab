## Claude Code・エコシステム

### スマートフォンリモート操作の3方式が整理された

Claude Codeをスマホから動かす方法として、① Remote Control、② SSH経由のターミナル、③ Claude.aiアプリ直接操作という3方式の比較解説が登場した。外出先からSEOデータ収集→分析→Slack自動投稿まで一気通貫で動かすユースケースが実例として紹介されており、bpr_labのクラウドセッション＋GitAutoSync構成に近い非同期エージェント運用パターンだ。
([記事](https://genai-ai.co.jp/ai-kanri/blog/cc-yt-remote-access-27/))

### Claude Skillsがメタスキル（スキルクリエイター）まで進化

2026年8月時点でClaude Codeには標準バンドルスキルが9本（v2.1.145以降）搭載されており、AI指示だけで新スキルのSKILL.mdとスクリプトを自動生成できる「スキルクリエイター」が登場した。GPTsとの本質的な違いはローカルファイルベースでバージョン管理できる点で、bpr_labのSKILL.md方式と整合する設計哲学だ。
([入門記事](https://genai-ai.co.jp/ai-kanri/blog/cc-yt-claude-skills-intro-25/))

合わせてスキル用途別厳選ガイドも登場。特に有用なのが「Hook vs Skill vs MCP の使い分け判断フロー」の整理——コードで規則を強制する場合はHook、ドメイン固有ロジックや補助ファイルが必要な場合はSkill、外部データ・ツール連携はMCPという基準だ。
([厳選ガイド](https://syusodo.co.jp/tech-blog/articles/claude-code-skills))

### Microsoft Agent Framework HarnessがGAに到達（一次ソース確認済み）

v1.13.0でFoundry Hosted Agents統合・Claude Agent SDKコネクタ・ワークフローリプレイが安定版へ移行した。Build 2026プレビューから本番グレードに到達したことで、MSとAnthropicのAgent SDKインターオペラビリティが正式に企業利用に対応した節目となる。
([Microsoft公式ブログ](https://devblogs.microsoft.com/agent-framework/the-microsoft-agent-framework-harness-is-now-released/))

### Agent SDK・MCPエコシステムの拡張加速

Claude Agent SDKの実装チュートリアルとして、1つのリードエージェントがチームを生成・並列タスク調整・後処理を担うパターンが公開された。Claude 4.7ではClaude Code内でのネイティブサブエージェントサポートが含まれており、LangGraph/OpenAI Agents SDKとの相互運用も可能。7月に追加されたDreaming（投機的プリフィル）・Outcomes・Claude Finance（10の金融特化エージェント）・Add-insも解説された。
([チュートリアル](https://kargarisaac.medium.com/agent-teams-with-claude-code-and-claude-agent-sdk-e7de4e0cb03e) / [技術深掘り](https://o-mega.ai/articles/claude-agent-sdk-the-2026-deep-dive))

日本語圏では国内最大117件のMCPサーバーカタログ（34カテゴリ）が公開された。Tier 1 SDK（TypeScript/Python）の月間DL数は5億件・累計10億DLを突破。2026-07-28新仕様（ステートレスコア・OAuth/OIDC強化）でCloudflare Workers/Vercel FunctionsでのMCPサーバー動作が可能になった。
([MCPディレクトリ](https://aiagent-navi.com/special/mcp-directory/))

## AIニュース・業界動向

### EU施行・米国グリッドロック・中国罰金という三極分化

EU AI ActのArticle 50（チャットボット開示・ディープフェイクラベリング義務）が8月2日から施行開始。罰則は最大1500万ユーロまたは売上高3%。高リスクAI（採用・信用・教育・法執行等）は2027年12月まで延期される。（**一次ソース確認済み**。ただし合成メディアの既存製品には12月2日までの移行期間あり）
([Al Jazeera報道](https://www.aljazeera.com/news/2026/8/6/what-came-into-force-with-the-eus-ai-act-this-week-and-what-didnt))

その対極として米国では、AI規制大統領令（EO14409）の2026年8月1日期限に成果物が公表されなかった。各州独自のAI法が進展しているが（2026年に15州が更新・施行）、連邦統一基準の不在がガバナンスの空白を生んでいる。日本企業・AI開発者にとって米国市場のコンプライアンス対応は「州法の複数対応」が現実的な選択肢となっている。
([Classmethod AIXC](https://classmethod.jp/aixc/articles/20260801-whitehouse-eo14409/))

### 国内AI産業：「試す」から「組み込む」フェーズへ

ソフトバンクが法人向けAIプラットフォーム「AGENTIC STAR」SaaS版に複数LLMを一元管理する「LLM Gateway」機能を標準搭載すると発表（8月7日）。業界全体として「AIを試す段階」から「AIを組織に組み込む段階」への移行が明確化している週だった。
([note/kaz0](https://note.com/kaz0/n/n960a8e8c9a05))

Sakana AIが日本語特化LLM「Sakana Namazu」のAPI提供を開始（8月3日）。（**一次ソース確認済み・留保あり**：実態はMoonshot AIのKimi K2.6をベースにSakana独自チューニングを施した構成。価格は$0.95/1Mトークン入力/$4.00/1M出力。EU/EEA/英国/スイスはGDPR対応未完了のため提供不可）tsuzumi（NTT）・PLaMo（PFN）との三つ巴の国産LLM競争が加速している。
([tech-noisy](https://tech-noisy.com/2026/08/05/ai-daily-news-2026-08-04/))

## AIトレーディング

### 2026年標準構成：MT5+EA主力、LLMはバックオフィス補助

証券・FX実務でのAI活用15ユースケース解説（2026年版）から、業界標準が整理できた。フロントの自動執行はリスク管理・説明責任の観点から人間監視が依然必須で、MT5+MQL5+AI補助（LLMは補助ツール、執行はEA）が実務標準だ。LLMが特に有効なのは①決算レポートのリサーチ要約、②コード補助（MQL5/Python）、③リスク管理レポート生成、④規制変更モニタリング等のミドル・バックオフィス領域。金融利用前提としてSOC2/ISO27001取得+データ非学習設定が必要で、各LLMの取得状況比較表が有用な一次情報として参照できる。
([aipicks](https://aipicks.jp/mag/ai-securities-fx-trading-2026))

Claude Code + MT5連携のケーススタディ（961コール事例）も言及されており、Claude Codeがトレードロジック開発を支援した実例として参照価値がある。Robinhoodが「agentic finance」への口座接続を開始したことも業界転換点の文脈として記録しておく。
([genai-ai](https://genai-ai.co.jp/ai-kanri/blog/cc-ai-stock-trading/))
