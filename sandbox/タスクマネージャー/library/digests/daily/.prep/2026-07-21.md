## Claude Code・エコシステム

### MCPがステートレスへ：7/28まであと1週間

MCP 2026-07-28仕様への移行は**一次ソース確認済み**の確定事項だ。DigitalAppliedの移行ガイドとStacktreeの差分リファレンスを合わせ読むと全容が見えてくる。

最大の変化はステートレスコアへの移行。`initialize` ハンドシェイクとセッション管理APIが廃止され、リモートMCPサーバーはスティッキーセッションも共有セッションストアも不要になる。ラウンドロビンLBをそのまま使えるため、スケーリングコストが大幅に下がる。新機能として**MCP Apps**（サンドボックス化されたHTMLベースUI）、**Tasks拡張**（長時間非同期処理）、W3C Trace ContextによるOpenTelemetry連携、JSON Schema 2020-12への厳密化が加わる。Python/TypeScript/Go/C# SDK betaも公開済みで、既存統合を持つ開発者は7/28前の動作確認が必須。

- 移行ガイド: <https://www.digitalapplied.com/blog/mcp-2026-07-28-spec-stateless-migration-guide>
- 変更点リファレンス: <https://stacktr.ee/blog/mcp-2026-spec-changes>

### Claude Agent SDKとマルチエージェントの現在地

Claude Codeから改名された**Claude Agent SDK**（2025年末）は、今や汎用エージェントランタイムとして40ツール・ヒエラルキカルサブエージェント生成（2026年6月出荷）を備える。O-mega.aiのディープダイブによれば、40ツール・フックシステム・パーミッションモードに加え、本番コスト最適化のパターンが充実してきた。

並列サブエージェント活用チュートリアル（aiforanything.io）によれば、4エージェント並列で逐次比最大3倍高速化が得られる。git worktreeを使った並列ファイル編集、プログレスハートビートによる長時間タスク管理など、FX自動取引エージェントの設計にそのまま転用できるアーキテクチャパターンが具体的コード付きで解説されている。

## AIニュース・業界動向

### Kimi K3：フロンティア参入の本命か、ベンチマーク誇張か

Moonshot AIが7月16日に発表したKimi K3は2.8兆パラメータ・100万トークンコンテキスト・ネイティブビジョンを備えた初のオープンウェイト超大規模モデルだ（フルウェイト公開は7/27予定、現在API限定）。CNBCも報じるなど一次メディアでの露出は大きく、中国AIの本格的グローバルフロンティア参入を象徴するニュースとして扱われている。

ただしベンチマーク数値は**精査が必要（一次ソース確認：PARTIAL）**。一部記事が主張する「FrontierSWE 77.8点で世界首位」は確認できず、公式ブログはKimiCodeハーネスでの「81.2 dominance score」を報告。BetterStack・Tom's Hardwareは「Fable 5・GPT-5.6 Solと拮抗またはわずかに下回る場合もある」と報告しており、明確な首位は過大主張の可能性がある。価格はGPT-5.6 Solの約1/3というコスト効率は複数ソースで一致しており、「安くて強い」という方向性自体は本物と見ていい。

- CNBC報道: <https://www.cnbc.com/2026/07/17/moonshot-ai-kimi-k3-model-openai-anthropic-china.html>
- ベンチマーク詳細（要注意）: <https://medium.com/data-science-in-your-pocket/kimi-k3-released-beats-claude-fable-glm-5-2-gpt-5-6-sol-2e6f9c90c72c>

### 米国AI規制：イリノイ州法成立で35州以上が乱立局面へ

イリノイ州知事Pritzkerが7月6日にAI Safety Measures Act（SB 315）に署名した（**一次ソース確認済み**）。第三者による強制年次監査、収益$500M超のフロンティアモデル開発者への適用、内部告発者保護を含む米国最包括的水準の法律で、要件発効は2028年1月1日。

Gunderson Dettmer（法律事務所）とTechPolicy.Pressの分析が重なる形で示すのは、直近四半期に35以上の州AI関連法が成立し、医療・雇用・金融など産業別の州規制が乱立しているという現実だ。EU AI Act透明性義務の2026年8月2日施行も重なり、AIシステムの国際コンプライアンス管理が半年単位での更新を要する複雑さになりつつある。DHS-CISAはアジェンティックAIへのプロンプトインジェクション対策義務化とヒューマンオーバーライド文書化要件を提言しており、FX自動取引のような重要インフラ隣接領域は注視が必要だ。

iret DX事業部の週次日本語ダイジェストでは、NTTデータ×NIKKEI KAI提携（AI調査・経営判断支援）、ソフトバンク「Patching as a Service」（AI駆動型サイバーセキュリティ）など国内エンタープライズの「実験→収益化」移行が報告されている。
