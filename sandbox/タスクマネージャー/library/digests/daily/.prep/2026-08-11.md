## Claude Code・エコシステム

### Self-Hosted Runner × Cross-Session Messagingで分散エージェントが現実に

Claude Code v2.1.224（2026-08-07リリース）の最大の変化は、これら二つの機能の組み合わせにある。Self-hosted runnerは`claude self-hosted-runner`コマンドで自社マシン・コンテナをセッション実行基盤として使える機能（Team/Enterpriseプラン、パブリックベータ）。Fixed（常時起動）とOn-demand（セッション到着時のみ）の2モードを提供し、企業ネットワーク内のツールやコンプライアンス要件を満たしながら運用できる。[^1]

これに`SendMessage`と`ListAgents`の2ツールが加わることで、**異なるマシン上のClaude Codeセッション同士がメッセージを交換できる**ようになった。複数サーバーにまたがるサブエージェントへのタスク委譲が可能になり、マルチマシン・エンタープライズ規模のエージェントネットワーク構築への道が開いた。[^2] 8月の主要バグ修正（Bashコマンド実行修正、/tui rewind改善、イベントループ停止削減）も含め、品質強化は7月から継続するトレンドだ。[^3]

### Skills・Hooks・MCP・Subagents ── 4要素の棲み分けが整理される

Claude Code拡張機能の使い分けに関する解説記事が複数出揃い、2026年版のコンセンサスが形成されつつある。共通の整理はこうだ：**単純な繰り返しルール→Skills、実行前後の自動検証→Hooks、重い並列処理→Subagents、外部データ統合→MCP**。非エンジニア向けの実践ガイドも登場し、ターミナルの専門用語なしでワークフローを設計する事例が増えている。[^4][^5]

Claude Code CLIの包括的アーキテクチャガイドでは、Hooksの21イベント（PreToolUse, PostToolUse等）の全パターン、git worktreeを使った並列エージェントのファイル競合回避、CLAUDE.mdの最適化（200行以内・コマンド先頭記述）が整理されている。「技術より構造がClaude Code高出力エンジニアと平均の差」という指摘は、日々CLAUDE.mdを育てているユーザーには刺さるはずだ。[^6][^7]

### MCP 2026：ステートレス化とエンタープライズロードマップ

Model Context Protocol公式ブログが2026年の主要方針6点を発表した（一次ソース確認済み）。最重要変更は**セッション廃止によるステートレスコアへの移行**で、ロードバランサー下での水平スケールに対応。マルチラウンドトリップリクエスト、OAuth 2.1認証強化、tools/listキャッシュも計画済み。2026-07-28仕様はRC版として公開済み。Tier 1 SDK（Python, TypeScript, Go, Java, Ruby, PHP, C#）の同期更新も予定。2026年3月時点でSDKは月間9,700万ダウンロード、GitHubスター8.1万超と普及は加速している。[^8][^9]

Claude Agent SDK（旧Claude Code SDK、2025年9月改名）のModal・Trigger.devへのサーバーレス展開も注目。2025年5月の月間50件から2026年4月に14,800件（296倍）に検索需要が急増しており、本番エージェントの無人実行ニーズが爆発的に増えている。[^10]

## AIニュース・業界動向

### Claude Opus 5：SWE-bench 96%・IMO 2026満点（一次ソース確認済み）

2026年7月24日リリースのClaude Opus 5の主要スコア：SWE-bench Verified 96.0%（コーディング最高水準）、IMO 2026で42/42（金メダル、エージェントハーネス・外部ツール不使用）。複数の独立ソースで確認済み。価格は入力$5/出力$25（100万トークン）でOpus 4.8と同価格を維持、Fable 5とほぼ同等性能で約半額のコスト効率を実現。FX取引システムの意思決定エンジンとして検討価値が高まっている。[^11]

### 2026年8月：モデルリリースラッシュと規制執行の同時進行

8月はAI業界にとって二重の変曲点だ。リリース側ではSeedance 2.5（ByteDance）、DeepSeek V4 Preview（2階層）、Llama 4 Scout（最大1000万トークン）、Tencent Hy3（グローバル展開）など主要プレイヤーが出揃い、「モデルはソフトウェアパッチのように出荷」される時代が加速。米国大統領令EO 14409の設計期限8/1が各社リリース集中を促した可能性が指摘されている。[^12]

規制側では**EU AI法第50条が8/2に施行**（一次ソース確認済み）。チャットボットのAI明示義務・ディープフェイクのラベル必須・AI生成コンテンツへの機械読取可能マーク義務化（2026年12月まで猶予あり）が発効。制裁は最大€1,500万または世界年間売上の3%。合計15カ国が8月に規制を更新しており、世界的に「施行フェーズ」が開幕した。[^13][^14]

Microsoft Agent Framework Harness v1.13.0もGA（一次ソース確認済み・注記あり）。AutoGen + Semantic Kernelのマージ後継として、Foundryホスティング・セッションストア・OpenTelemetry統合が追加。[^15]

## AIトレーディング

3記事が同日登場し、LLMトレーディングの現状認識がほぼ収束している。**共通の結論：M15以上のスイング・イントラデイ向き、高頻度スキャルピングは不適**（LLM推論遅延のため）。

主要リスクとして繰り返し挙げられているのが、(1)ハルシネーション（存在しない経済指標の捏造・価格パターン誤解釈）、(2)API遅延、(3)バックテスト困難、(4)説明責任の不明確さ。eToro調査ではAIツール利用率が前年比75%増だが、「情報優位のない個人開発者の成功は好調な相場ウィンドウの恩恵が大きい」という冷静な評価も。OSS主要フレームワークはTradingAgents（多エージェントLLM型）、ai-hedge-fund（投資家ペルソナ型）、FinRL（強化学習型）の3系統。MT5ベースFXシステムへの組み込みを検討する際の参考として。[^16][^17][^18]
