## Claude Code・エコシステム

### v2.1.269: プラグインを「数字で評価」する時代へ

9月11日にリリースされたClaude Code v2.1.269（98件のCLI変更）の目玉は`claude plugin eval`だ。
プラグインの有無それぞれで各テストケースを3回ずつ計6回実行し、WITH/W/OUTスコアとデルタを比較することで「このプラグインは本当に効いているか」を定量的に示す（[Dev.to週次まとめ](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-september-13-2026-1ob5)、[AI/TLDR](https://ai-tldr.dev/releases/anthropic-claude-code-2-1-269/)）。
出力はJSON＋HTMLレポートで、CI組み込みも視野に入る設計だ。
あわせて`/output-style`コマンドでリモート・ヘッドレス環境を含む全セッションの出力スタイルを切り替え可能になり、Bashツールはコマンド実行後のファイル差分を自動表示するようになった。
マネージドMCPサーバーのサインイン改善やGitLab MR認識追加も含む。

### Fable 5.1/Mythos 5.1: Terminal-Bench-Scienceで旧世代を圧倒（一次ソース確認済み）

9月1日リリースのClaude Fable 5.1について、各社が改めて詳細分析を掲載している。
Terminal-Bench-Scienceスコアは52.6%——Fable 5の24.7%から+27.9ptの跳躍であり、OpenAI GPT-5.6 Solも上回る（[Vellum AI](https://www.vellum.ai/blog/claude-fable-5-1-mythos-5-1-benchmarks-explained)・[MarkTechPost](https://www.marktechpost.com/2026/09/01/anthropic-releases-claude-fable-5-1-and-claude-mythos-5-1-52-6-on-terminal-bench-science-and-75-cheaper-cache-reads/)）。
CursorBench 73.4%・SWE-bench Pro 81.2%と実務コーディングでも強い数字だ。
コスト面では価格は据え置き（$10/$50 MTok）のままキャッシュ読み取りが$0.25/MTokと75%安くなり、エージェンティックな長時間ループを多く回す用途では最大45%のコスト削減が見込める（[MacRumors](https://www.macrumors.com/2026/09/01/anthropic-claude-fable-5-1/)）。
Claude Codeユーザーへのもう一つの恩恵がサイバーセキュリティ誤検知約60%削減だ。

Mythos 5.1は同一ウェイトで出力制限を強化した審査済み米国機関限定版。
MASKベンチマークで「プレッシャー下での誠実性低下」が確認されており、システムカードはアライメントリスクを「very low」から「low」に引き上げている点も記しておく。
なお、Sonnet 5の予定されていた価格引き上げ（$3/$15/MTok）はキャンセルされ、$2/$10の導入価格が永続化された。

### Python SDK v1.0: 静かな観測性クラッシュに注意

Anthropic Python SDK v1.0.0（8月20日リリース）には5つの破壊的変更がある（[DigitalApplied](https://www.digitalapplied.com/blog/anthropic-python-sdk-v1-0-0-breaking-change-migration)・[公式GitHub](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.0.0)）。
最も注意が必要なのはHTTPクライアントの`httpx`→`httpx2`移行で、APIは互換性があるものの、OpenTelemetryや`httpx`をモンキーパッチするライブラリが無音で壊れる。起動時に`httpx2.alias_httpx()`を呼び出す対応が必要だ。
その他: Python 3.10未満のサポート廃止、legacy Text Completions API削除、Messages APIから`temperature/top_p/top_k`削除、tool runnerの`client-side compaction_control`削除。
自動化スクリプトやエージェントパイプラインを持つ場合、計画的なマイグレーションが必要な変更量だ。

### MCP 2026: ステートレス化でロードバランサーが普通に使えるように

Obot の分析によると、MCP 2026-07-28確定仕様の最大変更はプロトコルのステートレス化だ（[Obot](https://obot.ai/blog/mcp-is-growing-up-the-2026-roadmap-takes-shape/)）。
ハンドシェイク不要・セッションID廃止により、スティッキールーティング不要で通常のラウンドロビンLBが使えるようになる。
Extensions Frameworkとして「MCP Apps」（sandboxed HTML UIをiframeでシップ）と「Tasks」（非同期ツール呼び出し、`tasks/get`・`update`・`cancel`で制御）がファーストクラスに昇格。
エコシステム規模は公開MCPサーバー1万台超・月間9700万SDK DL（2025-12時点）。

## AIニュース・業界動向

### DeepSeek V4.1-Flash: 890バイト/トークンという数字の意味（一次ソース確認済み）

9月10日リリースのDeepSeek V4.1-Flashは552B MoEモデルでありながら、KVキャッシュを890バイト/トークンまで削減した——V4-Flashの約1/4だ（[公式](https://www.deepseek.com/en/news/deepseek-v4-1-flash/)・[MarkTechPost](https://www.marktechpost.com/2026/09/10/deepseek-ai-released-deepseek-v4-1-flash-with-1m-context-fp4-kv-cache-and-cross-layer-attention-reuse/)・[Context Studios](https://www.contextstudios.ai/blog/deepseek-v4-1-flash-890-bytes-kv-cache-per-token)）。
技術的には2つの組み合わせで実現: ①FP16→FP4量子化（アテンションヘッド毎に4倍メモリ削減）、②クロスレイヤーアテンション再利用（複数Transformerレイヤーでアテンション行列を共有）。
1Mトークンのコンテキストキャッシュが約890MBに収まる意味は、「同一ハードウェアで長コンテキスト処理効率向上・大バッチサイズ実現・サービングコスト削減」だ。
料金は$0.15/MTok（未キャッシュ入力）・$0.60/MTok（出力）でMITオープンウェイト——552B規模を小型モデルと同等コストで運用できる。
9月14日 04:00 UTCから`deepseek-v4-pro`へのリクエストは自動的にV4.1-Flashにルーティングされ、V4.1-Flash料金が適用される。

### EU AI Act執行フェーズ: 9月は第一波コンプライアンス検査中

8月2日からEU AI Officeと加盟国当局が本格執行を開始し、9月は第一波コンプライアンス検査が進行中だ（[BrightDefense](https://www.brightdefense.com/news/eu-ai-act-delay-keeps-2026-compliance-pressure/)・[GrowToYourFullest](https://www.growtoyourfullest.com/single-post/governance-just-became-enforcement-ai-compliance-moment-every-enterprise-faces)）（一次ソース確認済み）。
現在適用中はArticle 50（GPAI透明性）。高リスクシステム要件は2027-2028に延期されているため、直近の焦点はHR AIツール（履歴書スクリーニング）・小売銀行の与信AI・民間医療AIトリアージの3領域だ。
違反罰則は最大€1500万または年間売上3%。12月2日にはArticle 50(2)の移行期間が終了する。
日本の公務員組織でもAI利用が広がる中、企業向けの実践ステップ（AI台帳整備・高リスク用途リスク評価・人間監視プロセス文書化）は参考になる。
米国ではコロラド州ADMTやカリフォルニアSB1000、ブラジルAI法案（9/16連邦議会採決予定）も同時進行しており、規制地図は急速に埋まっている。
