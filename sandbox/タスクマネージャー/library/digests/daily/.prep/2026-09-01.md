## Claude Code・エコシステム

### 8月の新機能：Auto モードが日常の起点に

（一次ソース確認済み）8月14日より、Claude Code の Auto モードが Pro/Max/Team プランの全新セッションでデフォルト化された。既存ユーザーには一度確認プロンプトが出るが、その後は自動で有効になる（Enterprise は引き続きオプトイン）。

これと合わせて注目すべきは `/design` スキルによるUI生成機能だ。ターミナルからスクリーンショットやアイデアを入力するだけでインタラクティブなデザインキャンバスを生成できる。「まず触ってみる」スタイルのユーザーなら即試す価値がある。他にも Concise output モード（結果を先頭に出し説明を後方へ）、自然文での allow/deny ルール記述（「Never delete production database rows」等）、サブエージェントのライブストリーミングが揃った。バイナリサイズも zstd 圧縮で 340MB→75MB（Linux x64）と大幅に軽量化されている。

[https://note.com/ai__worker/n/n74cb8328b0cb](https://note.com/ai__worker/n/n74cb8328b0cb)

### MCP 連携の実践：7パターンと OAuth 認証

MCP（Model Context Protocol）の2026年版実践ガイドが公開された。技術的な核心は「2026年時点の主流は HTTP transport で、旧 SSE transport は 2026-07-28 仕様で廃止方向」という移行情報だ。OAuth 認証の設定方法も詳説されており、既存の MCP サーバーを使っている場合は認証設定を見直すタイミングといえる。

実務活用の事例として、社内CRM連携（顧客IDから問い合わせ・購入履歴を即時把握）、オウンドメディア運用の自走化、PostgreSQL への直接クエリが紹介されている。また、Claude Code の5層アーキテクチャ（CLAUDE.md・MCP・スキル・フック・サブエージェント）の中での MCP の位置づけを整理した解説は、既に MCP を使っている場合でも整理の参考になる。なお本記事はファクトチェック未実施。

## AIニュース・業界動向

### 米国 AI 立法：規制は州から始まっている

（一次ソース確認済み）CDT（Center for Democracy & Technology）の2026年立法総括によれば、連邦レベルでのAI規制法案はまだ成立していないが、州レベルでは着実に整備が進んでいる。

注目は2つの州法だ。コロラド SB 24-205 は2026年2月1日施行で、「高リスク AI」を開発・導入する企業にリスク管理プログラム・消費者開示・アルゴリズム差別軽減を義務づけた米国初の包括的州 AI ガバナンス法。コネチカット CT SB 5 は2026年最も包括的とされる法案で、規制サンドボックスや独立検証機関の検討を含む。さらに34州以上でチャットボット特定法案約100件が提出されており、AI生成ヌード画像禁止は2026年12月施行予定だ。

FX取引ボットのような AI を活用したシステムを運用する立場では、米国向けサービス展開時の透明性・消費者開示要件が今後の設計に影響しうる。EU AI Act の影響が米国州法に波及しているという指摘は、グローバルな規制収束の観点でも把握しておくべき動向だ。

[https://cdt.org/insights/2026-state-and-federal-ai-legislation-updates/](https://cdt.org/insights/2026-state-and-federal-ai-legislation-updates/)

### 8月の AI 競合：GPT-5.6、Gemini 3.6 Flash、Grok 4.5

（一次ソース確認済み・要補足あり）TECH NOISY の週次まとめによれば、OpenAI GPT-5.6（Sol/Terra/Luna の3モデル構成）は正確だが、本リリースは7月9日（限定プレビューは6月26日）であり、8月は API 価格引き下げ（20%超）と GPT-5.6-Cyber の追加リリースが主な動きだった。Google は Gemini 3.6 Flash（高速・低コスト）を、SpaceX AI（旧xAI）はコーディング特化の Grok 4.5 を投入し、大手3社が同時期に攻勢をかけた格好だ。
