## Claude Code・エコシステム

### Claude Code v2.1.261：diff panelとFable 5.1デフォルト化（一次ソース確認済み）

9月4日時点の最新版v2.1.261で注目すべき変更が2点ある。まずv2.1.260で追加された**diff panel**——変更をリアルタイムで左右に並列表示する機能で、コードレビューの速度が体感で変わる類のアップデートだ。もう一点は**Claude Fable 5.1のデフォルトモデル化**（v2.1.257〜）。価格$10/$50/MTokを維持しつつキャッシュリードが$0.25/MTok（75%減）、コンテキスト1M・出力128K・適応的思考デフォルトONという構成で、ヘビーユーザーにとってはコスト面でも実質的な改善となる。

運用面では`bashOutputMaxChars`と`taskOutputMaxChars`がそれぞれ最大128Kに設定可能になった。長い出力が途中で切れるストレスが解消される。また`--append-subagent-system-prompt-file`でサブエージェントのシステムプロンプトをファイルから読み込めるようになり、マルチエージェント構成の管理が整理しやすくなった。バグ修正ではバックグラウンドエージェント再開失敗時のCPU高負荷ループが修正されており、長時間セッション運用の安定性が向上している。

> 参照: [Claude Code News September 2026 (MeanCEO)](https://blog.mean.ceo/claude-code-news-september-2026/)

### Claude Managed Agents：Dreaming・Outcomes・マルチエージェント本格化

5月6日発表の3機能が実運用に浸透しつつある。**Dreaming**（研究プレビュー）はオフライン中のバックグラウンド調査実行、**Outcomes**（パブリックベータ）はエージェントの目標達成率トラッキング、**Multi-Agent Orchestration**（パブリックベータ）は複数エージェントの協調フレームワーク。

Claude Agent SDK（TS/Python）でエージェントをコード定義し、Anthropic側がモデル呼び出し・ツールディスパッチ・コンテキスト圧縮・リトライを管理する構成は、Claude Codeのサブエージェント運用の延長線上にある。オーケストレーション方式は3種——①単一セッション内サブエージェント、②Agent Teams（リードエージェント+並列チームメイト）、③外部オーケストレーター（複数リポジトリ横断）——で、現行のClaude Code運用からスムーズに移行できる経路が整っている。

> 参照: [Claude Managed Agents解説 (DevelopersDigest)](https://www.developersdigest.tech/blog/claude-managed-agents-dreaming-outcomes-multi-agent)

### EU AI Act規制分断：高リスク義務は2027年12月へ正式延期（一次ソース確認済み）

EU AI Actの高リスクシステム義務（Annex III）が2027年12月2日へ正式延期、組込システム（Annex I）は2028年8月2日へ延期された（EU Digital Omnibus 2026/1744、7月27日発効）。透明性義務は8月2日に既施行済み。

米国はG20で規制緩和を積極主張し、産業成長優先のエグゼクティブオーダーで州法への連邦先占を図っている（未成立）。EU vs 米国の「正反対」アプローチに中国の独自路線が加わり、グローバルなコンプライアンス設計は複雑化の一途。公務員視点では、国内のAI調達・利用ガイドラインに欧州基準が直接影響しないまでも、日本企業・ベンダーが欧米基準どちらに合わせるかという波及は意識しておく価値がある。
