## Claude Code・エコシステム

### Linuxビルド75MB化とAuto modeデフォルト（8月末の実質的転換点）

Claude Codeの8月29日リリースで最も目立つ変化はLinuxビルドのサイズ削減だ。**一次ソース確認済み**: zstd圧縮採用により従来約340MBから約75MBへ（4.5倍削減）。ただし75MBは圧縮後のダウンロードサイズであり、展開後のインストールサイズとは異なる点に注意が必要。CI環境や低帯域のリモートサーバーへの展開が実用的になった。同アップデートで/cost・/usage・/tasksにトークン詳細表示が追加され、コスト把握の粒度が上がった。

8月14日にAuto modeがPro/Max/Teamプランのデフォルトとなり、Scheduled Tasksとの組み合わせで長期エージェント運用が標準的なワークフローに組み込まれた。Web/モバイルセッションがPR追跡・CI修正・コメント対応をクラウドで自動処理する構成が「特殊用途」から「標準機能」に変わったことは、このリポジトリの運用スタイルとも直接つながる。

### Claude Fable 5.1リリースとエコシステム統合（9月1日）

**一次ソース確認済み**: AnthropicはClaude Fable 5.1をリリースし、デフォルトFableモデルに設定した。価格は入力$10/MTok・キャッシュ済み$0.25/MTok・出力$50/MTok、コンテキストウィンドウ1Mトークン。Fable 5.1では時間・工数・サブエージェント制御が追加され、長時間タスクのリソース管理が可能になった。

SDK側ではfiles/skills APIのbeta/non-betaシェイプが統一され、Microsoft FoundryでSkills API・Files APIの提供が開始。BetaSkillがBetaContainerSkillにリネームされる等、APIの安定化に向けた整備が続く。Claude Agent SDK（旧Claude Code SDK、2025年9月リネーム）は2026年6月に階層的サブエージェントスポーンを追加しており、Managed AgentsとMCPサーバー連携を含む本番移行のガイドも整備されてきた。

### 実践セットアップとMCPステートレス化

4ヶ月日常利用の実践者と上級ベストプラクティス記事が共通して推奨するのは「小さく始める」構成だ。判断フレームワークは明快：ルールならHooks（PreToolUse/PostToolUse）、文脈知識ならSkills、委任境界ならSubagents、常時ガイダンスはCLAUDE.md（200行以内）。コスト管理は/compact（サマリー保持）・/clear（完全リセット）・/rewindの使い分けが核心で、「助走レーン」思考と親和性が高い。

MCPはこの文脈で大きな変化を迎えた。仕様2026-07-28でステートレス化（セッションIDと初期化処理を廃止）し、各リクエストが自己完結型となることでクラウド展開が通常HTTPワークロードと同等になった。ヘッダーベースルーティング・キャッシュ可能リスト・Enterprise-Managed Authorizationが安定版となり、breaking changesを含む最大の改訂。Microsoft Agent Framework（MAF 1.0、4月GA）がA2AプロトコルでMCP標準との相互運用を確保し、主要フレームワークの一角に入った。

### 米国AI州法：連邦・州・行政の三つ巴

**一次ソース部分確認済み**: カリフォルニア州SB-53（2025年9月署名、2026年1月施行）はフロンティアモデル開発者にリスク枠組みの公開と安全インシデント報告を義務付け、違反ペナルティ最高$1M/件は確認済み。「年収5億ドル超企業」という収益閾値は出典記事固有の要約の可能性があり注意が必要。一方でトランプ大統領令（2025年12月）が国家政策と相容れない州AI法をブロックする構造で、コロラド州は包括的AI法を廃止・置換（SB 26-189、2027年1月施行予定）。Gartner予測では2026年末までに大企業の50%超が義務的AIコンプライアンス監査に直面するとされ、公務員・制度運用の文脈でも動向を追う価値がある。

## AIトレーディング

### MT5 AI Assistant統合：FX自動売買の文脈変化

MetaTrader 5が2026年8月22日にAI AssistantをMCPプロトコルで統合した（MQL5公式発表）。単なるチャットボットではなく、注文発注・ストップレベル設定・チャート操作をAIがタスク分解して自律実行する。ローンチ後3週間で1兆トークン処理（MQL5 Liteモデル無料提供）。Expert Advisorsのミリ秒単位精度と強化学習エージェントによる市場適応、マルチアセットAIでの複数銘柄協調管理が実用域に入ってきた。現行のFX自動取引運用においてMT5を使うなら、このAI Assistantをまず小さく試す価値がある。

[^mql5]: https://www.mql5.com/en/blogs/post/774589

### LLMトレーディングの現実的評価

LLMトレーディングの評価記事（CoinEdition）は成功・失敗の両面を示す。一部実験では初週15%超の損失、別の実験では数ヶ月で大きな利益。差分の主因は「機関投資家が持ち、個人が持てない情報優位性」であり、技術アクセス（OSSフレームワーク：TradingAgents・FinRL・FinRobot等）は既に平準化されている。現行運用と整合する推奨は「AIがリサーチ・フィルタリング・アラートを担当し、ルールベース自動化が執行を担当」という分業構造で、AI判断による直接執行より情報処理を上流に置くアーキテクチャだ。
