## Claude Code・エコシステム

### セキュリティ修正とスキル自動実行廃止（Week 30リリース）

7月18〜19日のClaude Code Week 30リリースは、ヘビーユーザーにとって見逃せない内容だった。

**v2.1.214（7/18）** では重要なセキュリティバグが4件修正された（一次ソース確認済み）。なかでも目立つのは、`Edit(src/**)` のような単一セグメント許可ルールが任意のネストディレクトリへの書き込みを誤って承認していたバグだ。意図した許可範囲を超えてファイルが変更される恐れがあり、早期アップグレードが推奨される。ほかにもWindows PowerShell 5.1でのパーミッションチェックバイパス、Bashファイルディスクリプタリダイレクトの誤判定、10,000文字超コマンドの誤判定も修正されている。

**v2.1.215（7/19）** では `/verify` と `/code-review` スキルの自動実行が廃止された。今後はコマンドを明示的に呼び出す必要がある。これまで自動で動いていた前提で作業していた場合は運用の見直しが必要だ。

> 参照: [releasebot.io](https://releasebot.io/updates/anthropic/claude-code)（複数独立ソースで確認済み）

### Anthropic プラットフォームの大型アップデート群

APIを本格活用している開発者に関係する変更がまとめて届いた。

**Memory API beta（ヘッダ: `agent-memory-2026-07-22`）** では、メモリ一覧が安定したサーバー定義順で返るようになった（一次ソース確認済み）。`depth` パラメータは `0`・`1`・省略のみ許可、`path_prefix` には末尾 `/` と全セグメント一致が必須となる。既存エージェント統合で動作が変わる可能性があるため、SDK移行（Python 0.116.0 / TypeScript 0.110.0 以降）の確認を。

**HIPAA自己設定フロー** も正式公開された。EnterpriseまたはAPIプランの管理者がBAA確認・実装ガイドDL・HIPAA有効化を単一フローで完結できるようになり、医療AIへの参入障壁が大幅に下がった。

StackQL側でも `anthropic` プロバイダー（11サービス・26リソース・103オペレーション）と新設の `anthropic_admin` プロバイダーへの対応更新が入り、IaCでのAnthropicインフラ管理が正式にサポートされた。Claude ConsoleでAPIキーに有効期限を設定できるようになった点も運用管理上の改善だ。SonnetとHaikuのレートリミットがOpusと統一され、使用ティアはStart/Build/Scaleの3段階に集約されている。

> 参照: [platform.claude.com/docs](https://platform.claude.com/docs/en/managed-agents/memory)（公式ドキュメント確認済み）、[StackQL](https://stackql.io/blog/anthropic-providers-update-july-2026)

## AIニュース・業界動向

### EU AI Act、透明性義務ガイドライン正式公表——8月2日施行へ

欧州委員会が本日（7月20日）、AI Act第50条に基づく透明性義務ガイドラインを正式公表した（一次ソース確認済み）。違反時の罰則は最大€1,500万または年間売上3%の高い方と重い。EU域外でEUユーザーにサービス提供する日系企業も対象になり得るため、生成AIを含むシステムを運用する事業者は8月2日施行前に文書化・開示義務の対応状況を再確認する必要がある。

このガイドラインはAI Actの主要条項（高リスクAI分類・適合性評価・GPAI義務）完全施行直前の最終実務指針として位置づけられており、6月29日にEU理事会が承認したAIルール簡素化規制との組み合わせで実務コストの軽減も図られている。同日、「サイバーセキュリティ・AIアクションプラン」も発表された。

> 参照: [欧州委員会公式ガイドライン](https://digital-strategy.ec.europa.eu/en/library/guidelines-transparency-obligations-providers-and-deployers-ai-systems)

### 米国・国際的な規制動向（スタートアップ向けまとめ）

EU以外でも7月は規制ニュースが重なった。FTCがAIシステム精度ポリシーへのパブコメ募集中（締切7/31）、連邦議会ではAIチャットボット・デジタルレプリカ・非合意AI生成コンテンツ等の超党派法案が複数提出された。州レベルでは35以上の法律が成立済みで、ニューヨーク州は1週間で5本のAI関連法を可決（未成年向けチャットボット安全規制・学習データ透明性・FAIR News Act・データセンター一時停止・AI利用価格差別禁止）。医療AIでは連邦・州双方がHIPA対応と監査証跡を急務として位置づけており、AnthropicのHIPAA自己設定フロー公開はこの流れに合致したタイミングだ。

> 参照: [mean.ceo](https://blog.mean.ceo/ai-regulation-news-july-2026/)
