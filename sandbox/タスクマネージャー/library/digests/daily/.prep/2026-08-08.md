Claude Code が Opus 5 デフォルト化・ダイナミックワークフロー拡張・自己ホスト型環境ベータと一気に進化した週の情報が集積した日。EU AI Act の透明性義務（8月2日施行・一次ソース確認済み）と MCP 2026-07-28 仕様のステートレス化も要対応。FX 自動取引側では TradingAgents の多エージェント Bull/Bear 構造が実績数値付きで検証され（一次ソース確認済み）、LLM × MT5 の実践事例が充実。全体として「使える AI インフラ」が一段階成熟した一日。

## Claude Code・エコシステム

### Opus 5 デフォルト化と「インフラ基盤」への脱皮

今週の Claude Code アップデートの核心は、Claude Opus 5 のデフォルト Opus モデル化とダイナミックワークフロー（`/loop` コマンド拡張）、ネストされたサブエージェントの強化だ。スタートアップ向けニュースレターや gradually.ai の更新追跡が共に「コーディングツールを超え実用的なインフラ基盤に進化しつつある」と評するのは大げさではなく、自己ホスト型環境のパブリックベータ（Team/Enterprise プラン）と Enterprise 向け推論フック（DLP 適用ベータ）が並走することで、組織の情報統制ポリシーと AI エージェント実行を両立させるレイヤーが整ったことを意味する[^1][^2]。

ワークフロー論では複数ソースが同じ 8 パターン（Plan Mode → TDD → 監査 → マルチリポジトリ → ドキュメント → セキュリティ → エージェントスウォーム → 依存関係管理）を収束して引用しており、2025→2026 の変化が「コンテキスト管理の最適化から、成果の明確化」へのシフトだという主張で一致している。「スキルあるコントラクターとして扱い、境界・検証基準・ツール権限を明示する」という運用思想は、あなたの「小さく試して実績で引っ張る」スタイルと整合する[^3][^4][^5]。

### セットアップ 5 層構造と CLAUDE.md のリファクタ

2026 年版 Claude Code セットアップの整理として、5 層アーキテクチャが明文化された。① CLAUDE.md（常時 ON）→ ② スキル（能力付与型 vs 好み符号化型）→ ③ プラグイン→ ④ MCP コネクタ → ⑤ パーミッション＋フック、という積み重ねだ[^6]。

AgentLint（CLAUDE.md 静的解析ツール）のベストプラクティスはより刺さる: CLAUDE.md は 200 行未満が目標（250 行超でコンテキスト予算の 5% 超消費）、HTML コメント（`<!-- -->`）はトークン無消費で使えるため説明の整理に有用。そして「CLAUDE.md のルールは"お願い"に過ぎない——Hook/CI/リンターとペアにして初めて強制力を持つ」という指摘は、このリポジトリの CLAUDE.md 管理にも直接応用できる[^7]。

### Claude Agent SDK と MCP の構造変化

Claude Agent SDK（2025 年 9 月に Claude Code SDK から改名）は 2026 年 6 月 15 日よりインタラクティブ利用とは独立した月次クレジットプールに分離された。本番運用の原則として「セッションはエフェメラル → 状態は Postgres/Redis に永続化」「タスク/ユーザー/テナント単位のコストキャップをハーネスに実装」が推奨されており、このリポジトリの自動 digest パイプライン設計とも直結する[^8]。

MCP 2026-07-28 仕様はより破壊的だ。handshake 廃止・ステートレス化（ラウンドロビン LB で動作可）・HTTP+SSE 非推奨（1 年 offramp）が柱で、MCP Apps（サーバーレンダリング UI）と Tasks 拡張（長時間タスク）が追加された。既存の MCP サーバーをステートフルで構築していた場合は移行コストが発生する[^9]。

Anthropic 公式リリースノートでは **Legacy Workbench が 2026 年 8 月 17 日廃止**（一次ソース確認済み）、会話中途ツール変更ベータ（プロンプトキャッシュを維持しながらターン間でツール追加/削除）が追加確認できる。Workbench を利用しているならデータエクスポートは今週中に[^10]。

## AIニュース・業界動向

### EU AI Act 透明性義務の施行開始（一次ソース確認済み）

2026 年 8 月 2 日より EU AI Act の透明性義務が施行された。欧州委員会公式プレスリリースおよび複数独立ソースが確認している。具体的には①チャットボットの AI 開示義務②ディープフェイクのラベリング③AI 生成コンテンツへの機械可読マーク付与が即時適用。違反罰則は最大 1,500 万ユーロまたは世界売上高 3%。高リスク AI システム要件は AI Omnibus により 2027 年 12 月に延期された[^11]。

Cooley 法律事務所の実務解説では、適用対象は「EU 市場にサービスを提供するグローバル企業すべて」であり、日本企業も含む。公務員として組織の AI 導入を検討する際、EU 市場接続の有無に関わらず国際標準として先行参照する価値がある[^12]。

### LLM リリースラッシュと「モデルはパッチのように出荷される」時代

8 月上旬に主要 AI プレイヤーが 2 週間以内で次世代 LLM を相次ぎリリースした。背景は米国大統領令 EO 14409 の設計期限（8 月 1 日）と Q3 リソース配分タイミングの重なり。クラウド（OpenAI/Anthropic/Google）・オープンウェイト（Meta Llama 4）・軽量（エッジ向け）の「三極集中」構造が固まりつつある。Llama 4 Scout の最大 1,000 万トークンコンテキストが特に注目点で、長大なコードベース全体を一度に処理するユースケースが現実的になってきた[^13]。

## AIトレーディング

### TradingAgents と LLM × MT5 の実践（一次ソース確認済み）

AI 取引フレームワークの 2026 年評価が出揃った。TradingAgents（Bull/Bear Researcher が対立構造で議論するマルチ LLM エージェント）の AAPL 累積リターン 26.62%（vs buy-and-hold -5.23%、2024 年 6〜11 月バックテスト）は arxiv 論文(2412.20138)および複数サードパーティが確認している。ただし「特定期間のバックテストであり、情報優位性や市場環境への依存が排除できない」という警告は外せない[^14]。

実用的なアーキテクチャ例として FX Prime Bot（Node.js UI + Python コア + ML + LLM センチメント分析 + MT5）が紹介されている。MT5 連携の LLM 活用は感情分析・ニュース解析・リアルタイムトレンド取得が主で、マルチモーダル LLM によるチャート画像のテクニカル分析も実用化段階とのこと。TradingAgents v0.3.1（2026 年 7 月）が Claude Sonnet 5 対応を追加した点は現行 EA 環境との接続を検討する際に確認価値がある[^15]。

「AIを調査・フィルタ・アラートに使い、ルールベース自動化で執行するハイブリッド」という整理は、現在のあなたの EA 運用（FX 自動取引中）にそのまま当てはまるポジショニングだ。完全 AI 執行より AI + ルールベースのハイブリッドが 2026 年の現実解として複数ソースが収束している。
