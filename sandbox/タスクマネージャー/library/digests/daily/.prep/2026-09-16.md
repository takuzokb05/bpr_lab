## Claude Code・エコシステム

### Hooks完全解説：CI的ガードレールとしての再定義

2026年版Claude CodeのHooks機能について、複数メディアが同日に踏み込んだ解説を出した。
中でも注目は、UravationによるHooksガイドと、Qiitaの emi_ndk による本番運用ガイドの2本だ。

Hooksの核心は「**絶対に実行される保証**」にある。CLAUDE.mdやSkillsはClaudeが「参照する」
という性質だが、HooksはPreToolUse/PostToolUseなどのイベントに紐付いた
シェルスクリプトが必ず走る。これはCIのガードレールと同等の信頼性を持ち、
コード品質チェック・セキュリティ審査・自動フォーマットをエディタレベルで強制できる。
2026年版では SessionStart/SessionEnd など新イベントも追加されており、
セッション開始時の環境チェックやセッション終了時のtodo.md更新なども自動化できる。

noteのai_dev_notesが公開したHooksカタログは「コピペ即効果」を謳う実用派。
`rm -rf`系の危険コマンドを正規表現で検出してブロックするPreToolUse設定や、
長時間処理完了後のデスクトップ通知といった、チームで即展開できるパターンを収録している。

- Qiita emi_ndk 本番運用ガイド: <https://qiita.com/emi_ndk/items/56b2fc8bf4e7ed5ba7f3>
- note ai_dev_notes Hooksカタログ: <https://note.com/ai_dev_notes/n/nfe79dfbb8eeb>

### Plugins登場：Hooks/MCP/Agentを1バンドルで展開

Uravationはもう1本、Plugin開発ガイドを公開した。Pluginは
Hooks・Slash Command・MCP Server・Agentを1ディレクトリにまとめ、
`claude /plugin install github:org/plugin` の1行でチーム全員に展開できる仕組みだ。

これは組織導入の文脈で意味が大きい。これまでHooks設定・MCPサーバー設定・
Skillsの配置を各メンバーが個別に行う必要があったが、Pluginパッケージ化で
「チームの開発環境をリポジトリで管理・配布する」ことが標準化された。
plugin.jsonによる権限スコープ設定やプラグインマーケットプレース登録まで言及されており、
エンタープライズ向けの展開基盤として機能し始めていることがわかる。

- Uravation Plugin開発ガイド2026: <https://uravation.com/media/claude-code-plugin-development-hooks-mcp-integration-2026/>

### Skills vs MCP vs Hooks：3つの使い分け論が収束へ

Qiitaのemu_ndk本番運用ガイドとNgenの分析記事、romptnの業務自動化レシピが
それぞれ独立して「いつSkillsでいつMCPか」という判断基準を提示しており、
コミュニティの理解が一定の共通認識に収束しつつある。

整理すると：**Skills=Claude内に置く手順書・知識**、**MCP=外部システムへのパイプ**、
**Hooks=実行保証が必要な自動処理**という役割分担だ。
Slackに投稿したいならMCP、コードレビュー手順を統一したいならSkills、
コミット前のlintを確実に走らせたいならHooks、という判断フローが定着しつつある。

romptnは「まずHooksから始める」という初学者向けの学習順序も提案しており、
設定が最も具体的でフィードバックが早いHooksを起点にする戦略は理にかなっている。

- Qiita Ngen 判断軸3本: <https://qiita.com/Ngen/items/30c129861893e6b1a672>
- romptn 業務自動化レシピ: <https://romptn.com/article/105358>

### 非エンジニア活用：裾野拡大の実数

Uravationが非エンジニア完全ガイド2026を、StartLinkがマーケ・営業・経理の活用事例を
それぞれ公開した。注目は定量データの充実度だ。経理業務1人あたり月20〜40時間削減、
営業チーム10名の週次報告書が8時間→45分（3ヶ月実測）という数字が示されている。

公務員業務との親和性という視点では、「日本語指示のみで業務自動化」
「ターミナル不要のブラウザ版（Claude Cowork）」という切り口が参考になる。
非定型文書の整形・報告書フォーマット統一・会議録からのタスク変換といった
事務処理への応用は、エンジニアリング不要で実現できる領域だ。
ただし機密データ管理の注意点については両記事とも言及しており、
組織利用時の情報管理ポリシーの整備は必須とされている。

- Uravation 非エンジニア完全ガイド: <https://uravation.com/media/claude-code-non-engineer-complete-guide-2026/>
- StartLink 活用事例まとめ: <https://start-link.jp/hubspot-ai/ai/claude-code-practice/claude-code-non-engineer-use-cases>
