## Claude Code・エコシステム

### MCPがインフラ層へ：ステートレス化とエンタープライズ化

MCPエコシステムは2026年後半に入り、成熟の段階へ移行しつつある。7月28日最終版リリース予定の仕様RC（SEP-2575/SEP-2567）における最大変更は**ステートレス化**だ。従来のinitialize/initializedハンドシェイクとMcp-Session-Idヘッダが廃止され、スティッキーセッション不要でラウンドロビンLBが動作可能になる。14,000以上のサーバー・SDK累計9,700万DLを抱えるエコシステムには10週間の移行ウィンドウが設定されており、Claude CodeのMCPサーバー開発者は早期対応を推奨される。（[MCP 2026-07-28 RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)）

この仕様改定と並走する形で、エンタープライズ採用も加速している。X（旧Twitter）が6月30日に公式MCPサーバーを開始したことはMCPが事実上の業界標準となったことを示すマイルストーンであり、OpenAI・Google・Microsoft・Anthropicを横断してMCPが採用される構図が固まった。国産SaaS（楽楽精算・freee・kintone）の対応も進んでいる。（[TechCrunch](https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use/)）

Claude Agent SDK（旧Claude Code SDK）は6月15日から独立した月次クレジット課金に移行し、プロダクトとして本格格上げ。コード実行ツールが全言語対応（Python/TS/Go/Java/Ruby/PHP/C#）となり、Enterprise向け管理者APIも追加された。月次検索ボリュームが1年で50→14,800件（約300倍）と急増しており、開発者コミュニティの裾野が急速に広がっている。（[releasebot.io](https://releasebot.io/updates/anthropic/claude-developer-platform)）

### Claude Code Week 29：エージェント実用化が加速

Week 29の目玉は**Artifacts β**と**3段階ネスト**の2つだ。Artifactsはセッション成果物をclaude.aiのライブ共有ページとして公開・インプレース更新できる機能で、チーム内での成果物共有フローが変わる。3段階ネストの階層型エージェントスポーンにより、複数モジュール横断タスクを親→子→孫の構造で分解できるようになった。Opus 4.8がMax/Enterprise向けデフォルトとなり、複雑なエージェントタスクの標準品質が底上げされた。（[releasebot.io](https://releasebot.io/updates/anthropic/claude-code)）

実務活用という観点では、日本語ガイドとチートシートが今週まとめて公開された。Uravationによる2本（6月新機能活用ガイド・業務自動化10事例）は、Cron+Claudeによる議事録自動化パイプラインの実例と実装プロンプトを公開しており、即日導入できる内容だ。TechBytesのチートシートはHook 4種の使い分け（HTTP/MCPツール/プロンプト/エージェント）を整理しており、タスクマネージャーのスキル設計判断の参考になる。CLAUDE.md 200行以下推奨・HTML commentはトークン消費なしという設計指針も明記されている。（[Uravation](https://uravation.com/media/claude-code-june-2026-new-features-business-guide/) / [TechBytes](https://techbytes.app/posts/claude-code-2026-cheat-sheet-hooks-mcp-commands/)）

## AIニュース・業界動向

### 1週間で4モデルが集結：フロンティア競争の現在地

7月9〜16日の1週間に、フロンティアレベルのモデルが4本リリースされた。GPT-5.6（Luna/Terra/Sol、7/9）・Fable 5（6/9リリース）・Kimi K3（7/16）・Inkling（7/15）が同時期に並ぶ構図は2026年型の競争の激しさを象徴している。

**一次ソース確認済み**：GPT-5.6 Sol（$5/1Mトークン入力）はTerminal-Bench 2.1（91.9% vs 88.0%）・Agents' Last Exam（53.6 vs 40.5）でFable 5を上回る一方、SWE-Bench ProではSol 64.6%に対しClaude Mythos 5が80.3%と大差をつける。「Fable 5を全面的に超える」という見出しは誤りで、タスク依存が正確な理解だ。コンテキスト1Mトークン・知識カットオフ2026年2月は確認済み。（[llm-stats.com](https://llm-stats.com/ai-news)）

**一次ソース確認済み**：Fable 5は価格$10/$50 per 1Mトークン（入力/出力）でSWE-Bench Pro 80.3%と多数のベンチマーク首位を確認。「公開LLM最強」はリリース時点（6/9）での表記として正確だが、GPT-5.6 Sol登場後はエージェント系ベンチマークでは逆転されている。（[llm-stats.com](https://llm-stats.com/llm-updates)）

Kimi K3（Moonshot AI）は「米国主要ラボに匹敵」と専門家が評価し、DeepSeek V4以降の中国勢モデル投入の継続を示す。Inkling（Thinking Machines Lab）はOpenAI元CTO Mira Murati率いる新興ラボの初フラッグシップで、オープンウェイト提供と企業向けAPIのデュアル戦略が特徴的だ。両モデルともベンチマーク詳細は近日公開予定。

2026年7月は規制の多極化が鮮明になった月だ。米連邦FTCのAIアキュラシーポリシー（パブリックコメント7/31締切）・イリノイ州のフロンティアAI安全監査法（売上$500M超の開発者に年次独立監査義務化）・中国AIエージェント実施意見（7/15施行）が同時進行している。FX自動取引AIの運用にとっては中国規制と米国州法の動向が特に要注視で、規制強度は全体として高まる方向にある。（[aigovernance.com](https://aigovernance.com/news/ai-governance-weekly-july-16-2026)）
