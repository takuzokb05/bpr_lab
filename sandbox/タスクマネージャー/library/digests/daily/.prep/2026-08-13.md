## Claude Code・エコシステム

### Autoモードがデフォルトへ（一次ソース確認済み）

8月14日より、Claude CodeのPro・Max・TeamプランでAutoモードがデフォルトの権限モードになった。Anthropicの公式発表によると、同モードの安全性分類器は「不可逆・破壊的・環境外への操作」と判定されない限り自動実行し、危険コマンドの捕捉率は**89%**。旧来の手動承認ワークフローが捕捉できていた14%（正確には13.6%）から大幅な改善だ。1,053名の有償テスターによる実験では、セッション後半で人間の捕捉率が5%まで低下することも確認されており、「人間が見張るより機械に任せた方が安全」という逆説的な判断が下された。

Enterprise・API・AWS Bedrock・Google Cloud・Microsoft Foundryは来月中にデフォルト化予定。既に独自設定を持つユーザーは一度のプロンプトで確認が行われる。GIGAZINEの日本語解説記事では、VSCode Focus view追加やサンドボックスへの `mode:"mask"` 追加などの付随アップデートも紹介されている。

> 出典: [Anthropic公式](https://claude.com/blog/auto-mode-default-in-claude-code) / [TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) / [Simon Willison](https://simonwillison.net/2026/Aug/8/auto-mode/) / [GIGAZINE](https://gigazine.net/news/20260810-claude-code-auto-mode/) / [DigitalApplied](https://www.digitalapplied.com/blog/claude-code-auto-mode-default-permission-model-shift)

### Routines・拡張機能の体系的解説

Makerkitによる「[Claude Code Routinesの完全ガイド](https://makerkit.dev/blog/tutorials/claude-code-routines-guide)」が公開。2026年4月リリースのRoutines機能をローカルDevツールから「スケジュールされたクラウド自動化プラットフォーム」への転換と位置づける内容で、3種類のトリガー（スケジュール・API・GitHubイベント）と3種類の実行方法（クラウドRoutines・Desktopスケジュール・/loop）の違いを明快に整理している。ちなみに今あなたが読んでいるこのダイジェストもRoutinesで自動生成されている。

CodingNomadsはSkills・MCP・Hooksの役割分担を「Skillsが何をするかを定義し、MCPがデータを提供し、Hooksがルールを強制する」という一言フレームワークで整理した[チュートリアル](https://codingnomads.com/claude-code-extensions-skills-mcp-hooks)を公開。動画・クイズ付きの構造化コース形式で、MCPサーバーによるWebSearch・スクレイピング・DBアクセスの実例も含む実践的な内容だ。

業務ハックLabの[8月アップデートまとめ](https://yougears-lab.com/claude-update-20260805/)によると、Opus 5がMax/Team Premium/Enterprise/APIのデフォルトOpusに設定済み、APIキーへの有効期限設定機能追加（7日以上でメール通知）、レガシーWorkbench（Claude Console）の8月17日終了という3点が8月上旬の主要変更点。**8月17日はレガシーWorkbenchの終了日**なので、まだConsoleを使っている場合は移行要。

## AIニュース・業界動向

### Claude Opus 5: 「Fable 5相当の知性を半値で」（一次ソース確認済み）

7月24日に発表されたClaude Opus 5が各メディアで改めて取り上げられている。価格は入力 **$5/1M tokens・出力 $25/1M tokens**（Fable 5の約半額）で、SWE-bench Verified **96.0%**・IMO 2026 **42/42完全正答**（機械検証済み証明）という数値が確認されている。エフォートトグル（low/medium/high）によりリクエスト単位でコスト-性能をトレードオフできるのが最大の特徴。Claude CodeのMax/Team Premium/Enterprise/APIではデフォルトのOpusモデルとして既に稼働中。

Axiosはこのリリースを「Anthropicの2026年末IPO準備の一環」と報道。SiliconAngleはResponsible Scaling Policy準拠の安全評価とAuto modeデフォルト化との組み合わせで「より強力な自律AIエージェントが実現する」と分析している。

> 出典: [Anthropic公式](https://www.anthropic.com/news/claude-opus-5) / [Axios](https://www.axios.com/2026/07/24/anthropic-releases-new-model-opus-5) / [SiliconAngle](https://siliconangle.com/2026/07/24/anthropic-launches-claude-opus-5-efficiency-safety-improvements/)

### MCP ステートレス化：静かな革命（一次ソース確認済み）

GitHub MCPサーバーが[2026-07-28仕様](https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/)に対応。この仕様では `initialize` ハンドシェイクと `Mcp-Session-Id` ヘッダーが廃止され、完全ステートレス設計に移行した（SEP-2575/SEP-2567）。各リクエストの `_meta` フィールドにプロトコルバージョン・クライアント情報・ケーパビリティを含める設計に変わり、サーバーレス・エッジインフラへのデプロイが容易になる。Python SDK 2.0も同時リリース（主要クラス名変更あり）。Tier 1 SDK（Python/TypeScript/Java/C#）はすべて対応済み、Rustはベータ版。

MCPサーバーを自前でホストしている場合は移行手順の確認が必要。DigitalAppliedの[詳細技術分析](https://www.digitalapplied.com/blog/mcp-2026-07-28-stateless-spec-agent-infrastructure-2026)が参考になる。

### EU AI Act：2026年8月から実装フェーズへ

eguweb.jpの[週次まとめ](https://eguweb.jp/ai/81270/)によると、EU AI Act Article 50が8月2日から施行開始し、AI生成コンテンツへの機械可読マーキングが義務化された。本番AIエージェントの運用が始まるタイミングと規制施行が重なる「歴史的なタイミング」として分析されており、企業は権限・ログ・評価・コスト管理の整備が急務な段階に入っている。
