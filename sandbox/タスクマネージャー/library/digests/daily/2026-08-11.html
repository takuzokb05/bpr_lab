Claude Code・エコシステム

Self-Hosted Runner × Cross-Session Messagingで分散エージェントが現実に

Claude Code v2.1.224（2026-08-07リリース）の最大の変化は、これら二つの機能の組み合わせにある。Self-hosted runnerは`claude self-hosted-runner`コマンドで自社マシン・コンテナをセッション実行基盤として使える機能（Team/Enterpriseプラン、パブリックベータ）。Fixed（常時起動）とOn-demand（セッション到着時のみ）の2モードを提供し、企業ネットワーク内のツールやコンプライアンス要件を満たしながら運用できる。[^1]

これに`SendMessage`と`ListAgents`の2ツールが加わることで、異なるマシン上のClaude Codeセッション同士がメッセージを交換できるようになった。複数サーバーにまたがるサブエージェントへのタスク委譲が可能になり、マルチマシン・エンタープライズ規模のエージェントネットワーク構築への道が開いた。[^2] 8月の主要バグ修正（Bashコマンド実行修正、/tui rewind改善、イベントループ停止削減）も含め、品質強化は7月から継続するトレンドだ。[^3]

Skills・Hooks・MCP・Subagents ── 4要素の棲み分けが整理される

Claude Code拡張機能の使い分けに関する解説記事が複数出揃い、2026年版のコンセンサスが形成されつつある。共通の整理はこうだ：単純な繰り返しルール→Skills、実行前後の自動検証→Hooks、重い並列処理→Subagents、外部データ統合→MCP。非エンジニア向けの実践ガイドも登場し、ターミナルの専門用語なしでワークフローを設計する事例が増えている。[^4][^5]

Claude Code CLIの包括的アーキテクチャガイドでは、Hooksの21イベント（PreToolUse, PostToolUse等）の全パターン、git worktreeを使った並列エージェントのファイル競合回避、CLAUDE.mdの最適化（200行以内・コマンド先頭記述）が整理されている。「技術より構造がClaude Code高出力エンジニアと平均の差」という指摘は、日々CLAUDE.mdを育てているユーザーには刺さるはずだ。[^6][^7]

MCP 2026：ステートレス化とエンタープライズロードマップ

Model Context Protocol公式ブログが2026年の主要方針6点を発表した（一次ソース確認済み）。最重要変更はセッション廃止によるステートレスコアへの移行で、ロードバランサー下での水平スケールに対応。マルチラウンドトリップリクエスト、OAuth 2.1認証強化、tools/listキャッシュも計画済み。2026-07-28仕様はRC版として公開済み。Tier 1 SDK（Python, TypeScript, Go, Java, Ruby, PHP, C#）の同期更新も予定。2026年3月時点でSDKは月間9,700万ダウンロード、GitHubスター8.1万超と普及は加速している。[^8][^9]

Claude Agent SDK（旧Claude Code SDK、2025年9月改名）のModal・Trigger.devへのサーバーレス展開も注目。2025年5月の月間50件から2026年4月に14,800件（296倍）に検索需要が急増しており、本番エージェントの無人実行ニーズが爆発的に増えている。[^10]
