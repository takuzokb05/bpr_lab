## 要約
AnthropicのCode with Claudeイベントで発表されたClaude Agent SDK 2026の新機能解説。主要アップデートはDreaming（長期計画・仮説立案機能）、Outcomes（成果物追跡）、マルチエージェントオーケストレーション、Claude Finance（10個のプレビルドエージェント）。Managed Agentsではアクティブセッション中のツール・MCP設定のライブ更新が可能になり、100K+トークンのツール出力もサポート。ツール実行を自前インフラで実行しながらオーケストレーションはAnthropicレイヤーで継続できる「外部実行」機能も追加。SDK機能としてパターンが標準化されたことで各チームの独自実装が不要に。
