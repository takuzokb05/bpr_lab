# NVIDIA が Hugging Face を約$13B で正式買収発表（NVIDIA公式ブログ）

## 要約
2026年9月3日、NVIDIAはHugging Faceの買収合意を正式に発表した（買収額 約$12.93B＝約1.9兆円）。Hugging Faceは1,800万人以上の開発者・研究者が利用するオープンAIモデルの最大ハブで、300万以上のモデル・50万以上のデータセット・100万以上のアプリを公開している。NVIDIAはHugging Faceを「AIエコシステム全体のオープンプラットフォーム」として継続運営すると表明し、オープンウェイト/オープンソースモデルを引き続き支援する。買収対価には従業員向け最大$1Bの株式ベース報酬プログラムを含む。NVIDIAは既にHugging Faceへのオープンモデルおよびデータの最大コントリビューターであり、今回の買収でオープンAIエコシステムの中核インフラを掌握する。クロージングは2027年前半を見込む。
以前の報道（TechCrunch 2026-08-26）では「交渉中」とされていたが、今回は正式な合意発表。AI産業の勢力図に大きな影響を与える可能性がある（NVIDIAがAIチップ＋AIモデルハブを同時に支配）。
