# Anthropic Memory API beta (agent-memory-2026-07-22) & HIPAA自己設定機能（2026年7月）

## 要約
AnthropicがClaudeプラットフォームに追加した2つの開発者向け新機能。(1) **Memory API betaヘッダ（agent-memory-2026-07-22）**：Memory APIの挙動を変更するbetaヘッダを追加。変更点：メモリ一覧がサーバー定義の安定した順序で返されるよう変更、depth パラメータを0・1・省略のみ許可に制限、path_prefix は `/` で終わり全パスセグメントに一致することを必須化。エージェントメモリの一覧取得挙動の一貫性を改善するための変更。(2) **HIPAA自己設定**：EnterpriseおよびAPI組織の管理者がBusiness Associate Agreement（BAA）のレビュー・実装ガイドのダウンロード・HIPAA設定の有効化を単一フローで完結できるよう対応。医療・ヘルスケア分野での本番利用のハードルを大幅に引き下げる機能。エンタープライズ・ヘルスケア向けClaude活用の拡大を示唆。
