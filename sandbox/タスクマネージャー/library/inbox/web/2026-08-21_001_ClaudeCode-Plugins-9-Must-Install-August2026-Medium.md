## 要約
2026年8月時点での開発者向けClaude Codeプラグイン9選を実践的に紹介する記事。公式マーケットプレイスには250以上のプラグイン、コミュニティカタログには2,000以上が存在する中から厳選。プラグインはスキル・エージェント・フック・MCPサーバー・言語サーバーを単一ユニットとして/pluginコマンドで導入できる。人気MCP上位にはFigma（デザイントークン抽出）、Playwright（ブラウザ自動化）、Vercel（デプロイ管理）、PostgreSQL（DBクエリ）、GitHub（PR・Issue管理）が挙がる。Claude Code 2026のカスタマイズ3層（Skills / Hooks / Subagents）との組み合わせ方も解説。
