## 要約
Microsoft 公式開発者ブログによる BUILD 2026 での Agent Framework 発表内容。AutoGen と Semantic Kernel を統合した Microsoft Agent Framework が BUILD 2026 で新機能を発表。主な発表：Agent Harness（エージェントの実行管理基盤）・Hosted Agents（マネージド実行環境）・CodeAct（コード実行ベースのアクション）等。2026年4月2日に 1.0 GA に到達しており、信頼性が高まったエンタープライズ向けエージェントフレームワーク。Anthropic の Claude Agent SDK や Claude Code のマルチエージェント機能との比較において、Microsoft の対抗エコシステムの現況を把握するための一次情報。AI エージェントフレームワーク競合環境の理解に重要。
