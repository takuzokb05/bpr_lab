## 要約

2026年8月に主要LLMプロバイダーがほぼ同時期に次世代モデルを投入。米国大統領令EO 14409の設計期限（8月1日）が背景にあり、各社が新フレームワーク適用前の投入を目指したと分析。

**クラウドAPIモデル**:
- **Qwen3.8-Max**（Alibaba, 8/2）: 2.4兆パラメータMoE、950Bアクティブ、コーディング・自律タスク特化。価格$2/$6/Mトークン
- **OpenAI Astra**（8/1確認）: 未解決数学10問を形式的証明で解決、マルチエージェント長期推論設計。GPT-5.6の後継
- **Muse Spark 1.2**（Meta, 8/6）: Meta独自モデルシリーズ第二弾

**オープンウェイト**:
- **Kimi K3**（Moonshot AI, 7/27重み公開）: 2.8兆パラメータ、Modified MIT商用可
- **GLM-5.2**（Z.AI）: 約744Bパラメータ、オープンウェイトランキング1位、MIT
- **Qwen3.8-Max Open-Weight版**（Alibaba）: Max級モデルの重み公開はシリーズ初

**スモール・エッジモデル**:
- **LFM2.5-2.6B**（Liquid AI, 8/4）: スマートフォンで30トークン/秒、<2.5GBメモリ、ツール呼び出し対応エージェント向け
- **Gemma 4 E2B**（Google）: ~2.3Bパラメータ、Raspberry Pi 5で動作、128Kコンテキスト、Apache 2.0

**トレンド**: 「最強モデル」より「安いモデルを賢く使う」が勝ち筋。分類・下書き・要約は軽量モデルで十分なケースが多く、FX自動取引のシグナル判定にも小型モデルの活用余地あり。
