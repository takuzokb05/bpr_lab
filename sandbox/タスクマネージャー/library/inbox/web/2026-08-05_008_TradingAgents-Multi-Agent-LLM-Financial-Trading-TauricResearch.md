## 要約
TauricResearchによるTradingAgentsフレームワークの公式ページ。GitHub Stars 80,000超、Forks 15,500超のオープンソース最多スター数AI取引フレームワーク。UCLA+MITチームによる研究から生まれたマルチエージェント構成。7つの専門LLMエージェント（ファンダメンタル分析・センチメント分析・ニュース分析・テクニカル分析・強気/弱気リサーチャー・トレーダー・リスクマネージャー・ファンドマネージャー）が実際の取引会社を模倣して連携。対応プロバイダー：OpenAI（GPT-4o以降）・Anthropic Claude・Google Gemini・Grok（2026年4月時点）。v0.2.4ではLangGraphチェックポイント再開・永続的意思決定ログ・DeepSeek/Qwen/GLM/Azure対応を追加。バックテスト実績：AAPL累積リターン+26.62%（Buy-and-hold: -5.23%）。注意：ライブ取引での実績はなく、バックテスト期間は1四半期のみ。
