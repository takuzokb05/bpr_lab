# Anthropic Acquires Bun as Claude Code Hits $1 Billion Revenue Milestone

## 要約
AnthropicによるJavaScriptランタイム「Bun」買収の公式発表記事。Claude Codeは公開から6ヶ月でランレート$1B（10億ドル）を達成し、そのタイミングでの戦略的買収。BunはClaude Codeのランタイム・パッケージマネージャー・バンドラー・テストランナーとして中核インフラに位置づけられる。「Claude Codeがエラーを起こすとBunがクラッシュする」という依存関係が買収の主因。Bunはオープンソース・MITライセンスを継続し、JavaScriptエコシステムへの投資も継続。Claude CodeはAnthropicの初めて商業的に大成功した製品として位置付けられ、300億ドル超のIPOへ向けた布石。Wilson Sonsini法律事務所がIPO準備を担当。
