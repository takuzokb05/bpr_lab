## 要約
genai-ai.co.jpによるClaude Code Routines機能の日本語実践ガイド。Routinesは「プロンプト（実行内容）+ トリガー（実行タイミング）」の組み合わせで、PC不在でもクラウド上で自動実行される機能。3種のトリガー：①スケジュール（毎朝9時など時間ベース）、②API（外部イベント発生時に即起動）、③GitHub（開発フロー自動化）。活用事例：日次売上レポート自動生成、メール返信下書き作成、Notion×Gmail連携の問い合わせ対応。プラン別実行回数制限あり（Pro: 5回/日、Max: 15回/日）、複数業務を1回の起動にまとめることで回数を節約可能。従来の定期スクリプトとの違いはAIが「判断を伴う処理」を実行できる点。
