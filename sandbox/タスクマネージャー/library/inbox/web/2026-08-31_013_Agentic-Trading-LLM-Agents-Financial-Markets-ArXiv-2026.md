# Agentic Trading: When LLM Agents Meet Financial Markets

- ソース: web
- 言語: en

- 取得日: 2026-08-31

## 要約
2026年5月公開のArXiv論文。LLMエージェントが金融市場に適用される際の体系的なレビュー。バックテストでは強いリターンを示すが、本番運用では取引コスト・スリッページ・市場レジーム変化により差が大きい実証例を整理。TradingAgents（30日間で約7%リターン、S&P500の4.5%に対し）を実例として挙げながら、22%ドローダウンと再現性課題を指摘。2026年の実践的ワークフローとして「AI for context → トレーダーが判断 → ルールベースBotが執行 → バックテスト検証 → デモ練習 → ハードリスク上限」を推奨。学術的一次情報として価値高い。
