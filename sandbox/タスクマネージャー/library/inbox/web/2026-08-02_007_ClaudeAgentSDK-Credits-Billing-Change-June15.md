## 要約
2026年6月15日より施行されたClaude Agent SDK（旧Claude Code SDK）の料金体系変更を解説。サブスクリプションプランでのAgent SDK利用・非インタラクティブ実行は、インタラクティブ制限とは別の月次Agent SDKクレジットから消費: Pro $20/月、Max 5x $100/月、Max 20x $200/月。背景: Anthropicが2026年初頭にClaude Code SDKをClaude Agent SDKに改名（SDKがコード以上のエージェント構築を対象とする野心を反映）。API経由の直接利用はトークン課金のまま変更なし。Builders向けには無料tiersを超えた後のコスト試算方法、バッファ設定の推奨値も解説。非インタラクティブCI/CDパイプラインでの実行が特に影響を受ける点に注意。
