# MCP 2026-07-28で「普通のWebサイトがAI対応する時代」が近づいた

- ソース: web

## 要約
株式会社タレントクラウドが 2026-07-28 の MCP 仕様改定を日本語で詳解した記事。新仕様の核心として「ステートレスプロトコル」採用により、特別なインフラなしに普通の Web サーバー上で MCP サーバーを実装可能になったことを指摘。これにより「普通のWebサイトが AI 対応する時代」が実現に近づいた、という重要な示唆を提供。ビジネス活用の観点から、Slack MCP・DB MCP・Notion MCP の3つが業務効率化の核になり得ることを解説。GitHub MCP で自動コードレビュー、Slack MCP で定期報告自動化のユースケースも具体的。2026 年は楽楽精算・freee・kintone・サイボウズなど国産 SaaS の MCP 対応が本格化する見通し。
