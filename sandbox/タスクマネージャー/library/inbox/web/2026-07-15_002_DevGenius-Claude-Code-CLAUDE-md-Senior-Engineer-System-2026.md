## 要約
Dev GeniusのClaude Code実践チュートリアル（2026年）。CLAUDE.mdを「シニアエンジニアシステム」として設計する手順を解説。Key thesis: CLAUDE.mdはセッション開始ごとに読まれる特別ファイルで、テックスタック・プロジェクト構造・コーディング規約・ワークフロールールを記述することが出力品質の最大改善手段。推奨構成: ①Bash コマンド（build/test/lint/dev）、②コードスタイル（言語・フォーマッタ・命名規則）、③ワークフロールール。スキルはMDベースの再利用可能ワークフローでスラッシュコマンドと統一（2026年時点）。Hooksは「必ず実行されなければならないもの」のみ（PreToolUse/PostToolUse/SessionStartのライフサイクルイベント）。具体的なCLAUDE.mdテンプレートと実用パターンを含む。
