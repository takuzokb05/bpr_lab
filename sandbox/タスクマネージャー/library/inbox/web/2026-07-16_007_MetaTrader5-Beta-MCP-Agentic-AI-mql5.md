# MetaTrader 5 Beta Build 5955 — MCP・AIエージェントのネイティブサポート開始

- URL: https://www.mql5.com/en/forum/511825
- ソース: web
- 言語: en
- テーマ: ai-trading
- 取得日: 2026-07-16

## 要約

2026年7月16日（本日）、MetaQuotesがMetaTrader 5の新ベータビルド5955をリリース。最大の新機能はModel Context Protocol（MCP）とAIエージェントのビルトインサポート。クライアントターミナルとMetaEditorの両方で新機能が利用可能。AIエージェントが自然言語でMT5に直接接続し、マーケットデータ取得・注文発注・ポジション管理・テクニカル分析が可能になる。これまでコミュニティ製MCP Serverでの回避策が必要だったが、公式実装により信頼性と安定性が向上。Webull・Deriv・IG・eToro等の主要ブローカーもMCP統合を進める中、MetaQuotesがようやく追随。パブリックベータ参加を推奨。FX自動取引にLLMを組み込む実験の敷居が大幅に低下。
