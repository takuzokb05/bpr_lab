## 要約
Stacktreeによるモデルコンテキストプロトコル2026-07-28仕様の変更点まとめ。ステートレスコア・MCP Apps（サンドボックスHTML UI）・Tasks拡張・W3C Trace Context対応・JSON Schema 2020-12フルサポートが主な新機能。ブレーキングチェンジとしてセッション管理APIの削除、旧認証フローの廃止が挙げられる。JSONスキーマ対応によりMCPツールのパラメータ検証が厳密化。LinuxFoundationへのガバナンス移管も反映。MCP開発者が即座に参照すべき差分リファレンス。
