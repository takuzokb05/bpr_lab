## 要約
Uravationによる2026年9月版Claude Code Plugins完全ガイド。Pluginsとは従来のSkills/Hooks/MCP設定を一つのパッケージにバンドルし社内・社外に配布できる仕組みで、2026年9月時点でbeta表記のない正式機能。作成方法（SKILL.md＋hooks.jsonの組み合わせ）、公式Marketplaceへの公開手順、社内配布（settings.jsonへの追加）を解説。plugin eval機能を使ったQA方法も紹介（テストケース定義→スコアリング→ベースライン比較）。先行するSkills（ローカル）と異なりPluginsは配布・バージョン管理が可能。Claude Code拡張機能のエコシステム構築に向けた重要な機能。
