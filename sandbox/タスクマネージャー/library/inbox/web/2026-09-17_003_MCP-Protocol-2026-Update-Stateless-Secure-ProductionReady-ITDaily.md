# MCP protocol receives major update: more secure and production-ready

## 要約
2026-07-28仕様リリースを受けたMCPプロトコルの大型アップデート解説記事。最大の変更はリクエスト中心アーキテクチャへの移行（ステートフル→ステートレス）。各リクエストが必要な情報を自己完結的に運ぶため、ラウンドロビン負荷分散が可能になりエンタープライズ規模での運用に正式対応。改善点：(1)スケーラビリティ向上（共有ストレージ不要のサーバー分散）(2)認証強化（より厳格な認可制御＋ローカル結果キャッシュ）(3)廃止コンポーネントは12ヶ月以上動作保証。Agentic AI Foundation（Linux Foundation傘下）がAnthropicやOpenAI・Google・Microsoft・AWSなどと共に管理。2024年のオープンソース化から18ヶ月の実運用経験を反映した安定版。
