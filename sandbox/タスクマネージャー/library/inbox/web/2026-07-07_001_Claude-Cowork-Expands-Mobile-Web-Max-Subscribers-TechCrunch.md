## 要約
TechCrunch（2026-07-07）報道。Claude CoworkはデスクトップアプリとしてJanuary 2026に登場したが、本日（7/7）より**Maxサブスクライバー向けにWebおよびモバイルでも利用可能**になった。ユーザーはデスクから作業を開始し、スマートフォンで進捗確認し、ラップトップを閉じていてもアウトプットを後から受け取ることができる。Coworkはコーディングエージェント競争がオフィス業務全般に拡大する戦略の一環として位置づけられており、AnthropicはAIエージェントを開発者ツールから汎用業務自動化プラットフォームへ進化させる意図を示している。"The coding agent wars are spilling into the rest of the office"という見出しが示すように、GitHub CopilotやCursorとの差別化軸として「モバイルで確認できる非同期エージェント作業」を打ち出した。
