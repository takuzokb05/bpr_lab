# GSA Proposes Sweeping AI Data Safeguarding Rules for LLM Contractors

- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-07-06

## 要約
Holland & Knight 法律事務所による米国 GSA（一般調達庁）のAIデータ保護規則提案の解説。2026年6月17日、GSA が連邦官報で LLM 請負業者向けのデータ保護基準を公表・パブコメ募集開始。政府データを LLM システム内でどう取り扱うかの標準化された契約保護条項を策定。訓練・ファインチューニングへの政府データ利用禁止、データ削除手順の標準化、アクセスログの保持要件などが含まれる。EU AI Act の公共調達版に相当する規制として注目。政府向けAI製品・サービスを提供する企業が準拠を検討すべき重要な一次情報。
