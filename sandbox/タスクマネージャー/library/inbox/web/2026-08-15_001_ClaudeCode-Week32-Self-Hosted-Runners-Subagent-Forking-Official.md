## 要約
Anthropic 公式 Claude Code Docs の Week 32（2026年8月3〜7日）更新まとめ。主要変更点：(1) Self-Hosted Runners が Team/Enterprise に GA（`claude self-hosted-runner` コマンドで自社インフラ上でセッション実行可能、内部サービスアクセス可）、(2) サブエージェントの200件/セッション上限撤廃、(3) クロスセッション SendMessage のアップグレード、(4) デフォルトサブエージェントフォーキング（fork subagent が会話・プロンプトキャッシュを継承）、(5) GitLab MR サポート強化、(6) Compliance API が Cowork/Code 全プラットフォームに拡張。8月7日リリースで「どこで動くか」「誰の声を聞くか」「何本スポーン可能か」の3軸が同時に変わった重要アップデート。
