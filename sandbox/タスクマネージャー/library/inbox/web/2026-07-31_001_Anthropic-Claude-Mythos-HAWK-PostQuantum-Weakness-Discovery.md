# Claude Mythos Preview Discovers Post-Quantum Cryptographic Weakness (HAWK-256)

- URL: https://www.anthropic.com/research/discovering-cryptographic-weaknesses
- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-07-31

## 要約
Anthropicが2026年7月29日に発表した公式研究。未公開モデル「Claude Mythos Preview」が60時間でNISTポスト量子署名候補のHAWK-256に構造的脆弱性を発見した。HAWK-256の鍵強度が2^64から2^38オペレーションに大幅低下することが示された。具体的には格子構造内の未使用対称性（自己同型写像）を悪用したもので、2年間の人間による専門家レビューが発見できなかった欠陥をAIが短時間で発見した。同日HAWKチームはNISTのポスト量子署名標準化プロセスから撤退。加えてMythosByは7ラウンドAES-128攻撃の200〜800倍高速化も達成。現行本番システムへの即時脅威ではないが、AIによる暗号解析の新地平を示す重要な研究成果。
