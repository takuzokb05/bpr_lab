## 要約
シニアエンジニアが実践するClaude Code 10のワークフローTips。(1) CLAUDE.md を200行以内に保つ、(2) Plan ModeでShift+Tab→計画確認→実行、(3) サブエージェントで調査タスクを分離、(4) git worktreeで並列エージェント実行、(5) フックをガードレールとして使用、(6) ghインストールでGitHub直接操作、(7) Makefileでチーム共有ワークフロー化（make ai-review/test/security）、(8) MCP経由でDB・Jira・Slackと接続、(9) ハルシネーション防止の検証ループ、(10) @ 参照でVS Code拡張のコンテキスト管理。Anthropic社内テストでは無制限試行33%→構造化アプローチで大幅改善を示す実績データ付き。
