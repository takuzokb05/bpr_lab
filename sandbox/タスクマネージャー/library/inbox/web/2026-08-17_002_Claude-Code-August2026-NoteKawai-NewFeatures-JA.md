## 要約

2026年8月前半（8月1日〜15日）のClaude・Claude Code主要アップデートを実務視点でまとめた記事。note.comでの人気記事で実務活用を中心に解説。

主要アップデート:
- **Focus view**: ツール実行ログを折りたたみ、会話の見通しを確保（Ctrl+Alt+F）
- **サブエージェント200件上限撤廃**: 長期セッションでも無制限にサブエージェントを起動可能に
- **ディスパッチ機能強化**: スマホ・外出先からPCのClaude Codeを遠隔操作できるRemote Control resume対応
- **VS Code サイドバー**: セッショングループ表示が追加され複数プロジェクト管理が容易に
- **サンドボックス認証ファイルのマスク**: v2.1.221でmode:"mask"追加、外部API呼び出し時に実キーを渡さず安全に操作可能

筆者が特に評価するのはディスパッチ機能で、「外出中にスマホからPCのClaude Codeに指示を出せる」実運用を紹介。ルーティン機能と組み合わせて朝のリサーチ自動化も実現しているとのこと。
