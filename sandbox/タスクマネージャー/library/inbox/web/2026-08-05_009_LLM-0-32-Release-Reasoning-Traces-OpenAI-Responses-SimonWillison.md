# New release of LLM adds support for reasoning traces, OpenAI Responses, server-side tools, and smarter logging

- URL: https://simonwillison.net/2026/Aug/4/new-release-of-llm/
- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-08-05

## 要約
Simon WillisonによるLLM 0.32リリース（2026年8月4日）の公式発表。LLM初期ローンチ以来最重要なリリースと位置づけ。主要新機能：①可視化されたリーズニングトレース（Claude/o3等の思考過程を表示）、②OpenAI Responses APIサポート（GPT-5.6ファミリー対応）、③サーバーサイドプロバイダーツール（Web検索・コード実行をAPI側で処理）、④再設計されたコンテンツアドレス可能SQLiteログ（セッション跨ぎの検索改善）、⑤新モデル追加。GPT-5.6 Luna（$0.20/$1.20/Mトークン）がデフォルトモデルに。CLIおよびPython APIで利用可能。`pip install llm`でアップグレード。開発者向けのLLM実験・プロトタイピングに直結する変更。
