## 要約
Quollio Technologies株式会社が2026年8月26日、データインテリジェンスクラウド「QDIC（Quollio Data Intelligence Cloud）」にMCPサーバー機能を正式提供開始。Claude CodeなどのAIアシスタントからQDICのデータカタログ・系譜情報・品質メタデータに直接アクセス可能になる。データガバナンスプラットフォームへのMCP統合は国内エンタープライズ市場での事例として貴重。PRTimesの一次情報として信頼性高い。日本企業によるMCP活用の具体的製品リリース事例。
