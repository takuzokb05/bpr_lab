## 要約
Blake Crosleyが2026年7月に公開したClaude Code CLIの包括的リファレンスガイド。MCPサーバーで外部ツール（Web検索・スクレイピング・DB）と接続する方法、Hooksの全17イベント・4タイプ・3本の本番用サンプルを詳解。Skillsはフォルダベースの命令パックとして動作し、オンデマンドでロードして専門家モードに切り替え可能。最小構成として「CLAUDE.md 1枚・.mcp.json（必要なMCPのみ）・安全フック1本・再利用スキル1本・必要時のみサブエージェント」を推奨。実際のコード例付きで、サブエージェント並列化・git worktreeパターンも説明。2026年7月時点で42種の組み込みツール（File/Code系・Shell/Process系）を網羅。
