# AI Model Context Protocol Adds Centralised Auth for Enterprise

- テーマ: claude-ecosystem

## 要約
InfoQによるMCP（Model Context Protocol）の企業向け集中認証（Enterprise-Managed Authorisation, EMA）安定版リリース報告（2026年7月）。EMAはIDプロバイダー経由でMCPサーバーへのアクセスを組織が集中管理できる仕組みで、2026-07-28 MCP仕様RC候補でStableに昇格。OAuthとOpenID Connectとの整合性を強化した認証拡張。企業のAIエージェントデプロイ時のアクセス制御・監査要件を満たすための重要機能。MCP活用を企業環境に展開する上での鍵となるアップデート。
