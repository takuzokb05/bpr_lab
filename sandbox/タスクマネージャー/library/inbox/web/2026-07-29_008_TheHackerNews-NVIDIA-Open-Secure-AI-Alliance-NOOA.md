# NVIDIA Forms 37-Member Open Secure AI Alliance and Open-Sources NOOA Framework

- URL: https://thehackernews.com/2026/07/nvidia-forms-37-member-open-secure-ai.html
- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-07-29

## 要約
The Hacker NewsによるNVIDIA主導のOpen Secure AI Alliance（OSAIA）設立報道。37組織参加、AIエージェントのセキュリティ・テスト・監査・ガバナンスのためのOSSフレームワーク「NOOA（No-Operations Open Agents）」をApache 2.0でGitHub公開。主要貢献：HPEがSPIFFE/SPIREによるゼロトラスト認証、Hugging FaceがSafetensors（RCE防止）、IBM/Red HatがLightwell（署名付きパッチ配布）、MicrosoftがMDASH（マルチモデル脆弱性発見）を提供。HuggingFaceが7月インシデントでGLM 5.2を使い17,000アクションを分析したことが設立動機の一つ。
