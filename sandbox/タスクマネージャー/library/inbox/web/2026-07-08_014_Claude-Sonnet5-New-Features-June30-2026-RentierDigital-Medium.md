## 要約
Claude Sonnet 5（2026年6月30日リリース）の新機能詳細レビュー。性能：Opus 4.8に近い能力をより低価格で提供。Sonnet 4.6比での改善：推論・ツール使用・コーディング・ナレッジワーク全分野で向上。SWE-bench Pro 63.2%（Opus 4.8超え）、Terminal-Bench 2.1で80.4%（vs Opus 4.8の74.6%）。アジェンティック能力：Anthropicの「最もアジェンティックなSonnetモデル」—ブラウザ・ターミナル等のツールを使い自律実行、Sonnet 4.6が完了できなかった複雑タスクを完成、出力の自己チェック機能を持つ。技術仕様：1Mトークンコンテキスト（ネイティブ）、更新されたトークナイザー（性能向上のためテキスト処理を変更）。安全性：初のSonnetクラスの最新サイバーセキュリティ保護機能搭載、幻覚・お世辞傾向が低減。料金：プロモ$2/$10/M（8月31日まで）→その後$3/$15/M。Claude Codeのデフォルトモデルに設定済み。
