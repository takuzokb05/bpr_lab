## 要約
Claude Agent SDK（旧Claude Code SDK、2025年9月改名）を使ったエージェントの本番デプロイガイド。ModalとTrigger.devへのサーバーレス展開方法を解説。SDKはBash実行・ファイルシステム操作・Web検索などのツールと、複数ターンの推論ループ（計画→実行→観察→継続）を内包。「コードでエージェントを駆動したい、ツールを渡したい、構造化された結果を得たい」場合に最適。search demandは2025年5月の月間50件から2026年4月の14,800件に急増。Python・TypeScript対応、MCPサポート、セッション管理、ホスト型実行モデルを搭載。
