## 要約
Model Context Protocol 公式ブログによる 2026-07-28 最終仕様リリースの解説。最大の変更は「ステートレスプロトコルコア」への転換。従来の双方向ステートフルプロトコルからリクエスト/レスポンス型ステートレスへ移行し、スティッキーセッションや共有セッションストアが不要になった。Mcp-Method ヘッダーでルーティング可能になり、tools/list レスポンスをクライアントがキャッシュ可能。Extensions フレームワーク、Tasks、MCP Apps、認可強化、正式な Deprecation ポリシーも含む。Linux Foundation 傘下の Agentic AI Foundation（Anthropic・OpenAI・Block 共同創設）が管理。後方互換性のない変更があるため既存サーバーは移行確認が必要。
