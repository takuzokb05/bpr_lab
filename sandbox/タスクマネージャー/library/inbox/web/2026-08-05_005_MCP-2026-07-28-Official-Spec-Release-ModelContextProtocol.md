## 要約
Model Context Protocol公式ブログによる2026-07-28仕様の公式アナウンス。2026年5月21日にRC（リリース候補）がロックされ、7月28日に最終リリースとして出荷された最大規模の仕様改訂。主要変更点：①ステートレスコア（通常HTTPインフラでスケール可能、スティッキーセッション不要）、②Multi Round-Trip Requests、③ヘッダーベースルーティング、④キャッシュ可能なリスト結果、⑤認証強化（OAuth/OIDCアライン）、⑥正式な拡張フレームワーク（MCPアプリ・タスク拡張）、⑦Tier 1 SDK更新。非推奨化：Roots・Sampling・Logging機能。従来のステートフルなMCPサーバーが通常のラウンドロビンロードバランサーで動作可能に。
