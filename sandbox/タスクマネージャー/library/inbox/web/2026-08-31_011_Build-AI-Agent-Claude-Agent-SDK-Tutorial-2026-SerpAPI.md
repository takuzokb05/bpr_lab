## 要約
SerpAPIによるClaude Agent SDKのステップバイステップチュートリアル。Claude Agent SDKはClaude Codeを動かすのと同じエージェントループをライブラリとして提供する。Python版（v0.2.139）とTS版（@anthropic-ai/claude-agent-sdk v0.3.233）が毎週リリース中。チュートリアル内容: SDK インストール→初回エージェント作成→Claude Opus 4.8/Sonnet 4.6/Haiku 4.5の選択→パーミッション設定→インプロセスMCPサーバーでのカスタムツール統合→セーフティフック→サブエージェント委譲→完成プロジェクトのデプロイ。生の Claude API ツールコールループを書かずにエージェント機能を実装できる。
