## 要約
Claude Code 2026の包括ガイド。独自概念「Director Mode」を中心に解説：コードを1行ずつ指示するのではなく戦略的目標を委任するアプローチ。Hooks（PreToolUse/PostToolUse）によるセキュリティ・フォーマット自動化ワークフロー、MCPによる外部ツール・API接続、.claudeignoreによる不要ファイル除外。対応モデル：Haiku 4.5/Sonnet 5/Opus 4.8/Fable 5。必要環境：Node.js 18以上、環境変数でAPIキー設定。月間推定コスト：アクティブ開発者$20〜$50。特徴：マルチファイル操作・テスト・git操作の自動実行、IDE補完との補完的利用（全体的コードベース把握がIDEより優位）。セクション：①インストール・設定②必須コマンド③プロジェクト分析④高度な自動化⑤Director Mode⑥一般ワークフロー⑦パフォーマンス最適化⑧トラブルシューティング。
