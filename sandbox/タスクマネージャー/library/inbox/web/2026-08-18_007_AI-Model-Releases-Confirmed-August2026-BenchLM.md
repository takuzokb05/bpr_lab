- **Gemini 3.7 Flash** (Google, Aug 13)
- **Muse Spark 1.2** (Meta, Aug 6)
- **Grok 4.6** (xAI, Aug 6)
- **Seedance 2.5** (ByteDance, Aug 8)
- **Qwen Image 3.0 Pro / 3.0** (Alibaba, Aug 5)
トレンドとして、画像生成系モデルのリリースが多く、フロンティアLLMの競争はコスト低下（Claude Sonnet 5の$2/$10恒久化、Claude Opus 5の競合比半額）が焦点に。Gemini 3.5 Proの遅延やKimi K3の大規模オープンウェイトモデル公開が注目点。月次18リリースはペースとして過去最多水準。モデル選定コストの増大が開発者の課題として浮上している。
