# Claude Codeのおすすめスキル厳選6選——公式17種から実務向けを解説

## 要約
Orca株式会社エンジニアチームが公式17種スキルから実務で最も価値の高い6選を厳選解説。選定基準は「日常開発での使用頻度」「学習コスト対効果」「チーム導入のしやすさ」の3軸。code-review・verify・security-review・deep-research・run・simplifyが選ばれた理由と各スキルの具体的な使用例を示す。Claude Code Pro/Maxプランでの利用コストと時間削減効果の試算も付属。スキル導入前後の開発速度比較データ（内部調査）を含む。
