## 要約
Anthropic が2026年7月24日にClaude Opus 5をリリース。価格は入力$5/出力$25（100万トークンあたり）、コンテキストウィンドウ1Mトークン・最大出力128Kトークン。Frontier-Bench v0.1ではOpus 4.8の2倍超のスコアを達成しFable 5に迫る性能。ARC-AGI 3では次点モデルの3倍、OSWorld 2.0でもFable 5のベストを上回り1/3のコスト。Fast modeは通常速度の約2.5倍、価格は2倍。Claude Code内でもクレジット消費でFastモード利用可能。Opus 4.7のFastモードは同日廃止（リクエストはエラーに）。Claude Sonnet 5（6月30日リリース）との比較では、Opus 5は複雑エージェントタスク・長大コンテキスト・コスト妥協できない本番ワークロードに適し、Sonnet 5はコスト重視の繰り返しタスクに向く。
