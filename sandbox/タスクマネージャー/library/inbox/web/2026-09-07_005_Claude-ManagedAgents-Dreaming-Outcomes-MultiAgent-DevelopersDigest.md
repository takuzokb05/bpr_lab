## 要約
Anthropicが2026年5月6日に発表した3つの新機能「Dreaming（研究プレビュー）」「Outcomes（パブリックベータ）」「Multi-Agent Orchestration（パブリックベータ）」の詳細解説記事。Claude Agent SDK（TypeScript/Python）でエージェントをコードとして定義し、Anthropicがモデル呼び出し・ツールディスパッチ・コンテキスト圧縮・リトライを管理するマネージドエージェント基盤の仕組みを解説。オーケストレーターが複数の専門エージェントに並列でサブタスクを振り分ける構成、Agent Teamsのリードエージェント＋チームメイト構造も図解。Claude Codeを超えた自律エージェント構築の公式SDK活用の実践情報として重要。
