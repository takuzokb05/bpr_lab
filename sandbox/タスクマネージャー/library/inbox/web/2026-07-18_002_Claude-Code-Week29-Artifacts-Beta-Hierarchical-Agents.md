# Claude Code Week 29：Artifacts β・3段階ネスト・/cd コマンド・Voice Mode

- URL: https://releasebot.io/updates/anthropic/claude-code
- ソース: web
- 言語: en
- テーマ: claude-code
- 取得日: 2026-07-18

## 要約
Claude Code 2026年7月13-17日（Week 29）の主な新機能：(1) **Artifacts βリリース**：セッション成果物をclaude.ai上のライブ共有ページとして公開・インプレース更新が可能に。(2) **階層型エージェントスポーン**：親エージェントが最大3段階ネストで子エージェントを生成、複数モジュール横断タスクの分解に対応。(3) **/cd コマンド**：会話中に作業ディレクトリを変更してもプロンプトキャッシュを維持。(4) **Voice Mode**：/voice コマンドでスペースバー push-to-talk による音声入力に対応。(5) **Opus 4.8 デフォルト化**：Max/Team Premium/Enterprise pay-as-you-go でOpus 4.8がデフォルトモデルに。(6) **セーフモード（--safe-mode）**：全カスタマイズ無効化デバッグオプション追加。WebSearch上限200件/セッション・サブエージェント上限200件/セッションも設定可能に。
