## 要約
実務で得た8つのClaude Codeベストプラクティス。(1)CLAUDE.md: 200行以内・コマンド先頭記述・フォーマッター重複禁止。(2)Planモードを実行前に必ず使う。(3)サブエージェントで調査をオフロード。(4)git worktree活用の並列エージェント。(5)Hooksをガードレールとして使う（実行前後の検証）。(6)検証ループでハルシネーションを潰す。(7)コンテキスト肥大化の定期リセット。(8)チームMakefileで1コマンド習慣化。Anthropic内部テストでは無構造な試みの成功率33%に対し、構造化アプローチで高出力を確認。
