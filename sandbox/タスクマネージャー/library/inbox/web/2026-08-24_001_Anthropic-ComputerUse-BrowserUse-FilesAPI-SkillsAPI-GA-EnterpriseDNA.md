## 要約

2026年8月19日、AnthropicはAIエージェント関連の4つの主要機能を同日にGAリリースした。

1. **Computer Use** (`computer_toolset_20260801` として提供): デスクトップ画面を操作できるAIエージェントツール。GAによりエンタープライズ利用が可能に。
2. **Browser Use Tool**: ブラウザ操作専用ツール。Webページのナビゲーションやフォームへのデータ入力、コンテンツ抽出が可能。
3. **Files API**: ファイルのアップロード・管理・共有をClaude API経由で直接処理可能。
4. **Agent Skills API**: Claude Managed Agentsへのスキル追加・管理をAPIで実行。

これらは全てベータ版から正式版（GA）に移行。エンタープライズ環境でのプロダクション利用が公式にサポートされる。AnthropicはこれをAIエージェント基盤の「完成形」に近い状態として位置づけており、2026年の最も重要なプラットフォームアップデートの一つと評されている。Managed Agentsと組み合わせることで、ファイル読み取り・コマンド実行・ブラウザ操作・スクリーン操作を統合したフルスタックのエージェントワークフローが構築可能になる。
