## 要約

TechCrunchによるClaude Sonnet 5のリリース報道（2026年6月30日）。Anthropicはエージェントワークロードへのアクセス拡大を目的として、Opus 4.8に近い性能を低価格で提供するSonnet 5を発売。プランニング・ブラウジング・ターミナル操作などの自律的タスク実行能力が大幅向上。Sonnet 5は「エージェントとして計画を立て、ツールを使い、自律的に動作できる」能力を持つ最強のSonnetとして位置付けられる。Robinhoodのアジェンティック取引サービスなど既にパートナー企業への統合が進む。Anthropicとしては、高価なOpusを使うほどでもない日常的なエージェントタスクをSonnet 5で賄える設計を明示。
