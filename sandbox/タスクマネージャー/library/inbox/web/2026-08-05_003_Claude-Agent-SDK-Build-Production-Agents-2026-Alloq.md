## 要約
alloq.digitalによるClaude Agent SDK完全ガイド2026年版。Claude Agent SDKはAnthropicが提供するClaudeのフル能力（ファイル読み書き・シェルコマンド・Web検索・コード編集・MCP呼び出し）を持つ自律AIエージェントを構築するためのライブラリ。Claude Codeを動かすのと同じハーネスを使う。サブエージェントが深さ3までネスト可能（旧1）。主要な機能：カスタムツール定義・フック・スキル統合・MCP接続。プロダクション環境への移行手順（認証・料金・セキュリティ）を詳述。よくある落とし穴（MCP設定JSON構文エラー・コマンド解決失敗・サーバー起動失敗）への対処法も掲載。
