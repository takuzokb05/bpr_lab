## 要約
MCP ディレクトリ公式ブログによる 2026-07-28 RC の包括的解説。6つのSEP（Specification Enhancement Proposal）が一度に統合される背景と設計思想を解説。SEP-2575（ステートレスコア）、SEP-2549（キャッシュ制御）、SEP-1865（MCP Apps）、SEP-1492（Tasks）の詳細な仕様変更内容。特に MCP Apps によってサーバーがインタラクティブな HTML UI をホスト側に提供できる点は新しいエコシステムの可能性を開く。既存の 5,800+ サーバーへの影響と互換性維持策。SDK のティア別対応スケジュール（Tier 1: 10週、Tier 2: 6ヶ月）も記載。
