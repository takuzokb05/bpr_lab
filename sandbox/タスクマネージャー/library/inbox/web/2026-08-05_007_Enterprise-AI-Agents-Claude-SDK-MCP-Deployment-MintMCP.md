## 要約
MintMCPによるエンタープライズ向けAIエージェント構築ガイド。Claude Agent SDK + MCP統合でプロダクション品質のエージェントを構築する方法を解説。PoC（概念実証）→プロダクション移行で必要な認証・監視・コスト管理・セキュリティの実装パターンを詳述。Workload Identity Federation（WIF）を使った認証管理、MCPサーバーの権限スコープ管理（workspace:manage_tunnels等）、エンタープライズ管理認証（Enterprise-managed auth）の設定。MCPトンネル（2026-06-22仕様）の使い方とAPIエンドポイントの変更点。プライベートネットワーク接続・可観測性・埋め込みUIの統合例も含む。大規模導入（200+エージェント）でのベストプラクティス。
