## 要約
UnionAI（株式会社UnionAI）によるClaude Code Skills解説記事。Skillsの概念（SKILL.md + 任意のスクリプト・アセットから構成されるフォルダベースの指示パック）から実務活用まで網羅。用途別分類：コード品質（コードレビュー・テスト生成）、ドキュメント（PR説明・API仕様生成）、開発フロー（デプロイ・リリースノート）、プロジェクト固有（ドメイン知識・チーム規約）。実装例：`/review`スキルがリポジトリのコーディングガイドライン参照と自動チェックリスト生成。ユーザー投稿スキルパック（gstack等）の紹介あり。日本語記事として中級者向けの実践知識を提供。
