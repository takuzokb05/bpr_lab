## 要約
Claude Code v2.1.224で追加されたcross-session messaging機能の解説記事。`SendMessage`と`ListAgents`の2つの新ツールにより、異なるマシン上のClaude Codeセッション同士がメッセージを交換できるようになった。macOS・Linux対応。self-hosted runnerと組み合わせることで、分散エージェント協調（複数マシン上のサブエージェントへのタスク委譲）が可能になる。マルチエージェント・エンタープライズ用途での活用に向けた大きな一歩と位置づけられている。
