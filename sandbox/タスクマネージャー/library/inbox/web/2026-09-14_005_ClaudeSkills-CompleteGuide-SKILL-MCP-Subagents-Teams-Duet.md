## 要約
Claude Code Skills、MCP、Subagents、Agent Teamsの使い分けを網羅した実践ガイド。Skillsは`.claude/skills/<name>/SKILL.md`に配置するフォルダベースの命令パックで、YAMLフロントマターで起動トリガーを定義。MCPは外部システム接続（DB、API、ファイルシステム）に使い、Skillsは社内ワークフローのパッケージ化に使う。Agent Teamsは複数エージェントが並列作業する機能（実験的、2026年mid以降利用可）。Subagentsは独立したリサーチや検証タスクに使う。判断フローチャートと実際のSKILL.mdサンプル（コードレビュー、日次収集、PRドラフトなど）が含まれている。Anthropic公式ドキュメントを補完する詳細度が高いガイド。
