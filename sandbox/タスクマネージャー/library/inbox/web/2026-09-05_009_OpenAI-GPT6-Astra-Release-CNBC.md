# OpenAI announces rollout of GPT-6 Astra model

## 要約
CNBCによるGPT-6 Astraリリース報道（2026年9月3日）。主要事実: OpenAI GPT-6 Astraが9月3日に信頼パートナー向け限定プレビュー開始、翌4日に有料ユーザーへ段階展開。価格: $10/$50 per 1Mトークン（input/output）、コンテキスト1.05M。特徴: 「世界で最もインテリジェントかつアラインされたAIモデル」を自称、主要推論ベンチマークで満点または最高スコア、GPT-5.6 SolとClaude Fable 5を上回る。コンピューターユース機能（人間と同様にPCを操作）を搭載。7月のHugging Faceインシデントを受けてリリースを延期し安全策を強化した経緯あり。限定版でサイバーセキュリティ等特定プロンプトを拒否。
