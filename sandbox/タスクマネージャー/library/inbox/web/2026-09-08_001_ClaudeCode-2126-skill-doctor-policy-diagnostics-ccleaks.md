# Claude Code 2.1.261 adds /skill-doctor and policy diagnostics

- URL: https://ccleaks.com/news/claude-code-2-1-261-sep-2026
- ソース: web
- 言語: en
- テーマ: claude-code
- 取得日: 2026-09-08

## 要約
Claude Code v2.1.261（2026年9月4日リリース）の主要追加機能をまとめた記事。①`/skill-doctor`コマンド追加：読み込んでいるスキルのうち未使用のもの・コンテキストコスト過大なものを特定・剪定できる。②`/status`と`claude doctor`に「Organization policy」行を追加：組織ポリシーが読み込めない理由（プロキシ非対応など）を表示。③ポリシーヘルパー診断の強化：リフレッシュ失敗時に/statusへ表示、管理設定ダイアログ拒否時の終了理由表示、タイムアウト報告。④`bashOutputMaxChars`・`taskOutputMaxChars`設定追加：コマンド/バックグラウンドタスク出力の上限を最大128K文字まで引き上げ可能。⑤セッション・ターミナル・Remote Control・VS Code周りの信頼性修正多数。スキル管理とエンタープライズ向けポリシー診断の充実が今回のハイライト。
