## 要約
AI実務での副業時給2倍を達成した実践者によるClaude Code Hooksカタログ（note掲載）。コピペで即使えるHooksパターンをシーン別に整理。主な収録パターン：①コミット前の自動lint実行（PostToolUse: Bash）②危険コマンド検出ブロック（PreToolUse: Bash、rm -rf等を正規表現で検知）③テスト失敗時の自動リトライ（PostToolUse）④ファイル保存後の自動フォーマット（PostToolUse: Write）⑤セッション終了時のtodo.md自動更新（SessionEnd）⑥長時間処理のデスクトップ通知（PostToolUse）。各パターンにsettings.json記載例と実際の効果（所要時間・エラー削減率）を付記。2026年版の新フックイベントにも対応。
