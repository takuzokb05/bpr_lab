## 要約

Claude・Claude Code・Cowork・Chrome拡張の連携による業務自動化の包括ガイド。非エンジニア向けに実務活用フローを解説したGenAI Lab記事（2026年8月最新版）。

主な活用パターン:
- **Cowork**: デスクトップアプリからターミナルを触らずフォルダ指定で自動実行。GUI操作でClaude Codeのパワーを活用
- **Claude Code CLI**: ルーティン機能で毎朝のリサーチ・日次レポートを完全自動化
- **ディスパッチ機能**: スマホからPCのClaude Codeを遠隔起動、外出先からの業務委託が可能
- **Chrome連携**: Webサイト内容の直接取り込み・Claudeへの渡し方最適化

特筆すべきは、Max 20xサブスクリプション + サブエージェント並列実行の組み合わせで、従来10時間要していた業務を3時間前後に短縮した実例。スキルプリロード・永続メモリ・Hooksの三位一体運用で「状況を見てサブエージェントが自動判断して動く」境地を目指す設計指針を解説。
