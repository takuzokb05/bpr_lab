## 要約
Claude Code Skillsの選び方と導入手順を実践目線で解説。3軸の判断基準（頻度・重要性・自動化適性）でスキルを選定。推奨スキル：①skill-creator（対話でスキルを作るための基盤スキル）②コードレビューシステム（チームレビュー観点を標準化）③ドキュメント生成（docx/pdf/xlsx/pptx自動化）④frontend-design（UI生成品質向上）⑤webapp-testing（Playwrightブラウザ自動化）⑥セキュリティチェック（コード・依存関係の脆弱性スキャン）。段階的導入推奨：「最頻度タスクに合うスキル1つから始め、認識と自動トリガーを確認してから拡張」。重要知見：スキル説明（description）の書き方がトリガー成否を決める—モデルは説明のみをもとに使用判断するため、曖昧な説明は未使用のままに終わる。個人スキル（`~/.claude/skills/`）vs チーム共有（`.claude/skills/`、リポジトリレベル）の使い分けも詳説。
