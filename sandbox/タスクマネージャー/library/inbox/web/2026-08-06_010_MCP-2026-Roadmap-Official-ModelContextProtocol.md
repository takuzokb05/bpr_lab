## 要約
Model Context Protocol 公式ブログが発表した 2026 年の MCP ロードマップ。現時点で 5,000 以上の MCP サーバーが利用可能で、あらゆる主要な AI コーディングツールがサポート済み。2026年7月28日付けの最新仕様では、ステートレスプロトコルコア・マルチラウンドトリップリクエスト・ヘッダーベースルーティング・キャッシュ可能なリスト結果・認可強化・正式な拡張フレームワーク・更新済み Tier 1 SDK が追加された。MCP は「実験的」から「AI エージェントが外部ツール・DB・API に接続するための標準方式」へと昇格済み。ロードマップには普通の Web サーバー上で軽量に動く MCP サーバーの普及促進が含まれる。公式一次情報として信頼性が高い。
