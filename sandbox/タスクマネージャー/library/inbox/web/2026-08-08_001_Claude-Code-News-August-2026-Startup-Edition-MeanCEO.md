## 要約
2026年8月のClaude Code最新動向をスタートアップ視点でまとめたニュース記事。Claude Opus 5をデフォルトOpusモデルに追加、ダイナミックワークフローとネストされたサブエージェントの拡張、MCP・サンドボックス・モデルピッカー・リモートコントロールの改善が行われた。特筆すべきはパブリックベータとして自己ホスト型環境の提供開始（TeamおよびEnterpriseプラン向け）。Enterprise向けに推論フック（inference hooks）がベータ公開され、DLP（データ損失防止）をリアルタイムで適用可能に。使用上限警告のゲートウェイサポートや、`claude agents`のワークスペーストラストプロンプトも追加。スタートアップにとってClaude Codeは単なるコーディングツールを超え、実用的なインフラ基盤になりつつあるという見解。
