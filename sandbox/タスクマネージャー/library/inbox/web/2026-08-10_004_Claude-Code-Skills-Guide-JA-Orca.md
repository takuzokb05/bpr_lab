## 要約
Orca社によるClaude Code Skillsの実践ガイド。スキルの作り方を「手動作成」「Claudeに生成させる」「スキルから派生させる」の3パターンで解説。自動起動（コンテキスト連動）と明示的呼び出し（/スキル名）の使い分け、SKILL.mdの記述ルール、スキルの更新・廃止フローも説明。注意点として「スキルが長くなりすぎるとコンテキストを圧迫する」「チームで共有する場合の命名規約統一が重要」を指摘。具体的なユースケース（コードレビュー・デプロイ・レポート生成）のSKILL.mdサンプルを掲載。
