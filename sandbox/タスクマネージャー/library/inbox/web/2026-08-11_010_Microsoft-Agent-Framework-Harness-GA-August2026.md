# Microsoft Agent Framework Harness Now Generally Available

- URL: https://devblogs.microsoft.com/agent-framework/the-microsoft-agent-framework-harness-is-now-released/
- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-08-11

## 要約
MicrosoftがAgent Framework Harnessをリリース（2026年8月）。v1.13.0では豊富なFoundryホスティング・Responsesサポート、再利用可能なセッションストア、拡張されたテレメトリ・オブザーバビリティ、ワークフローリプレイ・承認機能が追加。.NETとPythonのSDKでDurable TaskとAzure Functions統合が強化。AutoGenとSemantic Kernelのマージにより生まれたフレームワークで、LangGraph 1.0、Claude Agent SDK、CrewAI 1.14等と並ぶ2026年主要エージェントフレームワークの一角となった。
