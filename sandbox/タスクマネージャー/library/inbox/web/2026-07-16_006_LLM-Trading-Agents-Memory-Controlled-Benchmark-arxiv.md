## 要約

2026年5月のarxiv論文。LLMトレーディングエージェントが株式市場で「知っている」から「やれる」への差を埋めるためのメモリ制御ベンチマーク。From Knowing to Doing（KTD）と題し、LLMが市場知識を保有していてもリアルタイム判断に変換できない「遂行ギャップ」を定量化。GPT-4o・Claude Sonnet・Gemini等のフロンティアモデルをCSI300銘柄で評価。結果として累積リターンは受動的な市場・スタイル露出で大部分が説明でき、株式選択アルファの持続的証拠は限定的。マルチエージェントフレームワークはアナリティクス精度を改善するが、完全自律の意思決定者ではなく「監督下のリサーチアシスタント」として捉えるべきとの結論。
