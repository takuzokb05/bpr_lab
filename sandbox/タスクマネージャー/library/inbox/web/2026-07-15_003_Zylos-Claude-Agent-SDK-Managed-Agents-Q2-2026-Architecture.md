## 要約
Zylos ResearchによるAnthropicのQ2 2026エージェントインフラ戦略の詳細分析。Claude Agent SDKとManaged Agentsは同時に投入されたが役割が明確に分離されている。Agent SDK: プログラマティックなセルフホストエージェント実行ハーネス（Python/TS）。独自のサブプロセスモデル・ツール実行エンジン・セッション永続化・権限システム・フックアーキテクチャ・マルチエージェント調整プロトコル・メモリスタックを内包。Managed Agents: 2026年4月8日公開ベータのホスト型インフラAPI。エージェントループ・ツール実行・ランタイムを自社構築不要で利用可能。今後の焦点はManaged Agentsでのクロスエージェント状態共有の信頼性と低コスト化（Q2-Q3 2026の未解決課題）。Anthropicの差別化戦略: 開発者はAgent SDKで深い制御を、プロダクト開発者はManaged Agentsで高速立ち上げを、という二層構造。
