## 要約
2026年8月17日、Claude Code v2.1.234がリリースされた。主な変更点は「使用量制限リセット時の自動セッション継続」と「認証情報漏洩に対するセキュリティ強化」。v2.1.232（Aug 13）では@メンション別セッション参照機能が追加。v2.1.233（Aug 14）はGitLab MRサポートとビルドコマンドのメモリ制限。v2.1.229（Aug 12）はリモートコントロール改善。またAnthropicはCompliance APIをClaude Codeのデスクトップ・Web・モバイル・CLIすべてに拡大し、Claude Enterprise顧客向けにbetaを提供。セキュリティチームが統合セッションコンテンツとメタデータを監査・eDiscovery用に取得可能になった。8月だけで v2.1.229〜v2.1.234まで6バージョンリリースされ、アップデートペースが加速している。
