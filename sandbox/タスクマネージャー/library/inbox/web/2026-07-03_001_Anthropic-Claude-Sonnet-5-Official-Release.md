# Claude Sonnet 5 公式リリース：最もアジェンティックなSonnetモデル

- URL: https://www.anthropic.com/news/claude-sonnet-5
- ソース: web
- 言語: en
- テーマ: claude-ecosystem
- 取得日: 2026-07-03

## 要約

2026年6月30日、AnthropicがClaude Sonnet 5を正式リリース。Opusクラスに近い性能をSonnet価格で提供する最もアジェンティックなモデル。主な特徴：①1Mコンテキストウィンドウ・128K出力、②アダプティブシンキングデフォルト有効、③新トークナイザー（同テキストで約30%多くトークン生成）、④推論・ツール使用・コーディング・知識作業でSonnet 4.6を大幅上回る。価格は8月31日まで入門価格$2/$10（入力/出力 per million tokens）、その後$3/$15に移行。Free/Proプランのデフォルトモデルに指定。Claude API・AWS Bedrock・Google Cloud・Microsoft Foundry（preview）で利用可能。Claude Codeでも新デフォルトモデルに設定済み。
