## 要約
CayTech Labによる Claude Code カスタムスキル完全ガイド（2026年版）。ビルトインスキルとカスタムスキルの違い・SKILL.mdの書き方・実践活用法を網羅。重要ポイント：(1)スキルは`.claude/skills/`（プロジェクトレベル）または`~/.claude/skills/`（ユーザーレベル）に保存。(2)SKILL.mdはMarkdownで記述するためプログラミング知識不要。(3)モデル主導（Model-invoked）：ユーザーが毎回「このスキルを使って」と言わなくてもClaudeが自律的に適切なスキルを選択・起動。(4)Claude Codeに「この作業をスキルにして」と話しかければSKILL.mdを自動生成可能。(5)2026年版の特徴としてxhighエフォートレベルの対応やOpus 4.8連携も解説。日本語の実践的カスタムスキルガイドとして詳細度が高い。
