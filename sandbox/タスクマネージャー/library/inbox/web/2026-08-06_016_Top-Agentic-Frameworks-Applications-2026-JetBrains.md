## 要約
JetBrains PyCharm ブログによる 2026 年主要 AI エージェントフレームワーク比較記事（2026年6月）。主要フレームワーク：LangChain（134K GitHub stars、1,000+ 組み込みインテグレーション、最多採用）・LangGraph（33,900 stars、月 3,450 万 DL、LangChain エコシステム内でのグラフ型エージェント）・Microsoft Agent Framework（AutoGen + Semantic Kernel の統合版、2026年4月2日 1.0 GA）・OpenHands・MetaGPT。注目点として AutoGen と Semantic Kernel が 2025年10月に Microsoft Agent Framework として統合された変化を報告。2026年は「フレームワーク乱立」から「成熟・統合」フェーズへ移行し、特に Microsoft の統合と Google LangGraph の成長が目立つ。
