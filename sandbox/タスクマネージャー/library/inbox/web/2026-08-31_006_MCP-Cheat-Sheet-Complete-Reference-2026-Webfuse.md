## 要約
Model Context Protocol (MCP) の完全チートシート。2026年7月28日リリースの最新MCP仕様に準拠。ステートレスプロトコルコア、Extensionsフレームワーク、Tasks（長時間エージェント対応）、MCP Apps（ReactダッシュボードなどのUI配信）、認証強化など主要機能を網羅。リモートMCPサーバーが通常のHTTPワークロードと同様に動作し、ラウンドロビンLBの背後に配置可能になった点は運用面で重要。Anthropic・OpenAI・Block共同でLinux Foundation傘下のAgentic AI Foundationが2025年12月から標準化を主導。即使用可能なリファレンス形式。
