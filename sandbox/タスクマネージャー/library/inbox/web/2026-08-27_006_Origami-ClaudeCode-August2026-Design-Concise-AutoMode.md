# Claude Code August 2026: /design Skill, Concise Output, Auto Mode as Default

## 要約
Origami.saによるClaude Code 2026年8月アップデートまとめ。主要新機能：(1)/designスキル——CLIを離れずにインターフェースのモックアップを作成、スクリーンショットをアップロードしてClaudeが実装コードを生成。(2)Conciseアウトプットスタイル——結果から始まり前置きと手順説明を省略（エラー・セキュリティ警告は除外）。(3)Auto Modeがデフォルト化——許可ポリシーが複雑なルールからプレーンな英文（soft_deny/hard_deny）に変更、ユーザー設定がプロジェクトレベルのconfigを上書き不可。(4)セッション自動継続——使用量制限リセット後に手動再起動不要。その他：GitLabマージリクエスト対応・より高い努力レベルでのバックグラウンドコードレビュー・セッション間メッセージング・フォークサブエージェントのデフォルト並列実行。
