# Beta SDKs for the 2026-07-28 MCP Spec Release Candidate Are Here

- ソース: web
- 言語: en
- テーマ: claude-ecosystem

## 要約
MCP 2026-07-28仕様のRC向けベータSDKが本日公開。対応言語：Python、TypeScript、Go、C#。ステートレスコア・Extensionsフレームワーク・OAuth/OIDC認可強化に対応した実装。SDK維持管理者とクライアント実装者向けに10週間の検証ウィンドウを設けている（本日が最終仕様リリース日で実質締め切り）。ステートレス化により、サーバーの実装はセッション状態管理が不要になり、tools/listレスポンスのクライアントキャッシュが可能に。既存コードとの非互換性があるため、各言語SDKのマイグレーションガイドも同時公開。Claude Codeは本日付けで新仕様をサポートする旨Anthropicが発表。
