## 要約
CodingNomadsによるClaude Code拡張機能（Skills・MCP・Hooks）の体系的チュートリアル。動画・クイズ付き構造化コース形式。Skills（マークダウンで繰り返し可能なワークフローを定義）・MCP（外部データ・ツールへのアクセス）・Hooks（ライフサイクルイベントでの決定論的スクリプト実行）の違いと使い方を明快に整理。「Skillsが何をするか定義し、MCPがデータを提供し、Hooksがルールを強制する」という役割分担フレームワーク。MCPサーバーによるWebSearch・ページスクレイピング・データベースアクセスの実例を含む実践的ガイド。
