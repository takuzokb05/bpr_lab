## 要約
Claude Code のアップデート履歴を September 2026 時点でまとめたチェンジログページ。8月の主要追加: /design スキル（アイデア・スクリーンショットから編集可能UIを生成）、Concise output スタイル（結果を先頭に提示）、利用制限後の auto-continue、Auto モードがデフォルト化（Pro/Max/Team の新セッション）、allow/deny ルールを自然文で記述可能。また Remote Control クライアントへのサブエージェントツール呼び出しのライブストリーミング追加、/usage に支出上限バーを追加。バイナリサイズは zstd 圧縮で 340MB→75MB（Linux x64）に削減。
