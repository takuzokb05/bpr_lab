## 要約
2026-07-28のMCP仕様リリース候補に対応した移行ガイド。最大の変更はステートレスコアへの移行で、スティッキーセッション・共有セッションストア・ゲートウェイでのDPIが不要になり、通常のラウンドロビンLBで運用可能になる。セッション管理コードの削除方法、Tasks/MCP Apps等の新拡張の組み込み方、OAuth/OIDCに準拠した新認証の移行手順を網羅。本番MCPサーバーを運用している開発者向けの実践的マイグレーションガイド。
