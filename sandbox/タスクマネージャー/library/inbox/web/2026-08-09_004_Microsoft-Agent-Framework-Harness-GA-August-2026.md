## 要約
MicrosoftがAgent Framework Harnessの一般提供（GA）を発表した公式ブログ記事（August 2026）。v1.13.0ではFoundry Hostingのサポート強化、Responsesサポート、再利用可能なセッションストア、テレメトリとオブザーバビリティの拡充、ワークフローリプレイと承認フローの強化が含まれる。GitHub Copilot・Claude Agent SDKコネクタ、オーケストレーションパターンが安定版に。Foundry Hosted Agentsとの統合でサーバーレスエージェント実行が可能に。Agent HarnessはBuild 2026でプレビュー発表されており、今回でエンタープライズ対応の本番グレードに到達した。
