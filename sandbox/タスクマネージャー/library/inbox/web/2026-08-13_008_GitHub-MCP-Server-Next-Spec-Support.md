## 要約
GitHub公式ChangelogによるGitHub MCPサーバーの2026-07-28 MCP仕様への対応発表。正式リリース前に新仕様をサポート開始した重要な動き。新仕様の核心「ステートレスコア」により、initialize ハンドシェイクとMcp-Session-Idヘッダーが廃止され、サーバーからのリクエストはリトライパターンに置換。これによりMCPサーバーがサーバーレス・エッジインフラにデプロイしやすくなる。GitHubが主要MCPサーバー提供者として仕様移行をリードしている構図。Tier 1 SDKはすべて2026-07-28仕様に対応済み。
