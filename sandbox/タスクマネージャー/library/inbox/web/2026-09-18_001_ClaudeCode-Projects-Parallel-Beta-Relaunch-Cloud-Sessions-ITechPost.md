# Claude Code Projects Gets Major Relaunch with Parallel AI Agents in the Cloud

## 要約
Anthropicが2026年9月17日、Claude CodeのProjects機能を大幅に刷新しベータ版として提供開始。新しいProjectsでは、コーディネーターが目標をパラレルスレッドに分割し、各スレッドがフルのClaude Codeクラウドセッションとして動作する。スレッドはラップトップを閉じた後も実行し続け、結果を会話に報告する。コーディネーターとワーカースレッドそれぞれでモデル（Opus等）と思考レベルを独立設定可能。共有メモリとプロジェクトライブラリで複数リポジトリをまたぐ長期作業を管理できる。1日最大200スレッド制限あり、Pro/Maxのうちクラウドセッション使用実績のあるユーザーが優先対象で他はウェイトリスト。
