# Claude Agent SDK 課金変更（6月15日）：独立クレジット制に移行

- URL: https://releasebot.io/updates/anthropic/claude-developer-platform
- ソース: web
- 言語: en
- テーマ: claude-ecosystem
- 取得日: 2026-07-18

## 要約
Anthropicは2026年6月15日より、Claude Agent SDK（旧：Claude Code SDK、2026年初頭に改名）の利用量を独立した月次エージェントSDKクレジットから課金開始。SDKはAnthropicの長時間ツール使用ワークフロー向けの生産用エージェントランタイムで、Claude Codeを動かすのと同じハーネス上に構築。「claude agent sdk」の月次検索数は2025年5月の50件から2026年4月の14,800件へと約50,000%増加。Claude Code本体の利用はこれまで通り別枠。同時期の関連API変更：Sonnet・Haiku APIレートリミットをOpus水準に統一、使用ティアをStart・Build・Scaleの3段階に集約、APIキー有効期限設定機能を追加、コード実行ツール（code_execution_20260120）サポートを全SDK言語（Python/TS/Go/Java/Ruby/PHP/C#）に追加。
