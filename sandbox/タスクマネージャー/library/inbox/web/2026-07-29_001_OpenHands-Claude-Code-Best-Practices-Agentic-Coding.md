## 要約
OpenHandsが公開したClaude Code向けアジェンティックコーディングの10のベストプラクティス（2026年7月版）。「探索→計画→コーディング」ワークフロー、Shift+Tabでのプランモード活用、CLAUDE.mdは200行以内で簡潔に保つこと、ルール強制にはHooks/permissions・文脈知識にはSkills・委任境界にはSubagentsを使い分けるという設計原則を解説。gitワークツリーでの並列エージェント実行、検証ループによる幻覚除去など実践的Tips多数。チーム全員が1コマンドで再現できるMakefileの活用も推奨。
