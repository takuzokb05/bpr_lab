## 要約
Anthropicの全製品（Claude API、Claude Code、Claude Developer Platform）の9月2026年リリースノートアグリゲーター。主な変更点：①Claude APIに`anthropic-workspace-id`レスポンスヘッダー追加（リクエストのAPIキーが解決したワークスペースIDを返す）、②SDKのFilesとSkillsのbeta/非betaのシェイプ統一・BetaSkillをBetaContainerSkillにリネーム・スキル削除挙動の変更、③Claude Sonnet 5の価格（$2/$10/MTok）が標準価格として正式確定（9月1日の$3/$15引き上げは実施されず）、④Skills APIとFiles APIがMicrosoft Foundryを通じて利用可能に、⑤Computer use・Browser useツールがGoogle Cloud Vertex AI経由でまもなく提供予定。Claude Developer Platformの変更履歴として信頼性が高い一次情報源。
