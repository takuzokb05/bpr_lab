## 要約
Microsoft BUILD 2026でのAgent Framework発表内容（公式Microsoft DevBlog）：
- MAF 1.0 GA: 2026年4月2日リリース、AutoGenとSemantic Kernelを統合した単一プラットフォーム
- Python・.NETランタイム両方が同日4月3日に1.0同時リリース
- 宣言的YAML agent configurationでバージョン管理されたデプロイが可能
- Agent Harness: マルチエージェントオーケストレーションの統一ランタイム
- Hosted Agents: Azureでの管理型エージェントホスティング
- CodeAct: コード生成+実行を統合したエージェントパターン
- A2A（Agent-to-Agent）プロトコル対応でMCP標準との相互運用性を確保
- LangGraph・CrewAI・Pydantic AI V2等と並ぶ主要フレームワークとして位置付け
