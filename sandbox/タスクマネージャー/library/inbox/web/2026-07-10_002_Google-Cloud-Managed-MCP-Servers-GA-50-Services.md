# Google Cloud：50以上のフルマネージドMCPサーバーがGA（2026年5月）

## 要約
Google Cloudが2026年5月21日（Google Cloud Next '26）にて50以上のフルマネージドMCPサーバーをGAおよびプレビュー公開。対象サービス：GKE・Cloud Run・Cloud Logging・BigQuery・Spanner・AlloyDB・Gmail・Drive・Calendar・Google Maps等。エンタープライズセキュリティ：Cloud IAM細粒度アクセス制御、Model ArmorによるプロンプトインジェクションとデータExfil防止、OTelトレーシングと監査ログ。相互運用性：Gemini CLI・Claude・ChatGPT・VS Code・LangChain・CrewAIすべてで動作確認済み。Insta360が自然言語入力でのAI動画編集エージェントをGCPエージェントエコシステムで構築した実例あり。Agent Registryでエージェント・MCPサーバー・ツールの統合ディレクトリ提供。
