# X（旧Twitter）がMCPサーバーを公式提供開始

- URL: https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use/
- ソース: web
- 言語: en
- テーマ: claude-ecosystem

## 要約
X（旧Twitter）が2026年6月30日、AIツールからプラットフォームを利用しやすくするための公式MCPサーバーを提供開始。TechCrunch報道。これによりClaude CodeをはじめとするAIエージェントからXのデータ・投稿・検索機能にMCPプロトコル経由で直接アクセス可能になる。OpenAI・Google・Microsoft・AnthropicがMCPを業界標準として採用した流れを受け、主要プラットフォームのMCP対応が急加速している。MCP SDKは9,700万累積ダウンロード・14,000以上サーバーが登録済み（PulseMCP集計）。AIエージェントのデータソース統合においてMCPが事実上の標準プロトコルとして確立したことを示す重要マイルストーン。
