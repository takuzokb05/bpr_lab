## 要約
GenAI-AI.co.jp による Plan Mode の非エンジニア向け解説（2026年8月最新）。Plan Mode は「設計図を確認してから施工する」専用モード。切り替え方法（/plan または Shift+Tab）、Plan Mode 中にできること・できないこと（ファイル編集不可、質問可能）、使いどころ（大規模改修前・複雑なリファクタリング・新機能追加の前段階）を整理。「Don't implement yet」プロンプトとの比較や、プラン確認後に通常モードへ切り替えて実行する流れも解説。Anthropic 推奨の explore → plan → code ワークフローに対応する内容。
