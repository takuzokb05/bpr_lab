## 要約
2026年8月時点のClaude Skills機能を入門者向けに徹底解説した記事。Claude Skillsは「長いプロンプトを保存するだけ」ではなく、手順・参照資料・必要な処理をまとめた再利用可能パッケージである点を強調。GPTs（OpenAI）との違いとして、Skills はローカルファイルベースで動作しコードベースと連携できる点が優位。2026年8月時点で Claude Code には9つのバンドル済みスキルが標準搭載（v2.1.145以降）。スキルクリエイター（「スキルを作るためのスキル」）が登場し、AI指示だけで新スキルのSKILL.mdとスクリプトを自動生成できるようになっている。MCPと組み合わせた最適活用パターンも紹介。
