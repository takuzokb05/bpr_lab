# Claude Cowork Gets Built-In Browser: No Extension Required

- URL: https://claude.com/blog/cowork-built-in-browser
- ソース: web
- 言語: en
- テーマ: claude-ecosystem
- 取得日: 2026-08-27

## 要約
AnthropicがClaude Coworkデスクトップアプリに内蔵ブラウザを追加（2026年8月26日）。タスクにWebサイトが必要な場合、サイドパネルにブラウザが開き、Claudeがページをナビゲート・クリック・入力できる。拡張機能不要・セットアップなし。Pro/Max/Teamプランに今後1週間かけてmacOS・Windows・Linux（ベータ）展開。Enterpriseプランはすでに利用可能（管理者がOrganization settings > Cowork > Built-in browserで管理）。既存のClaude in Chrome拡張機能との並立が可能で、すでに開いているページへのアクセスは引き続き拡張機能が最適。ポータルやダッシュボードを含む自律タスク完了が大幅に拡大。
