## 要約
Anthropic が 2026年7月24日に Claude Opus 5 をリリース。最大の特徴は「effort toggle」機能で、low/medium/high の3段階でモデルが費やす計算量を制御し、コストと性能のバランスを調整できる。価格は $5/$25 per M tokens（入力/出力）と Opus 4.8 と同一で、1M トークンコンテキストウィンドウ・128K max output を搭載。CursorBench 3.2 では Fable 5 の 0.5% 以内の性能を半額で達成。OSWorld 2.0 では Fable 5 のベストスコアをさらに上回り、コストは 1/3 以下。エンタープライズ・知識労働者・開発者向けの「日常モデル」として位置づけ。自律的なコード変更・回帰テスト・マルチツール連携など agentic coding ワークフローで特に強みを発揮。モデルが自律的にエラーから回復し、人間の介入なしで作業を継続する設計が評価されている。
