## 要約
Towards AI（2026年3月）掲載のゼロから始める Claude Code 完全ガイド。Claude Code のアーキテクチャを「memory・hooks・skills・subagents・plugins・MCP の分離されたレイヤー」として解説。Skills = SKILL.md ファイルを含むフォルダベースの命令パックでオンデマンドロード、Hooks = 毎セッション起動しアクション前後に実行されるルール、という区別が明確。スキルにはドメインロジックやヘルパーファイルがある場合、サブエージェントには並列独立作業、フックにはコードで規則を強制する場合に使う、という使い分け基準を提示。非エンジニア向けに書かれており、事前知識不要で読める。
