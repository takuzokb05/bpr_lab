## 要約
プロジェクト規模（小規模・中規模・大規模）ごとにCLAUDE.mdを設計するパターン集。単一ファイル詰め込み方式はプロジェクト規模が大きくなると破綻するため、`@import`や`.claude/rules/`のpaths指定で分割設計することを推奨。スモールプロジェクトはシンプルな単一CLAUDE.mdで十分だが、チーム規模・モノレポになると役割別/機能別のルールファイル分割が必要。具体的なテンプレートとアンチパターン（過度に詳細な実装手順の記述、更新されない古いルール、200行超え）を実例付きで解説。月1回のCLAUDE.mdメンテナンスサイクル（繰り返し無視されたルールの削除・更新）も提案。Claude CodeのCLAUDE.mdベストプラクティスの日本語実践ガイドとして2026年7月時点で最も体系的な一つ。
