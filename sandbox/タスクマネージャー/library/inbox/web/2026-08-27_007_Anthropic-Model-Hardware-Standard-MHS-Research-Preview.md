# Anthropic Launches Model Hardware Standard (MHS) Research Preview

- URL: https://www.anthropic.com/news
- ソース: web
- 言語: en
- テーマ: claude-ecosystem
- 取得日: 2026-08-27

## 要約
Anthropicが2026年8月27日、Model Hardware Standard（MHS）のリサーチプレビューを発表。AIエージェントが物理デバイスを安全に操作するための共有仕様。科学研究機関および先進製造業者向けに初期提供。AIが実世界の物理システムと直接対話する基盤標準を確立するもので、AIエージェントの適用範囲をデジタルからフィジカルへ拡張する重要なマイルストーン。Anthropicの科学者支援拡大施策の一環として発表された。
