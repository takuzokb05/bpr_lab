## 要約
TechCrunchによるClaude Code Autoモードデフォルト化のニュース報道。Anthropicの内部テストで、Autoモードの安全性分類器が危険なコマンドの89%を捕捉（旧来の手動承認ワークフローでは14%）という数値を引用。8月14日よりPro・Max・Teamプランでデフォルト有効化。ユーザーが独自設定をしている場合は変更されない。Enterprise・APIプランは当面オプトインのまま。AIエージェントが人間の割り込みなしに実行するデフォルト動作への移行という業界トレンドを反映した動き。
