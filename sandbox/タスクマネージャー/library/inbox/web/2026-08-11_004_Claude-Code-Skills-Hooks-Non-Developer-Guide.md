## 要約
非エンジニア向けのClaude Code Skills・Hooks実践ガイド。Skillsは「いつどのルールを適用するか」を制御し、Hooksは「Claude Codeのアクションの前後で何をするか」を自動化する。コンテンツパイプラインを実例にした意思決定フレームワーク（Skills vs Hooks vs MCP vs Subagentsの使い分け）を提供。ターミナルの専門用語なしで説明し、実際のワークフロー例を多数収録。自動化の閾値や、あえて自動化しないケースについても言及。
