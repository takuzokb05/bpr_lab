## 投稿内容
VentureBeat。2026年7月30日、OpenAIがGPT-5.6 Lunaを80%値下げ。AI価格戦争の新局面を分析。

## 要約
2026年7月30日、OpenAIが主要モデルの大幅値下げを断行。GPT-5.6ファミリーの3ティア構成での価格調整内容と背景を詳説。

**価格変更詳細（Input/Output per M tokens）:**
| モデル | 旧価格 | 新価格 | 削減率 |
|---|---|---|---|
| Luna | $1.00 / $6.00 | $0.20 / $1.20 | Input -80% |
| Terra | $2.50 / $15.00 | $2.00 / $12.00 | Input -20% |
| Sol（旗艦） | $5.00 / $30.00 | 変更なし | - |

**背景と競合状況:**
- GPT-5.6ファミリー初公開からわずか3週間での値下げ
- CNBC 7月7日調査: 中国モデルがOpenRouter米国エンタープライズトークン使用量の46%を占有、ピーク時は米国モデルを超過
- DeepSeek Input価格を下回る水準（$0.14/M）にLunaを設定
- Anthropic Claude Sonnet 5のプロモ価格$2/$10（8月末まで）とも競合

**市場への示唆:**
AIモデルの急速なコモディティ化。Lunaを$0.20に設定することで大量処理・バッチ処理市場をターゲット。Sol・Opusクラスの高性能モデルは価格維持で差別化を継続。LLMを使った自動化システム（FX取引のsentiment分析、Claude Codeバックグラウンドエージェント等）のコスト試算に要更新。
