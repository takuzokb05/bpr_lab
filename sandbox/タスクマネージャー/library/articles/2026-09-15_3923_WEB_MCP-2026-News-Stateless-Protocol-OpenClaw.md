## 投稿内容
OpenClaw Direct MCP news tracker for 2026. The 2026-07-28 specification is the biggest MCP release since launch. Key changes: stateless protocol core (sessions and init handshake removed), Multi Round-Trip Requests, header-based routing (Mcp-Method), cacheable list results (ttlMs), auth hardening, formal Extensions framework, Tasks, MCP Apps, Tier 1 SDK updates. Practical impact: remote MCP servers can now use plain round-robin load balancers, no sticky sessions, no shared session stores, no deep packet inspection. Breaking changes but migration easy with updated SDKs.
