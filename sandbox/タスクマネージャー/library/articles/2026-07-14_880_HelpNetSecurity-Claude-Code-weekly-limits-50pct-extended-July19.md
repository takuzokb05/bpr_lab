# Claude Code週次利用制限50%増プロモーション、7月19日まで延長

## 要約
Anthropicが2026年7月13日に発表。Claude Codeの週次利用制限50%増プロモーションを7月19日（PT 23:59）まで延長。対象プラン：Pro・Max・Team・旧来のEnterprise席。非対象：無料プラン・従量課金型Enterpriseシート。適用範囲：Claude Code（CLI・IDE拡張・デスクトップ・Web）のみ。他Claudeプロダクトや5時間上限には影響なし。手続き不要・自動適用。期限後は標準レベルに自動復帰で課金変更なし。この制限延長と並行して、Fable 5アクセスも同期限まで延長されている。
