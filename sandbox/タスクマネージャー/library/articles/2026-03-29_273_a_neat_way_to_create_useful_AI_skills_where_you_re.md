## 投稿内容

a neat way to create useful AI skills where you're not a subject matter expert yet

- create a Notebook in NotebookLM with anything you want to turn into a skill: a book or a PDF or a whole topic
- wire up the NotebookLM CLI to Claude Code/Cursor
- talk to the NotebookLM until you understand what skill to create and how it works
- use skill-creator skill to create a baseline skill in Claude Code/Cursor
- use evals-skills to create synth data or do it yourself
- ask AI to check the outputs of the evals with the NotebookLM
