"What plugins are:

Plugins are installable bundles for reusable Codex workflows. They make it easier to share the same setup across projects or teams, and they can package skills, optional app integrations, and MCP server configurations in a single place.

A plugin can contain:

Skills: prompts that describe workflows to Codex and can be progressively discovered by the agent.
Apps: optional app integrations or connector mappings packaged with the plugin.
MCP servers: remote tools or shared context the plugin needs."
