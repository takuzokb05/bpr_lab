大厂因为agent疯狂裁员，别慌！收好这份保命符

Claude code官方Anthropic 推出了13门免费课程
下面我来带你深入浅出的了解这13门课能让你学会什么

学习资源与实战课程，以及如何看中文版在最后

一.基础入门：真正学会和AI沟通
1.Claude 101：介绍核心功能，教你真正学会AI的用法

2. Framework and Foundations：学会AI协作思维
学完就能写出顶级提示词，让ai一次性给出正确结果

二：让Claude接管电脑，帮你干活
1.Claude Code in Action：教你在终端里使用cc
学会后直接在终端告诉cc，去整理桌面，他就自动执行

2.Introduction to Agent Skills：教你制作技能包
比如设定一个项目研报技能，以后Agent就能按标准流程自动完成任务，省时省力省token

3.Introduction to subagents：教你创建并使用子代理
遇到繁琐任务，主代理自动把小任务交给独立小代理完成
做完任务只返回结果，让任务过程尽可能干净高效

4.Introduction to Claude Cowork：教你用CC 真正成为你的电脑搭档
学会后要做任务只需下达指令就好，干活交给CC

三.怎么给你的CC装上干活用的手和脚
1.Introduction to MCP：教你怎么让Claude读取云端与本地数据（Github、Notion、Google Drive）
以前ai不能读取你的Google Drive等，学会这个就解决

2.MCP: Advanced Topics：让Claude自动化完成任务的水平更进一步
比如说自动实现读邮件、查数据、总结后生成报表交给你

3.Building with the Claude API：教你怎么把claude集成到自己的产品中
学会这节课，就能自己开发Claude产品

四.不同身份如何更好使用CC
1.Teaching AI Fluency：让你学会教别人使用AI，把AI思维系统的传授给别人

2. AI Fluency for educators / students / nonprofits (教育者/学生/非营利组织)
如果你是老师、学生、非盈利组织可以学会让cc复制自己更好的工作。

3.Claude with Amazon Bedrock / Google Cloud Vertex AI
适合企业级用户，让你在服务器上运行claude

课程：https://t.co/TknxTBp2rB
中文实战教程：https://t.co/boy4NPzERO
中文版课程可以在anthropic YouTube上看，配上翻译插件
也可以放在longcut点ai网站学习
