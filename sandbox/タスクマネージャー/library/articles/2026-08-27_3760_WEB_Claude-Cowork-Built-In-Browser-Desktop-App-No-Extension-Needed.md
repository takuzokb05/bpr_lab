# Claude Cowork Gets Built-In Browser: No Extension Required, Web Tasks Autonomous

- URL: https://claude.com/blog/cowork-built-in-browser
- ソース: web
- 言語: en
- テーマ: claude-ecosystem
- 取得日: 2026-08-27

## 投稿内容
Claude now has its own browser inside the Cowork desktop app. When a task needs to use a website, a browser opens in the side panel and Claude navigates webpages, reads them, clicks, and types. Claude can fill in a form, pull numbers from a dashboard, or work through a portal that has no connector. No extension, no setup, nothing shared from your own browser unless you choose to.

Rollout: Pro, Max, and Team plans over the coming week on macOS, Windows, and Linux (beta). Enterprise plans available now — admins manage via Organization settings > Cowork > Built-in browser. Existing Claude in Chrome extension still available for pages already open in your browser.

## 要約
AnthropicがClaude Coworkデスクトップアプリに内蔵ブラウザを追加（2026-08-26）。タスクがWebサイトを必要とする際、サイドパネルにブラウザが自動で開き、Claudeがページの閲覧・クリック・入力を自律実行。フォーム入力、ダッシュボードからの数値収集、コネクタなしのポータル操作が全て可能。拡張機能インストール不要・セットアップなし・ユーザーのブラウザとは完全分離。展開：Pro/Max/Teamプランに数日内でmacOS/Windows/Linux（ベータ）。Enterpriseはすでに利用可能。Claude in Chrome拡張機能とは並立で使用可能（既存ページへのアクセスは引き続き拡張機能が最適）。AIエージェントによる自律Webタスク完了の実用的な一歩として、Claude Code/Coworkの統合が深まる。
