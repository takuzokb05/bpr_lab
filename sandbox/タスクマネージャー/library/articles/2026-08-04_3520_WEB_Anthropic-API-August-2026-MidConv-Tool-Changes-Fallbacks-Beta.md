## 要約

ReleasebotによるAnthropicデベロッパープラットフォーム2026年8月アップデートまとめ。主要変更：(1)Mid-conversation tool changes（ベータ）: Claude Fable 5・Mythos 5・Opus 4.8・Opus 5で会話の途中でツールの追加・削除が可能に。ヘッダー`mid-conversation-tool-changes-2026-07-01`で有効化、プロンプトキャッシュを維持しながらツール変更できる。(2)Fallbacksパラメータに"default"モードを追加：Anthropicの推奨フォールバックモデルを拒否カテゴリ別に適用。ヘッダー`server-side-fallback-2026-07-01`でベータ有効化。(3)Opus 4.7のFast mode廃止（speed: "fast"はエラーを返す）。(4)レガシーWorkbench APIは8月17日退役。Mid-conversation tool changesは動的ツール切り替えが必要なエージェントアーキテクチャに重要な機能追加。
