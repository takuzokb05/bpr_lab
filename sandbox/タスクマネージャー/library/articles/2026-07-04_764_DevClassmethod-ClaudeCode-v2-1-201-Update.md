## 投稿内容

2026年7月3日リリース。v2.1.200・v2.1.201 合計18件の変更を含む安定性強化リリース。バックグラウンドセッション・バックグラウンドエージェント周りの不具合が多数解消された。

主な不具合修正：スリープ/復帰後のバックグラウンドセッション無言停止の解消、無効なMCP設定による起動時クラッシュの修正、キャンセル済みターンの誤再実行問題の解消、デーモンロック関連の起動不能問題を改善。

重要な仕様変更（2件）：(1) `AskUserQuestion` ダイアログが既定で自動継続しなくなった（`askUserQuestionTimeout` 設定で挙動を制御）、(2) パーミッションモードの「default」表示が「Manual」に変更。

その他改善：スクリーンリーダー向け出力の最適化、tmux 3.4以降での描画ちらつき修正。

## 要約

Claude Code のバグ修正中心リリース v2.1.200〜201。バックグラウンドエージェント安定性の複数問題が解消され、並行エージェント運用の信頼性が向上。特に Linux 環境での全エージェント強制終了バグ（約50秒周期）や、スリープ復帰後の無言停止など実運用に影響する問題が修正された。仕様変更として AskUserQuestion の自動継続デフォルト廃止・Manual パーミッションモードへのリネームが入っており、無人運用・CI/CD パイプライン利用者は設定確認が必要。スキル連続呼び出し（最大5個まで同時読み込み）も前バージョンで追加済み。DevelopersIO が日本語で詳細解説を提供しており、日本語圏での Claude Code 利用者に有用な情報源。
