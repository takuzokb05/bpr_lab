## 投稿内容
Aggregated Anthropic release notes covering Claude API, Claude Code, and Claude Developer Platform changes for September 2026.

## 要約
Anthropic全製品（Claude API・Claude Code・Claude Developer Platform）の2026年9月リリースノートアグリゲーター（releases.sh）。主な変更点：①Claude APIに`anthropic-workspace-id`レスポンスヘッダー追加（APIキーが解決したワークスペースIDを返す）、②SDKのFilesとSkillsのbeta/非betaシェイプを統一・`BetaSkill`→`BetaContainerSkill`リネーム・スキル削除挙動の変更、③Claude Sonnet 5価格（$2/$10/MTok）が標準価格として正式確定（9月1日の$3/$15引き上げは実施されず）、④Skills APIとFiles APIがMicrosoft Foundryを通じて利用可能に、⑤Computer use・Browser useツールがGoogle Cloud Vertex AI経由でまもなく提供予定、⑥Claude Code全スペックのフルスクリーン差分パネル追加・広域ヘッドレスコマンド対応・Claude apps gateway連携強化。Anthropicの変更を一元監視する際の信頼性の高い一次情報源。
