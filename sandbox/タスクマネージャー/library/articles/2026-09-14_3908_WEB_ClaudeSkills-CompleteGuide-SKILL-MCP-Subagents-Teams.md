## 要約
Claude Code Skills・MCP・Subagents・Agent Teamsの使い分け完全ガイド（Duet.so）。Skillsは`.claude/skills/<name>/SKILL.md`のフォルダベース命令パック、YAMLフロントマターで起動トリガーを定義。4要素の使い分けフレームワーク：MCPは外部システム接続（DB/API/ファイルシステム）・Skillsは社内ワークフローパッケージ化・Subagentsは独立リサーチ/検証タスク・Agent Teamsは並列マルチエージェント作業（実験的）。判断フローチャートと実際のSKILL.mdサンプル：コードレビュー自動化・日次情報収集・PRドラフト生成等。Agent Teamsは2026年mid以降利用可能で、並列設計/実装/テストを実現。Anthropic公式ドキュメントを補完する高詳細度のガイドで、設計判断理由（「なぜMCPでなくSkillsか」）の説明が豊富。
