## 投稿内容

日本の上場企業の構造化された財務データAPIを提供しているEDINET DBです。

GitHubスター18,000超の金融AIエージェント「Dexter」が海外でかなり話題になっています。銘柄について聞くだけで、スクリーニングから財務分析、投資レポートの作成まで全部自動でやってくれるOSSです。

ただ米国株専用だったので、EDINET DB API + J-Quants APIに差し替えて日本市場版を作りました。有報・決算短信・財務データ・株価まで揃うので、日本株でも同じことができます。

OSSで公開しています。
https://t.co/1vOVNJAfG2
どんなことができるかと、技術的な仕組みをスレッドで補足します。
