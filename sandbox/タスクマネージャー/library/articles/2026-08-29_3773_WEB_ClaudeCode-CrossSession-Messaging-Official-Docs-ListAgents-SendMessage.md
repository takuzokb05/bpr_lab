# Claude Code クロスセッションメッセージング公式ドキュメント: ListAgents・SendMessage

- URL: https://code.claude.com/docs/en/cross-session-messaging
- ソース: web
- 言語: en
- テーマ: claude-code
- 取得日: 2026-08-29

## 投稿内容

v2.1.224（2026-08-07リリース）から搭載されたクロスセッションメッセージング機能の公式リファレンス。

**仕組み:**
- 別のターミナルやworktreeで動く複数のClaudeインスタンスが互いにメッセージを見つけて送信できる
- `ListAgents`で到達可能なセッションを発見、`SendMessage`でテキストを送信
- ユーザーが両ツールを直接呼び出す必要はなく、ClaudeがAuto modeで自律的に判断して使用

**メッセージの内容:**
- メッセージは一方のClaudeが書いたテキストのみ（会話履歴・ファイル・承認は含まない）

**要件:**
- macOS・Linux（WSL2含む）: v2.1.224以降
- Windows（Native）: v2.1.234以降
- 設定なしで自動的にオン

**セキュリティ:**
- OSユーザー単位でinboxソケットを制限（同一マシンの別ユーザーのセッションには到達不可）
- Auto modeでSendMessageがディスパッチ前にパーミッションクラシファイアで評価される
- メッセージは相手セッションの承認や設定変更を行えない

**管理者制御:**
- マネージド設定からorg単位でインバウンドメッセージ拒否・`SendMessage`/`ListAgents`無効化が可能

**使用例:**
- あるセッションでの変更が別セッションの作業に影響する場合の自動通知
- 並列開発で一方がブロックしている質問の答えを別セッションから送信
- `/list-agents`（`/peers`でも可）コマンドで現在のセッション一覧を手動確認

## 要約
Claude Codeの新しいマルチエージェント協調機能。v2.1.224から複数セッション間でのテキストメッセージ送受信が可能になり、並列開発ワークフローの連携が格段に向上した。セキュリティ設計が堅牢（OSユーザー分離・パーミッションクラシファイア通過）で、送信されたメッセージが相手セッションの権限を昇格させることは不可能。FX自動取引のような複数エージェントが並列で異なる市場・戦略を監視するユースケースに直接応用可能。
