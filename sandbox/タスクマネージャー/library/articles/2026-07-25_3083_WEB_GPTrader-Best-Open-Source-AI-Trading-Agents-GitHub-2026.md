## 要約

- 2026年時点でGitHub上のオープンソースAIトレーディングエージェントのランキングと各フレームワークの特徴解説
- TradingAgents（TauricResearch）: GitHub最多スター80,000+・フォーク15,500+。Bull/Bear Researcher + Risk Manager + Trader の7エージェント構成。Apache 2.0ライセンス。7月にv0.3.1リリース（Claude Sonnet 5対応）
- フレームワーク選定基準: LLMバックエンドの対応範囲・バックテスト能力・リアルタイムデータ統合・リスク管理機能
- GPT・Claude・Gemini・Grokをバックエンドとして利用可能なマルチLLMフレームワークが主流
- Robinhood が2026年5月に「AI エージェントとブローカーアカウントの直接接続」を発表したことで、オープンソース実装の需要が急増
- 各フレームワークのアーキテクチャ図・利用手順・パフォーマンス結果を比較
- 個人投資家がFX・株式・暗号資産向けにLLM取引エージェントを構築する際の出発点として有用
