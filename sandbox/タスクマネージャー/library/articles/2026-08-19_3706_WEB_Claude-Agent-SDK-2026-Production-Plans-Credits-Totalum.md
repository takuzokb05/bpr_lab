## 要約
Claude Agent SDKはClaude Codeを動かすのと同じエージェントループ・ビルトインツール・パーミッションシステム・サブエージェントを開発者向けに公開したライブラリ。仕組み: SDKがモデルを呼び出し→モデルがツール選択→SDKが実行→結果をフィードバック→タスク完了まで繰り返し。カスタムツールはPython/TypeScript関数としてin-process MCPツールに登録。MCP対応によりカスタム実装なしで外部ツール・DBに接続。料金・クレジット管理・本番デプロイ戦略（Agent Memory APIのagent-memory-2026-07-22 betaヘッダ等）を包括的にカバー。
