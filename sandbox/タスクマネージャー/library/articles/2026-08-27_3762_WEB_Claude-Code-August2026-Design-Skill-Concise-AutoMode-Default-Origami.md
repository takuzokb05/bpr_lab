## 投稿内容
Origami.sa summarizes key Claude Code August 2026 updates:

**Design in the Terminal**: The /design skill lets developers create editable interface mockups without leaving the CLI. Users describe ideas or upload screenshots to get design options, then have Claude generate implementing code—all in one workflow.

**Concise Output Style**: New output mode leads with the result, drops the preamble and the step-by-step narration. Maintains full technical depth while removing verbose explanations, except for error reports and security warnings.

**Auto Mode Becomes Default**: Permission policies now use plain-language sentences instead of complex rules. Teams define soft_deny and hard_deny entries in user settings that can't be overridden by project-level configs—solving a key security challenge.

**Session Auto-Continue**: When usage limits reset, sessions automatically resume rather than requiring manual restart.

**Additional**: GitLab MR support in worktree, background code review at higher effort levels, sessions can message each other, fork subagents run in parallel by default.
