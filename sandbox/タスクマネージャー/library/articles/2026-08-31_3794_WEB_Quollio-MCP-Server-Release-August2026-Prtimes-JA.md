## 投稿内容
Quollio Technologies株式会社が2026年8月26日、QDIC（Quollio Data Intelligence Cloud）にMCPサーバー機能を正式提供開始したプレスリリース。

## 要約
Quollio Technologies社のPRTimes公式プレスリリース（2026年8月26日）。「Quollio Data Intelligence Cloud（QDIC）」の新機能として「MCPサーバー機能」を正式提供開始。Claude CodeなどのAIアシスタントがMCPプロトコル経由でQDICのデータカタログ・データ系譜情報・データ品質メタデータに直接アクセス可能になる。エンタープライズ・データガバナンスプラットフォームへのMCP統合は国内での先行事例として貴重。データカタログとAIコーディングツールの連携ユースケース（カラム説明の自動補完・データ品質の自動チェック等）を提示。PRTimesの一次情報として信頼性高い。
