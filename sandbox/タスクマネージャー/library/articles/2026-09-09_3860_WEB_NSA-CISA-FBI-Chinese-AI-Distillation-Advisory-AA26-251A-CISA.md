# NSA・CISA・FBI が中国AI企業6社の「産業規模モデル蒸留」を正式警告 — AA26-251A

- URL: https://www.cisa.gov/news-events/cybersecurity-advisories/aa26-251a
- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-09-09

## 要約
2026年9月8日、NSA・CISA・FBIは合同サイバーセキュリティ勧告（AA26-251A）を発行。中国拠点の6つのAI企業が遅くとも2024年後半から米国フロンティアモデルを対象に「産業規模の知識蒸留（distillation）キャンペーン」を実施してきたと断定した。
名指しされた企業：DeepSeek・Moonshot AI・Alibaba・MiniMax・StepFun・Z.AI。
DeepSeekへの具体的な指摘：①Claude・GPT・Gemini複数バージョンを使い合成訓練データを生成→R1・V3モデルを構築。②公称トレーニングコスト$5.6Mは悪意ある蒸留で取得したデータコストを除外した「誤解を招く数値」。③不正アカウント・バルクプレミアム購読・プロキシルーティング（転送局）を用いて検出を回避。
勧告の推奨事項：AI企業に対し、悪意ある蒸留を高確信で特定されたアカウントへの応答を「静かに劣化させる（quietly degrade）」こと（単純ブロックより発見が困難）を推奨。
意義：AI知的財産の盗用問題が米国政府機関の公式勧告レベルに到達した初めてのケース。米中AI技術競争における規制・制裁面の激化を示す重要マイルストーン。AIプロバイダー側（Anthropic・OpenAI・Google）に新たな監視・対策負担が生じる可能性。DeepSeek等のコスト効率性の根拠が疑問視される。
