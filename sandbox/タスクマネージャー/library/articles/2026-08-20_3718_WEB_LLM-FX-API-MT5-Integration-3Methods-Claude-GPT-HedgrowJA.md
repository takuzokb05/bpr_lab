## 投稿内容

hedgrow mediaによるLLM（Claude/GPT）とMetaTrader5（MT5）を連携してFX自動売買に活用するための実装ガイド（日本語）。3つのアーキテクチャを体系的に整理し、実装コード例・コスト管理・セキュリティを含む包括的解説。

**3つの接続方式:**

1. **ファイルベース連携（最シンプル）**
   - PythonがLLMシグナルをJSON形式でファイル出力 → MT5（MQL5）が定期ポーリングで読み込む
   - レイテンシ: 数秒〜数十秒
   - 特徴: 実装が最も簡単、既存環境への影響が少ない

2. **Pythonミドルウェア（HTTPサーバー）**
   - FastAPIサーバーがMT5からのリクエストを受け付け、Claude API等へ問い合わせてシグナルを返す
   - レイテンシ: 数百ms〜秒単位
   - 特徴: 中間的な複雑さ、フィルタリングロジックをPython側で柔軟に実装可能

3. **直接MQL5 WebRequest**
   - MQL5コード内からClaude APIへHTTPリクエストを直接送信
   - レイテンシ: 最低（ミリ秒単位）
   - 特徴: ブローカー側のホワイトリスト設定が必要

**重要な実践知見:**
- LLMの役割はテクニカルシグナルの「フィルター」であり、主要取引ロジックではない
- APIキーをMQL5ソース内にハードコードしない（セキュリティリスク）
- バックテスト環境ではソケット通信が動作しない（本番とは別対応が必要）
- コスト管理: キャッシュとレート制限の実装で API費用を制御
- Claude Codeを使えばプログラミング知識なしでもFX/CFD自動売買スクリプトの作成が可能

## 要約

MT5とLLMを連携させるFX自動売買実装の3アーキテクチャを実用的に解説した日本語ガイド。ファイルベース→Pythonミドルウェア→直接MQL5の順に複雑性とレイテンシのトレードオフが整理されており、自分のスキルセットと要件に応じて選択できる。FX自動取引プロジェクトを進める上で「LLMをどう組み込むか」の実装設計に直接使える一次情報。バックテスト非対応の注意点やAPIキー管理など実践的なリスク管理知見も含む。
