## 要約
2026年7月時点のClaude Code全67機能を体系化したリファレンス。サーフェス展開: Chat・Desktop・Browser・Terminal・IDE・API の6面で利用可能。新機能3本柱: （1）Cowork — WebとモバイルにGA拡大、ファイル・セッション状態をClaudeアカウントに保存しデバイス間同期、リモートセッションbeta（ラップトップを閉じても継続）。（2）インブラウジング — セッション内でのブラウザ操作統合（フォーム入力・スクリーンショット・ページスクレイピング）。（3）/fork コマンド — セッションのブランチ作成で実験的変更をメインコンテキストから分離。組み込みツール42種の完全分類: File/Code系（Read・Write・Edit・MultiEdit・Glob・Grep・LS・NotebookRead/Edit・LSP Diagnostics/Hover/References等）、Shell/Process系（Bash・PowerShell・Monitor・TaskCreate/Update/Get/Output/Stop）。Agent Controls: allowlist/denylist設定・スコープ別信頼設定（project/user/session）・tool approval policy。Artifacts: 公開共有URL発行・閲覧者のMCPコネクタアクセス機能。/doctor: 環境・MCP接続・権限の自動診断。エディタロール: チーム内で読み取り専用・提案のみ・フル制御の権限分離。
