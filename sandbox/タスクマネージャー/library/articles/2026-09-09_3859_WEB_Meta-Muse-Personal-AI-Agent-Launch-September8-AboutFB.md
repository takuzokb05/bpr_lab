# Meta がパーソナルAIエージェント「Muse」を正式ローンチ — 専用Secure VM・$0/$20/$100/月

- 言語: en
- テーマ: ai-news
- 取得日: 2026-09-09

## 要約
Metaは2026年9月8日、パーソナルAIエージェント「Muse」を正式発表した（米国ユーザー向けには9日公開）。MuseはユーザーごとにMuse Secure VM（専用クラウド仮想マシン）を割り当て、エージェント・ブラウザ・認証情報を隔離して実行する。接続サービス：Google Workspace・Ticketmaster・OpenTable・Spotify・Apple Healthなど。
主な機能：メール送信・旅行予約・料金交渉・買い物・会議スケジュール・長期目標の追跡。チャットUIはテキストスレッドに近い形で、「アプリを閉じた後も稼働し続け、変更が生じたり承認が必要なとき（メール送信前・購入確定前など）にユーザーへ通知する」非同期エージェント設計。ユーザーはエージェントに名前・アバター・コミュニケーションスタイルをカスタマイズ可能。
価格：無料ティア + $20/月（Basic） + $100/月（Premium）の3段階。
意義：Claude Managed Agents・OpenAI Agents・Google Duplex系との直接競合。専用VM分離アーキテクチャはプライバシー訴求だが「Metaが全行動履歴にアクセス可能では？」という懸念もある。AIエージェントが一般消費者向けに本格展開する節目。
