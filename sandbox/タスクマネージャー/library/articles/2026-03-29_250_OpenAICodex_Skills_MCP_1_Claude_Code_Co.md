## 投稿内容

OpenAIのCodexが
「プラグインシステム」を正式投入。

Skills + MCP + アプリ統合を
1つのバンドルにして
インストールできる。

つまり、Claude Codeが
「自分でスキルを書く」なら

Codexは「誰かが作った
プラグインを入れる」方向。

エコシステムの設計思想が真逆。

AIコーディングツールの競争軸が
「モデルの賢さ」から
「拡張の仕組み」に移った。

─────────────────

【 Codexプラグインの構造 】

・.codex-plugin/plugin.json（マニフェスト）
・skills/（ワークフロー記述）
・.mcp.json（MCPサーバー設定）
・CLIで /plugins 
　→ ブラウズ・インストール・削除

─────────────────

Claude Codeユーザーとして正直に言うと
このマーケットプレイス型は
初心者には圧倒的に優しい。

自分でSKILL.md書ける人にはClaude Code。
書けない人にはCodex。

ここが分かれ目になる。
