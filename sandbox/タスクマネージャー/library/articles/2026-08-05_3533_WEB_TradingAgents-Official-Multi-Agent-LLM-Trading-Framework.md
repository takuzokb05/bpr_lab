## 要約
TauricResearch（UCLA+MIT研究チーム）によるTradingAgents公式ページ。GitHub Stars 80,000超・Forks 15,500超でオープンソースAI取引フレームワーク最多スター数を維持。7つの専門LLMエージェントが実際の取引会社を模倣して協働：ファンダメンタル分析・センチメント分析・ニュース分析・テクニカル分析（4種類のオシレーター・モメンタム指標）・強気/弱気リサーチャー（反対意見で相互検証）・トレーダー・リスクマネージャー・ファンドマネージャー。対応プロバイダー：OpenAI（GPT-4o以降）・Anthropic Claude（全系列）・Google Gemini・Grok（2026年4月時点）。v0.2.4（2026年4月リリース）追加機能：LangGraphチェックポイント再開・永続的意思決定ログ・DeepSeek/Qwen/GLM/Azure対応・構造化出力エージェント。バックテスト実績：AAPL累積リターン+26.62% vs Buy-and-hold -5.23%（Jun-Nov 2024）。注意事項：ライブ取引実績なし・バックテスト期間は1四半期のみ・本番運用前に十分な検証が必要。
