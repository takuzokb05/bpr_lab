ちょっとしたTipsコーナー📣

Claude Codeが英語で嫌だなという方は、

Claude Codeに、
『~/.claude/CLAUDE.mdに「日本語で応答してください。」と追記して』
と伝えてください。

ご自身でCLAUDE.mdに記載してもOKです。

プロジェクトじゃなくグローバルに設定するのが良いと思います。

~/.claude/CLAUDE.md を開いて、一番頭に

『# 基本設定
 日本語で応答してください。』
とか、書いておきましょう。

その場合でも、Claude Codeにハードコーディングされてる要素（たとえば、「Allow once / Allow always / Deny」とか）は英語のままです。

あくまでClaudeの応答が日本語になるだけです。

日本語になったかどうかは /config で確認できます。
