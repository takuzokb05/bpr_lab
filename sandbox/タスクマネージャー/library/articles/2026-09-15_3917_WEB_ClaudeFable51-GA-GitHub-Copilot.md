## 投稿内容
GitHub official changelog announcing Claude Fable 5.1 is generally available in GitHub Copilot (September 1, 2026). Fable 5.1 joins Claude API, Amazon Bedrock, Google Cloud, and Microsoft Azure availability. Model ID: claude-fable-5-1. Features: 1M token context, 128K max output, adjustable thinking effort. Price same as Fable 5 ($10/$50 per MTok) with 75% cache read reduction ($0.25/MTok).
