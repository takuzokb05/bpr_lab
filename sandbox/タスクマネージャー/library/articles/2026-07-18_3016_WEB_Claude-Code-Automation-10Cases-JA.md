## 投稿内容
UravationによるClaude Code業務自動化10事例集（実装プロンプト付き公開）。Claude Code v2.1.101（Sonnet 4.6統合・Cowork GA・Agent Teams強化済み）での実践ガイド。主な自動化パターン：(1) 定型CRUD処理・APIクライアントコード自動生成、(2) 画面コンポーネントテンプレート作成・バリデーションロジック生成、(3) /team-onboardingコマンド（プロジェクト分析→新規参加者向け環境構築手順自動生成）、(4) Cron定期実行による議事録自動化（文字起こし→議事録→メール下書き→Slack通知）、(5) レポート自動集計・送信。非エンジニアも含め「パターン化された実装」をClaude Codeに完全委任することで、開発者はより本質的な設計・仕様検討に集中できる。

## 要約
Claude Codeの業務自動化実装例をプロンプト付きで公開した実践ガイド（JA）。/team-onboardingコマンドはチームインフラとして特に価値が高い。Cron+Claudeの組み合わせによる定期レポート・通知自動化は即日導入できる実用パターン。タスクマネージャー内でも応用できるアイデアが多数含まれる。
