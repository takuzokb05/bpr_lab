SitePointによるClaude Code June 2026の主要新機能10件の解説記事。

## 要約

- Claude Codeが2026年6月に追加した10の主要機能を詳解。最大の注目点は「階層型エージェントスポーン」で、親エージェントが子エージェントを生成し、最大3階層まで深くネスト可能になった
- 大規模なコードベース移行などで、トップレベルエージェントがモジュール単位のエージェントに委任し、さらに関数レベルエージェントに再委任するという構成が可能
- 各エージェントノードは独自のロール・モデル・制約セット・コンテキストウィンドウを持つ
- ファイルシステム分離（7月に追加）: `sandbox.filesystem.disabled`設定でファイルシステム分離をスキップしつつネットワーク出口制御を維持可能
- `/fork`コマンド（7/16追加）: 現在の会話を新バックグラウンドセッションにコピーしながら作業を継続できる
- `/subtask`コマンドがインセッションのサブエージェント機能を置き換え
- セッション全体でのWebSearchツールコール数制限とサブエージェントスポーン上限が追加（暴走ループ防止）
- スクリーンリーダーモードの追加（プレーンテキストレンダリング）
- 長時間MCPツールコールの自動バックグラウンド移行によりセッションの応答性を維持
- Claude Code 5.xシリーズへの進化を示す技術記事として価値が高い
