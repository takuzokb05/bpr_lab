# MetaTrader 5 Build 6180: AIアシスタントがStrategy Tester統合コパイロットに進化

- URL: https://fxnewsgroup.com/forex-news/platforms/new-mt5-release-comes-equipped-with-more-ai-features/
- ソース: web
- 言語: en
- テーマ: ai-trading
- 取得日: 2026-09-10

## 投稿内容
2026年9月4日リリースのMT5 Build 6180でAIアシスタントが大幅拡張。新機能（公式MQL5フォーラムより）：（1）Strategy Testerのレポート・ログの取得と分析、（2）現在のターミナル設定の確認、（3）最適化の起動支援、（4）指定パラメータ付きインジケーターをチャートに追加、（5）EAログおよびターミナルログへのアクセスと解析。従来は「チャットで質問に答えるだけ」だったAIアシスタントが、実際のプラットフォーム操作・設定変更・バックテスト分析まで実行できる統合コパイロットに変化。

## 要約
FX自動売買システム開発者にとって直接的な影響がある更新。MT5のAIアシスタントがStrategy Testerと統合されることで、EAのバックテスト→レポート分析→最適化サイクルを自然言語で操作できるようになる。具体的なワークフロー変化：「このパラメータで最適化を回してみて」「前回のテスト結果と比べてどうか分析して」といった指示が直接MT5内で実行可能。Claude Code + MT5 MCPサーバーとの組み合わせでさらに強力な統合AIトレーディング環境が実現できる見通し。MT5を活用したFX自動取引プロジェクト（sandbox/FX自動取引）において、Build 6180へのアップグレードを検討すべき。
