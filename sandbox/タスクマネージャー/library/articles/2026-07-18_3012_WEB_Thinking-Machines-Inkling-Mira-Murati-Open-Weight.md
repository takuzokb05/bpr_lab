# Thinking Machines Lab「Inkling」：Mira Muratiの新ラボがオープンウェイトモデル初リリース

- URL: https://aiflashreport.com/model-releases.html
- ソース: web
- 言語: en
- テーマ: ai-news
- 取得日: 2026-07-18

## 投稿内容
OpenAI元CTO Mira Muratiが設立したThinking Machines Labが2026年7月15日頃、初のフラッグシップモデル「Inkling」を公開。特徴：オープンウェイト（重みダウンロード可）、リファレンス推論スタック公開、企業向けホストAPIも提供。汎用推論・コーディングモデルとして主流クローズドモデルとの競合を標榜。Meta Llama系に続くフロンティアレベルのオープンウェイトモデルとして業界内の注目度高し。詳細ベンチマークは近日公開予定でGPT-5.6・Fable 5との比較が控えている。オープンウェイトと企業向けAPIのデュアル提供戦略が特徴的。

## 要約
Inkling（Thinking Machines Lab）はMira Murati率いる新興ラボの初フラッグシップ。オープンウェイト提供でローカルデプロイ・自前ファインチューニングが可能。FX自動取引等での利用可能性も検討余地あり。2026年7月のモデルラッシュの中で「オープンウェイト×フロンティア品質」という差別化ポジションを確立しようとしている。
