## 要約
2026年8月時点のClaude Codeプラグインエコシステム紹介記事。公式マーケットプレイスには250以上のプラグイン、コミュニティカタログには2,000以上が存在する中から厳選9本を解説。プラグインはスキル・エージェント・フック・MCPサーバー・言語サーバーをバンドルし、/pluginコマンドで一括導入できる。人気MCP：Figma（デザイントークン抽出・コード生成）、Playwright（E2Eテスト・スクリーンショット）、Vercel（デプロイ・ログ管理）、PostgreSQL（DBクエリ・スキーマ確認）、GitHub（PR作成・Issue管理）。Claude Code 2026の3層カスタマイズ（Skills・Hooks・Subagents）との組み合わせ方も解説。実務ユースケース付き。
