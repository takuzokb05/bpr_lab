# CLAUDE.md, Skills, Subagents, Hooks: When to Use Which

## 要約
BuildThisNow.com によるClaude Code 4プリミティブの役割分担ガイド。トークンコスト・発火タイミング・強制力を軸にした明確な判断フレームワーク。

**4プリミティブの定義と用途**:

**CLAUDE.md** — 「Claudeが常に知っていること」
- 毎セッションターンにロードされる
- リポジトリレイアウト・命名規則・ハード制約等の普遍的知識
- 肥大化はすべてのターンのコストを増加させる → 短く最新に保つ

**Skills** — 「オンデマンドのプレイブック」
- 初期オーバーヘッド: 約100トークン（名前と説明のみ）
- モデルがタスクに合わせて関連Skillを呼び出す（確率的）
- ステップバイステップの手順をモデルが選択的に実行

**Hooks** — 「Claudeが制御できない強制ルール」
- ライフサイクルイベントで確定的に発火（モデルの外部で実行）
- モデルはHooksを無効化・迂回できない
- 安全チェック・lint・監査等の「例外なし要件」に使用

**Subagents** — 「隔離コンテキストの並列ワーカー」
- 生成オーバーヘッド: 約20,000トークン
- 独立したコンテキストウィンドウを持つ分離実行
- 並列実行・制限付きツールセット・コンテキスト分離が必要な場合のみ使用

**優先順序**: Hooks（法律=強制）> CLAUDE.md/Skills（指針=勧告）> Subagents（スコープワーカー）

Hooks は優先度最上位（モデル外で動作）。競合する場合、Hooks が常に勝つ。
