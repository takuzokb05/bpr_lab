## 投稿内容

Anthropic 把 Claude Code auto mode 的安全设计写了篇工程博客——分类器怎么判断哪些操作要拦、哪些放行，连漏报率都没藏着。

有个细节很妙：分类器判断时，agent 自己写的"理由"会被剥离，只看用户指令和实际操作。因为 agent 能把危险操作解释得头头是道。

做决定的人和写理由的人必须分开。这个直觉放在哪个领域都成立。
