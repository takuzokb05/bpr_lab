## 要約

2026年8月17日、Claude Code v2.1.234がリリース。8月だけでv2.1.229〜v2.1.234まで6バージョンがリリースされ、アップデートペースが加速している。

### 各バージョンの主な変更点
- **v2.1.234（Aug 17）**: 使用量制限リセット時の自動セッション継続機能・認証情報漏洩に対するセキュリティ強化
- **v2.1.233（Aug 14）**: GitLab MRサポート・ビルドコマンドのメモリ制限（暴走ビルド防止）
- **v2.1.232（Aug 13）**: @メンションで別Claude Codeセッションを名前で参照するクロスセッション機能
- **v2.1.229（Aug 12）**: 長い思考停止中の接続維持とリモートコントロール改善

### Compliance API 展開
AnthropicはCompliance APIをClaude Codeのデスクトップ・Web・モバイル・CLI全サーフェスに拡大。Claude Enterprise顧客向けbetaとして提供開始。セキュリティチームが統合セッションコンテンツとメタデータを監査・eDiscovery用に取得可能になった。大企業でのClaude Code導入を加速させる重要なガバナンス機能強化。

自動セッション継続機能により、使用量制限を超えた場合もリセット後自動再開するため、長時間バッチ処理がより安定して動作するようになった。
