## 要約
Claude Code 2026のマルチエージェント構成を3層に整理した実践ガイド。①同一セッション内のサブエージェント（タスク分解・軽量並列処理）②Agent Teams機能（独立したコンテキストウィンドウを持つ並列チームメート、チームリードが指揮・統合）③外部オーケストレーター（複数リポジトリ・チーム横断の大規模構成）。Claude Agent SDKへの機能統合により、これらのパターンが各チームの個別実装なしに利用可能になった点が2026年の大きな変化。チームメートはタスクリスト経由で相互メッセージ可能。並列エージェントでの品質向上・完了時間短縮の実例を掲載。FX自動取引などの複雑タスクにも応用できるアーキテクチャ。
