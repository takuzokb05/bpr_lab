## 要約
Technspireによる2026年版AIエージェントSDK選定ガイド。Claude Agent SDK・LangGraph・AutoGenを5軸（アーキテクチャ・スケーラビリティ・学習曲線・コスト・エコシステム）で比較。Claude Agent SDK：Managed AgentsとDreaming機能で自律性最高・Anthropicネイティブ統合強・6月15日より従量課金分離。LangGraph：グラフ型ワークフローで複雑状態管理に最優、月間ダウンロード3450万件・エンタープライズ採用急増、状態遷移の明示的制御が必要なシステムに適合。AutoGen：Microsoft提供でAzure統合が最も容易・コードエージェント中心。ユースケース別推奨SDKの決定木（自律度・Azure依存・複雑状態の3軸）と本番デプロイ企業事例3社/SDKを収録。
