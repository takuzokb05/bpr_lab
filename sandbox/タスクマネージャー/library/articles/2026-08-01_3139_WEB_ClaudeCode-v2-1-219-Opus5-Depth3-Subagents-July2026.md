## 投稿内容
Releasebot集計のClaude Code 2026年7月リリースノート。v2.1.219（7/24）：Opus 5デフォルト化・深度3ネストサブエージェント・sandbox.network.strictAllowlist。v2.1.218（7/22）：/code-reviewのバックグラウンドサブエージェント化。v2.1.217（7/21）：emoji shortcodeオートコンプリート。v2.1.215（7/19）：/verify・/code-reviewの自動呼び出し廃止。Week 28（7/6-10）：デスクトップブラウザ統合・/doctor強化・Auto mode保護。

## 要約
2026年7月のClaude Codeは「より大きく、より制御可能に」方向で進化。Opus 5の1Mコンテキストウィンドウと$10/$50/Mtok価格がデフォルトになり、動的ワークフローと深度3ネストサブエージェントで複雑な並列タスクオーケストレーションが公式サポート。`sandbox.network.strictAllowlist`設定追加でセキュリティ強化も進む。`/code-review`がバックグラウンドサブエージェント化により、レビュー中に他の作業が継続可能に。重要な行動変更：v2.1.215で`/verify`と`/code-review`の自動呼び出しが廃止され、明示的コマンドが必要に（自動実行の過剰なコスト問題への対応）。Week 28では`/doctor`が単なる診断から修復ツールにアップグレードされ、デスクトップブラウザ統合で外部サイトへのアクセスが可能に。
