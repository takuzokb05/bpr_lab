## 投稿内容
2026年8月の生成AI/LLMモデルリリース動向を「クラウドAPI・オープンウェイト・エッジ軽量」の三極構造で分析した日本語ブログ記事。

**背景**: 米国大統領令EO 14409の設計期限（8月1日）が各社の投入タイミングに影響。新フレームワーク適用前の戦略的リリースが集中。

**クラウドAPIモデル**:
- Qwen3.8-Max（Alibaba, 8/2）: 2.4兆パラメータMoE、950Bアクティブ、コーディング・自律タスク特化、$2/$6/Mトークン
- OpenAI Astra（8/1）: 未解決数学10問を形式証明で解決、マルチエージェント長期推論設計
- Muse Spark 1.2（Meta, 8/6）

**オープンウェイト**:
- Kimi K3（Moonshot AI, 7/27重み公開）: 2.8兆パラメータ、Modified MIT
- GLM-5.2（Z.AI）: 約744B、オープンウェイト1位、MIT
- Qwen3.8-Max Open-Weight版（Alibaba）: Maxクラス重み公開はシリーズ初

**エッジ・軽量**:
- LFM2.5-2.6B（Liquid AI, 8/4）: スマホ30tok/s、<2.5GBメモリ、ツール呼び出しエージェント向け
- Gemma 4 E2B（Google）: Raspberry Pi 5で動作、128Kコンテキスト、Apache 2.0

**実務示唆**: 「最強モデル」より「安いモデルを賢く使う」が勝ち筋。分類・下書き・要約は軽量モデルで十分なケースが多く、FX自動取引でも経済指標速報の分類はLFM2.5クラスで処理しフロンティアモデルは戦略判断のみに使う構成が費用対効果高い。
