## 要約
Makerkitによる2026年版Claude Code Routinesの包括ガイド。2026年4月リリースのRoutines機能をClaude CodeをローカルDev툿から「スケジュールされたクラウド自動化プラットフォーム」に変えるものと位置づけ。Routineの構成要素（プロンプト・リポジトリ・コネクター）を解説。3種類のトリガー：スケジュール・API呼び出し・GitHubイベント。3種類の実行方法：Routines（クラウド、PC不要）・Desktopスケジュール（ローカル、アプリ起動必要）・/loop（セッション内）の違いを明確に説明。/scheduleコマンドまたはDesktopアプリのNew routineから設定可能。
