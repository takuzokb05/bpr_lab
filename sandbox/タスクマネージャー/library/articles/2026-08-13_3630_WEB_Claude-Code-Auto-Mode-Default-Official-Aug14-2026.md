# Auto mode is now the default in Claude Code for Pro, Max, and Team plans

## 要約
Anthropic公式ブログ。2026年8月14日より、Claude CodeのPro・Max・TeamプランでAutoモードがデフォルトの権限モードになると発表。Autoモードでは「不可逆・破壊的・環境外への操作」と判定されない限り、人間の承認を求めずに進む。旧手動承認ワークフローが危険コマンドを捕捉できたのは14%に対し、Autoモードの分類器は89%を捕捉。企業・API・AWS Bedrock・Google Cloud・Microsoft FoundryはしばらくオプトインのままだがAnthropic社は来月中にデフォルト化予定。既に別のデフォルトを設定済みのユーザーは一度のプロンプトで切り替え確認が行われる。
