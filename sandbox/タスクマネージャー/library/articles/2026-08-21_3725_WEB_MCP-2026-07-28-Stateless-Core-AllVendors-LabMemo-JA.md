## 要約
2026年のMCP（Model Context Protocol）を日本語で包括的に解説。最大の変化は2026-07-28仕様での「プロトコルのステートレス化」で、セッション依存が廃止され一般的なWebサービスと同様の水平スケーリングが可能に。その他主要変更点：Multi Round-Trip Requests、ヘッダーベースルーティング、キャッシュ可能なlistレスポンス、OAuth/OIDC認証強化、拡張フレームワーク正式化。MCPはLinux Foundationに寄贈され、Anthropic・OpenAI・Microsoft・Google全4社が採用表明（事実上の業界標準）。日本語圏では国内117選MCPディレクトリ（34カテゴリ）が整備済み。Sansanなど国内SaaSの公式MCP提供事例も増加中。
