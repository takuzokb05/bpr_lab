1. In terminal, run `gsd-sdk init @path_to_a_prd_or_document_for_context`

then it'll run through the project initialization on its own (or you can do the old school /gsd:new-project in Claude Code to get the context scaffolded)

2. In terminal, run `gsd-sdk auto`
