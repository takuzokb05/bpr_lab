## 要約
2026年6月15日のClaude課金変更を開発者目線で解説。対話セッションとエージェント自動化の課金が分離。

**変更内容**:
- 自動エージェント使用（Claude Agent SDK / ヘッドレスClaude Code / GitHub Actions / サードパーティエージェント）→ 月次クレジット制、APIレートで課金
- 対話型Claude.aiチャット＋ターミナルセッション → 従来サブスクリプションのまま

**プラン別クレジット割り当て**:
| プラン | 月次クレジット |
|--------|----------------|
| Pro | ~$20 |
| Max 5x | ~$100 |
| Max 20x | ~$200 |

クレジットは翌月繰越なし。上限到達後は標準API料金が加算課金される。

**背景**: サブスクリプションが重い自動使用を推定15〜30倍補助していたため、AnthropicがAPIコストを反映した課金体系に移行。

**影響対象**: CI/CDパイプライン / スケジュールcronジョブ / ビルドシステム / ボット実装。対話型ユーザーは影響なし。

**推奨対応**:
1. 自動化ワークフローの事前監査（使用量計測）
2. プロンプトキャッシュ活用でトークン最適化
3. 重い処理は直接APIキーへ移行（予測可能な課金）
4. トークン使用量モニタリング・予算アラートの導入
