## 投稿内容
Agent Skills が全てオープンソース化され、Codex・Claude Code・Cursor などのAIエージェントで使える75個のスキルがまとめられていた、という紹介。内容は Webデザイン / LP制作 / モーション設計 / WebGL表現 / UIスタイル / アセット生成 に特化。
- 「Video to Super Prompt」: デザイン/LP/アニメの画面録画を読み込み、Codexがそのまま実装できるレベルの詳細プロンプトへ変換
- 「HTML to Interaction Prompts」: 既存HTMLを解析しセクション構成・ボタン・アニメ・WebGL・インタラクション指示まで抽出
- 「Stitched Full Page Capture」: ヒーローだけでなくLP全体をキャプチャしデザイン参考に
- 「Daily UI Inspiration」: 優れたLPを巡回・キャプチャし詳細プロンプトパックへ変換する自動ループ

## 要約
Web制作（デザイン/LP/モーション/WebGL/UI/アセット）に特化した75個の Agent Skills 群がOSS化されているという紹介。Claude Code だけでなく Codex・Cursor でも使える横断的なスキル集で、特に「画面録画→実装可能な超詳細プロンプト」「既存HTML→インタラクション指示抽出」「LP巡回→プロンプトパック自動生成ループ」など、視覚成果物をエージェントの入力プロンプトに変換する系が充実。Skills を"自作する"だけでなく"既製の高品質スキルを輸入する"供給源として、当リポジトリの skills 運用の参考になる。

判定理由: 実在のOSSスキル集（75個）の紹介で、具体的スキル名と機能を列挙。Skills輸入元の候補となる実質情報でSIGNAL。
