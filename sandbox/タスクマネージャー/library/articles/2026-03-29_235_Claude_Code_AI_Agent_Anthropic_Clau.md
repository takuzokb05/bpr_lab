## 投稿内容

Claude Code 这次上的自动模式，
解决一个现实的问题：
别让 AI 越用越笨

Agent 用久了，
会记住你的偏好、习惯、修正和规则。
但记忆一多，
也会开始变乱：
过时的信息、重复的笔记、互相冲突的判断，都会堆进去。

结果就是：
看起来记住了很多，
实际却越来越容易跑偏。
Anthropic 这次给 Claude Code 加的 Auto Dream，
本质上就是在做一件事：
定期整理记忆。

留下重要的，
删掉没用的，
把乱掉的上下文重新收拾干净。
这比再加 100 万 token更重要。

未来真正好用的 Agent，
拼的可能不是谁记得更多。
而是谁更会忘
