## 投稿内容
Microsoft's official blog post announcing Agent Framework Harness general availability (August 2026). Version 1.13.0 ships: richer Foundry Hosted Agents integration, Responses API support, reusable session stores, expanded telemetry and observability, stronger workflow replay and approvals. GitHub Copilot connector, Claude Agent SDK connector, and orchestration patterns now stable. Foundry Hosted Agents (serverless agent execution) available as part of the stack. Harness was first previewed at Build 2026; this GA release brings enterprise-grade production support. InfoQ analysis confirms the same: "Agent framework moves from research demos to production DevOps automation in 2026." First time the MS + Anthropic Agent SDK interoperability has reached a production-stable milestone.
