## 要約
Claude Code Skillsの日本語包括解説：①Skillsの概念整理：CLAUDE.md「常に適用するルール」とSkills「特定作業時のみ必要な手順」の使い分けが基本原則。②作り方：`.claude/skills/<名前>/SKILL.md`に手順を書くだけ、/initコマンドでCLAUDE.md自動生成補助。③活用事例：議事録整理・メール下書きチェック・ブログ記事品質確認・コードレビュー・テスト生成・ドキュメント更新。④チーム展開：スキルはリポジトリにコミットするためチーム間共有が容易、個人設定は`.claude/settings.local.json`で分離。⑤2026年9月追加ポイント：/skill-doctorコマンドで未使用スキル・コンテキスト消費量を確認して定期剪定を推奨。非エンジニアにも適用可能なユースケースが豊富で、日本語で読みやすい入門記事。このリポジトリのスキル管理・CLAUDE.md最適化の参考に有用。
