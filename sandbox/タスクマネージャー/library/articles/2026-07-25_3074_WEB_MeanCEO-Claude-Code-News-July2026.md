## 投稿内容

mean.ceoによるClaude Code 2026年7月ニュースのまとめ記事。

## 要約

- 7月の主要変更: `/fork`コマンド（7/16）でバックグラウンドセッション分岐が可能に。`/subtask`がインセッションサブエージェントを置き換え
- セッション全体でのWebSearchコール数制限とサブエージェントスポーン上限が追加（暴走ループ防止）
- ファイルシステム分離コントロール強化（7/20リリース）: `sandbox.filesystem.disabled`設定を追加
- サブエージェントのデフォルトスポーン深度が変更（デフォルトで入れ子サブエージェントを生成しなくなった。`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`環境変数で制御）
- 長時間MCPツールコールの自動バックグラウンド移行、スクリーンリーダーモード追加
- `/resume`コマンドに過去セッション（削除済み含む）の一覧ピッカー機能が追加
- Claude Codeは「ターミナルベースの業務レイヤー」として進化中 — バグ修正・ファイル編集・テスト・git操作を開発フロー内で処理
- July 2026時点でのClaude Codeの最前線をキャッチアップするのに最適なサマリー記事
