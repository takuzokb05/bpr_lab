## 投稿内容
Developers DigestがCodexとClaude Code両ツールのJuly 2026アップデートを比較分析。Claude CodeはJuly updateで/fork・/doctor・公開アーティファクト共有・エディタロール・BroadcastAutoModeを追加。Claude Sonnet 5が新デフォルトモデル（SWE-bench 72.7%）、Opus 5が7/23リリースでFrontier-Benchトップ達成。

## 要約
2026年7月にCodexとClaude Code両ツールで追加されたAgent Controls機能を比較分析した記事。Claude CodeのJulyアップデート主要項目: /fork（セッション分岐・実験的変更を安全に試せるブランチ機能）、/doctor（環境診断コマンド）、公開アーティファクト共有、アーティファクトへのMCPコネクタアクセス、エディタロール（チーム内権限分離）、BroadcastAutoMode（Bedrock・Google Cloud Agent Platform・Microsoft Foundry対応拡大）。モデル更新: Claude Sonnet 5がデフォルト（SWE-bench 72.7%、Terminal-bench 76.1%、$2/$10 per Mtok促販〜8/31）、Claude Opus 5（7/23リリース）がFrontier-Bench v0.1で全モデル首位・Fable 5と0.5%差でHalf price。CoworkがWebとモバイルに拡大し、リモートセッション（ファイル・セッション状態をアカウント保存・デバイス間同期）がベータ提供開始。Agent Controlsは権限の許可・拒否・信頼スコープをAPI/CLI/UIの各レベルで設定でき、チーム環境での安全なエージェント運用の基盤となる機能。Codexとの比較ではCoworkによるリモート継続実行が最大の差別化ポイント。
