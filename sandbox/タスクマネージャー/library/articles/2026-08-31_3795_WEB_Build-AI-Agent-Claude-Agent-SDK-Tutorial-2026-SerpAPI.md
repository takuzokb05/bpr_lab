## 投稿内容
SerpAPI's step-by-step tutorial on building an AI agent using the Claude Agent SDK. Covers installation, agent creation, model selection, permissions, MCP integration, safety hooks, subagents, and production deployment.

## 要約
SerpAPIによるClaude Agent SDKのステップバイステップチュートリアル。SDK概要: Python版（v0.2.139/PyPI）とTS版（@anthropic-ai/claude-agent-sdk v0.3.233/npm）が毎週リリース中。Claude Codeを動かすのと同じエージェントループをライブラリとして提供—ファイルアクセス・シェルコマンド・Web検索・パーミッション処理・マルチエージェント協調がOut-of-the-boxで利用可能。チュートリアル内容: インストール→初回エージェント作成→モデル選択（Opus 4.8/Sonnet 4.6/Haiku 4.5）→パーミッションロックダウン→インプロセスMCPサーバーでカスタムツール統合→セーフティフック→サブエージェント委譲→プロダクションデプロイ。生APIループを書かずに済む実用的な入門。
