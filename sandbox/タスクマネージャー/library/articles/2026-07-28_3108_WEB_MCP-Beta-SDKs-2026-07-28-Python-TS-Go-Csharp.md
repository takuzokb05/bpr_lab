## 投稿内容
Beta SDKs for the MCP 2026-07-28 specification are now available for Python, TypeScript, Go, and C#. Implements the stateless core, Extensions framework, and hardened OAuth/OIDC authorization from the new spec. The ten-week validation window closes today as the final spec ships. Stateless model means no session state management needed server-side, and clients can cache tools/list responses. Migration guides included for each language SDK. Breaking changes from the old spec require updates to existing MCP server implementations.
