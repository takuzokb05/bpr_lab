## 投稿内容

TotalumによるClaude Agent SDK 2026年版の解説。何か・いつ使うか・どうシップするかを実践的に解説。

## 要約

- Claude Agent SDKはClaude Code自体を動かすのと同じハーネスの上にプロダクションAIエージェントを構築するためのAnthropic公式ライブラリ
- Python・TypeScriptの2フレーバーで提供。バンドルされたCLIバイナリ・サブエージェント・セッション・MCPサポート・ホステッド実行モデルを同梱
- 2026年時点でAgent SDKはAnthropic Managed Agentsの下位層に位置し、Managed Agentsにはスケジューラ・ドリーミングパス・ルーブリックベースの成果評価機能が追加されている
- CLAUDE.md・Skills・Subagents・スラッシュコマンド・Hooks・MCPサーバーという同一プリミティブをプログラマティックに操作可能
- 利用シナリオの明確化: 繰り返し実行・バッチ処理・外部イベントトリガー・複数並列エージェントなどでCLIより適切
- TotalumはAgent SDKをSaaSプロダクトに統合する際のパターンとベストプラクティスを実例で提示
- 2026年のエージェント構築スタックの全体像を把握するのに有用な技術解説
