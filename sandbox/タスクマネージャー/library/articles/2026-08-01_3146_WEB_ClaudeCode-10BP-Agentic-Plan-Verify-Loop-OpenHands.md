## 投稿内容
OpenHands社（2026年7月2日）によるClaude Code エージェントコーディングベストプラクティス10選。探索→計画→実装→コミット→プロンプト設計→検証→CLAUDE.md→権限→拡張→コンテキスト管理の順序で整理。「サイレントな誤答はクラッシュより高コスト」という核心知見を提示。

## 要約
エージェントコーディング成熟期の2026年7月に発行されたOpenHands社の実践ガイド。10 BPの構造は「段階的信頼構築」：（1-2）plan modeで読み取り専用探索→レビュー済みプランへ変換（Anthropic内部テストで無指導時33%成功率が計画後に大幅向上）。（3-4）プランに沿った段階的実装→gitチェックポイントコミット（可逆性とセキュリティスキャンのため）。（5）エージェントが完了できるスコープでプロンプト設計：症状でバグ説明、既存パターン参照、1プロンプト1課題。（6）検証設計：「サイレントな誤答はクラッシュよりはるかに高コスト」という原則から軽量インプロンプトチェック～外部評価者の多層検証。（7）CLAUDE.mdはコマンド・アーキテクチャ決定・チームルール中心に簡潔に。（8-9）allow/ask/denyで権限を意図的に設定、スキル・サブエージェント・MCPで拡張。（10）/clear・/compact・サブエージェント分離でコンテキスト汚染を防止。核心メッセージ：エンジニアの役割は「実行」から「成果・制約・検証の仕様化」に移行中。チームスケールでは企業権限管理と監査証跡が不可欠。
