# China AI Agent Regulations Enforceable July 15, 2026: World's First AI Agent Law

## 投稿内容
2026年7月15日、中国が「AIエージェントに関する実施意見」を施行——世界初のAIエージェント専用規制フレームワーク。3層の意思決定認可構造：Level 1=スケジューリング等の日常業務は自律操作可、Level 2=契約・価格設定等の重要決定は人間承認必須、Level 3=法律・財務・安全事項はエージェント判断禁止。Level 2・3は事前デプロイメントレビューと四半期報告書が義務。中国ユーザー・データに影響を与える全組織（物理的所在地不問）に適用。EU・米国での類似基準導入の先例となる見込み。

## 要約
MachineBriefによる中国AIエージェント規制（2026年7月15日施行）のレポート。世界初のAIエージェント専用法的カテゴリーとして歴史的な意義を持つ。3層フレームワーク（自律可/人間承認必要/禁止）により、商用AIエージェントの用途分類・デプロイメント審査・定期報告が義務化。域外適用（中国ユーザー・データへの影響があれば海外企業も対象）が実務上の重要課題。EUのAI Act(8月2日)と並び、2026年後半のAIエージェント商用化に大きく影響する規制の一次情報。FX自動取引エージェント開発においても将来的な規制リスクとして把握必須。
