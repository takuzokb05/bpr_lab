# MetaTrader 5 Beta Build 5955 — MCP・AIエージェントのネイティブサポート開始

- URL: https://www.mql5.com/en/forum/511825
- ソース: web
- 言語: en
- テーマ: ai-trading
- 取得日: 2026-07-16

## 要約

2026年7月16日（本日）、MetaQuotesがMT5新ベータビルド5955を公開。最大の新機能はModel Context Protocol（MCP）とAIエージェントのビルトインサポート。クライアントターミナルとMetaEditor両方で利用可能。AIエージェントが自然言語でMT5に接続し、マーケットデータ取得・注文発注・ポジション管理・テクニカル分析が可能に。従来はコミュニティ製MCP Serverでの回避策が必要だったが公式実装で信頼性向上。Webull・Deriv・IG・eToro等の主要ブローカーに続きMetaQuotesが追随。FX自動取引にLLMを組み込む実験の敷居が大幅低下。パブリックベータ参加推奨。本日リリースの一次情報。
