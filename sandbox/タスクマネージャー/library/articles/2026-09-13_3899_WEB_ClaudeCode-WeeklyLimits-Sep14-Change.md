## 要約
Claude Code週次利用制限の変更（2026-09-14〜）: 2026-05-13から続いた+50%プロモは09-13 23:59 PTで終了。09-14から新しい恒久上限（元の標準比+25%）が適用。Pro/Max/Teamプランとも同様の調整比率。実使用への影響: プロモ期間より利用可能トークンは減るが、2026年5月以前の基準より25%多い水準が永続する。Claude Code 2.1.268（09-10リリース）と2.1.269（09-11リリース）も同週に提供——デバッグ中の週次制限切れを避けるためバージョン確認を推奨。
