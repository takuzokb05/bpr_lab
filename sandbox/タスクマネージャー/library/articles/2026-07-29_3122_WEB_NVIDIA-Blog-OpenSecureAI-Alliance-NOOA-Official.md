## 投稿内容

NVIDIA Official Blog (July 2026): Announcement of Open Secure AI Alliance (OSAIA) formation.

**Alliance Overview**
- 37 organizations joining forces for AI agent security
- Mission: develop and share open technologies, techniques, and tools for securing software and AI agents
- Open-source first approach

**NVIDIA's Contribution: NOOA Framework**
- NOOA = No-Operations Open Agents
- Apache 2.0 license on GitHub
- Designed to make agent behavior easier to test, trace, audit, and govern
- Research framework for AI agent behavioral analysis

**Partner Contributions**
- **HPE**: SPIFFE/SPIRE — zero-trust identity verification for AI agents and services
- **Hugging Face**: Safetensors format — prevents remote code execution in model weights (contributed to PyTorch Foundation)
- **IBM/Red Hat**: Lightwell — digitally signed patch distribution across open-source supply chains
- **Microsoft**: MDASH — multi-model agentic scanning harness for vulnerability discovery and verification

**Motivation: The July 2026 Incident**
Hugging Face deployed GLM 5.2 on its own infrastructure to analyze 17,000+ actions during a July 2026 intrusion. Closed AI tools proved inadequate. This demonstrated that open, auditable AI security frameworks are essential for effective incident response.

**Industry Significance**
This marks the first major industry coalition specifically targeting AI agent security with open-source tooling, signaling a shift from proprietary to ecosystem-based AI security.
