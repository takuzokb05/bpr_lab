## 投稿内容
Anthropic shipped "Record a Skill" inside Claude Cowork on July 21, 2026. This feature allows Pro, Max, and Team users to screen-record themselves performing a task once, and Claude automatically converts that into a reusable, rerunnable skill. The system captures screen activity, mouse clicks, keystrokes, and voice commentary, then processes the demonstration into a structured skill definition that Claude can execute autonomously. No prompt engineering required — users just demonstrate the workflow and Claude figures out the automation. The feature is accessible via the "+" menu in the Claude desktop app by selecting "Record a skill." This democratizes digital automation by eliminating the need for complex prompt writing, replacing it with visual demonstration. Available to Pro, Max, and Team subscribers.
