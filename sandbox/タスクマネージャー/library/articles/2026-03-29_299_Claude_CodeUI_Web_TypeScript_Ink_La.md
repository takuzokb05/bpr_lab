【金融リサーチ特化の自律エージェント】
最近、注目しているオープンソースです。
Claude Codeのようなエージェント型UIを、投資・企業分析・財務調査向けに寄せた設計で、複雑な金融質問をタスク分解し、データ取得→自己検証→再実行まで回しながら答えを作るタイプ。

主な用途は、
・企業分析
・財務諸表チェック
・バリュエーション補助
・Web検索を含む投資調査の自動化

技術的には TypeScript + Ink + LangChain、実行基盤は Bun。

OpenAI / Anthropic / Google / xAI / Ollama など複数LLMに対応し、検索や金融データも外部ソース連携前提。

重要なのは、これは
トレード執行エンジンではなく、金融リサーチ用エージェント
だということ。
調査エージェント層としては、かなり面白いOSS。
