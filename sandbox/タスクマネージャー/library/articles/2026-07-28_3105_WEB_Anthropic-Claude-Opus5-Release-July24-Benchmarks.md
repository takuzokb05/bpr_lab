## 投稿内容
Anthropic released Claude Opus 5 on July 24, 2026. Pricing: $5 input / $25 output per million tokens. Context window: 1M tokens, max output 128K tokens. Performance: on Frontier-Bench v0.1, Opus 5 more than doubles Opus 4.8 and surpasses all other models. On ARC-AGI 3, Opus 5 scores 3x the next-best model. On OSWorld 2.0, surpasses Fable 5 at 1/3 the cost. Fast mode: ~2.5x default speed at 2x base price. Claude Opus 4.7 fast mode deprecated same day. Sonnet 5 (June 30): better for cost-sensitive repetitive tasks; Opus 5: complex agents, long context, production workloads where cost is secondary.

## 要約
2026年7月24日にClaude Opus 5正式リリース。価格は入力$5/出力$25（100万トークン）でコンテキスト1Mトークン・最大出力128Kトークン。Frontier-Bench v0.1でOpus 4.8の2倍超スコアを達成しFable 5水準に迫る。ARC-AGI 3では次点モデルの3倍スコア、OSWorld 2.0ではFable 5を上回りコストは1/3。Fastモードは約2.5倍速で価格2倍。同日Opus 4.7 Fastモードは廃止（リクエストエラーに）。Claude Sonnet 5（6月30日）はコスト重視の繰り返しタスク向け、Opus 5は複雑エージェントタスク・長コンテキスト・本番ワークロードに最適。
