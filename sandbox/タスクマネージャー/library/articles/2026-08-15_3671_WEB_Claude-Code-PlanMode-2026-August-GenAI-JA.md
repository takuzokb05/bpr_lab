## 要約
GenAI-AI.co.jp による Plan Mode の非エンジニア向け解説（2026年8月最新）。Plan Mode は「設計図を確認してから施工する」専用モード。切り替え方法：/plan コマンドまたは Shift+Tab。Plan Mode 中の制限：ファイル編集不可、質問応答のみ可能。使いどころ：大規模改修前・複雑なリファクタリング・新機能追加の前段階・多ファイル横断変更の影響確認。「Don't implement yet」プロンプトとの比較（Plan Mode の方がより明示的で確実）。プラン確認後に通常モードへ切り替えて実行する流れも解説。Anthropic 推奨の explore→plan→code ワークフローに対応。非エンジニアが実装ミスを防ぐための最重要機能として紹介。
