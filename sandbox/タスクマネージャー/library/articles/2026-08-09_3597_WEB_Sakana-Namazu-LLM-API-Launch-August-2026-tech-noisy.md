## 投稿内容
2026年8月3日、Sakana AIが日本語特化の大規模言語モデルAPI「Sakana Namazu」の提供開始を発表。日本語タスクに特化した設計で、企業・研究機関向けAPI提供。Sakana AIは「進化的AIアルゴリズム」を研究する日本発スタートアップ。同記事では同週の主要AI発表も掲載：①MicrosoftがCopilotアプリでPC画面録画AI機能を無料公開、②EU AI Actの透明性義務（Article 50）が8月2日から施行開始。2026年8月第1週のAI公式発表ダイジェスト（3分でチェック可能な形式）。国産LLMとして自立語処理・日本語文書要約・自治体・金融向け用途が想定される。他の国産LLM（tsuzumi by NTT、PLaMo by Preferred Networks）との競争が激化。

## 要約
Sakana AIが日本語特化 LLM「Sakana Namazu」の API を正式提供開始（2026年8月3日）。国産 LLM 競争が加速している一次情報。tsuzumi（NTT）・PLaMo（PFN）との三つ巴の構図。日本語自然言語処理に特化した国産 API として、日本企業向けユースケースでのコスト・プライバシー優位を訴求。2026年8月第1週の AI 業界ダイジェストとして参照価値あり。
