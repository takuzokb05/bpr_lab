## 要約

2026年5月arxiv論文。From Knowing to Doing（KTD）：LLMが市場知識を持っていても実際の取引判断に変換できない「遂行ギャップ」を定量化するメモリ制御ベンチマーク。GPT-4o・Claude Sonnet・Gemini等をCSI300銘柄で評価。結果：累積リターンは受動的な市場・スタイル露出で大部分が説明でき、株式選択アルファの持続的証拠は限定的。マルチエージェントフレームワークはアナリティクス精度を改善するが、「完全自律の意思決定者ではなく監督下のリサーチアシスタント」として捉えるべきとの結論。FX自動取引へのLLM適用の期待値を合理的に設定する上で重要な研究。
