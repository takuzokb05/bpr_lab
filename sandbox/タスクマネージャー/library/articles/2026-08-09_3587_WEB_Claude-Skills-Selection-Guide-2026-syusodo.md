## 投稿内容
2026年版 Claude Code スキル用途別比較ガイド。フロントエンド開発向け frontend-design スキル（インストール数最多クラス）、コードレビュー向け、ドキュメント生成向け等の実務カテゴリ別推奨スキルリスト。導入手順（.claude/skills/配下に SKILL.md 配置）の具体解説。チーム共有のベストプラクティス（リポジトリへのコミット方法）。スキル vs MCP vs Hooks の使い分け判断フロー付き：コードで規則を強制する→Hook、ドメイン固有ロジックや補助ファイルが必要→Skill、外部データ・ツール連携→MCP。
