## 要約
CLAUDE.mdの役割・書き方・アンチパターンを解説した日本語記事（Fyve社）。「書きすぎが逆効果」という実践知見が核心。

主な内容:
- **トークン上限の実態**：フロンティアモデルが確実に従える指示は150〜200行が上限。Claude Codeのシステムプロンプトが既に約50命令消費しているため残量に注意
- **HTMLコメント活用**：`<!-- ノート -->` 形式のコメントはコンテキスト到達前にストリップされ、トークン消費ゼロのメモ空間として活用可能
- **推奨構成5要素**：プロジェクト概要・技術スタック（バージョン含む）・命名規則/ファイル構造・テスト方針・AI挙動制御
- **2026年ベストプラクティス**：CLAUDE.md単体ではなく `rules/ + Memory + Skills + Hooks` の多層構造として設計する
- **テンプレート5選**を収録（プロジェクト別テンプレート）

コードのようにバージョン管理し、PRでレビューし、肥大化したら積極的に削る「メンテナンス重視」の設計思想を提唱。
