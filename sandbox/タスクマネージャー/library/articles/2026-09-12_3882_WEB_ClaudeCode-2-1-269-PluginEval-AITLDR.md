Claude Code v2.1.269 (September 11, 2026) ships 98 CLI changes. Headline: `claude plugin eval` — run a plugin's eval suite against Claude Code and get scored, reproducible results (JSON + HTML report). Improved managed MCP servers sign-in, faster session resume, better workflow views, and numerous reliability, terminal, prompt-cache, and session fixes.
