## 投稿内容
Technical reference for changes in the MCP 2026-07-28 specification. New features: stateless core, MCP Apps (sandboxed HTML-based user interfaces), Tasks extension, W3C Trace Context propagation for OpenTelemetry, JSON Schema 2020-12 full support, cache-control hints (ttlMs and cacheScope). Breaking changes: removal of session management APIs, deprecation of legacy auth flows, stricter parameter validation via JSON Schema. Linux Foundation governance migration also reflected.
