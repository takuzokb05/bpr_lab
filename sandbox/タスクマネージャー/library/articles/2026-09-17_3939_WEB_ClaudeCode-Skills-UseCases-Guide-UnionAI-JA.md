## 要約
株式会社UnionAIによるClaude Code Skills解説記事（日本語）。概念説明から実務活用分類まで。

**Skillsの基本構造**: SKILL.md + 任意のスクリプト・アセットから構成されるフォルダベースの指示パック。`/skill-name` でClaude Codeが専門家として振る舞う。

**用途別カテゴリ**:
- **コード品質**: コードレビュー（PR差分+ガイドライン参照）、テスト生成（カバレッジ基準適用）
- **ドキュメント**: PR説明自動生成、API仕様生成（OpenAPI準拠）
- **開発フロー**: デプロイ手順実行、リリースノート作成
- **プロジェクト固有**: ドメイン知識（業務用語辞書）、チーム規約適用

**実装例**: `/review`スキルがリポジトリのコーディングガイドラインを参照しながら自動チェックリストを生成。10時間かかっていたタスクを30分に短縮できると報告。

**コミュニティリソース**: gstack（Garry Tan作、113K GitHub stars）が23スキル+8パワーツール+4バイナリを提供する代表的公開スキルパック。

**Skillsのメリット**: バージョン管理可能・チーム共有可能・特定タスクに集中した小さな指示で高精度。チーム全員が同じ品質基準でClaude Codeを使える。
