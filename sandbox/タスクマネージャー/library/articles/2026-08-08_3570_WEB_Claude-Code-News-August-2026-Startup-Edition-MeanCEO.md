## 投稿内容
Claude Code adds Claude Opus 5 as the default Opus model, expands dynamic workflows and nested subagents, and improves MCP, sandbox, model picker, and remote control behavior. Public beta self-hosted environments now available for Team and Enterprise plans. Enterprise inference hooks (DLP enforcement) in beta. Gateway spend-limit support, workspace trust prompts for `claude agents`, and Remote Control message starts by name added.
