## 要約

QiitaのClaude Codeスキルアイデアカタログ記事。実装・チーム展開の両視点でスキル設計を解説。

### スキル設計の基本ルール（公式ガイドライン準拠）
- SKILL.mdファイルは500行以内
- 参照ファイルは1階層下まで
- トリガー設計: キーワードマッチ vs 明示呼び出しの使い分け
- `CLAUDE_CODE_NEW_INIT=1`環境変数でインタラクティブなスキル初期設定フロー

### 代表的スキルアイデア20選（カテゴリ別）

**開発効率化系**
1. コードレビュー（チーム規約チェック自動化）
2. テスト自動生成（`/generate-test UserService`形式）
3. PR説明文生成（diff→説明文の自動変換）
4. デプロイスキル（環境別フロー自動化）

**品質管理系**
5. セキュリティレビュー
6. パフォーマンスプロファイリング
7. 依存関係監査
8. アクセシビリティチェック

**ドキュメント系**
9. APIドキュメント生成
10. CHANGELOG自動生成
11. CLAUDE.md自動更新（AIが使用してアップデート）
12. README更新

**情報収集系**（本リポジトリに特に関連）
13. 日次情報収集スキル
14. ダイジェスト生成スキル
15. drop処理スキル

繰り返し手順のスキル化により、チーム全体の工数削減と品質均質化が実現できる。スキルはコードレビューのようにバージョン管理し、段階的に育てることが推奨されている。
