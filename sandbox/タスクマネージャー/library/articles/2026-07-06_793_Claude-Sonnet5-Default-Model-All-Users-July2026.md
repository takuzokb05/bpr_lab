## 投稿内容
Anthropic が2026年7月1日より Claude Sonnet 5 を Free・Pro ユーザーのデフォルトモデルに設定した経緯と影響。Sonnet 5 は 1M トークンのネイティブコンテキストウィンドウを持ち、長文タスク・エージェント型作業に最適化。プロモーション価格は $2/$10 per Mtok（8月31日まで）。Claude Code では v2.1.197 以降でデフォルト使用可能。旧 Sonnet 4.6 は引き続きAPI経由で利用可能。Max/Team/Enterpriseユーザーもデフォルト変更。
