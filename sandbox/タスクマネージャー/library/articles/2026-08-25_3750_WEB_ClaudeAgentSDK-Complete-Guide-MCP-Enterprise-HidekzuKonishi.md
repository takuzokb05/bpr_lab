## 要約
Claude Agent SDK（旧Claude Code SDK、2025年9月に改名）の包括的ガイド。主要内容：(1) SDKはClaude Codeを動かすのと同じハーネスを開発者向けに公開—ファイル読み書き・シェルコマンド・Web検索・コード編集・MCPサーバー呼び出しが可能。(2) MCP統合—1000以上の公開コミュニティMCPサーバーに接続可能、命名規則はmcp__servername__toolname。(3) エンタープライズ展開—一元認証・監査証跡・ガバナンスコントロールが本番環境で必要。(4) Managed Agents—anthropic-managed-agentsパッケージによりサーバーホスト型エージェントを構築可能、allowed_domains等でセキュリティ制御。(5) ビルトインのツールループ・コンテキスト管理・リトライハンドリングを提供。ドキュメントは2026年6月時点で最新。
