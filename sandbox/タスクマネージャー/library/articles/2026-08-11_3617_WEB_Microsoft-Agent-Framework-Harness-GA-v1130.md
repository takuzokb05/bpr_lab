# Microsoft Agent Framework Harness GA: v1.13.0 Foundry, Durable Tasks

## 要約
MicrosoftがAgent Framework Harness v1.13.0をGA（一般提供）リリース（2026年8月）。AutoGenとSemantic Kernelのマージにより生まれたフレームワーク。v1.13.0の主要追加：豊富なFoundryホスティング・Responsesサポート、再利用可能なセッションストア、拡張されたテレメトリ・オブザーバビリティ（OpenTelemetry統合）、ワークフローリプレイ・承認機能。.NET・PythonでDurable TaskとAzure Functions統合変更。BUILD 2026での発表内容（Agent Harness, Hosted Agents, CodeAct）が正式リリースに。2026年主要エージェントフレームワーク：LangGraph 1.0、Claude Agent SDK、CrewAI 1.14、Microsoft Agent Framework 1.0、LlamaIndex Workflows 1.0、Pydantic AI V2。
