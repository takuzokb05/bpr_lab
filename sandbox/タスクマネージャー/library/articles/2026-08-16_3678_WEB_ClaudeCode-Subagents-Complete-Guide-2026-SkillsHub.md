## 投稿内容
Comprehensive guide to Claude Code subagents as of August 2026. Covers August 2026 features: built-in subagent types, nested subagents (up to depth 5), Dynamic Workflows for parallel deployment of tens to hundreds of subagents, and the Performance Outcomes Grader that re-submits results until meeting a rubric. Details the isolation model: parent sees only final summary, keeping main transcript clean for orchestration.

2026年8月時点のClaude Code サブエージェント完全ガイド。August 2026の新機能：組み込みサブエージェントタイプ搭載・ネストサブエージェント（深さ5）・Dynamic Workflowsで数十〜数百の並列展開・Performance Outcomes Graderによる自動品質再チェック。実践推奨：3〜5並列が大半のタスクで最適で、10超えると統合オーバーヘッドが効率化を上回る。メインセッションは各サブエージェントの最終サマリーのみ受け取るため、オーケストレーションが清潔に保たれる。fork型（既存コンテキスト継承）vs 新規型の使い分け判断フローも解説。
