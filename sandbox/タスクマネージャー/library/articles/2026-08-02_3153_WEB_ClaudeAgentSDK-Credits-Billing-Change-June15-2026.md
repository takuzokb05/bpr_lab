## 投稿内容
2026年6月15日施行のClaude Agent SDK（旧Claude Code SDK）料金体系変更を解説。サブスクリプションプランでの非インタラクティブ実行がインタラクティブ制限とは別の月次クレジットから消費される仕組みの詳細。

## 要約
Claude Agent SDKの課金体系変更（2026/6/15施行）の完全解説。背景: 2026年初頭にClaude Code SDKをClaude Agent SDKに改名（コード以上のエージェント構築の野心を反映）。変更内容: サブスクリプションプランでのAgent SDK利用・非インタラクティブ実行は、インタラクティブ会話制限とは別の月次Agent SDKクレジットプールから消費。プラン別クレジット: Pro $20/月、Max 5x $100/月、Max 20x $200/月。影響を受ける実行: `claude -p` フラグでの非インタラクティブ起動、CI/CDパイプライン内でのスクリプト実行、バックグラウンドエージェント、Managed Agents経由のタスク。影響を受けない実行: API直接呼び出し（引き続きトークン単価課金）、インタラクティブなターミナルセッション。対策推奨: CI/CDでの実行頻度を計測→月次クレジット消費量の試算→超過リスクのあるジョブはAPI直接呼び出しに切り替え。スケジュールされた自動実行タスク（日次収集ルーチン等）は特にクレジット消費量の事前確認が必要。
