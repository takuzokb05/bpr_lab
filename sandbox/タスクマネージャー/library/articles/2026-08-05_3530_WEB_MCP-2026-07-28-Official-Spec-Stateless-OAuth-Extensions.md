## 要約
Model Context Protocol公式ブログによる2026-07-28仕様の最終リリース発表。2026年5月21日にRC確定後、7月28日に最終版として出荷。MCPローンチ以来最大の仕様改訂。主要変更7点：①ステートレスプロトコルコア（通常HTTPインフラで動作・スティッキーセッション不要・ラウンドロビンLB対応）、②Multi Round-Trip Requests、③ヘッダーベースルーティング、④キャッシュ可能なlistレスポンス、⑤認証強化（OAuth 2.1/OIDC準拠・WIF対応）、⑥正式な拡張フレームワーク（MCP Apps：サーバーレンダリングUI、Tasks：長時間非同期処理）、⑦Tier 1 SDK更新（Python・TypeScript・Go・Rust・C#）。非推奨化：Roots・Sampling・Logging機能（次期仕様v2026-11-05で削除予定）。Anthropic Claude・OpenAI・Google Gemini等主要クライアントが採用予定。
