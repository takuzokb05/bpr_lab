## 要約
Anthropic公式ブログ。Claude Code v2.1.224（2026-08-07リリース）でself-hosted environments（自己ホスト環境）がパブリックベータとして追加された。`claude self-hosted-runner`コマンドで自社マシンやコンテナをClaude Codeセッションの実行基盤として使用可能。Team・Enterpriseプランが対象。Fixed（常時起動）とOn-demand（セッション到着時に起動・終了）の2モードを提供。自社インフラ内のネットワークアクセス、カスタムツール、コンプライアンス要件に対応。WebセッションやモバイルアプリからもOK。企業データ主権を確保しながらAIエージェント活用が可能になる重要マイルストーン。
