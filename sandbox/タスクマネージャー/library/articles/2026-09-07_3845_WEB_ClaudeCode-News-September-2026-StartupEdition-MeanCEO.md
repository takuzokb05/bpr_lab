## 投稿内容
Claude Code News September 2026 (Startup Edition) — curated monthly digest of Claude Code updates from a startup perspective. Covers Claude Code v2.1.261 as latest release (September 4), new diff panel for side-by-side review, Claude Fable 5.1 as default model with expanded context, new bashOutputMaxChars/taskOutputMaxChars settings (up to 128K), improved VS Code workflows, Remote Control enhancements, startup reliability improvements, and numerous bug fixes across authentication, session handling, and tool functionality.

## 要約
スタートアップ向けClaude Codeニュースレターの2026年9月号。最新v2.1.261（9月4日時点）を中心に月次アップデートをキュレーション。主要変更点: ①変更をリアルタイムで並列表示するdiff panel追加（v2.1.260）、②Claude Fable 5.1がデフォルトモデルに（v2.1.257〜）、③bashOutputMaxCharsとtaskOutputMaxCharsをそれぞれ最大128Kに設定可能、④サブエージェントシステムプロンプトをファイルから読み込む--append-subagent-system-prompt-file追加。バグ修正: バックグラウンドエージェント再開失敗時のCPU高負荷ループ修正・Bedrockでの認証ヘッダー二重送信修正など。公式Anthropicリリースノートをサードパーティ視点でまとめた月次キュレーションとして有用。
