## 要約
Claude Agent SDK（旧Claude Code SDK、2025年9月改名）のModal・Trigger.devへのサーバーレス展開ガイド。SDKの核心機能：Bash実行・ファイルシステム操作・Web検索等のツール統合と、複数ターンの推論ループ（計画→実行→観察→継続）。「コードでエージェントを駆動したい・ツールを渡したい・構造化された結果を得たい」ケースに最適。Python・TypeScript対応、MCPサポート、セッション管理、ホスト型実行モデル。実装パターン：プログラマティックに会話を制御し、ツール定義を渡し、構造化出力を取得。search demand：2025年5月の月間50件→2026年4月の14,800件に急増（296倍）。本番エージェントを無人実行させるための実践ガイド。
