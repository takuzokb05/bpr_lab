## 要約
2026年最新版のClaude Code Hooksガイド（株式会社Uravation）。PreToolUse/PostToolUseなどの12種類以上のフックイベントを使ってコード品質ゲート・セキュリティチェック・自動フォーマットを設定する方法を詳解。フックはCLAUDE.mdやSkillsと異なり「絶対に実行される」保証があり、CI的なガードレールとして機能する。settings.jsonへの書き方・シェルスクリプト連携・環境変数受け渡しまで実践的な設定手順を網羅。Claude Code 2026年版の新フックイベント（SessionStart/SessionEnd等）にも対応。
