## 投稿内容

2026年8月19日、AnthropicはAIエージェント基盤の4機能を同日にGA（正式版）移行。これは年内最大規模のプラットフォームアップデートと評価されている。

**GA移行の4機能:**
1. **Computer Use** — `computer_toolset_20260801` として提供。AIがデスクトップ画面を直接操作可能。
2. **Browser Use Tool** — Webブラウジング・フォーム入力・コンテンツ抽出をAPI経由で実行。
3. **Files API** — ファイルのアップロード・管理・共有をClaude APIで直接処理。
4. **Agent Skills API** — Managed Agentsへのスキル定義・管理をAPI経由で実施。

全ての機能がエンタープライズグレードのSLA・セキュリティ基準でプロダクション利用可能に。

## 要約

2026年8月19日は、AnthropicのAIエージェント基盤が一斉に成熟を迎えた日として位置づけられる。Computer Use・Browser Use・Files API・Agent Skills APIの4機能が同日にGA移行。

- **Computer Use** (`computer_toolset_20260801`): デスクトップ画面の直接操作。ベータ期間中のフィードバックを基に安定性・精度が大幅向上。企業内RPA代替から複合エージェントの目・手として機能する。
- **Browser Use**: Webブラウジング専用ツール。APIの`allowed_domains`/`blocked_domains`設定でアクセス範囲を制御可能（同日発表のManaged Agents機能強化と連携）。
- **Files API**: マルチターン会話でのファイル参照やエージェントへのデータ注入が標準化。
- **Agent Skills API**: `claude agent skills`コマンドと対応するAPIエンドポイントが安定版に。

この同日GA移行により、「Managed Agent + Skills + Computer/Browser Use + Files」を組み合わせたフルスタックの自律エージェントが、エンタープライズのプロダクション環境で正式に構築可能になった。Anthropicのプラットフォームとしての完成度を示す重要マイルストーン。
