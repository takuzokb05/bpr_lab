## 投稿内容

Cline released Kanban, a free, open-source local web app that runs multiple CLI agents in parallel on your git repo.

Each task card gets its own terminal and isolated worktree, so agents never conflict. 

Works with Claude Code, Codex, and Cline CLI right now, with more agents coming soon.
