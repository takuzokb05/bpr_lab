# /digest — HTMLダイジェスト生成スキル

## 概要

`library/articles/` の記事群を横断分析し、ドメイン別ハイライト・注目記事・アクション提案を
**単一HTMLファイル**として `library/digests/` に出力する。

## 入力

- 期間指定（デフォルト: 直近7日間）
  - `/digest` → 直近7日
  - `/digest 3` → 直近3日
  - `/digest 2026-03-24 2026-03-29` → 範囲指定

## 出力

`library/digests/YYYY-MM-DD_digest.html`（単一ファイル、外部依存ゼロ）

## 処理フロー

### Step 1: 対象記事の収集

1. `library/articles/` から対象期間の `.md` ファイルを Glob で収集
2. 各ファイルのメタデータ（テーマ、言語、いいね数等）と投稿内容を読み込む
3. ドメイン別に分類・集計

### Step 2: ユーザーコンテキストの読み込み

`library/alter-ego.md` を Read して、ユーザーの:
- 関心領域（FX自動取引、公務員DX、Claude Code運用）
- 意思決定スタイル（即断即決、小さく試す）
- 現在進行中のプロジェクト

を把握する。これを元に「注目記事」と「アクション提案」をパーソナライズする。

### Step 3: ドメイン別分析

各ドメインについて:
1. **件数と傾向** — 何件あったか、どのテーマが多かったか
2. **注目記事3〜5選** — faves・技術的重要度・ユーザーとの関連度で選定
3. **1行サマリー** — 各注目記事の「何が重要か」「ユーザーに何が使えるか」

### Step 4: 横断分析

ドメインをまたいだパターン:
- 複数ドメインで同時に言及されたツール・概念
- 前週と比較したトレンドの変化（過去のdigestがあれば）
- 「発見パターン」（catalog.mdの発見パターンに該当するもの）

### Step 5: アクション提案

alter-ego.md のコンテキストを踏まえて、**具体的な次のアクション**を3〜5件提案:
- 「設定ファイルに○○を追加する」レベルの具体性
- 各アクションに根拠となる記事をリンク
- 優先度（高/中/低）付き

### Step 6: HTML生成

以下の構成で単一HTMLを生成する。

---

## HTML構成

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>Weekly Digest YYYY-MM-DD</title>
  <style>/* 全スタイルをインライン */</style>
</head>
<body>
  <!-- ヘッダー: 期間・件数サマリー -->
  <!-- タブUI: 4ドメイン切り替え -->
  <!-- 注目記事セクション -->
  <!-- ドメイン別詳細 -->
  <!-- 横断分析 -->
  <!-- アクション提案 -->
</body>
</html>
```

### デザイン要件

- **単一ファイル**: CSS/JSすべてインライン。外部依存ゼロ
- **タブUI**: 4ドメイン（Claude Code / Ecosystem / Trading / News）をタブで切り替え。純粋なCSS + 最小JSで実装
- **配色**: ダークモード対応。ドメインごとに色分け:
  - Claude Code: 青系 (#3B82F6)
  - Ecosystem: 緑系 (#10B981)
  - Trading: オレンジ系 (#F59E0B)
  - News: 紫系 (#8B5CF6)
- **カード型レイアウト**: 各記事はカードで表示。タイトル・1行サマリー・メタ情報（faves, 投稿者, 言語）
- **レスポンシブ**: PC/タブレットで見やすいグリッド。モバイルはスタック
- **フォント**: system-ui（依存ゼロ維持）
- **AI臭の排除**: グラデーション背景・絵文字乱用・過剰なアニメーション禁止。クリーンで情報密度の高いデザイン

### セクション詳細

#### 1. ヘッダー
```
Weekly Digest 2026-03-24 〜 2026-03-29
収集 N件 → ハイライト N件 → アクション N件
```

#### 2. 注目ピックアップ（全ドメイン横断、3〜5件）
ユーザーへの影響度が最も高い記事をカードで大きく表示。
各カードに「なぜこれが重要か」の1〜2行コメント付き。

#### 3. ドメイン別タブ
各タブ内:
- 件数バー（SIGNAL数 / 全収集数）
- トレンドキーワード（頻出語3〜5個）
- 記事カード一覧（faves降順、最大20件）

#### 4. 横断分析
- 今週のキーワードクラウド（テキストベース、画像不要）
- ドメイン間の接続（例: 「MCP」がClaude CodeとEcosystem両方で言及）

#### 5. アクション提案
チェックリスト形式:
```
□ [高] Hooks if条件をsettings.jsonに追加する（根拠: #094, #184）
□ [中] TradingAgentsのdebate機構をFXシステムに検討（根拠: #036, #038）
□ [低] Figma MCP → スライド生成ワークフロー試行（根拠: #099）
```

---

## Gotchas

- 記事数が0件の期間を指定された場合は「対象記事なし」を表示して終了
- alter-ego.md が存在しない場合はパーソナライズなしの汎用ダイジェストを生成
- HTMLは5000行以内に収める。記事が多すぎる場合は上位件数で打ち切り
- 記事のURLはHTMLリンクとして埋め込む（クリックで元記事に飛べる）
- `## 要約` が「次回追記」のままの記事は、投稿内容から要約を自動生成してダイジェストに含める
- 日本語中心で出力。英語記事も日本語で要約
