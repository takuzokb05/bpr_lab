会話履歴を分析し、CLAUDE.mdに追記すべきルール・知見・禁止パターンを提案する。セッション終了前に実行。

## タスク

この会話の内容を分析し、CLAUDE.md に追記すべきルール・知見・禁止パターンがないか提案してください。

## 分析の観点

以下を探してください:

1. **繰り返された修正指示** — 同じ指摘を2回以上していたらルール化候補
2. **プロジェクト固有の判断** — このプロジェクトでしか通用しない暗黙のルール
3. **新しいワークフロー** — 定着しそうな手順が生まれていたら WORKFLOWS に追加
4. **禁止パターン** — 「やるな」と言われたこと、失敗から学んだこと
5. **分類タグの新設** — catalog.md の既存タグに収まらないテーマ
6. **品質基準の更新** — 既存の品質基準に追加・修正すべき項目

## 分析対象外（無視してよい）

- 一般的なプログラミング知識（言語仕様、ライブラリの使い方など）
- 一度きりの作業手順で再利用性がないもの
- 既に CLAUDE.md に書かれていること

## 出力フォーマット

提案がある場合:

```
### 提案 1: [タイトル]

**追記先**: CLAUDE.md の [セクション名] / docs/[ファイル名]
**内容**:
> [具体的な追記テキスト]

**理由**: [なぜこれをルール化すべきか — 会話中の具体的な箇所を引用]
```

提案がない場合:

```
この会話から CLAUDE.md に追記すべき新しい知見は見つかりませんでした。
```

## 注意

- 提案は具体的に。「〜に注意する」ではなく「〜の場合は〜する」の形式で
- 既存のルールと重複・矛盾しないか確認してから提案する
- 提案数は多くても3つまでに絞る（本当に重要なものだけ）
- docs/ 配下のファイルへの追記も提案可（agent-governance.md, known-pitfalls.md 等）
