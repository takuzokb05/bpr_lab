会話履歴を分析し、alter-ego.md（人物プロファイル）に追記すべき新しいパターンを抽出する。セッション終了前に実行。

## 事前準備

**まず `alter-ego.md` を読んでください。** 既存プロファイルの内容を把握してから分析に入ること。既に記載済みのパターンと重複する提案は不要。

## タスク

`alter-ego.md` の既存内容を踏まえた上で、この会話に現れた**新しい**パターンだけを抽出してください。

## 分析の観点

以下の5軸で、この会話に現れたユーザーの特徴を探してください:

### 1. 意思決定パターン
- 何にYes/Noと言ったか
- どこで方向修正したか
- 即断したこと vs 慎重になったこと
- 優先順位の判断基準（スピード、品質、コスト、シンプルさ等）

### 2. コミュニケーションスタイル
- 口癖・表現パターン（「〜かな」「面白いけど」「まあいいか」等）
- 指示の出し方（具体的 vs 方向性だけ）
- フィードバックの仕方（直接的 vs 婉曲）

### 3. 価値観・信念
- 何を大事にしているか
- 何に怒る/何を許容するか
- 仕事観・チーム観

### 4. 得意/不得意の自己認識
- 何を自分でやり、何をAIに任せたか
- どこで自信を見せ、どこで不安を見せたか

### 5. リスク許容度
- 新しいことへの反応（即試す / 調べてから / 慎重）
- 失敗への態度

## 分析対象外

- AIの発言・提案内容（ユーザーの反応のみが対象）
- 技術的な知識レベルの評価（DIAアセスメントが別途ある）

## 出力フォーマット

```
## 今回の会話で見つかったパターン

### [軸名]: [発見したパターン]
**根拠**: [会話中の具体的なやりとりを引用]
**既存プロファイルとの関係**: 新規 / 補強 / 変化（以前は〜だったが今は〜）

---
（繰り返し）
```

発見がない軸は省略してOK。無理に全軸埋めなくてよい。
本当に特徴的なパターンだけを3〜5個に絞ること。
