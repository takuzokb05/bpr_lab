## 2. YobCon（空家予防コンシェル）

### 2.1 サービス概要

| 項目 | 内容 |
|------|------|
| **正式名称** | YobCon 空家予防コンシェル |
| **提供開始日** | 2026年2月13日（令和8年2月13日） |
| **運営** | 横浜市 × SocioFuture株式会社（連携協定） |
| **プラットフォーム** | LINE公式アカウント（@701bkpor） |
| **利用料** | 無料 |
| **対象者** | 主に実家を相続予定の子世代 |
| **政令市初** | 生成AI活用の空き家予防サービスとして政令市初 |

### 2.2 提供機能（3つ）

1. **実家の空家化リスク診断** -- 質問回答によるスコアリングとリスク度合いの判定、対策提示
2. **実家の相続TODOナビ** -- 状況選択で相続・家財整理・不動産手続きを段階的に提案
3. **空家予防AIチャット診断** -- 項目選択や自由入力で専門的相談が可能（24時間対応）

### 2.3 導入背景

- 横浜市は高齢者のみ世帯の増加に伴い、2025年以降の空家急増を懸念
- 相続時の登記負担や解体費用が原因で、子世代が空家化リスクを認識できていない課題
- SocioFutureの生成AI活用提案がプロジェクト始動のきっかけ
- ソース: [SocioFuture 横浜市導入事例](https://www.scft.co.jp/service/case/yokohama_city)

### 2.4 利用実績

**データなし**。2026年2月13日に実証実験を開始したばかりであり、利用者数・友だち登録数・相談件数等の統計データは2026年3月3日時点で未公開。

- ソース: [空家の課題解決につながる2つの新サービスを開始します](https://www.city.yokohama.lg.jp/city-info/koho-kocho/press/kenchiku/2025/0213akiya.html)
- ソース: [横浜市、生成AIで空き家予防サービス - 日経](https://www.nikkei.com/article/DGXZQOCC165D90W6A210C2000000/)

### 2.5 今後の展望

- 段階的アプローチで住宅ストックの好循環を目指す
- 不動産・金融業界への展開を視野に入れている

- 会場: 横浜市開港記念会館講堂

## 4. 脱炭素リノベ住宅推進補助

### 4.1 令和7年度の制度概要

| 項目 | 内容 |
|------|------|
| **制度名** | 脱炭素リノベ住宅推進補助制度 |
| **補助額（子育て世代住替え）** | 最大150万円 |
| **補助額（定住）** | 最大120万円 |
| **申請受付期間** | 令和7年7月1日 〜 令和8年1月31日 |
| **申請状況** | **受付終了**（令和8年1月31日締切） |
| **対象** | 既存住宅の断熱改修（等級6または7） |

### 4.2 主な要件

- 断熱材使用工事を実施し、断熱等性能等級6または7を達成
- 再生可能エネルギー設備（太陽光3kW以上または太陽熱利用）を備える
- 一定の耐震基準を満たす
- 申請者は「よこはま健康・省エネ住宅事業者登録制度」登録事業者に限定

### 4.3 併用可能な制度

- 先進的窓リノベ2025事業
- 給湯省エネ2025事業
- 耐震改修補助
- **併用時の合計最大**: 約496万円

### 4.4 実績

**データなし**。令和7年度の申請件数・交付件数は2026年3月3日時点で未公開。受付終了済みのため、今後実績が公表される可能性がある。

### 4.5 令和8年度の見通し

令和8年度（2026年度）も継続実施される見込みだが、制度詳細は未公表。

- ソース: [令和7年度脱炭素リノベ住宅推進補助制度 横浜市](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/shoene/event/r7daturansorinbehojo.html)
