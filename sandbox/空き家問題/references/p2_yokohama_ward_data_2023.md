## 4. 分析ポイント

### 4-1. 空き家が増加した区（要注意）

1. **港南区**: +2,200戸（+26.13%）、空き家率も+1.41pp上昇。最も悪化した区。
2. **南区**: +860戸（+7.12%）。元々高い空き家率がさらに上昇。
3. **緑区**: +700戸（+10.84%）。空き家率も微増。
4. **栄区**: +540戸（+11.39%）。空き家率も微増。
5. **旭区**: +550戸（+5.20%）。空き家率微増。

### 4-2. 空き家が大幅に減少した区

1. **港北区**: -6,590戸（-35.34%）、空き家率-3.87pp。最も大きく改善。新築マンション建設・中古流通活性化が要因か。
2. **青葉区**: -2,490戸（-22.02%）、空き家率-1.93pp。
3. **泉区**: -1,920戸（-41.47%）、空き家率-2.99pp。最大の減少率。
4. **鶴見区**: -1,530戸（-9.40%）。

## 情報の信頼性評価

- **一次ソース（公式統計）**: 2件 — 横浜市統計書（第16表・第23表）、総務省住宅・土地統計調査
- **データの精度**: 住宅・土地統計調査は標本調査（全数調査ではない）のため、100戸単位に丸められた概数。各区の合計と横浜市計は必ずしも一致しない（四捨五入による差）。
- **注意事項**: e-Stat上の「構造等集計」（2025年1月29日公表）ではさらに詳細な建て方・構造別データが利用可能だが、本調査では横浜市統計書の基本集計データを使用。
