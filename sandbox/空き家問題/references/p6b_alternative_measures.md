調査日: 2026-03-03

## 1. カシニワ制度（柏市）

### 1.1 制度概要

| 項目 | 内容 |
|------|------|
| **正式名称** | カシニワ制度 |
| **意味** | 「かしわ（柏）の庭」＋「かす（貸す）庭」の造語 |
| **創設年** | 2010年度 |
| **自治体** | 千葉県柏市（人口約43万人） |
| **所管** | 柏市都市部公園緑政課 |
| **目的** | 空き地を地域の人々が手を加え「地域の庭」として活用し、柏の緑を守る・増やす |

### 1.2 3つの活動形態

1. **地域の庭** -- 空き地を借りて花壇や菜園を市民が整備
2. **里山** -- 樹林地を借りて整備・管理
3. **オープンガーデン** -- 個人所有の庭を一般に公開

### 1.3 実績（15年間の累計）

| 指標 | 数値 |
|------|------|
| **土地登録数** | 延べ124件 |
| **合計面積** | 約41ヘクタール |
| **オープンガーデン登録** | 延べ89件 |
| **現在活動中（地域の庭・里山）** | 55カ所 |
| **現在活動中（オープンガーデン）** | 66件 |

- ソース: [空き地で市民が花壇や菜園づくり、柏市「カシニワ制度」の15年 - 日経BP](https://project.nikkeibp.co.jp/atclppp/PPP/434167/061700300/)
- ソース: [カシニワ制度について - 国交省資料](https://www.mlit.go.jp/common/001216492.pdf)

### 1.4 カシニワ・フェスタ

- 毎年5月上旬開催（例: 2024年は5月8日〜12日）
- 60〜67カ所以上のカシニワが一斉公開
- 多い年で期間中約1万人が来場

### 1.5 参加者の特性

- 中心は70代
- 里山は男性が多い傾向
- オープンガーデンは女性が多い傾向
- 農園型は男性が多め

### 1.6 「カシニワ・おうち」制度（2021年度追加）

- 2021年度に空き家・空き店舗活用を促進する「カシニワ・おうち」情報バンクを追加
- 空き家活用補助制度: 上限300万円（対象経費の1/2）
- 地域の通いの場の整備にも使われている
- 柏市の空き家実態調査（2022年度）: 空き家総数1,739件、うち特定空き家候補372件（21.4%）
- ソース: [空き家活用補助制度 - 柏市](https://www.city.kashiwa.lg.jp/jukankyo/living_environment/jutaku/1576.html)

### 1.7 横浜市への適用可能性の評価

**空き家の「庭」だけの活用事例**: カシニワ制度は空き地（更地）を対象としており、空き家の「庭部分のみ」を活用した事例は検索結果では確認できなかった。ただし、制度の枠組みは空き家敷地内の庭への適用も理論上可能。

## 2. シェア畑の横浜市内展開状況

### 2.1 展開規模

- **横浜市内のシェア畑**: 約16農園（2022年1月時点）
- **主な農園**: 新横浜、横浜鶴見、横浜十日市場、横浜高田など
- **運営**: 株式会社アグリメディア

### 2.2 サービス内容

- 種・苗、肥料、農具、水道完備
- 経験豊富なアドバイザーが常駐
- 初心者でも手軽に開始可能

### 2.3 土地活用（遊休地の貸出）

- 農地・遊休地・生産緑地を貸し出すことで安定した賃料収入を得られる「まるごとお任せプラン」あり
- 空き家の敷地（庭部分）をシェア畑化する直接的な事例は確認できず

- ソース: [シェア畑 横浜市一覧](https://www.sharebatake.com/farms/kanagawa/yokohama)

## 3. 定期借家 × 子育て世代の活用事例

### 3.1 JTI マイホーム借上げ制度

| 項目 | 内容 |
|------|------|
| **運営** | 一般社団法人 移住・住みかえ支援機構（JTI） |
| **対象** | 原則50歳以上の住宅所有者 |
| **方式** | 定期借家契約で借上げ、賃貸住宅として転貸 |
| **期間** | 最長で終身 |
| **メリット** | 入居者の居座り・立ち退き料なし。定期借家終了後にマイホームに戻れる |
| **家賃保証** | 空室時も一定賃料を保証（1人目入居後） |

**利用実績**: 具体的な利用件数データはWeb検索で取得できなかった。

- ソース: [マイホーム借上げ制度のあらまし - JTI](https://jti.or.jp/lease)

### 3.2 自治体による空き家借り上げ事例

**沖縄県国頭村**: 空き家を改修して移住者向け賃貸住宅として活用。村が改修工事を実施し、地域の担い手となる移住者に月額33,000円で貸出。
- ソース: [空き家活用の成功事例15選 - ジチタイワークス](https://jichitai.works/articles/3296)

### 3.3 空き家リフォーム・改修補助の対象者整理

**注意**: 空き家バンク関連の補助制度は「所有者（貸主）」「購入者（買主）」が主対象であり、「借主（賃借人）」が直接対象となる制度は少数派である。以下では対象者を正確に区分する。

#### (A) 所有者・購入者が主対象の制度

| 自治体 | 制度内容 | 補助上限 | 対象者 |
|--------|---------|---------|--------|
| **飛騨市** | 空き家を賃貸住宅として登録するための改修費補助 | 最大250万円 | **所有者（貸主）のみ** |
| **愛知県日進市** | 子育て世帯が市外から空家を購入する際の登記・引越し費用補助 | 上限30万円 | **購入者（買主）のみ**（賃貸は対象外） |
| **栃木市** | 空き家バンク物件のリフォーム補助 | 最大50万円 + 家財処分10万円 | **所有者・購入者**（公式サイト本文。補助ガイドPDFでは賃借人も対象との記述あり、要確認） |

- ソース: [飛騨市公式 令和7年度空き家等賃貸住宅改修事業補助金](https://www.city.hida.gifu.jp/soshiki/9/52612.html) — 公式
- ソース: [日進市公式 空家バンク子育て世帯定住促進補助金](https://www.city.nisshin.lg.jp/department/toshisangyo/toshi/7/3/2/2/5330.html) — 公式
- ソース: [栃木市空き家バンク 補助金について](https://www.tochigi-akiya.jp/subsidy/) — 公式

#### (B) 借主（賃借人）が直接対象となる制度

| 自治体 | 制度名 | 補助内容 | 借主の条件 |
|--------|--------|---------|-----------|
| **大阪市** | 空家利活用改修補助（住宅再生型） | 耐震改修上限100万円 + 性能向上上限75万円 | 「賃借予定者」が対象に明記。2000年5月以前建築、3ヶ月以上空き家 |
| **兵庫県** | 空き家活用支援事業（住宅型・一般） | 工事費100万〜300万円で40〜90万円 | 賃借の場合も対象（10年以上の賃借期間、所有者同意が必要）。※UJIターン・若年子育て世帯タイプは所有が必須 |
| **佐倉市**（千葉） | 空き家バンク賃貸登録物件リフォーム補助 | 工事費の1/2（上限30万円） | 賃借した利用者も対象。賃貸契約から1年以内 |
| **岡山市** | 空家等適正管理支援事業（リフォーム） | 対象経費の1/3（上限50万円） | 所有者の承諾を得た賃借人。耐震・バリアフリー・省エネのいずれかを含む50万円以上の工事 |
| **長野市** | 移住者空き家改修等補助金 | 対象経費の2/3（首都圏40歳未満は3/4）、上限50〜100万円 | 県外からの移住者（賃借人を含む）。子育て世帯は1人20万円加算 |
| **三笠市**（北海道） | 若者移住定住促進家賃助成事業 | 家賃の1/2（月額上限2〜3万円、最長60ヶ月） | 転入した借主に直接家賃補助（商品券）。40歳未満または中学生以下の子がいる世帯 |

- ソース: [大阪市公式 空家利活用改修補助制度](https://www.city.osaka.lg.jp/toshiseibi/page/0000470652.html) — 公式
- ソース: [兵庫県公式 空き家活用支援事業](https://web.pref.hyogo.lg.jp/ks26/machi-saisei/sato-akiya/sato-akiya.html) — 公式
- ソース: [佐倉市公式 空き家バンク賃貸登録物件リフォーム補助](https://www.city.sakura.lg.jp/soshiki/jutakuka/103/3921.html) — 公式
- ソース: [岡山市公式 空家等適正管理支援事業（リフォーム）](https://www.city.okayama.jp/kurashi/0000006210.html) — 公式
- ソース: [長野市公式 移住者空き家改修等補助金](https://www.city.nagano.nagano.jp/n041600/iju/p006156.html) — 公式

#### (C) 横浜市への示唆

- 借主向け補助は**地方の移住促進**文脈で設けられているケースが多い（長野市・三笠市等）
- 大都市で借主を対象にしている事例は**大阪市**と**兵庫県**のみ。大阪市は耐震性確保が主目的、兵庫県は空き家の利活用促進が目的
- 横浜市で借主向け補助を導入する場合、大阪市モデル（耐震改修と連動）または兵庫県モデル（一般住宅型で賃借も可）が参考になる
- チャットログで笠羽氏が提案した「借り手側にリフォーム補助 + 最低居住年数 + 途中退去なら補助返還」は、長野市の移住者向け制度（居住義務あり）に類似

### 3.4 DIY型賃貸借

- 国土交通省が2016年4月に「DIY型賃貸借に関する契約書式例」と「DIY型賃貸借のすすめ」を公表
- 借主が自ら改修可能な賃貸契約。空き家活用の手段として推進
- 古民家再生などで事例が出ているが、まだ一般には浸透していないのが現状
- ソース: [DIY型賃貸借に関する契約書式例とガイドブック - 国交省](https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000046.html)

### 3.5 横浜市の借り上げ市営住宅制度

- 横浜市は民間の土地所有者等が建設した住宅を市営住宅として借上げる制度あり
- 市営住宅全体で約3万戸超
- 入居者は借上げ期間満了後、別の市営住宅へ転居
- **空き家を借り上げる制度ではない**（新築住宅の借上げが基本）
- ソース: [借上型市営住宅の紹介 横浜市](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/joho/kariage.html)

## 4. 空き家保有コスト見える化ツール

### 4.1 「すまいの終活ナビ」横浜市版

| 項目 | 内容 |
|------|------|
| **提供者** | 株式会社クラッソーネ × 横浜市（連携協定） |
| **採択** | 2021〜2023年度国土交通省空き家対策モデル事業 |
| **全国初** | 自治体版の導入は横浜市が全国初 |

**提供機能**:

1. **解体費用シミュレーション** -- 建物・ブロック塀・カーポートの解体費用を最短1分で概算
2. **土地査定価格の同時算出** -- 解体費用と並行して不動産価値を評価（手残りが分かる）
3. **固定資産税シミュレーター** -- 解体による税額変化の試算
4. **空き家迷惑度診断** -- 近隣への影響度を判定
5. **リスク確認ツール** -- 追加費用発生の可能性を診断
6. **家じまい相談窓口** -- 売却・活用・解体の無料相談

**保有コスト試算機能の有無**:
- **直接的な「年間保有コストシミュレーション」機能は確認できなかった**
- ただし、固定資産税シミュレーターにより税負担の変化は試算可能
- 「解体費用 vs 土地売却価格」の手残り計算で、保有し続けるコストと処分のメリットを比較可能
- 注: 「本査定価格は参考金額であり、売却価格、解体費用を保証するものではありません」と明示

- ソース: [すまいの終活ナビ 横浜市版 - クラッソーネ](https://www.crassone.jp/simulator/navi/kanagawa/yokohamashi)
- ソース: [住まいの終活 横浜市](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/sumaisyuukatsu.html)
- ソース: [自治体担当者インタビュー：横浜市 - クラッソーネ](https://www.crassone.co.jp/blog/16758/)

  - ソース: [AI査定で手軽に空家の解体概算額等が調べられます - 日高市](https://www.city.hidaka.lg.jp/soshiki/toshiseibi/toshikeikaku/keikakusuishinkigyoyuchijyuutakuseisaku/sumai/akiya/24649.html)

## 5. ふるさと納税 × 空き家管理

### 5.1 日本空き家サポートの展開状況

| 項目 | 内容 |
|------|------|
| **運営** | 日本空き家サポート |
| **モデル** | ふるさと納税返礼品として空き家管理サービスを提供 |
| **参加自治体** | **約36自治体**（2026年3月時点。公式サイト掲載ベース） |

### 5.2 参加自治体一覧（地域別）

| 地域 | 自治体 |
|------|--------|
| 北海道 | 美幌町、恵庭市 |
| 東北 | 横手市（秋田） |
| 関東 | 鹿嶋市（茨城）、日高市・吉川市（埼玉） |
| 中部 | 甲府市・韮崎市（山梨）、佐久市（長野）、富士宮市・伊東市（静岡）、岡崎市・一宮市・半田市（愛知）、伊勢市・名張市（三重） |
| 関西 | 福知山市（京都）、大東市（大阪） |
| 中国・四国 | 津山市（岡山）、廿日市市（広島）、山口市・下松市（山口）、阿波市（徳島）、丸亀市（香川） |
| 九州 | 大牟田市・那珂川市（福岡）、唐津市・伊万里市（佐賀）、熊本市・八代市（熊本）、霧島市（鹿児島） |

### 5.3 サービス内容

- 建物や庭木、雑草等を目視で確認
- 簡易清掃・簡易除草を実施
- 写真付き報告書を作成・送付
- ふるさと納税の控除を利用すれば、自己負担額は最小2,000円

### 5.4 利用プラットフォーム

- さとふる、ふるさとチョイス、ふるなび等の外部サイト経由

### 5.5 大都市での適用可能性

**課題**:
- 現在の参加自治体は地方都市が中心。大都市（政令指定都市）は熊本市のみ
- 横浜市のような大都市では、ふるさと納税が「流出」側になるため、返礼品としての空き家管理は財政的にネガティブな側面がある
- ただし、市外在住の空き家所有者が横浜市に「ふるさと納税」することで管理サービスを受けるモデルは理論上成立する
- 2025年10月からのポイント付与禁止、2026年10月の地場産品基準厳格化も影響する可能性

- ソース: [ふるさと納税で空き家管理 - 日本空き家サポート](https://xn--w8jvl3b6d9gz83xm5o0mc223e.jp/portal/furusato/)
- ソース: [ふるさと納税で空き家管理 - あわら市](https://www.city.awara.lg.jp/mokuteki/life/jyutaku1/p000000.html)
- ソース: [ふるさと納税返礼品に空き家管理サービス - 朝日町](https://www2.town.asahi.mie.jp/www/contents/1741745187344/index.html)
