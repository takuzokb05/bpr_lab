## 横浜市の既存施策とその効果

### 主要な発見

1. **第3期 横浜市空家等対策計画の概要と目標**
   - 要点: 横浜市は2024年3月に「第3期 横浜市空家等対策計画」を策定した。計画期間は2023年度〜2032年度の10年間（5年ごとに見直し）。「空家化の予防」「空家等の流通・活用促進」「管理不足空家等の防止・解消」の3本柱で総合的な対策を推進している。
   - データ/数字:
     - 計画期間: 2023（令和5）年度〜2032（令和14）年度（10年間）
     - 数値目標: 2028年までに「その他の住宅」を約22,000戸以下に抑制（現状は約19,000戸で目標を下回っている）
     - 3つの柱: (1) 空家化の予防、(2) 空家等の流通・活用促進、(3) 管理不足空家等の防止・解消
   - ソース: [「第3期 横浜市空家等対策計画」を策定しました（横浜市プレスリリース）](https://www.city.yokohama.lg.jp/city-info/koho-kocho/press/kenchiku/2023/0329akiyakeikaku.html)
   - ソース: [第3期 横浜市空家等対策計画（PDF）](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/shiryo/keikaku/housdata.files/0138_20240326.pdf)

2. **特定空家等の認定・措置の実績**
   - 要点: 横浜市は空家法に基づき、周辺に著しい悪影響を及ぼす空家を「特定空家等」として認定し、助言・指導→勧告→命令→行政代執行の段階的措置を実施している。令和6年度末までに累計447件を特定空家等に認定し、その半数以上の241件で改善を確認した。着実な成果を上げている。
   - データ/数字:
     - 令和4年度末: 特定空家等認定 累計356件、改善確認 累計140件
     - 令和6年度末: 特定空家等認定 累計447件、改善確認 累計241件（改善率54%）
     - 措置の段階: 助言・指導 → 勧告 → 命令 → 行政代執行
     - 市への年間相談件数: 約750件（うち約2/3が「雑草や樹木の繁茂」、次いで「建物の破損」）
   - ソース: [横浜市の空家等対策について](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/akiyatoutaisaku.html)
   - ソース: [第20回横浜市空家等対策協議会資料](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/kyogikai.files/0627_20240110.pdf)

3. **管理不全空家（2023年改正法で新設）への対応状況**
   - 要点: 2023年6月の空家法改正（同年12月施行）により「管理不全空家等」の制度が新設された。横浜市は改正に対応し、特定空家等及び管理不全空家等の認定基準を令和6年10月に改正した。なお、従前から使用していた「管理不全な空家」を「管理不足空家等」と改称し、法律上の「管理不全空家等」と用語を使い分けている。空家等管理活用支援法人の指定については、方針策定までの間、指定を行わないこととしている。
   - データ/数字:
     - 認定基準改正: 令和6年10月
     - 管理不全空家等: 放置すれば特定空家等に該当するおそれのある空家。指導・勧告が可能
     - 勧告を受けると固定資産税の住宅用地特例（1/6減額）が解除される
     - 支援法人制度: 横浜市は現時点で指定を行わない方針
   - ソース: [横浜市の空家等対策について](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/akiyatoutaisaku.html)
   - ソース: [特定空家等の認定基準（横浜市）](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/shiryo/keikaku/housdata.files/0131_20210520.pdf)
   - ソース: [空家対策特別措置法の改正内容解説](https://www.zennichi.or.jp/column/202312-akiya-kaiseiho/)

4. **補助金・助成制度**
   - 要点: 横浜市は空き家の解体・活用双方を支援する補助制度を整備している。主な制度は (a) 住宅除却補助（耐震性不足の木造住宅の解体費用補助）、(b) 空家の改修等補助金・地域貢献型（子育て支援施設・コワーキングスペース等への改修費補助）である。ただし、補助金額の上限は比較的控えめであり、市の方針として「事業者への直接補助より自走可能な枠組み」を重視している。
   - データ/数字:
     - **住宅除却補助**: 補助額は以下の最も低い額: (1) 20万円（課税世帯）or 40万円（非課税世帯）、(2) 延べ面積(m2) x 13,500円/m2 x 1/3、(3) 解体工事費の1/3。対象は平成12年5月末以前着工の耐震性不足の木造住宅
     - **空家の改修等補助金（地域貢献型）**: 補助対象経費の1/2（上限100万円）。対象は自治会、NPO、事業者による地域活性化施設（子育て支援、高齢者支援、コワーキングスペース等）への改修
     - **脱炭素リノベ住宅推進補助**: 既存住宅の断熱改修（断熱等性能等級6または7を達成）への補助。子育て世代住替え型は最大150万円、定住型は最大120万円。再生可能エネルギー設備（太陽光3kW以上等）の設置が要件。令和7年度は申請受付終了（令和8年1月31日締切）。先進的窓リノベ2025事業等との併用で合計最大約496万円。令和8年度も継続実施見込み。申請件数等の実績は未公開。（出典: [横浜市公式](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/katsuyou.html)）
   - ソース: [住宅除却補助制度（横浜市）](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/bosai/taishin/hojokinshienseido/mokutai/jyuutakujyokyaku.html)
   - ソース: [空家の改修等補助金（地域貢献型）](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/akiyatiikikoken.html)
   - ソース: [空家の活用・改善等で利用できる各種支援制度等の一覧](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/akiyashienseido.html)
   - ソース: [空家を手放したい方へ（解体・売却に利用できる補助制度の紹介など）](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/kaitai.html)

5. **相談窓口・マッチング支援**
   - 要点: 横浜市は多層的な相談・支援体制を構築している。特筆すべきは (a) 政令市初の生成AI活用サービス「YobCon空家予防コンシェル」（LINE公式アカウント）、(b) ワンストップ伴走支援型の「空家のこれから相談窓口」（2025年2月開始）、(c) 空家活用マッチング制度、(d) 「すまいの終活ナビ」（AI解体費用・土地売却価格シミュレーション、全国初）の4つの柱である。
   - データ/数字:
     - **YobCon 空家予防コンシェル**: LINEで無料利用可能な3つのコンテンツ: (1) 実家の空家化リスク診断、(2) 実家の相続TODOナビ、(3) 空家予防AIチャット診断。**2026年2月13日に実証実験を開始**（政令市初の生成AI活用空き家予防サービス）。横浜市とSocioFuture株式会社の連携協定に基づく。主ターゲットは「実家を相続予定の子世代」。利用実績データは2026年3月時点で未公開。（出典: [横浜市プレスリリース](https://www.city.yokohama.lg.jp/city-info/koho-kocho/press/kenchiku/2025/0213akiya.html)）
     - **空家のこれから相談窓口**: 専門相談員がワンストップで相談〜業者紹介〜マッチングまで伴走支援（無料）。**2026年3月17日開設予定**。空き家活用株式会社が運営、建築局住宅部住宅政策課が共催。協定期間は令和7年12月下旬〜令和10年3月31日（約2年3ヶ月）。キックオフイベントは2026年3月17日13:00〜、横浜市開港記念会館にて開催（先着300名）。（出典: [横浜市公式](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/akiyaonestop.html)）
     - **空家活用マッチング制度**: 空家所有者と地域活動拠点を探す団体・事業者の橋渡し。国土交通省「人生100年を支える住まい環境整備モデル事業」にも選定
     - **すまいの終活ナビ**: 株式会社クラッソーネとの連携協定に基づくAI査定ツール。解体費用と土地売却価格の概算を同時に無料で算出（全国初導入）
     - **専門相談員派遣事業**: 宅地建物取引士・建築士等を無料で派遣し、賃貸借契約・改修・事業計画作成等を支援
     - **空家等管理代行事業者リスト**: 遠方居住の所有者向けに管理代行事業者をリスト化して公開
     - **シルバー人材センター**: 横浜市と協定を締結し、空家管理サービス（不法投棄確認、破損確認、庭木雑草確認等）を提供
   - ソース: [空家予防コンシェル「YobCon」について（横浜市プレスリリース資料）](https://www.city.yokohama.lg.jp/city-info/koho-kocho/press/kenchiku/2025/0213akiya.files/20260213.pdf)
   - ソース: [空家の課題解決につながる2つの新サービスを開始します](https://www.city.yokohama.lg.jp/city-info/koho-kocho/press/kenchiku/2025/0213akiya.html)

6. **横浜市空家等に係る適切な管理、措置等に関する条例（空家条例）**
   - 要点: 横浜市は令和3年3月5日に独自の空家条例を制定し、同年8月1日に施行した。空家法では努力義務にとどまっていた「空家の適切な管理」を条例で義務化したのが最大の特徴である。また、特定空家等に起因する危険への対応として、空家法よりも早い段階（勧告段階）で標識設置が可能であり、緊急時には市長が応急的危険回避措置を講じることができる。
   - データ/数字:
     - 制定: 令和3年3月5日、施行: 令和3年8月1日
     - 主な内容: (1) 空家の適切な管理を義務化（空家法では努力義務）、(2) 勧告段階での標識設置（空家法よりも早い段階）、(3) 所有者不明の場合等の応急的危険回避措置、(4) 市長による緊急時の必要最小限措置
   - ソース: [横浜市空家等に係る適切な管理、措置等に関する条例（条例全文）](https://cgi.city.yokohama.lg.jp/somu/reiki/reiki_honbun/g202RG00002019.html)
   - ソース: [横浜の空き家は横浜市条例で管理が義務化！特定空家の罰則](https://junxion.co.jp/rules/)
   - ソース: [横浜市の空家等対策について](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/sien/akiya/akiyatoutaisaku.html)

7. **「横浜モデル」の特徴: 共創と住宅の連鎖（チェーン）**
   - 要点: 横浜市の空き家対策は「所有者に寄り添い、共創で挑む」姿勢が特徴的である。資産価値が比較的高い横浜市内では「空き家活用はビジネスとして成立し得る」との認識のもと、市から事業者への直接的な補助は最小限にとどめ、「事業者が自走できる持続可能な枠組み」を重視している。また、空き家の解体→新築→中古流通という「住宅の連鎖（チェーン）」を循環させることで、住宅ストック全体の新陳代謝を促す考え方を採用している。
   - データ/数字:
     - 推計19,000戸の一戸建て空き家（「その他の住宅」）
     - 高齢者のみ世帯の一戸建居住が増加中 → 今後5〜10年で団塊世代の相続が急増し、昭和40〜50年代開発の郊外戸建て住宅団地で空き家大量発生のリスク
     - 市の方針: 事業者への直接補助より自走可能な枠組みの構築を重視
   - ソース: [『住宅の連鎖(チェーン)』を回していく 自治体"空き家対策最前線" vol.2 横浜市](https://www.atpress.ne.jp/news/3039700)
   - ソース: [第3期 横浜市空家等対策計画](https://www.city.yokohama.lg.jp/kurashi/sumai-kurashi/jutaku/shiryo/keikaku/housdata.files/0138_20240326.pdf)

8. **検討中の新施策: 空き家の定期借家×子育て専用市営住宅化**
   - 要点: 横浜市建築局の寺口氏は「現在、空家を市で定期借家にて借り上げて、子育て専用の市営住宅にするという検討を進めています」と明言（2026年2月のチャットログ）。既存の借上型市営住宅制度（民間の新築マンションを一棟借上げ）を戸建空き家に展開する構想である。
   - 検討の背景:
     - 横浜市では子育て世代が住宅購入時に、不動産価格が比較的低廉な周辺市町村に流出超過している傾向がある（寺口氏証言）
     - 定期借家契約により所有者は期間満了後に物件を取り戻せるため、「手放す恐怖」を軽減できる
     - 市が借り手となることで所有者の信頼を確保
   - 課題: 「貸していただける物件がどのくらいあるのか心配」（寺口氏）。供給側の確保が最大の不確実性。管理不全空家では「借地権がネックになって進まない案件もある」（寺口氏）。
   - 関連提案: 笠羽氏は「定期借家権とセットで間取りや設備の改修費を（子育て世代に）補助する」民民契約モデルも提案。改修費補助＋最低居住年数縛り＋補助金返還条項の組み合わせで悪意ある契約を排除可能と指摘。
   - 注: 本施策は検討段階であり、正式な政策決定・予算化はなされていない。

### 施策の効果と課題の総合評価

#### 効果が出ている領域
- **特定空家等への対応**: 累計447件認定、241件改善（改善率54%）は着実な成果
- **「その他の住宅」の抑制**: 目標22,000戸以下に対し、現状約19,000戸と目標を前倒しで達成
- **空き家総数の減少**: 2018年の178,300戸から2023年の168,600戸へ約5.4%減少
- **DX推進**: YobCon（生成AI）、すまいの終活ナビ（AIシミュレーション）など先進的なテクノロジー活用

#### 課題が残る領域
- **地域活用マッチングの件数**: 伸び悩んでおり、住宅としての再利用や移住促進への展開が必要
- **補助金額の水準**: 解体補助の上限が20〜40万円、改修補助が上限100万円と比較的控えめ。実際の解体費用（数百万円規模）との乖離が大きい
- **支援法人制度の未活用**: 2023年改正法で新設された空家等管理活用支援法人の指定を行っておらず、民間との連携強化の余地がある
- **将来リスクへの備え**: 団塊世代の相続に伴う空き家急増リスクに対し、予防的施策（YobCon等）の効果検証はこれから
- **定量的な効果測定の公開**: 各施策の利用件数、費用対効果などの詳細な実績データの公開が限定的
