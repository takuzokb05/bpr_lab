# アイコンファイルについて

この拡張機能にはアイコンが必要です。

以下のサイズのPNG画像を用意してください：
- icon16.png (16x16px)
- icon48.png (48x48px)
- icon128.png (128x128px)

## 推奨デザイン

- 📸 カメラアイコン + 📚 本のアイコンを組み合わせたデザイン
- 背景色: グラデーション（#667eea → #764ba2）
- アイコンカラー: 白

## 一時的な対処

アイコンがない場合、拡張機能は動作しますが、デフォルトのアイコンが表示されます。

## アイコン生成ツール

以下のツールで簡単に生成できます：
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/
