# 🚀 Kindle Auto-Capture - クイックスタートガイド

## 📋 事前準備

1. **Kindle for PCを起動**
2. **撮影したい本を開く**
3. **ウィンドウを見やすい位置に配置**

## ▶️ 実行方法

```powershell
python main.py
```

## 📖 初回セットアップ（2ステップ）

### ステップ1: 撮影範囲の指定
- 黒い半透明のオーバーレイが表示されます
- **本文エリアをマウスでドラッグして選択**
- 確認ダイアログで「はい」をクリック

### ステップ2: クリック位置の指定
- 再度オーバーレイが表示されます
- **「次へ」ボタン（またはページ右端）を1回クリック**
- 確認ダイアログで「はい」をクリック

### テスト実行
- 自動的に1ページだけめくってスクリーンショットを表示
- 撮影範囲が正しいか確認
- ウィンドウを閉じる
- 「このまま続行しますか？」で「はい」をクリック

## 🎬 自動撮影開始

- 撮影が自動的に開始されます
- コンソールに進捗が表示されます: `📸 ページ 1 を撮影中...`
- **停止したい場合**: Escキーを2秒間長押し

## ✅ 完了

- 最終ページを自動検出して停止
- PDFを自動生成
- `C:\Users\{ユーザー名}\Downloads\Kindle_Export_YYYYMMDD_HHMMSS.pdf` に保存

## 🔄 2回目以降

1. `python main.py` を実行
2. 「前回の設定を使用しますか？」で「はい」を選択
3. テスト実行を確認
4. 自動撮影開始

## ⚠️ 注意事項

- 撮影中は**マウス・キーボードを操作しない**でください
- 画面を**ロックしない**でください
- Kindleウィンドウが**他のウィンドウに隠れない**ようにしてください

## 🛠️ トラブルシューティング

### Kindleウィンドウが見つからない
→ Kindle for PCを起動してから再実行

### 範囲選択がうまくいかない
→ 小さすぎる範囲はエラーになります（最小50x50px）

### ページめくりが動作しない
→ クリック位置を再設定してください（`config.json`を削除して再実行）

### 最終ページで停止しない
→ 画像の類似度が低い可能性があります（ページ番号の変化など）

## 📁 設定のリセット

設定をやり直したい場合:
```powershell
del config.json
python main.py
```
