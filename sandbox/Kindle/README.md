# Kindle Auto-Capture to PDF Tool

Pythonを用いたKindle for PCの自動撮影・PDF変換ツール

## 機能

- ✅ Kindleウィンドウの自動検出とアクティブ化
- ✅ 直感的な範囲指定UI（ドラッグ選択）
- ✅ クリック位置の記憶（次へボタン）
- ✅ 相対座標による設定の再利用
- ✅ テスト実行による事前確認
- ✅ 画像差分検知による最終ページ自動判定
- ✅ Escキー長押しによる緊急停止
- ✅ 自動PDF生成とダウンロードフォルダへの保存

## 必要要件

- Windows 10/11
- Python 3.10以上
- Kindle for PC

## インストール

1. リポジトリをクローンまたはダウンロード

2. 依存パッケージをインストール:
```bash
pip install -r requirements.txt
```

## 使い方

### 初回実行

1. Kindle for PCを起動し、撮影したい本を開く

2. ツールを実行:
```bash
python main.py
```

3. セットアップウィザードに従う:
   - **ステップ1**: 本文エリアをドラッグで選択
   - **ステップ2**: 「次へ」ボタンを1回クリック
   - **テスト実行**: 1ページ撮影のデモを確認
   - **確認**: 「このまま続行しますか？」で「はい」を選択

4. 自動撮影が開始されます
   - 進捗状況がコンソールに表示されます
   - 停止する場合はEscキーを2秒間長押し

5. 完了後、PDFが`C:\Users\{ユーザー名}\Downloads\`に保存されます

### 2回目以降

1. Kindle for PCで本を開く

2. ツールを実行:
```bash
python main.py
```

3. 「前回の設定を使用しますか？」で「はい」を選択

4. テスト実行を確認後、自動撮影が開始されます

## ファイル構成

```
Kindle/
├── main.py              # メインコントローラー
├── window_manager.py    # ウィンドウ管理
├── capture.py           # 撮影ロジック
├── pdf_engine.py        # PDF生成
├── requirements.txt     # 依存パッケージ
└── config.json          # 設定ファイル（自動生成）
```

## 設定ファイル

初回実行後、`config.json`が自動生成されます:

```json
{
  "captureArea": {
    "relativeX": 100,
    "relativeY": 100,
    "width": 800,
    "height": 1000
  },
  "clickPosition": {
    "relativeX": 900,
    "relativeY": 500
  },
  "windowReference": {
    "title": "Kindle for PC",
    "lastX": 0,
    "lastY": 0
  }
}
```

設定をリセットしたい場合は、このファイルを削除してください。

## トラブルシューティング

### Kindleウィンドウが見つからない
- Kindle for PCが起動しているか確認
- ウィンドウタイトルに「Kindle」が含まれているか確認

### 範囲が画面外にはみ出す
- Kindleウィンドウを画面内に収める
- 範囲選択をやり直す

### ページめくりが動作しない
- クリック位置を再設定
- Kindleの「次へ」ボタンの位置を確認

### 最終ページで停止しない
- 画像の類似度閾値が高すぎる可能性
- `capture.py`の`compareImages`の`threshold`を調整（デフォルト0.99）
