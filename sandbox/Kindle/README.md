# Kindle Auto-Capture to PDF Tool

Kindle for PC の本を自動撮影し、OCRテキスト層付きの検索可能PDFに変換するツール。
NotebookLM 等のAIツールへの取り込みを主目的とした個人利用ツールです。

## 特徴（v2）

- ✅ **セットアップ不要**: ウィンドウ検出・撮影範囲・開き方向をすべて自動判定
- ✅ **開き方向の自動判定**: 右開き（縦書き）/ 左開き（横書き）を→/←キーのプローブで判別
- ✅ **キー方式のページめくり**: クリック位置指定が不要（キー非対応本には `--manual-turn`）
- ✅ **描画安定待ち**: 固定待機ではなく描画完了を検知してから撮影
- ✅ **終端の自動検知**: 同一画面が続いたら最終ページと判定（白紙ページ耐性あり）
- ✅ **余白の自動クロップ**: 全ページの本文領域からクロップ範囲を自動計算
- ✅ **OCRテキスト層**: ocrmypdf + Tesseract（jpn+eng）で検索可能PDFを出力
- ✅ **JPEG(q80)で埋め込み**: NotebookLM等の「1ソース200MB」上限に収めるためPDFを約半分に圧縮
- ✅ **書名の自動命名**: `{書名}_{日時}.pdf` としてダウンロードフォルダに保存
  - ウィンドウタイトルに書名が無い場合（新Store版Kindle）は、ページ上部のヘッダーをOCRして補完
- ✅ **連続モード**: 1冊終わったら次の本を開いてEnterするだけ（まとめ買い対応）
- ✅ **緊急停止**: Escキー2秒長押し（途中分の保存可否を選択可能）
- ✅ **失敗時の保全**: エラー時は撮影済み画像を削除せず一時フォルダに残す

## 必要要件

- Windows 10/11
- Python 3.10以上
- Kindle for PC
- （OCR利用時）Tesseract OCR: `winget install UB-Mannheim.TesseractOCR`
  - winget導入では日本語データ（jpn）が同梱されます。Ghostscriptは不要です

## インストール

```powershell
pip install -r requirements.txt
python test_basic.py   # 導入確認
```

## 使い方

1. Kindle for PC で撮影したい本を開き、**1ページ目**を表示する
2. ツールを実行:

```powershell
python main.py
```

3. コンソールで Enter を押すと、開き方向の判定 → 自動撮影 → クロップ → OCR → PDF保存まで自動で進みます
4. 完了後、`C:\Users\{ユーザー名}\Downloads\{書名}_{日時}.pdf` に保存されます
5. 次の本を撮る場合は、Kindleで次の本を1ページ目で開いて Enter（qで終了）

### オプション

| オプション | 用途 |
|---|---|
| `--manual-turn` | 矢印キーでめくれない本向け。クリック位置を指定してクリックでめくる |
| `--manual-area` | 自動クロップを使わず、撮影範囲をドラッグで手動指定する |
| `--no-ocr` | OCRをスキップして画像のみのPDFを出力する |

## ファイル構成

```
Kindle/
├── main.py              # メインコントローラー（連続モード・緊急停止）
├── window_manager.py    # ウィンドウ検出（プロセス名判定）・クライアント領域取得
├── capture.py           # 開き方向プローブ・撮影ループ・終端検知・手動フォールバックUI
├── postprocess.py       # 余白の自動クロップ（全ページ和集合bbox）
├── ocr.py               # ocrmypdfによるテキスト層付与・環境チェック
├── pdf_engine.py        # PDF結合・書名サニタイズ・保存先決定
├── tests/               # pytestスイート（ロジック検証）
├── test_basic.py        # 導入確認スモーク（import可否のみ）
├── requirements.txt     # 実行時依存
└── requirements-dev.txt # 開発用依存（pytest / ruff / mypy）
```

## トラブルシューティング

### Kindleウィンドウが見つからない
- Kindle for PC が起動しているか確認（プロセス名 kindle.exe で検出します）

### 「矢印キーでページが変化しませんでした」と出る
- 固定レイアウト本などキー操作非対応の本の可能性 → `--manual-turn` で再実行
- Kindleウィンドウにフォーカスが当たっているか確認

### 1ページ目から撮影されていない
- 撮影開始前に本を**1ページ目**にしてから Enter を押してください（開き方向判定は1ページ目前提です）

### OCRが「利用不可」と表示される
- 起動時に表示される導入手順に従って Tesseract をインストールしてください
- インストール後はターミナルを開き直して PATH を反映させてください

### 最終ページで停止しない / 途中で止まる
- 終端判定は「同一画面が4枚連続」です。描画が極端に遅い環境では `capture.py` の `waitForStablePage` のタイムアウトを延ばしてください

### 書名がファイル名にならない / 変な書名になる

- 新しいMicrosoft Store版Kindleはウィンドウタイトルが常に `Kindle` で書名を含みません。本ツールは本文ページ上部の書名ヘッダーをOCRして補完します
- ヘッダーが無い本では自動取得に失敗し、コンソールで書名の入力を求めます（空Enterで `Kindle_Export_{日時}.pdf`）
- 誤読を書名にしないため、複数ページで同じ文字列が読めたときだけ自動採用します

## 既知の制約

- **プライマリモニタ限定**: 撮影はメインモニタ上でのみ可能です（範囲外はエラーで停止します）。Kindleウィンドウをメインモニタ内に収めてください
- **撮影中のウィンドウ移動・リサイズ不可**: 撮影範囲は開始時に固定されます。撮影中はKindleウィンドウを動かさないでください
- **緊急停止のEscはKindleにも届きます**: 長押し中のEscで本が閉じてライブラリ画面が写り込む可能性があります。停止後は途中分の保存可否を確認するので、不要なら破棄してください
- **OCR実行中はEscで中断できません**: 停止が効くのは撮影ループ中のみです
- **JPEG化により小さい文字のOCR精度がわずかに落ちます**: 本文への影響はありませんが、ページ番号表示のような極小文字の読み取り成功率が実測で 145/174 → 132/174 に低下します。画質を優先する場合は `pdf_engine.py` の `JPEG_QUALITY` を上げるか `None`（PNGのまま）にしてください
