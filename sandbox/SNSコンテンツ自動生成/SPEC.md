# SNSコンテンツ自動生成 — 実装仕様書

> Phase A（技術調査）完了後に詳細化する。現時点では機能概要のみ記載。

## 1. 概要

- 目的: 自分のSNS発信を効率化する下書き生成ツール
- 対象ユーザー: 自分（個人利用）
- 主要な価値: 文体一貫性 + 最新情報 + エンゲージメント最適化

## 2. 機能一覧

| ID | 機能名 | 説明 | 優先度 | 依存 |
|----|--------|------|--------|------|
| F1 | CLI基盤 | コマンド体系・設定管理・API接続 | Must | - |
| F2 | ツイート履歴取得 | X API で自分のツイート + エンゲージメントを取得・DB保存 | Must | F1 |
| F3 | 文体分析 | 過去のツイート/Noteから文体特徴を抽出 | Must | F2 |
| F4 | 最新情報収集 | AI関連ニュース・リリース情報の自動収集 | Should | F1 |
| F5 | ツイート生成 | Grok API でツイート下書きを生成 | Must | F3 |
| F6 | Note記事生成 | Gemini API でNote記事下書きを生成 | Must | F3 |
| F7 | 出力・プレビュー | 生成物の表示・ファイル出力 | Should | F5, F6 |
