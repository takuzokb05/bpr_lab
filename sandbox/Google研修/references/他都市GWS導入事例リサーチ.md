## 1. 札幌市（政令指定都市初の全庁導入）

| 項目 | 内容 |
|------|------|
| 規模 | **16,000ユーザー**（全庁） |
| 導入時期 | 2025年5月 |
| 特徴 | 政令指定都市として初のGWS全庁導入 |

### 主な取り組み
- **Chat推奨文化**: メールではなくGoogle Chatを庁内コミュニケーションの主軸に据えた
- **共同編集の定着**: ファイルはDrive上に置き、全員で同時編集する文化を推進
- **Gemini活用**: 業務マニュアルの整理・要約、新規マニュアル作成での活用を推進。業務標準化・引継ぎ効率化に期待

### 横浜市への示唆
- 同じ政令指定都市として最も参考になる事例。規模感（16,000人）も横浜に近い水準
- 「メール→Chat」の文化変革が重要ポイント
- マニュアル整備へのGemini活用は即座に横展開可能

> 出典: [Google Workspace ブログ - 札幌市](https://workspace.google.com/blog/ja/customer-stories/sapporo-google-workspace-deployment?hl=ja) / [IT Leaders](https://it.impress.co.jp/articles/-/28027)

## 2. 秋田県（都道府県初の全庁導入）

| 項目 | 内容 |
|------|------|
| 規模 | **5,000 ID**（全庁） |
| 導入時期 | 2025年4月 |
| 事業費 | 約2億2,430万円 |
| 特徴 | 都道府県として全国初のGWS全庁導入 |

### 主な成果
- **会議録作成**: 30分以上 → **5分以下**に短縮
- **Gemini活用**: 週あたり **105分の時間削減** を実現
- **Web会議**: 県庁〜出先機関間の移動時間を大幅削減
- **部署連携**: 横串でのコラボレーションが活性化

### 導入のポイント
- 人口減少トップの県として「持続可能な行政運営」を大義名分に導入を推進
- Geminiがライセンスに標準搭載されたことで、追加コストなく全職員がAIを利用可能
- ソフトバンク・Googleとの3者連携協定を締結

### 横浜市への示唆
- 「会議録30分→5分」は極めて分かりやすいKPIで、庁内説得力がある
- 「全員が使ってこそ効率化」という方針（トップダウン + 全庁展開の重要性）

> 出典: [ジチタイワークスWEB](https://jichitai.works/articles/3352) / [ソフトバンク導入事例](https://www.softbank.jp/biz/customer-success-stories/202507/akita/) / [秋田魁新報](https://www.sakigake.jp/news/article/20260126AK0012/)

## 3. 京都府舞鶴市（「日本一働きやすい市役所」）

| 項目 | 内容 |
|------|------|
| 規模 | **約1,100人**（正職員+会計年度職員） |
| 導入時期 | 2024年9月〜（Chromebook配布は2025年2月〜） |
| 特徴 | Chromebook 950台 + GWS + Gemini のフルGoogle環境 |

### 主な取り組み
- **Chromebook全面移行**: Windows PCからChromebookへ完全移行し、端末コスト・管理コストを削減
- **Gemini利用率**: 導入1ヶ月で **約半数の職員** が利用（当初反対していた職員も活用）
- **NotebookLM活用**: 庁内FAQを読み込ませ、**わずか2時間**でチャットボットのプロトタイプを構築
- **Meet文字起こし**: 日本語自動文字起こし＋話者識別で議事録作成を効率化

### 横浜市への示唆
- NotebookLMによる庁内FAQチャットボットは低コスト・短期間で実現可能な即効事例
- 「反対派の職員も使うようになった」→実際に便利さを体験させることが最大の説得材料
- 小規模自治体でも先進的な取り組みが可能（「日本一」というビジョンの力）

> 出典: [Google Workspace ブログ - 舞鶴市](https://workspace.google.com/blog/ja/public-sector/maizuru-city-the-best-city-hall-in-japan-to-work-for?hl=ja) / [舞鶴市デジタル推進課 note](https://note.com/maizuru_digital/n/nb15e1a22beb8) / [レバテックラボ](https://levtech.jp/media/article/focus/detail_713/)

## まとめ: 横浜市が参考にすべきポイント

### すぐに使える数字（研修成果報告・上申用）
| 自治体 | 効果 |
|--------|------|
| 秋田県 | 会議録作成 30分→5分、Geminiで週105分削減 |
| 下呂市 | 会議資料〜議事録 9時間→50分 |
| 舞鶴市 | NotebookLMで庁内FAQ bot を2時間で構築 |
| 北区 | AIサイト内検索を2週間で開発 |

### 3つの重要成功要因
1. **トップダウンの文化変革**: メール→Chat、紙→共同編集（札幌市・秋田県）
2. **Geminiの全員利用**: ライセンスに標準搭載＝追加コスト不要が導入の追い風（秋田県）
3. **小さく始めて広げる**: NotebookLMでbot構築（舞鶴市）やPoC 2週間（北区）のように、短期間で成果を出す

### 横浜市で即座に試せそうな施策
1. **Gemini × 議事録作成**: Meet文字起こし＋Gemini要約（効果実証が最も容易）
2. **NotebookLM × 庁内FAQ**: 規定集・マニュアルを読み込ませてQAボット化
3. **AI サイト内検索PoC**: 横浜市HPの情報量を活かしたVertex AI活用
4. **ごみ分別AIガイド**: 市民向けサービスのAI活用として分かりやすい事例
