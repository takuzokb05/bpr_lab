# 横浜市 公示送達 掲載ページ URL 存在確認

18区 × 3制度（国保 / 介護 / 後期）の計54URLについて、公示送達の子ページが存在するかを実地に確認した記録。

- 実施日: 2026-08-24
- 成果物: `横浜市_公示送達URL一覧_確認済み_20260824.xlsx`（元ファイルの列構成・シート構成・書式はそのまま、C列「状態」とD列「備考」のみ追記）

## 判定方法（キャリブレーション結果）

存在が確実な中区「後期」と、同階層で末尾を存在しない文字列に変えたURLの2本を先に叩いて挙動を比較した。

| | 存在するページ | 存在しないページ |
|---|---|---|
| HTTPステータス | 200 | **404** |
| title | `公示送達　横浜市中区` | `お探しのページは見つかりませんでした　横浜市` |
| 本文中の「公示送達」 | 6件 | 0件 |

**横浜市CMSはハード404を返す**ため、ステータスコードだけで判定して差し支えない。ただし将来的なソフト404に備え、本スクリプトは以下の複合条件で判定している。

- **あり**: HTTP 200 かつ title がエラーページでない かつ 本文に「公示送達」を含む
- **なし**: HTTP 404、または HTTP 200 でも本文がエラーページ（ソフト404）

「あり」判定の全件で title が `公示送達　横浜市{区名}` となっており、意図しない別ページへの着地はなかった。

## 取得条件

- リダイレクトは追跡（全件で末尾スラッシュ付与の301が1回のみ発生。存在しないページでも同様に発生してから404を返す）
- リクエスト間に1秒スリープ
- 取得失敗時は最大2回リトライ

## 集計

| 制度 | あり | なし |
|---|---:|---:|
| 国保 | 18 | 0 |
| 介護 | 11 | 7 |
| 後期 | 2 | 16 |

「なし」の区
- 介護（7）: 西区・南区・青葉区・戸塚区・栄区・泉区・瀬谷区
- 後期（16）: 中区・港南区を除く全区

- `write.py` — `results.json` を元に判定してxlsxのC/D列を埋める
- `results.json` — 取得の生ログ
