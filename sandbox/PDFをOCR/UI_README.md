# Gemini OCR Studio - Web UI

stitch.zipのデザインを完全に再現したHTML+WebSocketベースのOCR処理UIです。

## 🎨 デザイン特徴

stitch.zipのHTMLデザインを忠実に再現:
- **左サイドバー**: ページファイルリスト (サムネイル、処理状態表示)
- **メインエリア**: 大きな進捗バー、統計カード、リアルタイムログ
- **下部コントロールバー**: 一時停止、停止、出力ファイルを開くボタン
- **ダークモード**: #0f172a背景、#13a4ecプライマリカラー
- **アニメーション**: 進捗バーのシマー効果、接続ステータスの点滅

## 🚀 起動方法

### 1. サーバーを起動

```powershell
.\start_server.bat
```

または

```powershell
python ocr_server.py
```

### 2. UIを開く

ブラウザで `ocr_ui.html` を開く:

```powershell
start ocr_ui.html
```

## 📖 使い方

### 初回処理

1. コマンドラインでPDFを変換:
   ```powershell
   python main.py --input your_file.pdf
   ```

2. ブラウザでUIを開く
3. 自動的に処理が開始されます

### 再開

1. サーバーを起動
2. UIを開く
3. 自動的に前回の続きから再開されます

### 一時停止・再開

- **OCR一時停止**ボタン: 処理を一時停止 (再度クリックで再開)
- **処理を完全に停止**ボタン: 処理を終了 (進捗は保存されます)

## 🎯 UI機能

### ヘッダー
- **接続ステータス**: WebSocket接続状態をリアルタイム表示
- **設定・ヘルプボタン**: (将来実装予定)

### サイドバー
- **プロジェクトファイル**: 現在処理中のページファイル一覧
- **ファイルサムネイル**: 各ページの状態 (待機中/処理中)
- **更新ボタン**: ファイルリストを手動更新

### メインエリア

#### 進捗セクション
- **PDFファイル名**: 現在処理中のファイル
- **ジョブステータス**: 待機中/処理中ジョブ/完了
- **進捗バー**: アニメーション付き進捗表示
- **処理済みページ数**: 45/100形式で表示
- **開始時刻・経過時間**: リアルタイム更新

#### 統計カード
1. **現在の章**: 処理中の章情報
2. **ウィンドウサイズ**: バッチサイズと重複設定
3. **前回の末尾テキスト**: 文脈継続のための末尾テキスト

#### リアルタイムログ
- タイムスタンプ付きログ
- レベル別色分け (INFO/SUCCESS/ERROR/WARN)
- 自動スクロール
- モノスペースフォント

### コントロールバー
- **OCR一時停止**: 処理の一時停止/再開
- **output.mdを開く**: 生成されたMarkdownを開く
- **処理を完全に停止**: 処理を終了

## 🔧 技術構成

### フロントエンド
- **HTML + Tailwind CSS**: stitch.zipデザインの完全再現
- **WebSocket Client**: リアルタイム通信
- **Material Symbols**: アイコン

### バックエンド
- **WebSocket Server** (`ocr_server.py`): フロントエンドとOCRコードの橋渡し
- **既存OCRモジュール統合**:
  - `pdf_processor.py`
  - `ocr_engine.py`
  - `state_manager.py`
  - `error_handler.py`

## 🔧 トラブルシューティング

### WebSocket接続エラー

```powershell
pip install websockets
```

### UIが表示されない

ブラウザのコンソールを確認してください。WebSocket接続エラーが表示される場合は、サーバーが起動しているか確認してください。

### 処理が開始されない

1. `progress.json` が存在するか確認
2. `temp_pages/` にページ画像が存在するか確認
3. 最初に `python main.py --input file.pdf` でPDFを変換してください

## 📝 注意事項

- 初回はコマンドラインでPDFを変換する必要があります
- WebSocketサーバーを起動してからUIを開いてください
- 処理中はブラウザを閉じないでください
- 進捗は自動的に `progress.json` に保存されます
