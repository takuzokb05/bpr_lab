# Gemini OCR Studio - Web UI

既存のOCRコマンドラインツールをWebブラウザから操作できるようにするGradioベースのインターフェースです。

## 🎨 機能

### OCR処理
- **PDFアップロード**: ブラウザから直接PDFファイルをアップロード
- **処理設定**: バッチサイズ、重複、モデル選択を GUI で設定
- **リアルタイム進捗**: 処理状況をリアルタイムで確認
- **中断・再開**: 処理を中断して後から再開可能
- **ログ表示**: 詳細なログをリアルタイムで表示

### 結果表示
- **Markdownプレビュー**: 生成されたMarkdownをブラウザで確認
- **ファイルダウンロード**: output.mdを直接ダウンロード

### 管理機能
- **状態確認**: 現在の処理状態を確認
- **クリーンアップ**: 一時ファイルを一括削除

## 🚀 起動方法

### 方法1: バッチファイル (推奨)

```powershell
.\launch_ui.bat
```

### 方法2: 直接実行

```powershell
python ocr_ui.py
```

ブラウザで自動的に http://localhost:7860 が開きます。

## 📖 使い方

### 1. PDFをアップロード

1. **📄 OCR処理タブ**を開く
2. 「PDFファイルをアップロード」からPDFを選択
3. バッチサイズ、重複、モデルを設定
4. **📤 PDFを読み込む**をクリック

### 2. OCR処理を開始

1. **🚀 新規処理開始**をクリック
2. リアルタイムログで進捗を確認
3. 処理完了まで待機

### 3. 結果を確認

1. **📝 結果タブ**を開く
2. **🔄 更新**をクリックしてプレビューを表示
3. output.mdをダウンロード

### 中断・再開

- 処理中に **⛔ 停止**をクリックで中断
- 次回起動時に **▶️ 再開**をクリックで継続

## ⚙️ 設定

### モデル選択

- `gemini-3-flash`: 高速・低コスト (推奨)
- `gemini-3-pro`: 高精度
- `gemini-2.5-flash`: バランス型

### バッチサイズ

- 小さい値 (5-8): メモリ節約、処理時間長い
- 推奨値 (10): バランス
- 大きい値 (15-20): 高速、メモリ使用量大

### 重複ページ数

- 0: 重複なし (高速だが精度低下の可能性)
- 1-2: 推奨 (文脈の連続性を保つ)
- 3以上: 高精度だが処理時間増加

## 🔧 トラブルシューティング

### UIが起動しない

```powershell
pip install gradio
```

### API接続エラー

- `API_KEY.txt` が正しく設定されているか確認
- APIキーが有効か確認

### PDF変換エラー

- Popplerがインストールされているか確認
- `POPPLER_SETUP.md` を参照

### 処理が進まない

- ログを確認してエラーメッセージを確認
- APIクォータが残っているか確認

## 📝 注意事項

- 大きなPDFファイル (100ページ以上) は処理に時間がかかります
- 処理中はブラウザを閉じないでください
- 中断した場合、progress.jsonに状態が保存されます
- API使用には料金が発生する場合があります
